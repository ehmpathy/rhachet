# core

the one rule this role carries, at full length. it is deliberately long: the cap this fixture
declares sits below what this document costs, so a boot that renders it in full is refused.

## .why it is long

a fixture whose breach no trim can close proves only that the halt renders. to prove the halt is
escapable, the payload must be able to shrink below the cap by an act the author can actually
take — and the cheapest such act on the halt's own ladder is a condense.

## .the rule itself

when a role declares a budget, the boot renders its payload only where that payload fits. the cap
is measured against the full emitted payload rather than against the resident documents alone, so
the xml chrome, the ref roster, and both stats blocks each count toward it.

an author who meets the halt has four moves, and the ladder names them cheapest first. the first
two cost the reader naught: catalogize replaces a whole set with one index, and condense leaves a
shorter variant beside the original for the renderer to prefer. the third costs one dereference —
a say entry moves to ref, where its path stays addressable and its body no longer loads. only the
fourth costs the document itself.

## .what the ladder deliberately omits

the halt names no individual resource, ever. the gate measures what each document costs and can
see naught at all of what each document is worth, so a list sorted by cost would advise on the
one quantity uncorrelated with the decision. a brief that runs two thousand tokens may carry the
argument the whole role rests on, and a three-hundred-token one may be dead weight.

the author is the only party who holds both numbers. the gate hands them the arithmetic and the
vocabulary, and leaves the choice where it belongs.

## .the consequence for this fixture

this document exists to be too expensive. a shorter variant of it, written beside it, is what
closes the breach — and the spec above never changes between the two boots.

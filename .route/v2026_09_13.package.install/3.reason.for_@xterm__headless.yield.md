# reason: @xterm/headless@6.0.0

## package
- name: @xterm/headless
- version: 6.0.0
- type: prod

## reason
the daemon reads the clone's rendered screen to classify input state (buffered / enqueued / withheld) and the on-screen turn counts; a pty is a byte stream, so a terminal emulator is required to render the grid before it can be read. @xterm/headless is the vs-code terminal core: zero runtime deps, pure js, no native addon, pinned. see define.pty-stream-vs-screen and the fix-clone-say vision (V5).

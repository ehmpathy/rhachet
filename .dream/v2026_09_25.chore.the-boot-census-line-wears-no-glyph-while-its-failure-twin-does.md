# 🌙 dream: the boot census line wears no glyph, while its failure twin does

- **kind** = chore
- **owner** = `ehmpathy/rhachet` — `src/domain.operations/boot/asBrainDirBootReportLines.ts`
- **caught** = 2026-09-25

## .the cue that fired

review 7 of stone `5.3.verification` (`has-ergonomics-validated`) scored the captured i/o of
`rhx init --hooks` against `def.ergonomic`. the *output is scannable* criterion surfaced an
asymmetry between the two renderers of the same fact.

## .the gap, precisely

the **success** census is a bare `key: value` line with no glyph and no treestruct:

```
boot.md (default): /…/actor.via.slug=.default/brain/.claude/boot.md — 21 roles, 809187 chars
```

its **failure** twin, `asBrainDirBootFailureLines.ts`, carries both a glyph and the treestruct:

```
✗ boot.md (default) not written: 💥 MalfunctionError: brain dir boot.md could not be written
   ├─ brainDir: /repo/x
   └─ cause: Error: EACCES: permission denied
```

so a human who scans for *"did the boot render land?"* looks for a glyph and finds one only on
failure. and because the census is prepended **before** the caller's own mascot/artifact header, the
`rhx init --hooks` render opens with an unglyphed line and then a `🔭` header — the two-header shape
of `howto.write.skills-stdout` is broken at the very first line.

checkable:

```
npx rhx init --hooks | head -2
# line 1: boot.md (default): … — no glyph, no treestruct
# line 2: 🔭 search for linked roles with hooks...
```

⚠️ **the flat shape is not an accident.** the renderer is shared by `init`, `roles link` and
`enroll`, each with its own header, so the census has no parent node to hang a treestruct off. the
gap is the **glyph parity**, not the flat shape.

## .the shape of the fix

   fix is not taken unilaterally (`F42` in the route's fulcrum inventory)

3. update the four pinned sites: `asBrainDirBootReportLines.test.ts:25` (`toEqual` on the full
   string) and `:47`, plus `invokeInit.integration.test.ts:621` and
   `invokeRolesLink.integration.test.ts:357` (both `startsWith('boot.md (default): ')`)
4. re-run the boot units, `invokeInit.integration`, `invokeRolesLink.integration`, and the journey
   snapshots that mask this span (`maskBootCensusVolatiles`)

## .why it is not done in this round

- **SAFE?** ✅ yes — it changes one rendered string
- **CLEAN?** 🔴 no — it changes a **pinned output contract** across 3 callers and 4+ assertion sites
  mid-verification-stone, and it needs a **glyph choice** that is the wisher's to make. per
  `rule.forbid.overzealous-blockers`' harm test, no shipped harm can be named: the line is legible,
  first, and names its file, scope, role count and char count

## .the cue that fired

the 2026-09-06 reversal split the breadcrumb into a treestruct — a ROOT that confirms
(`😶 clone enrolled`) and a BRANCH that discloses the reach
(`   └─ 🔌 reachable at: rhx clone say @:<address> --what "…"`).

the split is what made the defect legible. as one line the claim was fused, so an eye slid
over it. as two rows the branch states a **capability**, on its own line, in its own words —
and that capability is not always present.

## .the gap, precisely

`invokeEnroll` gates the emit on `mode === 'tree'` alone. it does **not** consult
`result.clone.socketEligible`, which sits in scope two statements above and is already
projected into the json twin.

so an enroll whose clone stood up **DEAF** still prints `reachable at: rhx clone say …`.

⚠️ **our own snapshots demonstrate it, in one suite, at one case.** in
`enroll.acceptance.test.ts` `[case2b]`:

| the twin | what it holds |
|---|---|
| `[t1]` json | `{"outcome":"baked","serial":"…","slug":null,"socketEligible":false}` |
| `[t0]` tree | `😶 clone enrolled` + `   └─ 🔌 reachable at: rhx clone say @:… --what "…"` |

**the two channels disagree about the same clone.** the machine is told the socket is
absent; the human is told where to reach it.

and `enroll.reach.acceptance.test.ts` `[case3]` already clamps what happens next: a `say` to
a DEAF clone is *"refused loud."* so the branch names a command this repo holds a test
against — a test that asserts the refusal.

## ⚠️ .the bound — this is NOT a claim that the line is wrong in a terminal

`isCloneSocketEligible` gates on `socketCapable && interactive && !noSocket`. in a real human
terminal `interactive` is true, so the socket stands up and the branch is accurate. the
divergence appears where the enroll is **piped** — a cron, a dispatch handler, a test harness,
a supervisor — which is also the case least likely to have a human at the screen.

⇒ the overclaim is real and it is **narrower** than it first reads. worth stated plainly, so
a later reader does not size the repair against the wrong population.

## .the shape of the fix

**do NOT suppress the whole breadcrumb.** the wisher's 2026-09-06 verdict is that a successful
enroll owes one rhachet-authored line of CONFIRMATION, and a named enroll that emitted none
was the defect that verdict retired. to gate the root on the socket would re-open it.

the treestruct already separates the two jobs, so the repair swaps only the BRANCH:

| the clone is | the root | the branch |
|---|---|---|
| socket-eligible | `😶 clone enrolled` | `   └─ 🔌 reachable at: rhx clone say @:<address> --what "…"` |
| **DEAF** | `😶 clone enrolled` | `   └─ 🔇 deaf — no socket stood up; observe it with \`rhx clone get @:<address>\`` |

`rhx clone get` is the right second cure: `[case3][t1]` already clamps that
*"`clone get` still observes it — DEAF is observe-only, not dead."*

the seam is one input: `asCloneReachBreadcrumb({ address, reachable })`. its unit file already
locks the exact text of both rows, so the DEAF variant lands as a second `given` beside the
extant three.

⚠️ the glyph is a **choice**, not a settled term — `🔇` is a guess. check
`domain.glyphs/catalog.of=glyph._.md` before it is claimed, per
`im_an.obsessive_learner.for.domain.glyphs`: a grep proves a glyph unused, never unclaimed.

🚨 **and the defect predates this branch.** the old one-line form emitted on the same
un-gated condition, so no regression is shipped by the deferral — only an inaccuracy that is
now easier to see, which is the treestruct at work.

## 🚨 the close — measured 2026-09-07

**the deferral above was reversed inside the same behavior**, because the `r010` peer lane
raised the identical defect as a blocker at i075 and a blocker is not a thing to defer. all
three seams are shut, and each is quoted from the file that owns it rather than asserted:

### 1. the value learned the deaf render

`asCloneReachBreadcrumb` takes a **required** `reachable: boolean` — required rather than
defaulted, so an omission is a compile error rather than a reachable render for a deaf clone:

```ts
  if (!input.reachable)
    return [
      '😶 clone enrolled — deaf, so it cannot hear a `say`',
      `   └─ 🎧 rhx clone get ${address} --tail 50`,
    ].join('\n');
```

### 2. the invoker passes the real flag

`invokeEnroll`'s tree-mode emit reads the same field the json twin reports:

```ts
      asCloneReachBreadcrumb({
        slug,
        serial,
        // 🚨 the breadcrumb reads the SAME flag the json handoff reports above, so the two
        //   renders of one enroll cannot disagree about whether the clone can hear
        reachable: result.clone.socketEligible,
      }),
```

### 3. a real enroll's real stderr is clamped

`enroll.reach.acceptance.test.ts` `[case3]` gained the row that reads the enroll itself —
`then('the ENROLL ITSELF never promised a say it cannot honor', …)` — which asserts the
confirmation stays, the `say` is absent, the cause is named, and the `get` remains.

⚠️ **seam 3 is the one that could not be skipped**, and its docblock says why: the unit clamp
proves the VALUE is right for a `reachable: false` input, and *"cannot prove the INVOKER passes
that input — a hardcoded `reachable: true` at the call site would leave every unit row green."*

### what the landed shape does DIFFERENTLY from the plan above

| the plan proposed | what shipped | why |
|---|---|---|
| a `🔇` glyph, flagged as an unsettled guess | **no new glyph** — `🎧` on the extant `get` row | the guess was never claimed, so no catalog entry was owed. one fewer coinage |
| the deaf branch carries the cause | the **ROOT** carries the cause | a row that explains an absent row is a row about the output rather than about the clone |
| a second acceptance case | a row inside the **extant** `[case3]` | that case already enrolls a socketless clone, so the fixture cost was already paid |

⇒ the deferral's stated cost — *"a fresh test matrix on a diff already near ~293 files"* — was
real for the shape it costed, and **smaller for the shape that shipped**: no new case, no new
snapshot, no glyph to settle. worth recorded, because the estimate was made against a design
that a review round then improved.

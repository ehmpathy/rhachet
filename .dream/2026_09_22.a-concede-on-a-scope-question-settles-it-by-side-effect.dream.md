## .the gap, precisely

`rule.always.concede-with-a-severity` makes **concede the default** and dispute *"the escalation
(severe or recurs)"*. that is right for a concern about **implementation**. it is wrong for a
concern whose fix is a **contract surface**, and the rule set has no word for that case:

| rule | what it covers | the gap |
|---|---|---|
| `rule.always.concede-with-a-severity` | the HARM axis — `better` vs `urgent` | silent on whether the FIX is mine to make |
| `rule.always.defer-fulcrums-to-last` | a fulcrum I raise mid-drive | silent on a fulcrum a REVIEWER re-opens |
| `rule.always.absorb-every-concern` | that every concern gets a disposition | silent on WHICH disposition a scope question takes |

🔴 **so the driver's whole rule set grades a concern on harm and on count, and never on who owns
the ANSWER.** a reviewer's severity bump reads as new evidence; it is not — the argument was
unchanged between i011 and i013, only the grade moved.

⚠️ **and the pull is toward the wrong answer.** a concede is procedurally cheap, feels responsive,
and needs no record. a dispute needs a fulcrum `--why` and reads as pushback on a reviewer who was,
on the merits of the observation, correct.

concern about an implementation detail stays a concede however much it costs.

## 🔴 .the amendment — 2026-09-23. the rule is NOT owed; it was already booted

**the wisher struck the drafted rule in one question: did the driver's extant fulcrum rules not
already cover this?** they do, and the one that covers it was resident in the booted context for
every round of this stone.

`rule.always.raise-a-blocker-a-taken-cannot-close` carries a **fulcrum-council clause**, and it
says the same in fewer words and with a sharper test:

| the drafted test | 🔴 the extant rule's test |
|---|---|
| *"does the fix add a surface a CALLER can see?"* | *"does an itemized fulcrum already reserve this call?"* |
| a **judgment** — what counts as a surface? a flag? an output field? a file path? | 🔴 **mechanical** — a `Glob` of `.fulcrums/` answers it, with no judgment at all |
| its cue table needs five rows to bound the judgment | one question, and the answer is a file that exists or does not |

⇒ **the drafted test grades the FIX. the extant test grades the RECORD** — and the record is what a
drive can check without a re-litigation of what counts as a surface.

### 🔴 and it names the ACTION the draft omitted

the draft's verdict was *dispute, and cite the fulcrum*. that is one move short:

> the extant rule says **halt, and hand up BOTH the objection and the fulcrum row** — because to
> argue an itemized fulcrum down settles by side effect a question the drive reserved for the
> wisher, and the wisher never learns it was asked twice.

**a dispute keeps the call in the drive's own hands. a halt returns it to the party who owns it.**
that is the whole difference, and the draft had it wrong.

### 🟡 what SURVIVES as owed to the driver tree

the **kernel** is withdrawn. what is still worth a re-seed is the **worked case**, which the extant
rule lacks: a dated instance where the rule was resident, recitable, and not read — the i013
concede, the shipped flag, the settings edit, the three-question strike, and the revert set.

⇒ **residency is not readership**, and a rule whose failure mode is *"nobody read it"* is best
repaired by a worked case rather than by a second rule that would fail the same way.

### 🔴 the lesson this dream now carries

> **the reflex a defect should trigger is a SEARCH, not a DRAFT.**

the drive found a real gap, held the context to name it precisely, and reached for a new rule —
which is the expensive move. the cheap move was a grep of the booted rules for the conduct it was
about to author. ⇒ `S15`, and the second instance of that failure in this route (`S9` was the
first).

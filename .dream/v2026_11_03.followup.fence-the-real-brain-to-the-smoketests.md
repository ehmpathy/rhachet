# 🌙 dream: fence the real brain to the smoketests

kind = followup · owner = rhachet · caught 2026-11-03

## .the cue that fired

the nano route `v2026_11_03.fix-tests-mock-the-claude-cli.nano` moved the six src sdk suites onto
mocks. it holds "only the smoketests call the api" by absence: no src test calls a real brain
(the searches are cited in `inventory.of=requirements.case=10`). naught refuses a new one.

## .the gap, precisely

- a new src integration suite may `genBrainRepl({ slug: 'claude/code/haiku' })` and pass review;
  behind `describeBrainLiveOnDemand` it is silent by default, outside it, it spends credit every run
- the real-tui `*.realbrain` suites each spawn their own haiku session; a credit lapse reddens all
  of them at once, with mechanism cases mixed in
- `enroll.shared-brain-auth` spawns a real claude on fake logins; it bills no api call, but it
  depends on the real cli's refresh path
- `invokeImagineStitcher.integration` and `enweaveOneStitcher.integration` reach openai direct through
  `getContextOpenAI` (no brain seam) behind `given.runIf(!process.env.CI)`: a skip in ci, a real
  call on a crew box. the fence pr decides whether they move onto a mock or onto the smoketest list

## .the shape of the fix

the full plan lives in git history, at commit `4fe875c`, in
`.behavior/v2026_11_01.fix-tests-mock-the-claude-cli/3.3.1.blueprint.product.yield.md`:

- a smoketest registry, and one fence at two doors: the access (`genRealClaudeAccess`) refuses a
  caller off the registry, and a tripwire `claude` shim leads the PATH each jest worker inherits
- a drift check that flags a test file with a real-brain signature off the registry
- the six realbrain suites folded into one shared haiku session with a cascade guard
- the mechanism cases of the realbrain suites and `enroll.shared-brain-auth` moved onto the mock cli
- a failure footer that parts a refused real-brain call from a red mechanism case

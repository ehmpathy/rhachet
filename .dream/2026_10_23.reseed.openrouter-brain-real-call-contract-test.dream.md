## .the cue that fired

a peer reviewer in rhachet flagged `src/.test/defaultPeerReviewerBrain.integration.test.ts`: it reads
`BRAIN_DEFAULT_OF_REVIEW` off the installed package and makes no real call.

## .the gap, precisely

rhachet selects `openrouter/deepseek/flash` as the default peer-review brain and never calls it, so
its test proves the selection only. whether that brain answers, and whether its response parses, is
a contract the openrouter package owns — and should prove with a real call
(`rule.require.external-contract-integration-tests`).

## .the shape of the fix

in `rhachet-brains-openrouter`: an integration test that invokes the `BRAIN_DEFAULT_OF_REVIEW` atom
with a one-line prompt and asserts a non-empty response of the declared shape, plus a case that an
absent `OPENROUTER_API_KEY` fails fast with a hint.

it belongs to another repo: rhachet holds no code on the call path. see fulcrum F13 of

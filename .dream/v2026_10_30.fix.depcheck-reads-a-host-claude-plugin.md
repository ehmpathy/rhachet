# 🌙 dream: depcheck must not read the brain dir's claude plugins

kind = fix · owner = rhachet (the `.depcheckrc.yml` practice, declapract-typescript-ehmpathy) · caught 2026-10-30

## .the cue that fired

`rhx git.repo.test --what lint` failed on a crew box with `Missing dependencies · claude-code:
./.claude/plugins/marketplaces/claude-plugins-official/plugins/code-modernization/tests/hostile.test.ts`.

## .the gap, precisely

`<repo>/.claude` links to the repo actor's brain dir. claude code installs marketplace plugins
there, and a plugin ships its own `.ts` files. depcheck walks into the link and reads the plugin's
imports as the repo's own, so lint is red on any box where claude installed a plugin, and green on
a clean ci checkout. the state is host-made; the lint verdict should not depend on it.

## .the shape of the fix

add `.claude` (and `.agent/.actors`) to the `ignores` patterns of `.depcheckrc.yml`, in the
declapract practice that owns the file, so every repo inherits it.

## .why it is not done in this round

the file is practice-owned; a local edit drifts from the practice and is overwritten on the next
upgrade. the fix belongs upstream, beside the practice it changes.

# 🌙 dream: a byhand skill re-measures the real claude tui

kind = followup · owner = rhachet · caught 2026-11-01

## .the cue that fired

`v2026_11_01.fix-tests-mock-the-claude-cli` keeps the realbrain clamps in one shared smoketest
session, but moves the research half of `clone.screen-dogfood.realbrain.acceptance` — its emit of
measured screen grids to a research artifact — out of the jest tiers. the stub's `modal`, `busy`,
`bufferedhold` modes imitate those grids, and with the emit gone, no run re-measures the real tui
when a claude-code bump may have moved it. (the stub's `busy` mode already drifted once: it holds a
queued message out of the transcript, which `clone.transcript-lag` measured false.)

## .the gap, precisely

no on-demand way to ask "how does the real claude tui draw a modal, a queue hint, its input box,
today?" — the knowledge the stub modes imitate goes stale with each pin bump, and only a red
smoketest (which covers reach, not render) would hint at it.

## .the shape of the fix

a skill under `.agent/repo=.this/role=any/skills/`, in the shape of `claude.cli.secstore.trial.sh`
(`howto.entool-a-measurement-as-a-skill`): install a pinned claude via `claude.cli.probe`, boot it
under a pty on haiku, drive the probe prompts the retired suites drove, and print the measured
screen shape (rows, markers, queue hint) beside what each stub mode draws.

## .why it is not done in this round

the wish asks to move tests onto a mock, not to build new tools. the measurement skill is a new
capability with its own contract, and the retirement does not depend on it.

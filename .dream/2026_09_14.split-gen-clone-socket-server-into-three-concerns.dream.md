## .the cue that fired

r011 (enroll-impl-arch-defects) decompose-for-recompose item 2: `genCloneSocketServer.ts` is 532
lines with 14 internal imports — the highest fan-in file in the feature — and bundles three
separable concerns, each independently unit-testable if extracted.

## .the gap, precisely

three concerns share one file, reachable today only through the 1124-line socket integration test:

1. the ~35-line dequeue-write closure (screen read → precheck → bulk write → delayed submit,
   lines ~106-142) — extractable as `computeCloneDequeueWrite` (or a `genCloneDequeueWrite`
   closure factory), unit-testable at the boundary.
2. the ~200-line bind-lifecycle state machine (lines ~300-520) — it carries its own docblock
   essay, a signal it has outgrown "one function in a bigger file"; extractable as
   `genCloneSocketBind`.
3. per-connection frame dispatch — the residual.

## .the shape of the fix

1. extract the dequeue-write closure into its own operation with an inline unit test that feeds a
   stub screen-read + write + submit and asserts the precheck/gate branches directly (today only
   the integration test reaches them).
2. extract the bind-lifecycle state machine into `genCloneSocketBind`, with its docblock essay as
   the file header.
3. leave frame dispatch in `genCloneSocketServer`, now a thin composer of the two.
4. keep the 1124-line socket integration test green throughout (it becomes the composition clamp);
   add the two new unit clamps.

## .why it is not done in this round

it fails the CLEAN test (`rule.always.fix-forward-under-scouts-honor`): a 532-line highest-fan-in
file split into three operations ripples across 14 import sites, the socket integration test, and
the bind lifecycle — a large structural refactor of the feature's central file, exactly the
"massive dirty refactor that deserves its own dedicated pr" the driver directive carves out. the
reviewer graded it a nitpick, not a blocker (the file is correct as-is, only large), so per
`rule.forbid.deferrals-short-of-a-dedicated-pr` it lands as a scoped follow-on PR. the decision to
defer is recorded as fulcrum F21.

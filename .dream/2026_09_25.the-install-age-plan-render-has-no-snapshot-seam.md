# 🌙 dream: a bimodal render has no seam to make it deterministic

- **kind** = repair
- **owner** = `ehmpathy/rhachet`
- **caught** = 2026-09-25

## .the cue that fired

a peer reviewer (`ergo-contract-snapshots`) graded the `install.age` PLAN render a nitpick against
`rule.require.contract-snapshot-exhaustiveness` — it is a surface a caller reads with no snapshot,
and the rule says a non-deterministic output is to be MASKED then snapped, never carved out.

## .the gap, precisely

the render has two shapes, chosen by host state:

| host | render |
|---|---|
| `age` absent | `age: NOT on PATH` + `would run` + the cicd command |
| `age` installed | `✅ already on PATH` + `where:` + a VERSION string |

⇒ a snapshot recorded on either host is red on the other.

## 🔴 .both standard remedies were tried, and both are refuted by measurement

**1. a mask.** a mask neutralizes a volatile FIELD inside one stable shape. here the two modes
differ in shape — different line counts, different glyphs, different sentences — so a mask wide
enough to unify them erases the very text it exists to pin. it would snap a shape, never a render.

**2. a bound PATH**, to force the absent branch on every host. this is the remedy that should have
worked, and the platform refuses it:

```
$ which -a age
/usr/bin/age
/bin/age
```

`age` ships at `/usr/bin/age` on the debian platform cicd provisions
(`.github/workflows/.test.yml:209` installs it via apt). that directory also holds `bash`, `env`,
and the `apt-get` this very plan path probes at `install.age.sh:143`.

⇒ a PATH that hides `age` hides the interpreter with it. **measured:** the child exited **127**
with **empty stdout** — it never reached the skill at all.

## .the shape of the fix

the variance needs a seam, and the skill has none. two candidates, both real design calls:

1. **an injected probe.** let the skill read its presence check from an env var override —
   `AGE_PRESENCE_PROBE=absent` — so a test can pin either branch with no PATH surgery.
   ⚠️ a production seam that exists only for a test needs a declared home; an env var that alters
   a safety surface is a real contract, never a test hook.
2. **a render extraction.** move the two branch renders into a pure transformer that takes
   `{ presence, whereFound, version }` and returns the lines. the transformer is then unit-testable
   on both branches with no host at all, and the acceptance case keeps its invariant assertion.

🟡 **option 2 is the stronger one** — it adds no production seam, makes both branches provable, and
leaves the acceptance tier to prove that the parts connect rather than the text. it is also the
larger change: the skill is a `.sh`, so the extraction implies a `.ts` half it does not yet have.

## .why it is not done in this round

graded against `rule.always.fix-forward-under-scouts-honor`'s two questions, inside a
`5.3.verification` stone:

- **SAFE?** 🔴 no — option 1 moves a safety surface's contract; option 2 restructures the skill
- **CLEAN?** 🔴 no — option 2 adds a `.ts` half to a `.sh` skill, which ripples into the skill
  dispatch and its own acceptance shape

⇒ deferred, and **conceded** rather than disputed on the point itself. the severity is `better`: an
unpinned bimodal render is a review-visibility cost a future engineer pays, never a harm a user or
an on-call engineer suffers. the surface is asserted on its invariant today, so a regression that
breaks the contract — a plan that installs, or a non-zero exit — is still caught loud by `[case1]`.

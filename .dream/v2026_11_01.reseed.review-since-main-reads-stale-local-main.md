# 🌙 dream: `rhx review --diffs since-main` diffs against the stale local `main`, not `origin/main`

- kind = reseed
- owner = ehmpathy/rhachet-roles-bhrain (role=reviewer, skill=review)
- caught 2026-11-01

## .the cue that fired

a peer reviewer on `ehmpathy/rhachet` @ `beav/fix-clone-auth-lookup-timeout` raised a blocker and four
nitpicks on lines 43–525 of `genCloneSocketServer.integration.test.ts`. this branch adds only 71 lines
to that file (`git diff --stat HEAD`). local `main` sat at `c512891a` (v1.47.3); the branch was cut from
`origin/main` `6e26ecac` (v1.50.1).

## .the gap, precisely

`--diffs since-main` reads the local `main` ref as its base. in a worktree setup the local `main` is
rarely fast-forwarded, so the scope swells with every release since the last pull, and reviewers
grade other PRs' code as this one's. this is the stale-ref class the mechanic's
`rule.require.clamp-edge-cases` names in its worked example.

## .the shape of the fix

compute the base as `git merge-base HEAD origin/main` (fetch first, or fall back to local `main` with
a loud warn when no remote ref exists). clamp it: a temp repo with local `main` one commit behind
`origin/main`; assert only the branch's change is in scope.

## .why it is not done in this round

the skill lives in another repo; a local fast-forward of `main` here would touch a ref the main
checkout shares, and would only hide the defect for this one host.

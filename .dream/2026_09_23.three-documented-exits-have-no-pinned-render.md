# 🌙 dream: three documented exits have no pinned render

- **kind** = gap
- **owner** = `ehmpathy/rhachet` — `.agent/repo=.this/role=any/skills/calc.tokens.sh`,
  `.agent/repo=.this/role=any/skills/get.package.format.sh`
- **caught** = 2026-09-23, at `5.1.execution.from_vision` i016 (`ergo-friction-hazards` nitpicks 1–2)

---

## .the cue that fired

a lane read the two measurement skills' `--help` blocks against their acceptance suites and found
the same hole twice:

> the acceptance suite meticulously pins every arg/glob/corpus constraint path … but no case
> provokes a read failure (exit 1) or a vanished-file (exit 2) refusal, so those two documented
> exits have no snapshot a reviewer can vibecheck.

⇒ **the help is a contract, and three of its clauses are unenforced.** the phrase can change and no
clamp reddens.

## .the gap, precisely

| # | the skill | the exit | what `--help` promises |
|---|---|---|---|
| 1 | `calc.tokens` | **2** | *"a matched file that VANISHED between the glob and the read"* |
| 2 | `calc.tokens` | **1** | *"a matched file that cannot be read"* |
| 3 | `get.package.format` | **1** | *"the probe could not run"* |

each is a caller-meets-it surface. each is named in the docblock's `guarantee` block **and** in the
`show_help` render, so each is stated twice and verified nowhere.

🔴 **this repo's own rule is stricter than the rubric that caught it.**
`rule.require.contract-snapshot-exhaustiveness` (behaver) demands *"every output variant a caller
can encounter (positive, negative, edge) must be snapshotted."* so this is arrears against a
declared rule, not a discretionary polish.

## 🔴 .why it is not done in this round — the CLAMP, at all three sites

`rule.require.clamp-edge-cases` demands a regression test that goes **red** under the un-fixed
defect. each site fails that bar for its own reason, and two of the three fail it in the worst way —
the cheap fixture yields a clamp that passes under the defect:

| # | the cheap fixture | why it does not bite |
|---|---|---|
| 1 | a file removed between the glob and the read | 🔴 **a race is not a fixture.** the window is not statically constructible — the identical bar defers `.dream/2026_09_23.the-walk-refuses-a-vanish-at-its-entries-and-swallows-one-at-its-root` |
| 2 | a `chmod 000` file | 🔴 **not portable.** CI often runs as root, where the read SUCCEEDS — so the clamp is green on the host where it matters and red only on a dev box |
| 3 | a package whose `require()` faults for a reason other than esm-only | every cheap candidate lands on exit **0** (it loads) or exit **2** (not installed). the exit-1 arm needs a fault the probe cannot manufacture |

⇒ **SAFE ✅ / CLEAN 🔴.** the skills are shell, so the repair is not risky; what is un-clean is that
a correct clamp needs a seam none of the three has.

## .the shape of the fix

🔴 **one shape, applied at three sites: a fault seam the acceptance suite can drive.**

```bash
# an env-gated fault injection, honored ONLY when the var is set, so the
# production path is byte-identical with it absent
: "${CALC_TOKENS_FAULT:=}"   # '' | 'read' | 'vanish'
```

| the seam | what it makes reachable |
|---|---|
| `CALC_TOKENS_FAULT=vanish` | remove the matched file after the glob, before the read ⇒ exit 2 |
| `CALC_TOKENS_FAULT=read` | force the read to fault ⇒ exit 1 |
| `GET_PACKAGE_FORMAT_FAULT=probe` | force the `require()` probe to fault ⇒ exit 1 |

then one acceptance case per exit, each snapped, each proved by revert: strip the seam's arm and the
case MUST go red.

🟡 **the seam is the debatable half, and the alternative is worth a weigh before it lands.** an
env-gated fault path is a second code path in a production skill, which
`rule.prefer.fewer-paths-via-idempotency` pushes against. the counter is that the three faults are
genuinely un-manufacturable from outside, and a documented exit with no clamp is the larger defect.
⇒ that trade is a fulcrum the round which takes this up owes, not one this dream settles.

## .what to do first, when it is taken up

1. settle the seam-vs-no-clamp fulcrum above — it decides whether the rest is work or a doc edit
2. if the seam lands: one case per exit, each snapped, each proved by revert
3. if it does not: **correct the help** at all three sites rather than leave a contract clause with
   no enforcement behind it — an unenforced promise is worse than an absent one

# 🌙 dream: `rmsafe`'s restore hint must name a command that restores a dir

kind = reseed · owner = ehmpathy/rhachet-roles-ehmpathy (role=mechanic) · caught 2026-11-14

## .the cue that fired

`rhx rmsafe --path '.agent/repo=.mods' --recursive` printed
`you can restore from trash` → `rhx cpsafe .agent/.cache/…/trash/.agent/repo=.mods ./.agent/repo=.mods`.
that exact command failed: `error: source must be a file, not a directory`.

## .the gap, precisely

`rmsafe` trashes a dir, then prints a `cpsafe` restore that `cpsafe` refuses for a dir. a documented
recovery path that fails on its first run, at the moment a human most needs it.

## .the shape of the fix

either `cpsafe` accepts a dir source (recursive copy, still bounded to the repo), or `rmsafe`
prints a restore that works for a dir (`rhx mvsafe --from <trash dir> --into <dir>`, if `mvsafe`
moves dirs). clamp: an integration case that trashes a dir, runs the printed hint verbatim, and
asserts the dir is back.

## .why it is not done in this round

the skill is owned by another repo; a tree adopts only what is scoped to itself.

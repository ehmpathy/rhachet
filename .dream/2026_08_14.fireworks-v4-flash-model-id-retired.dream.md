## .what

`fireworks/deepseek/v4-flash` points at a model id fireworks no longer serves, so **every review
that takes the default brain fails with a 404**.

```
NotFoundError: 404 Model not found, inaccessible, and/or not deployed
  param: 'model', code: 'NOT_FOUND'
  requestID: 'chatcmpl-9fa180fb54ee49f2993987d9d7b98ec3'
```

## .where

`src/domain.operations/atom/BrainAtom.config.js` (dist line 63), the `fireworks/deepseek/v4-flash`
entry:

```diff
  'fireworks/deepseek/v4-flash': {
-     model: 'accounts/fireworks/models/deepseek-v4-flash',
+     model: 'accounts/fireworks/models/deepseek-v4-flash-0731',
```

the **slug stays** `fireworks/deepseek/v4-flash` — only the account-qualified model id moves.

## .why

DeepSeek-V4-Flash **exited preview on 2026-07-31** and shipped as `deepseek-v4-flash-0731`, which
fireworks calls the official release that supersedes the preview version. the preview deployment
behind the un-suffixed id was retired with it.

⚠️ the catalog page at `fireworks.ai/models/fireworks/deepseek-v4-flash` still renders **"Ready"**
with live rates — that page is stale. the api is authoritative and returns NOT_FOUND for that id.

- replacement: https://fireworks.ai/models/deepseek-ai/deepseek-v4-flash-0731
  ("Available Serverless", `accounts/fireworks/models/deepseek-v4-flash-0731`, same
  `$0.14 / $0.028 / $0.28` per 1M rates)

## .the evidence — three models, one client, one key, one code path

| brain slug | model id sent | result |
|---|---|---|
| `fireworks/deepseek/v4-pro` | `accounts/fireworks/models/deepseek-v4-pro` | ✅ 30.2s, real verdict, $0.0091 |
| `fireworks/glm/5.2` | `accounts/fireworks/models/glm-5.2` | ✅ 9.8s, real verdict, $0.0041 |
| **`fireworks/deepseek/v4-flash`** | `accounts/fireworks/models/deepseek-v4-flash` | ❌ **404 NOT_FOUND** |

the deepseek family is reachable on this account, so this is neither a credential nor an
account-access problem — exactly one model id is dead.

## .verified after the patch

patched the id locally in `node_modules` and re-ran the default-brain path:

```

✨ metrics.realized
   ├─ tokens: input 2,745 / output 1,267
   ├─ cost: $0.000739060
   └─ time: 12,883ms
   └─ summary: 0 blockers, 0 nitpicks
```

the realized cost lands on the **flash** rate card, which confirms the `-0731` id resolves to flash
and not silently to a pricier peer model.

## .blast radius

`DEFAULT_BRAIN` / `FIXED_FALLBACK_BRAIN` in `rhachet-roles-bhrain` both name this slug, so the 404
takes down **every peer reviewer in every repo** that does not pass an explicit `--brain`. observed
here as 9/9 level-1 reviewers that malfunctioned identically across two full route passes; the
stone could not obtain a verdict.

## .fix

1. bump the model id to `accounts/fireworks/models/deepseek-v4-flash-0731`
2. release, so consumers no longer need a local `node_modules` patch

## .worth a look

a startup or contract check that a configured model id actually resolves would turn this class of
break from a mid-route malfunction into a loud, named error at the boundary. the current failure
surfaces as an unhandled `NotFoundError` stack trace, which reads as "the reviewer broke" rather
than "this model id is retired — use `-0731`".

# 🌙 dream: rhachet-brains-anthropic writes post-tool and post-compact hooks to the wrong claude events

kind · reseed
owner · ehmpathy/rhachet-brains-anthropic (the published claude code hooks adapter)
caught 2026-11-18, on route `v2026_11_17.feat-live-clones-take-boot-drift`, stone 5.3.verification

## .the cue that fired

`npx rhx init --hooks`, run back to back, prints `ehmpathy/mechanic → anthropic/claude/code: ~1` and
`1 updated` on every run, while `settings.of.repo.json` stays byte-equal.

## .the gap, precisely

the published adapter, `rhachet-brains-anthropic@0.4.3` (the latest on npm), has no `PostToolUse` and no
`PostCompact` in its translator (`dist/domain.operations/hooks/` names them only in a `.d.ts`). so:

| declared by `ehmpathy/mechanic` | written to | effect |
|---|---|---|
| `onTool` · `posttooluse.guardBorder.onWebfetch` · `filter: { what: 'WebFetch', when: 'after' }` | `PreToolUse`, matcher `WebFetch` | 🔴 fires BEFORE the fetch, so the border guard reads no fetched content |
| `onBoot` · `postcompact.trust-but-verify` · `filter: { what: 'PostCompact' }` | `SessionStart`, matcher `PostCompact` | 🔴 never fires: SessionStart matches `startup`, `resume`, `clear`, `compact` |

the read-back of the first returns `filter: { what: 'WebFetch' }` with no `when`, which never equals
the declared `when: 'after'`, so rhachet's diff (`syncOneRoleHooksIntoOneBrainRepl.computeHookDiff`)
marks it `toUpdate` on every sync, and the adapter rewrites the same bytes. the `~1` is the visible
symptom; the two misplaced hooks are the harm.

rhachet's own copy under `src/_topublish/rhachet-brains-anthropic/src/hooks/` already handles both:
`translateHookToClaudeCode` writes `when: 'after'` to `PostToolUse` and an onBoot `filter.what` of
`PreCompact`/`PostCompact` to that event; `upsert` drops a hook from its sibling buckets when it moves.

## .the shape of the fix

1. in `ehmpathy/rhachet-brains-anthropic`, port the translate + sibling-bucket upsert from rhachet's
   `src/_topublish/rhachet-brains-anthropic/src/hooks/`
2. clamp: sync a role with one `when: 'after'` onTool hook and one `PostCompact` onBoot hook, twice;
   assert they land in `PostToolUse` and `PostCompact`, and the second sync reports no update
3. publish; bump `rhachet-brains-anthropic` here; re-run `rhx init --hooks` twice and read
   `no changes needed`

## .why it is not done in this round

the defect lives in another repo's published adapter; rhachet only consumes it, and a fix here would
fork the adapter rather than cure it. it is dispatched to its owner.

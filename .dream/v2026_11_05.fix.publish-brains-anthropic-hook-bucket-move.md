# 🌙 dream: publish the claude hook adapter's bucket move, so a `when: 'after'` hook lands in PostToolUse

kind = fix · owner = ehmpathy/rhachet (`src/_topublish/rhachet-brains-anthropic`) · caught 2026-11-05

## .the cue that fired

a dogfood `npx rhx init --hooks`, run twice in a row on this repo, printed
`ehmpathy/mechanic → anthropic/claude/code: ~1` and `✨ hooks └─ 1 updated` both times, while the
file it writes stayed byte-identical. an update that changes naught, on every run.

## .the gap, precisely

- the mechanic role (`rhachet-roles-ehmpathy@1.39.9`, `getMechanicRole.js` lines 164–165) declares
  `posttooluse.guardBorder.onWebfetch.sh` with `filter: { what: 'WebFetch', when: 'after' }`
- the repo actor's `settings.of.repo.json` holds that hook under `PreToolUse` (matcher `WebFetch`)
- the sync reads it back with no `when` (= before), finds the body unequal to `after`, and upserts
  (`syncOneRoleHooksIntoOneBrainRepl.ts` line 226)
- the installed adapter, `rhachet-brains-anthropic@0.4.3`, upserts in place and never moves the hook
  across buckets, so the file never changes and the next run repeats it
- this repo's own `src/_topublish/rhachet-brains-anthropic/src/hooks/genBrainHooksAdapterForClaudeCode.ts`
  lines 130–131 already drop the hook from each other bucket of its event, so a moved `when` lands
  once, in the right bucket. that copy is not published

## .the harm

- behavioral: the web fetch border guard fires BEFORE each fetch, where it was declared to fire
  after — so it never sees the fetched content it exists to inspect
- a report that lies: every `init --hooks` claims `1 updated`, so a real update reads as noise

## .the shape of the fix

1. publish `rhachet-brains-anthropic` from `_topublish` (its next version)
2. bump it in `package.json`; `npx rhx init --hooks` once — the hook moves to `PostToolUse`
3. clamp: an integration test that seeds a `when: 'after'` hook under `PreToolUse`, syncs twice,
   and asserts it sits in `PostToolUse` alone and the second sync reports 0 updated

not CLEAN: the cure is another package's release plus a dependency bump, outside this diff. the

# 🌙 dream: classify the walk's residual error codes in `getAllFilesFromDir`

- **kind** = defect
- **owner** = `ehmpathy/rhachet`
- **caught** = 2026-09-18, at `v2026_09_17.feat-boot-manifest-and-budget` `5.1.execution`
  `review.self r5` (`behavior-declaration-coverage`)

> 🔴 **the CYCLE half of this dream is CLOSED, in that same behavior.** `getAllFilesFromDir`
> now carries an ancestor-chain guard keyed on `realpathSync`, clamped by three cases in
> `getAllFilesFromDir.integration.test.ts` (self-cycle, mutual cycle, and a dag that must
> still be walked twice). what follows is the **residual**, which is narrower.

---

## .the cue that fired

a requirement-5 probe — *"does `--manifest` fail loud on a path that points at no file?"* — was run
against a **directory** rather than a typo:

```
$ npx rhachet roles boot --manifest src
MalfunctionError: ELOOP: too many symbolic links encountered, stat
  '…/node_modules/rhachet/node_modules/rhachet/node_modules/rhachet/…'
EXIT=1
```

two defects sat under one symptom. the walk's unbounded recursion is repaired; **its error
classification is not.**

---

## .the gap, precisely

`src/infra/filesystem/getAllFilesFromDir.ts`, the per-entry loop:

```ts
let stats: ReturnType<typeof statSync>;
try { stats = statSync(fullPath); }
catch (error: unknown) {
  if ((error as NodeJS.ErrnoException).code === 'ENOENT') continue;
  throw error;                                   // 🔴 every other code rethrows raw
}
```

| code | what it means | what the caller gets today |
|---|---|---|
| `ENOENT` | a broken link | ✅ skipped, deliberately |
| `ELOOP` | a chain too deep for the kernel, with no cycle to guard | 🔴 raw throw ⇒ `MalfunctionError` ⇒ **exit 1** |
| `EACCES` | a dir the process may not read | 🔴 raw throw ⇒ `MalfunctionError` ⇒ **exit 1** |

⇒ both residual codes name a fault in the **caller's own tree**, which a re-run on a repaired tree
fixes — exit **2** by the test `rule.require.exit-code-semantics` sorts by. an unclassified raw
throw calls the server at fault for the caller's filesystem.

🟡 **the cycle guard narrowed this, and did not close it.** a cycle can no longer produce `ELOOP`,
so the code now arises only from a genuinely deep non-cyclic chain — rarer, and still unclassified
when it comes.

🟡 **and `statSync` still follows the link** where `lstatSync` would let a symlinked dir be a
decision rather than an accident. that is a readability claim rather than a defect: the cycle guard
already bounds the walk, and two test suites pin the follow-the-link behavior on purpose.

---

## .the shape of the fix

1. widen the catch to classify `ELOOP` and `EACCES` into a `ConstraintError` that names the path
   and the code, so a caller-caused walk exits 2
2. keep `ENOENT` a silent skip — a broken link is routine, and the suites pin it
3. clamp each new code with a fixture: a ≥40-deep non-cyclic symlink chain for `ELOOP`, a
   `chmod 000` dir for `EACCES`. **prove each goes red under the ENOENT-only catch**
   (`rule.require.clamp-edge-cases`)

---

## .why it is not done in this round

the SAFE/CLEAN test (`rule.always.fix-forward-under-scouts-honor`):

| question | answer |
|---|---|
| **SAFE?** | ✅ yes — it re-classes two codes that today crash, and touches no green path |
| **CLEAN?** | 🔴 **no** |

the dirt is the same structure that deferred the cycle half, minus the part this behavior had to
close:

- **6 production callers**, none of which this diff otherwise touches for error classification —
  `discoverSkillExecutables`, `discoverInitExecutables`, `getRoleFileCosts`,
  `findNonExecutableShellSkills`, `assertRegistryHasNoOrphanBriefs`, `genBootPayload`. a code that
  crashes today would start to **refuse** instead, at every one
- an `EACCES` clamp needs a `chmod 000` fixture, which is a new hazard class in this suite (it must
  be restored on teardown or it poisons the temp-dir prune)
- it lives in `src/infra/`, which every layer may reach

⇒ the **cycle** half was in scope because this behavior opened the door to it: a manifest's
`rootDir` is `dirname(pathToSpec)`, so `--manifest ./boot.yml` walks the repo root and hits the
`link:.` self-symlink.

### 🔴 .corrected 2026-09-20 — this section once claimed the door stays shut, and it does not

it read: *"the classification half opens no such door — no path this feature adds can produce
`ELOOP` or `EACCES` that the cycle guard does not already stop."* **that is true of `ELOOP` and
false of `EACCES`**, and a peer reviewer named the half it got wrong (`review.peer r010` §5):

| the code | does the cycle guard stop it? |
|---|---|
| `ELOOP` | ✅ **yes** — a cycle is an ancestor revisit, and the guard terminates every one |
| 🔴 `EACCES` | 🔴 **no. a cycle guard has naught to do with permissions.** a `chmod 000` dir under a manifest's `rootDir` raises it, and the `ENOENT`-only catch rethrows it raw |

⇒ so `--manifest` **does** open a door for `EACCES`: it is the first caller in the repo's history
that walks a root the caller chose, and an unreadable dir anywhere beneath it exits **1** where
every other refusal on this path exits 2.

🟡 **the deferral still holds, and its warrant changed.** it is no longer *"no door"* — it is the
**CLEAN** row above: the repair lands on an `src/infra/` arm 6 callers share, and the two candidate
answers differ in kind. a **skip** is a silent undercount (the direction a budget gate must never
fail in); a **refuse** is correct and moves all 6 from *crash* to *refuse*, each with clamps to
re-bless.

⇒ **the live scope of this dream is `EACCES` alone.** the `ELOOP` half it was caught for was closed
by the cycle guard, and the residual deep-non-cyclic `ELOOP` is a rarity this feature does not make
reachable. the full re-grade is `F20`'s `.2b, re-graded` section.

---

## 🔴 .the scope narrowed a SECOND time, by LAYER rather than by errno — 2026-09-24

*"`EACCES` alone"* named the errno and silently carried the **layer** of the original report with it.
there are **two** stats on a `--manifest` path, and only one of them is this dream's:

| the stat | whose | verdict |
|---|---|---|
| the **manifest's own path** — `getOneBootSourceFromManifest.ts` | the feature's own code, 1 caller | ✅ **narrowed** — a closed errno set raises a `ConstraintError` at exit 2, clamped at `[case5]` |
| 🔴 the **walk beneath it** — `getAllFilesFromDir.ts` | `src/infra/`, 6 callers | 🔴 **this dream** — unchanged |

⇒ **the CLEAN warrant above has no purchase on the first row**, and that is what let it ship while
this dream stayed open. an `src/infra/` arm 6 callers share is dear to widen; a narrow on a site the
feature wrote costs one clamp.

🟡 **the lesson: enumerate the SITES a concern touches, never only the errno it named.** this dream
was caught on one stack trace, so it inherited that trace's layer as though the layer were part of
the defect. one pass over the sites would have parted the cheap half from the dear half a round
earlier — and the cheap half is the one a caller actually meets, since a manifest's own path is what
they typed.

⚠️ **it does NOT shrink the walk's defect.** a `chmod 000` dir anywhere under a reachable `rootDir`
still yields exit 1 for a caller-repairable fault. the door is narrower, never shut.

# 🌙 dream: a bare `claude` yields an UNENROLLED clone, and no mechanism refuses one

- **kind** = feature
- **owner** = `ehmpathy/rhachet`
- **caught** = 2026-09-22

> 🔴 **this is a REQUIREMENT the vision established, deliberately deferred to its own behavior.**
> it is not a nicety noticed in passing — `.seeds/…case=S7` records the wisher's verdict that
> enrollment is a **hard requirement overall**. what is deferred is the *mechanism*, never the
> requirement.

## .the cue that fired

the F1 ruling puts the role corpus in a **spawn flag** — `--append-system-prompt-file <path>`,
passed by `asBrainCliSpawnArgs` when `rhx enroll` spawns the cli.

⇒ **a transport that only applies when enrolled is worthless if a bare launch silently works
anyway.** a human who types `claude` out of habit gets a clone with **no briefs at all**, and every
signal says the boot worked.

🔴 **that is cell #4's failure mode reached by a different door** — and a strictly easier door,
because it needs no unusual machine, only a habit.

## .the gap, precisely

**enrollment already carried weight before this feature existed, and the wisher named the sharper
half:**

| the capability | what it needs from enrollment |
|---|---|
| briefs at the system prompt (this feature) | the corpus rides a spawn flag. **no flag → no briefs** |
| `rhx clone get` / `rhx clone say` (**extant today**) | the clone's address + socket register **at enroll**. a bare clone is `dark` and `deaf` |

⇒ an unenrolled clone is not merely brief-less; **it is unreachable**. so this is a gap the
transport *reveals* rather than a cost it *imposes*.

**and no mechanism refuses one today.** a bare `claude` in this repo starts, works, and is
indistinguishable to its human from an enrolled one until a brief is missed or a `say` is refused.

## .the shape of the fix — two levers, and neither subsumes the other

### lever 1 — a **PATH shim** that proxies `claude` → `rhx enroll claude`

🟢 **the pit-of-success form**, and the wisher's preferred shape: the human types `claude` and
**gets an enrolled clone**. there is naught to restart and no refusal to read.

⚠️ the sharper variant the wisher then proposed — *"or, the shim just requires you to call
`rhx enroll claude`"* — **refuses** rather than proxies. that is a real fork, and it is not settled
here: to proxy is friendlier; to refuse keeps one entrypoint and teaches the habit. ⇒ **the fork is
part of what makes this its own behavior.**

🔴 **the recursion hazard, which any implementation must answer first.**
`asBrainCliSpawnArgs` spawns `claude`. if the shim wins `PATH`, **rhachet's own spawn hits the
shim**:

```
claude → rhx enroll claude → spawns `claude` → the shim → rhx enroll claude → …
```

the cure is an env marker, read in the opposite direction from the hook's use of it:

```sh
[ -n "$RHACHET_ENROLLED" ] && exec "$REAL_CLAUDE" "$@"   # called BY rhachet → passthrough
exec rhx enroll claude -- "$@"                            # called by a human → enroll
```

⇒ **one marker serves both levers.** verified: the `env` key in a `--settings` file IS exported
into hook processes, so the same marker is readable from a hook.

**three more constraints the shim owes:**

| # | constraint | why |
|---|---|---|
| 1 | **repo-aware** — no rhachet repo at cwd → `exec` the real binary, silently | a global shim hits every directory; `claude` in `~/scratch` must not become `rhx enroll claude` |
| 2 | **self-healing** — `pnpm add -g @anthropic-ai/claude-code` overwrites `~/.local/share/pnpm/claude`, exactly where the shim sits | ⇒ **`rhx upgrade` is the right owner rather than merely a convenient one: the command that clobbers it re-plants it.** but `upgrade` alone leaves a fresh machine bare, so it is a `gen` (findsert) from **`enroll` and `init` too** — check-or-plant, idempotent |
| 3 | **composes with an extant wrapper** | measured on this host: the shell already defines a `claude()` function that runs the binary under `systemd-run --user --scope -p MemoryMax=8G`. it derives `$bin` via `PATH` with the function unset, so it would find the shim and run it under the cap. **they compose** — a design that assumed it was the outermost layer would be wrong here |

### lever 2 — a **repo hook** that refuses a bare session

three findings, each checked against the current docs:

| # | finding | consequence |
|---|---|---|
| 1 | 🔴 **`SessionStart` CANNOT hard-abort.** exit 2 shows stderr and the session *continues*; no JSON field blocks it | the obvious design fails — a startup check can warn, never refuse |
| 2 | ✅ **`PreToolUse` CAN deny every tool** — matcher `*`, `permissionDecision: "deny"`, reason fed back to the model | **the brick lives here.** a session with no tools can only chat |
| 3 | ✅ **`--settings <path>` loads INDEPENDENTLY of `--setting-sources`** | the enroll-generated config always applies |

⚠️ **the docs CONFLICT on finding 1** — `hooks-guide` says exit 2 continues; the hooks reference
reads as though it blocks. **this was never measured.** a probe was set up and the round moved on:
one `-p` run against a settings file with a `SessionStart` hook that exits 2, on each of the two
installed binaries (`2.1.87` and `2.1.278`). ⇒ **that measurement is owed before the hook design is
chosen**, because a real abort makes the `PreToolUse` brick unnecessary.

🟢 **the cost concern answers itself.** the brick lives in `.claude/settings.json` — the **project**
source — and `asBrainCliSpawnArgs` already passes `--setting-sources local`, which **excludes that
file entirely**. so for an enrolled clone the hook is not *skipped at runtime*; it **is never
registered**. no spawn, no per-tool-call overhead.

⇒ **the hook cost is paid only by sessions that are already broken.**

⚠️ that couples enforcement to a flag passed today for an unrelated reason. if `--setting-sources
local` ever changes, the brick starts firing on enrolled clones — loud rather than silent, but it
owes a comment in `asBrainCliSpawnArgs` and a clamp in its test.

### how they divide

| | shim | hook |
|---|---|---|
| lives on | the **machine** | the **repo** |
| ladder rung | 🔴 **1–2** — makes the wrong call impossible or hard | 3–4 — catches and reports |
| outcome | the human **gets an enrolled clone** | the human gets a refusal and a command |
| covers | any repo, on a machine that has it | any machine, in a repo that has it |

⇒ **neither subsumes the other**, which is why both are wanted.

## ⚠️ .the bound — what this can and cannot do

- **not adversary-proof.** `claude --setting-sources user` dodges the hook; a `PATH` edit dodges the
  shim. **no local scheme defeats a determined local user, and the goal is not to try**
- **the target is the ACCIDENT** — a human typing `claude` from habit, an automation that forgot the
  wrapper, a CI job that calls the binary directly
- **a hook refusal is a degradation, not an abort.** the model can still chat; it simply has no
  tools. ⇒ **the deny reason must name the command to run instead**, or it is a wall with no door

## .why it is not done in this round

the SAFE/CLEAN test, answered honestly:

- **safe?** ⚠️ **no, not fully.** lever 1 installs a binary shim on the host `PATH`, and its
  recursion hazard is real: get the marker wrong and **every `claude` invocation fork-bombs**. that
  is a blast radius well beyond this feature's own surface
- **clean?** 🔴 **no.** it needs: a settled fork (proxy-vs-refuse), a measurement the round never
  took (does `SessionStart` exit 2 abort?), a new install surface owned across **three** commands
  (`upgrade` + `enroll` + `init`), repo-detection, a marker contract shared by two levers, and an
  interaction with an extant shell wrapper

⇒ **the wisher's own verdict settles it:** the mandate is its own dream, to be done after this
work, since it alone is a bit complicated.

🔴 **the deferral is of the MECHANISM, never the requirement.** S7 stands: an unenrolled clone is a
defect. this behavior's vision carries the requirement and its experience cells; **the enforcement
is this dream.**

## .the ordering constraint

**do this AFTER the boot-briefs work lands, and BEFORE the fleet leans on the new transport.**

the gap is not *created* by this feature — a bare `claude` is already `dark` and `deaf` today. but
the feature **widens** it: once briefs ride a spawn flag, an unenrolled clone loses its whole
corpus rather than merely its reachability.

⇒ the window between the two is the period where the landmine is largest.

# 🌙 dream: the cli refusal's `[args]` trailer reads as debug noise

kind = fix · owner = rhachet (`src/contract/cli/emitCliErrorAndExit.ts`) · caught 2026-11-04

## .the cue that fired

a peer review of `v2026_11_02.fix-boot-briefs-cacheable` 5.3 flagged the `[args] init,--roles,…` line in
eleven refusal snapshots as debug noise wedged under the error frame.

## .the gap, precisely

the generic top-level handler prints `[args] <comma-joined raw argv>` after every unclassified refusal.
it is flush-left, outside the error's tree, comma-joined so a human cannot paste it back, and it names
no label a reader would recognize. the keyrack commands already replaced it with a tree branch that
spells the command shell-shaped (`getKeyrackBlockedReport.ts`).

## .the shape of the fix

- the handler renders the argv as one branch under the error, space-joined as a command line
  (`├─ ran = rhx init --roles +nonesuch`), the same shape the probe skills use
- `invoke.unclassifiedThrow.integration.test.ts` moves its "trailer rides along" assert to the new shape
- one resnap pass over the cli refusal snapshots

## .why it is not done in this round

the handler is shared by every unclassified refusal, a surface the boot-cache wish does not touch, and a
test pins the current shape on purpose (F19).

`test-fns` owns the temp-dir guarantee, so no consumer ever hand-rolls a teardown.

**status: realized directly, never bridged toward.** behavior `v2026_08_30.fix-test-tempdir-leak`
chose upstream-first — it builds no local bridge, and depends on ehmpathy/test-fns#64 instead. this

## the debt

`genTempDir` allocates but never reclaims. its only reclaim is `pruneStaleOnce` — a
fire-and-forget, once-per-process, **7-day** age prune
(`test-fns/src/domain.operations/genTempDir/pruneStale.ts:5`). the public contract exports only
`genTempDir` and `isTempDir` — no teardown hook, no exit handler.

so every consumer that wants **zero dirs after the run** must build the same layer. each one that
hand-rolls it is a place the guarantee can be got wrong.

a second, smaller debt: `genTempDir` returns the **symlink** handle
(`@gitroot/.temp/genTempDir.symlink/{name}`), which lives inside the caller's own git repo. tests
that need a cwd which is **not any** git repo must `realpathSync` it to reach the physical dir.
that deref is a workaround for an absent contract option.

## why the bridge was the wrong shape

the bridge would have been a rhachet-local wrapper plus an `afterAll` prune. three probes killed
it (full evidence in the behavior's `1.vision.yield.md`):

| the bridge would need | probe verdict |
|---|---|
| a process-scoped registry | ⛔ jest resets the module registry per test file — the list is empty every file |
| or a `process.on('exit')` hook | ⛔ jest kills its workers; the hook never fires, even when still registered |
| or a per-worker id in `process.env` | ⛔ jest hands each test file a fresh env copy — a worker-local mint is erased between files |

so the bridge would have had to reimplement, verbatim, the one shape that works: **mint a session
before the fork, stamp it into the dir name, prune by stamp from a framework hook.** that shape has
exactly one right home, and it is not rhachet.

and the cost of the bridge is not merely duplicate work — every other test-fns consumer keeps its
leak for as long as the fix stays local.

## the end state

- **ehmpathy/test-fns#64** — the session-scoped teardown. mint in a `globalSetup`, fold the session
  into the dir name, prune by session from a shipped jest setup. `TEST_FNS_KEEP` as the hold hatch.
  keep the age gate as the backstop for a `--keep` hold and a `kill -9`'d run.
- **ehmpathy/test-fns#65** — expose the physical path (e.g. `genTempDir({ deref: true })`), so a
  not-a-git-repo cwd is a first-class case rather than a `realpathSync` at each call site.
- **ehmpathy/test-fns#66** — key the temp scope on the git *common* dir, so worktrees share one
  scope and a deleted worktree leaves no orphan. shorten the age gate and expose it as config.

## acceptance signal

a full rhachet acceptance run leaves **zero** new `/tmp` dirs, and:

- rhachet holds no temp-dir registry, no prune, no teardown of its own
- `jest.*.config.ts` declares two keys that point at **test-fns** modules
- no site calls `realpathSync` on a `genTempDir` result

that is: the guarantee holds and rhachet contains none of the machinery for it — because
`test-fns` does.

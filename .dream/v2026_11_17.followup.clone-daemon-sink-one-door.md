# 🌙 dream: a clone daemon part cannot reach the stderr tee, by construction

- kind = followup
- owner = rhachet (clone daemon trace sinks)
- caught 2026-11-17, by route v2026_11_16.fix-loop-stall-trace-off-pane, peer r010 and r011
  nitpicks (i005, i006)

## .the cue that fired

peer reviews r010 and r011 graded a set of nitpicks `[better]`, all about the daemon's sink door
and the shape of the parts beside it:
- `getCloneTraceSink` (the client tee to stderr) keeps the obvious name and sits beside the daemon
  sink; no test fails if a new daemon part imports it by habit
- the `getOneCloneTraceSinkForDaemonAtCwd()` default is hand-copied at four sites, each with its own
  gap record
- the loop-watch liveness line is written by the socket server, though the watch owns its tick and
  threshold
- the sink file holds ~110 lines of pure gap logic (the gap record, its reducers, the gap line) that
  only a real-fs test reaches
- the mirror's `writeOut` is only meant between `enterAsyncMirror` and its release, with no handle to
  say so; and a tty handle that lacks the switch leaves the loop stall in place with no trace
- the fallback dir under the os tmpdir is made `0o700`, but an extant dir at that path is not
  checked for owner, and `appendFileSync` follows a planted symlink

## .the gap, precisely

the daemon is log-only today at every site, proven in real children for the socket server, the
write queue, and the screen feed. what is absent is a guard that keeps it so as new parts land, one
construction site, and the smaller shape repairs above.

## .the shape of the fix

1. rename `getCloneTraceSink` → `getCloneTraceSinkForClientTee` (name says it paints stderr)
2. make `trace` required on the inner daemon parts (screen feed, write queue, socket server);
   construct one daemon sink in `genBrainCliPtyClone` / the detached host and pass it down
3. let `genCloneLoopLagWatch` announce itself through `trace` at start; clamps filter by prefix
4. add a source-scan unit clamp: no file under `clone/pty`, `clone/screen`, `clone/socket`
   imports the client tee or names `process.stderr`
5. extract the gap record, reducers, and `asCloneTraceGapLine` into one-op files with a caselist
   unit test (the `1 line` / `2 lines`, kept / lost branches)
6. replace `writeOut` + `enterAsyncMirror` with one `openMirror(): { write, release }` handle; have the
   tty switch report whether it applied, and trace once when it did not
7. open the fallback log with `O_NOFOLLOW | O_APPEND | O_CREAT`, mode `0o600`, after an `lstat` owner
   check on the dir; a foreign or non-dir path counts the line as lost
8. let the gap record keep every distinct fallback path it wrote (a gap that spans midnight lands
   in two day files), and name them all in the gap line — a case in the step-5 caselist
9. build the trace-log location in both `clone say` hints (`computeCloneUnreachableHint`,
   `computeCloneOperationalRejectClass`) from `getCloneTraceLogPath` and
   `CLONE_TRACE_FALLBACK_DIR`, so a moved log moves its hints
10. snapshot the operator's artifacts: the stall line, the four gap-line shapes, a fallback line,
    and a day-log excerpt, temp paths masked
11. in the healthy interactive enroll acceptance scenes and in case7, assert the screen holds no
    daemon trace line (`clone daemon`, `clone socket`, `clone screen feed`, a `pid=` stamp)
12. derive the daemon sink's repo from the clone's own `cwd` (`genBrainCliPtyClone`'s `input.cwd`),
    never the runner's `process.cwd()`: in prod the two are one dir, but this repo's integration
    suites spawn clones from the repo root, so their fault and liveness lines land in the
    developer's real `.agent/.cache/repo=rhachet/skill=clone-say/daemon.<day>.log` beside real
    ones (seen 2026-11-17: the `nd-ptyclone-bind` bind faults at lines 60, 62, 84, 86)

## .why it is not done in this round

each step is a contract change across several modules and their tests (required inputs, a rename
with callers, clamp rewrites, a host interface change). the wish's behavior holds and is proven;
this is the pit-of-success guard work, which earns its own reviewed pr.

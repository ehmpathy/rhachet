# 🌙 dream: make `daemon.integration` `[case9]` wait for the `.pid` file it reads

- kind  = fix
- owner = ehmpathy/rhachet
- caught 2026-09-25

## .the cue that fired

a full integration tier run on `beav/feat-boot-briefs-into-claude-md` came back **1180 passed, 1
failed** — and the one failure sat in a subsystem this route never touches. a scoped re-run of the
same case passed at once, so the tier is not red; it is **flaky**, and a flaky tier is the kind of
red that trains a reader to skip the count.

## .the gap, precisely

`src/domain.operations/keyrack/daemon/daemon.integration.test.ts`, `runOneRound` (≈ line 870):

```ts
const pidPath = socketPath.replace(/\.sock$/, '.pid');
daemonPidsSpawned.push(parseInt(readFileSync(pidPath, 'utf-8'), 10));
```

the read is **unguarded**. the daemon writes its socket and its `.pid` as two separate acts, so a
round that samples between them throws:

```
ENOENT: no such file or directory, open '/tmp/keyrack-accum-test-2321373/keyrack.9999.aaaa0010.pid'
   at runOneRound (…/daemon.integration.test.ts:870:40)
   at Object.<anonymous> (…/daemon.integration.test.ts:889:38)
```

⇒ the test awaits the **socket** and then reads the **pid**, which is a different file with a
later birth. it is a read-before-write race in the test, not a defect in the daemon.

## .the shape of the fix

poll for the `.pid` file the same way the case already polls for the socket — a bounded
wait-until-present, then the read. the bound must **fail loud** on expiry (a `ConstraintError` or
a plain throw that states the path), never fall through to a skip, so a genuine daemon defect
still surfaces (`rule.forbid.failhide`).

a shared helper is the better home than an inline loop: the same socket → pid read appears in more
than one case in that file, and each instance carries the identical race.

## .why it is not done in this round

- **CLEAN fails.** the file lives under `src/**`, which is inside the artifact set of the stone
  currently under review (`5.5.playtest`). an edit there restarts its peer review ladder — a cost
  paid by a change this route does not need.
- **SAFE is borderline.** the right fix is a shared wait helper across several cases in a
  concurrency suite; a hasty inline poll in one case leaves the other instances of the same race
  in place and reads as though the class were closed.

⇒ the fix belongs in its own round, against that file alone, where its own reviewers can read it.

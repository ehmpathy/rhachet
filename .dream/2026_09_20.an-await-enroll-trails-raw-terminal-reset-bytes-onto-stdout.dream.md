## .the gap, precisely

an `await` enroll takes the **mirrored** host, so the child's pty output tees to the enroller's
stdout. on exit the brain-cli emits its terminal-reset sequences — mouse reports off, bracketed
paste off, cursor show, title reset — and the mirror forwards them verbatim.

that is correct for a `watch` enroll: a human's terminal genuinely needs the reset. it is wrong for
an `await` enroll, whose stdout is a **machine channel** — a guard lane reads it for a verdict, a
`.given` file persists it for a human to read later.

### what it does and does not break

| | state |
|---|---|
| the verdict parse | ✅ **survives** — `asPeerGivenVerdict` reads a numeric count, and the count sits on its own line above the trailer. measured: the cure-23 proof parsed |
| a `.given` a human reads | 🔴 every `await`-enroll lane's record now carries a line of escape noise (`rule.forbid.snapshot-visual-blemishes`) |
| any downstream that takes the last line | 🔴 would take the trailer |

### 🟡 the origin is UNMEASURED

I did not establish whether `origin/main` emits the same trailer. it plausibly does — the mirror
path predates this wish — but the prior route's approved `.given` files live on another branch and
are not in this worktree, so I have no observation either way.

⇒ so this is recorded as a **live blemish of unknown age**, never as a regression of this wish.

first act of the fix.

## .the shape of the fix

the trailer must be dropped for `await` and kept for `watch`, so the filter is **mode-conditional**:

1. measure the origin first (above), so the fix records whether it repairs or merely improves
2. the seam is the mirror tee in `genPtyCloneHostFromProcess` — the same place cure 23's
   `genCloneOndisk` branch picks between the mirrored and detached hosts
3. the filter belongs in a named transformer, never inline — e.g. `asCloneMirrorBytesForMachine`,
   so the orchestrator reads as narrative (`rule.forbid.inline-decode-friction`)
4. 🟡 **the hazard: do not strip ALL escapes.** a reviewer's answer may legitimately carry color, and
   a blanket strip would also eat content. the target is the narrow reset set the child emits at
   teardown, and the clamp must assert a colored answer body survives
5. the clamp grain is **acceptance** — it needs a real child that exits, so a unit test cannot
   observe it

## .why it is not done in this round

- **SAFE?** 🔴 no. the filter sits in the mirror path that **every** `watch` enroll uses, so a wrong
  predicate silently corrupts a human's interactive session — output a human reads and cannot diff
- **CLEAN?** 🔴 no. it ripples into `genPtyCloneHostFromProcess`, a new transformer, and an
  acceptance clamp that spawns a real brain — none of which cure 23 touched
- and it repairs **no defect this wish's gate measures**: the verdict parses, so the lane passes

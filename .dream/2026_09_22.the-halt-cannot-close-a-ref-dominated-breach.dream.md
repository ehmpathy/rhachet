# 🌙 dream: the budget halt names four strategies, and none of them reaches the cost that dominates

- **kind** = defect
- **owner** = `ehmpathy/rhachet`
- **caught** = 2026-09-22

## .the cue that fired

a dogfood. `budget: { tokens: 5_000 }` was declared on this repo's own
`.agent/repo=.this/role=any/boot.yml`, the boot halted at **297% of budget**, and the halt said:

```
├─ some say resources must go — you choose which
└─ fix — four strategies, cheapest first
   ├─ catalogize  replace a set with one catalog that indexes it
   ├─ condense    author an x.md.min beside x.md
   ├─ reference   move a say entry to ref
   └─ eliminate   delete what does not earn its boot
```

⇒ **every one of the four acts on a `say` resource.** so the author measured the say set, and
found it was not the problem.

## .the gap, precisely

measured on `repo=.this/role=any`, 2026-09-22:

| quantity | value | how |
|---|---|---|
| emitted payload | **50,256 chars** → **14,837 tokens** | emitted to a file; `calc.tokens`. reproduces the halt's own count exactly |
| 🔴 **the ref roster — 276 lines** | 🔴 **8,404 tokens (57%)** | the ref lines extracted to their own file and tokenized alone |
| the whole **say** set — readme + 8 briefs + 9 skills | 🟡 **~5,185 tokens (35%)** | `rhx calc.tokens` over the say globs, `.md.min` preferred |
| chrome — 2 `<stats>` blocks, say wrappers, `<also>` | ~1,248 tokens (8%) | the remainder |

**one ref line = 30.4 tokens**, at 3.16 chars/token — path strings are the densest text a boot
emits.

> 🔴 **eliminate EVERY say resource — all four strategies taken to their limit — and the payload
> is still ~9,650 tokens.** a budget under that number cannot be met by any advice the halt gives.

⚠️ **the split is measured, never derived.** the two files tokenized separately sum to the gate's
own 14,837. a first pass reported the roster at *~9,650 / 65%* by subtraction, which silently
folded chrome into the roster — the direct measurement is **8,404 / 57%**.

two defects, one root:

1. 🔴 **the halt's headline is false for this shape.** *"some say resources must go"* asserts the
   breach is closable by a say trim. here it is not.
2. **the remedy ladder has no rung for the ref roster.** `catalogize` is the closest — a catalog
   that indexes 30 briefs replaces 30 ref lines with 1 — but its gloss frames it as a say remedy,
   so an author over budget on refs has no reason to reach for it.

🔴 **a third defect, and the sharpest — already repaired in the round that found this:** the
`reference` gloss read *"costs no tokens"*. it costs its path line — **measured at 30.4 tokens** —
and at 276 refs that "free" remedy is **the single largest line item in the payload, larger than
every resident document combined**. fixed to *"costs its path line"*.

## .the shape of the fix

**report the split, never the resources.** the gate can see a resource's cost and not its value
(`F13`), so it must not name files — but the **class** split is a fact it can state, and it is
exactly what the author needs to pick a rung:

```
├─ payload  = 14,837 tokens   (full emitted payload, o200k_base)
│  ├─ say    =  5,185         (the resident docs)
│  └─ ref    =  9,652         (274 path lines + chrome)
```

a class split is not a per-resource list, so `F13` is untouched — and it turns *"which of four
strategies?"* from a guess into a read.

then make the ladder honest about the ref roster:

- when **ref** dominates, lead with `catalogize`, and gloss it as *"one catalog replaces N ref
  lines"* rather than as a say remedy
- consider a fifth verb for the roster itself — a role with 274 briefs pays ~9,650 tokens to
  advertise them, on every boot, whether or not one is ever dereferenced

⚠️ **and the open question the split surfaces: should a `ref` line be in the budget at all?**
`F12` settled that the gate counts the full emitted payload, and that settlement is right — a ref
line IS resident context. but it means **a role's budget is dominated by its brief COUNT rather
than by its curation**, which is not the incentive the budget was built to create.

## .why it is not done in this round

**not SAFE.** the class split changes the halt's rendered shape, which is a snapshotted human
surface pinned by `case=2` `[t0]`, the acceptance tier, and two integration snapshots. and the
open question above is a **contract** question — whether ref lines are budgeted — which is the
wisher's to settle, not a render tweak.

**not CLEAN.** `calcBootPayloadTokens` counts one emitted string, so a say/ref split means the
renderer must hand the gate a partitioned payload rather than a blob — a real change to the seam
between `genBootPayload` and the gate.

⇒ the one half that WAS safe and clean — the false *"costs no tokens"* gloss — was fixed on
contact (`rule.always.fix-forward-under-scouts-honor`).

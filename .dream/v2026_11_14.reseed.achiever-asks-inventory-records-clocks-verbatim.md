human messages, recorded verbatim, held clock times (a switch hour, a deadline hour). the hook forbids
any clock in a tracked file and allows no exemption.

## .the gap, precisely

- the achiever records each peer message verbatim into `asks.inventory.jsonl`, clocks included
- repos that run `check.timestamps.sh` (the declapract husky practice) refuse any tracked file with a
  clock, so every ask that names a time blocks the next commit of the route's goals
- the `goal.guard` hook forbids a driver direct access to `.goals/`, so the driver cannot repair the
  file it is refused on; here a human had to authorize a mask in place

## .the shape of the fix

- at record time, mask each clock in `content` the way the hook's own guidance says: `[time]` for a
  bare clock, `[timestamp]` for a zoned or iso stamp (reuse the hook's `TIMESTAMP_PATTERN`, minus iso
  durations)
- compute `hash` over the raw message before the mask, so coverage still keys on the ask as received
- a clamp: an ask that holds a bare clock and a zoned clock records them as `[time]` and
  `[timestamp]`, and a staged commit of the inventory passes `check.timestamps.sh` (the test builds its
  clock strings at runtime in a `.ts` file, which the hook skips)

## .the gap, precisely

1. `bin/hooks.dispatch.sh:143-145` says a keyless event "reads no key, so only a `*` rule fits it".
   line 217 says otherwise: an empty key name sets `mk=all`, so every row of a keyless event runs,
   whatever its matcher. the note is false; the behavior is safe only because claude applies no
   matcher on Stop and UserPromptSubmit either.
2. a row slower than the 60 s floor raises its event's wire timeout at the next sync. the swap report
   says naught of it, and a seat already up keeps the old wire until it respawns.

## .the shape of the fix

1. reword the note: "any other event reads no key, so every row of it runs, matcher or not; claude
   applies no matcher there either". `constants.manifest-parity` [t4] already pins the key table
2. in `asHookDispatchSwapLines`, a leaf under an event whose wire timeout exceeds `floor + margin`:
   `wire timeout raised to Ns; a seat already up keeps the prior one until it respawns`. one snapshot

## .why it is not done in this round

the wish bounds this change to `src/**` and its tests, so the bash note is out of reach. the report
line moves the init, upgrade and boot-guard snapshots for an alterpath the director ruled holds (F2).

# 🌙 dream: a focus parses once, at the boundary, into a `RoleFocus` domain literal

- kind  = refactor
- owner = ehmpathy/rhachet (`src/domain.operations/roles/focus/`, `RoleDelta`, `ActorOndisk`)
- caught 2026-10-22, by `.behavior/v2026_10_21.feat-enroll-role-subject-focus` (stone 5.1, i004
  r011 blocker.1)

## .the cue that fired

the l3 arch lane: the focus is a string tucked inside `RoleSlug`, so the hooks invariant holds
only while every consumer recalls to strip it.

## .the gap, precisely

- the token `mechanic::flow` rides inside `RoleSlug` through `RoleDelta.role`,
  `ActorOndisk.roles` and `getSettingsForRoles({ roles: string[] })`. none of those types refuse a
  focused token
- `asRoleFocusParts` strips the focus at each exact-match site — 13 files. every site is tested,
  so no site leaks today; the NEXT consumer of `actor.roles` can leak with no type error, and the
  leak is the wish's worst harm (a silent drop of a role's hooks, at exit 0)
- anonymous `{ role, subjects }` bags repeat in `asRoleFocusMap`, `asRoleRefsAtFoci`,
  `getAllRolesUnlinked`, `getAllRoleFociOfDeltas`; `isSameFocus` is written twice
  (`asRolesUpsertedByDelta.ts`, `asRoleFocusChanges.ts`)

## .the shape of the fix

1. declare `RoleFocus extends DomainLiteral<{ role: RoleSlug; subjects: string[] | null }>`
2. parse at the cli boundary, once: `asRoleFoci({ tokens }) → RoleFocus[]`, one entry per role
   (`asRoleFocusMap`'s rule, moved)
3. hook filters (`getSettingsForRoles`, `getAllHooksOfUnenrolledRoles`) take `RoleSlug[]` of bare
   roles; the render takes `RoleFocus[]`. a focused token then cannot reach a hook filter: it is no
   longer the type the filter accepts
4. the token string survives only where it is persisted: `actor.json`, the identity hash, the
   `prepare:rhachet` replay — each with an `asRoleFocusTokens` at the write and an `asRoleFoci` at
   the read
5. F2 (whole and focused in one set) becomes structural: one entry per role cannot hold both
6. the repeat work collapses with it (i004 r011 point 6): `getRoleDeltas` parses each token once,
   not six times; init's discovery runs once, shared by `assertInitRoleFociDeclared` and
   `initRolesFromPackages` via `getRolesFoundFromSlugs`; the repo actor derives its render one way,
   through `asRoleRefsForEnrolledSlugs`, not via both `asRoleSlugsAmbientAtFocus` and
   `asRoleRefsAtFocus`

### .the preferred shape (i005 r011) — derive once per command, persist tokens as today

steps 1–4 re-type persisted contracts. a lighter path reaches the same guard: derive one
`RoleFocusResolved { ref, subjects, spec, alwaysShed, elsewhere }` per command, at one choke
point, in the spec's declaration order. `actor.json`, the identity hash and the replay keep their
token strings; `RoleDelta` and `ActorOndisk` stay as they are. it feeds the declared check, the
receipt, the render and the summary, and removes:

- the three reads of one boot spec (`assertRoleFociDeclared`, `getAllRolesAtFocusAlwaysShed`,
  `getOneRoleBootContent`)
- the three compositions of "ambient = linked + record" (`invokeEnroll`, `setDeltaActorsOndisk`,
  `setRepoActorBrainDir`)
- `invokeInit`'s four views of one delta list (`deltas`, `deltasUnfocused`, `roleSlugsForFlags`,
  `roleSlugsUnfocused`) — return them as named sinks, `{ forLink, forKeyrack, forReplay, forRecord }`

### .names and schema the same pass settles (i006 r011)

- split the `always` section schema from the subject schema: `config.always` then carries no
  `inherit`, and `assertNoInertInherit`'s by-place branch goes away
- one `foci` shape (the Record of `ambient/*` or the array of `asRoleFocusMap`), one
  `isSameFocus` (single-subject vs set equality are two names today), and `asRoleRefsAtFoci` vs
  `asRoleRefsAtFocus` renamed apart

## .why it is not done in this round

**safe, not clean.** it re-types `RoleDelta`, `ActorOndisk.roles` and the hook filters — contracts
the clone, actor and upgrade domains read far beyond this wish — and every persisted read and write
of a roleset. the leak it guards against is closed today at every site, each with a test; the
recompose guards the sites not yet written. a judged deferral, so it carries fulcrum `F10`.

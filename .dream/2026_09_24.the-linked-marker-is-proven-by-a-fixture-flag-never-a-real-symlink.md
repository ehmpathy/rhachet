# 🌙 dream: prove `roles cost --all`'s `(linked)` marker with a real symlink

- kind  = fix
- owner = `ehmpathy/rhachet`
- caught 2026-09-24

## .the cue that fired

`i027`'s `enroll-impl-behavior-intent` lane, nitpick.5:

> Requirement 8's foreign-spec `(linked)` marker in `roles cost --all` has no acceptance fixture
> driving a *real* `roles link`-produced symlink through it … though the audit found the budget
> suite itself *does* use a real symlink for the halt/warn path, so this gap is narrower than it
> first reads: likely just the `roles cost --all` roster-labeling path specifically.

⇒ **the lane narrowed its own item, and the narrowed form is the accurate one.** the path that
carries the weight — the one where ownership **changes a refusal** — is covered by a real
`roles link` symlink in `roles.boot.budget.acceptance.test.ts`. what is not covered is the render
detail one command over.

## .the gap, precisely

requirement 8 rests on one syscall — `lstat().isSymbolicLink()`
(`define.invariant.a-symlink-under-agent-is-foreign`) — and that syscall feeds **two** consumers:

| consumer | what ownership decides | proven by |
|---|---|---|
| `roles boot` / `repo introspect` | 🔴 **the RUNG** — halt on ours, warn on foreign | ✅ a real `roles link` symlink, `roles.boot.budget.acceptance.test.ts` |
| `roles cost --all` | the `(linked)` **label** on a roster row | 🟡 a fixture that stages the shape, never a `roles link` |

⇒ so the invariant itself is proven against reality; the **second consumer** of it is proven against
a staged approximation.

🟡 **checkable, and it is the check that makes this a dream rather than a hunch:** point a sweep at
a tree whose foreign spec is a *regular file* placed where a symlink belongs, and the roster renders
identically. a fixture that cannot tell the two apart cannot prove the marker consults the syscall.

## .the shape of the fix

the pavement already exists — the budget suite does exactly this, one command over:

1. in the `roles cost --all` acceptance fixture, run a **real** `rhx roles link` for one role, so
   `.agent/repo=$slug/role=$name/boot.yml` is a genuine symlink into `node_modules`
2. leave one repo-local spec as a regular file, so the roster carries **both** kinds
3. assert the marker **discriminates** rather than merely appears — the linked row carries
   `(linked)`, the local row does not
4. 🔴 **prove the teeth**: swap the symlink for a regular file at the same path and the linked row
   must lose its marker. a marker that survives that swap consults the path, never the syscall

⇒ step 4 is the one that matters. `i027` shipped a clamp that passed under a reverted repair because
its fixture could not express the difference it meant to catch (`rule.require.clamp-edge-cases`) —
this fix is one `lstat` away from the identical trap.

## .why it is not done in this round

**SAFE ✅ / CLEAN 🔴** — it fails CLEAN, not SAFE.

a real `roles link` in the cost fixture reaches beyond the diff already open: `roles link` writes
into `node_modules` and `.agent/`, so the fixture gains an install-order dependency and a cleanup
contract the extant cost fixtures do not carry. the budget suite pays that cost because ownership
changes its **verdict**; the cost roster pays it for a **label**.

and the harm is bounded in a way the halt's is not:

| if the marker is wrong | what a reader loses |
|---|---|
| in `roles boot` | 🔴 a refusal they cannot act on, or a refusal that never fires |
| in `roles cost --all` | a mislabeled row in a **report that refuses naught** (`S13`) |

⇒ graded `better` under `rule.always.concede-with-a-severity`: no shipped harm to name. a human
reads a roster row and, at worst, opens a file to check whose it is.

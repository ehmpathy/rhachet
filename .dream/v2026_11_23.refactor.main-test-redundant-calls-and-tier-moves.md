## .the gap, precisely

- an expensive call repeated across adjacent `then` blocks (`rule.forbid.redundant-expensive-operations`):
  - `keyrack/fill/fillKeyrackKeys.integration.test.ts` (three `fillKeyrackKeys` calls)
  - `keyrack/getKeyrackKeyGrant.integration.test.ts` (a grant re-read per `then`)
  - `keyrack/adapters/vaults/os.direct/vaultAdapterOsDirect.integration.test.ts`
  - `keyrack/adapters/vaults/os.secure/vaultAdapterOsSecure.integration.test.ts`
  - `keyrack/session/unlockKeyrackKeys.integration.test.ts`
  - `manifest/getRoleRegistryManifest.integration.test.ts` and `.test.ts`
  - `keyrack/daemon/infra/getAllKeyrackDaemonSocketPaths.integration.test.ts`
  - `keyrack/initKeyrack.test.ts`
- unit tests that cross the filesystem (`rule.forbid.unit.remote-boundaries`): `initKeyrack.test.ts`,
  `getRoleRegistryManifest.test.ts`, `_topublish/file-fns/src/getFile.test.ts`,
  `_topublish/rhachet-brains-opencode/src/hooks/config.dao.test.ts`,
  `genBrainHooksAdapterForOpencode.test.ts`

- test seams that prove an external contract against a stand-in (fulcrum F011): the aws.params
  suite's local SSM stand-in, the github-app suites' stub `gh` on PATH, the `promptHiddenInput`
  module mocks, an integration test's swapped `console.log` — each owes a `.mock` / `.why` /
  `.real` note, or a real-service backstop
- `blackbox/.test/infra/genKeyrackRuntimeDir.ts`: the `rk.<slug>` link it makes in the runtime
  base outlives its run; reclaim it in the fixture's teardown

## .the shape of the fix

per suite: lift the call into one `useThen` (or `useWhen` across `when` blocks) and assert on its
shared result; for each fs-bound unit test, rename to `.integration.test.ts`, or inject a fake fs
via context so it stays a unit. one suite per commit, each proven green on its own.

## .why it is not done in this round

it is a restructure of main's tests, out of the temp-dir behavior's bound; to fold it in would be a
large refactor smuggled into an unrelated change.

# 🌙 dream: rhachet-brains-anthropic lets a caller name the claude executable

kind = reseed · owner = rhachet-brains-anthropic · caught 2026-11-02

## .the cue that fired

the director ruled Q2 of `v2026_11_01.fix-tests-mock-the-claude-cli`: the sdk suites take a mocked
repl inside rhachet now, and the exec-path change in brains-anthropic is a later dispatch.

## .the gap, precisely

`rhachet-brains-anthropic@0.4.3` `dist/domain.operations/repls/genBrainRepl.js:182-194` calls the
agent sdk's `query()` with no `pathToClaudeCodeExecutable`, so the sdk always spawns its bundled
cli. a PATH mock of claude cannot reach that path, and rhachet must mock one layer higher (the
`BrainRepl`), which skips the supplier's own code in every sdk pass-through suite.

## .the shape of the fix

`genBrainRepl` accepts an optional executable path (input, or an env var such as
`RHACHET_CLAUDE_BIN`) and forwards it as `pathToClaudeCodeExecutable`. rhachet's sdk suites can then
run the real supplier against the mock claude cli, and the mocked repl may retire.

## .why it is not done in this round

another repo's code, and the director scoped it out of this route.

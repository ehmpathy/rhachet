# 🌙 dream: blackbox tests run under a temp HOME, never the host's

kind = fix (this repo, blackbox test infra)
owner = the director queues it as its own tree
caught 2026-11-04, on `beav/fix-init-never-writes-outside-repo` (PR #669)

## .the cue that fired
the local acceptance run on this branch (`.log/role=mechanic/skill=git.repo.test/what=acceptance/2026-10-26T21-08-30Z.*`)
went 4468 passed / 183 failed. CI on the same head was green. two of the four host causes came
from the test process itself:

- **HOME.** blackbox suites spawn `rhx` with the host `HOME`. on a box whose
  `~/.claude/settings.json` is 0444, the pinned mechanic role init (rhachet-roles-ehmpathy 1.39.3,
  `init.claude.sh` + `init.claude.permissions.sh`) backs the file up twice in one second, and the
  second `cp` fails EACCES. red there: `init.incremental`, `init.delta-live`, `clone`, `enroll`,
  `upgrade`, `rhx`, `actor`
- **socket path.** the keyrack daemon socket lands under the temp repo, whose path in a long-named
  worktree (plus `.temp/genTempDir.symlink`) passes the 108-char `sun_path` cap, so `connect` fails
  `EINVAL`. red there: `keyrack.get`, `keyrack.source`, `keyrack.source.is-optional-if-has`,
  `keyrack.reach`, `keyrack.machine-wide-skips-manifest`

## .the gap, precisely
a blackbox test reads and writes the human's real home, so its verdict depends on the host's
dotfiles. a suite that can go red on a file mode in `~` is not hermetic, and it can also mutate the
human's home (`rule.require.hermetic-tests`, `rule.forbid.reads-outside-the-repo`).

## .the shape of the fix
- `blackbox/.test/infra/genTestTempRepo.ts`: findsert a temp HOME beside each temp repo (via
  `genTempDir`), seed the minimal `~/.claude/settings.json` a test needs, and return it
- `blackbox/.test/infra/invokeRhachetCliBinary.ts` (sync + async) and `spawnRhachetCliBackground`:
  pass `HOME` (and `XDG_CONFIG_HOME`) from that temp dir by default; a test that means to reach the
  host home opts in by name
- socket dir: root the daemon socket at a short path (`$XDG_RUNTIME_DIR`, or a short `os.tmpdir`
  child keyed by a hash), never under the temp repo, so the path stays under 108 chars on any
  worktree name
- clamp: one acceptance case on a temp HOME whose `settings.json` is 0444 and a temp repo under a
  deliberately long path; red on the current infra, green with the fix

# 🌙 dream: decouple the case1 `[t7]` snapshot from its conversation `total`

- **kind** = fix
- **owner** = `ehmpathy/rhachet`
- **caught** = 2026-09-20

## .the cue that fired

a new `when` block was planted under `[case1]` in `blackbox/cli/clone.acceptance.test.ts`. it said
one message to case1's clone — the only act it performs. that reddened a **different** test:

```
● [case1] › [t7] the talk verbs under --output json + --tail › the get json machine shape is locked
    - Snapshot  - 1
    + Received  + 1
    -   "total": 10,
    +   "total": 12,
```

⇒ the new block was relocated to its own `given` (`[case15]`), which restored `total: 10` and
changed no extant assertion. **the order-dependence it exposed was not created by that block and is
still live.**

## .the gap, precisely

`[case1] [t7]` snapshots `clone get --output json --tail 1` stdout. that payload carries a
`total` — the count of messages in the clone's whole conversation — and every `say` that any
`when` under `[case1]` performs increments it.

so the snapshot locks a value that is a **function of how many peer tests ran before it**:

| the order-dependence | the consequence |
|---|---|
| `total` counts case1's prior says | any new `when` under `[case1]` that says reddens `[t7]` |
| the diff names `total`, never the cause | a future author reads a shape drift where the cause is test order |
| a `name://`-scoped run skips `[t7]` | 🔴 the break is **invisible** until a path-wide run |

⇒ the snapshot's own docblock states its purpose as *"the json key-set + the bounded `messages`
shape lock against drift"*. **`total` is payload incidental to that purpose**, and it is the one
field in the capture that no shape change would move.

## .the checkable evidence

- `blackbox/cli/clone.acceptance.test.ts:707-719` — the `[t7]` snapshot + its stated purpose
- `blackbox/cli/__snapshots__/clone.acceptance.test.ts.snap:133` — `"total": 10,`
- measured 2026-09-20: one added `say` under `[case1]` moved it to `12`; a
  `--scope name://t1b` run passed while the `--scope path://clone.acceptance` run failed

## .the shape of the fix

mask the counter, keep the shape. `asSnapshotSafe` already rewrites volatile tokens (a uuid →
`__SERIAL__`, a temp dir → `/TMP_TEST_DIR/`, a date → `__DATE__`), so the counter belongs in the
same family:

```ts
// in asSnapshotSafe, beside the extant masks
.replace(/"total": \d+/g, '"total": __TOTAL__')
```

⚠️ **and it must be argued, never merely applied.** to drop a locked value from a snapshot is a
loosen by default (`rule.forbid.test-intent-violations`), so the change owes an inline statement
that `total` is order-derived rather than shape-derived, plus a field-level assert that keeps the
count checked where it is deterministic:

```ts
// the count is still asserted, at a grain that does not couple to peer tests
expect(parsed.total).toBeGreaterThanOrEqual(parsed.messages.length);
```

⇒ the alternative — one fresh clone per `when` under `[case1]` — decouples it too, and costs an
enroll per block (~15s each across seven blocks). the mask is the cheaper honest fix.

## .why it is not done in this round

the SAFE/CLEAN test (`rule.always.fix-forward-under-scouts-honor`):

| question | answer |
|---|---|
| **safe?** | 🔴 **no.** it drops a locked value from a shipped snapshot, which is a loosen until argued. the argument needs a reviewer, not a fix-forward |
| **clean?** | 🔴 **no.** `asSnapshotSafe` is shared across every blackbox suite, so a new mask there re-snaps files this round never touched |

⇒ dirty on both axes, so it is deferred with a fulcrum beside this dream (`F36`) — the fulcrum
records the **judgment** to defer, this records the **work**.

🟡 the bound on the deferral: the break fires only on a NEW `say` under `[case1]`, and the
path-wide run catches it every time. so it costs a misleading diff, never a shipped defect.

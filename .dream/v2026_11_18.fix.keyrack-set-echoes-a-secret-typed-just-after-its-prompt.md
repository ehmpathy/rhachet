# 🌙 dream: keyrack set echoes a secret typed just after its prompt

- kind = fix
- owner = rhachet (keyrack)
- caught 2026-11-18

## .the cue that fired

`keyrack.aws-params.githubApp` [case4] with the precise pattern `choice: |enter secret for`: the
helper sees `enter secret for XAI_API_KEY: `, waits 50ms, and writes the secret. the output then
reads `enter secret for XAI_API_KEY: xai-fixture-secret` and, on the next line, the 18 mask stars.

## .the gap, precisely

- the clear copy reads as the terminal driver's echo: bytes that arrived while the tty was still
  in canonical mode with echo on. if so, a secret typed or pasted then shows on screen and in
  scrollback. harm: a secret shown in the clear (reputation, security)
- 🔴 seen once, and not reproduced. a second run with timestamps in the real `keyrack set` path
  passed: `setRawMode(true)` landed in the same millisecond as the prompt write, and the answer
  arrived 126ms later, masked. so there is no measured window; the one red may share a cause with
  the box load of that run rather than with the prompt
- `promptHiddenInput` prints and sets raw mode in one synchronous turn, and two stubs that do the
  same show no echo (`blackbox/.test/assets/pty-with-answers.integration.test.ts` [case1], [case3]).
  `withStdoutPrefix` is not on this path; only `keyrack fill` uses it

## .the shape of the fix

- first, find a repro: run [case4] with `choice: |enter secret for` in a loop under load, with
  timestamps on the prompt write, `setRawMode(true)`, and the answer write. no repro in N runs →
  close this dream as not a defect
- if it reproduces: set raw mode BEFORE the prompt text is written, in `promptHiddenInput` and
  `promptLineInput`, so no byte can arrive in canonical mode once the prompt is visible. that order
  is safe to adopt either way, since it closes the window by construction
- clamp: [case4] with `choice: |enter secret for` — red with the window, green after

## .why it is not done in this round

#761 is the acceptance suite's box share. this is a possible keyrack defect with one sight and no
repro, and it owes its own review.

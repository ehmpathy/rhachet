## .the gap, precisely

1. **the carry is silent about what it leaves.** `setRepoActorSettingsCarried` moves the former
   `actor.via.repo=ambient/brain/.claude/settings.of.repo.json` to the `ambient:` actor's slug dir.
   any other entry of the former dir is neither carried nor named in the init report, which the
   wish forbids ("a hand edit under `.agent/` is never silently kept or silently reverted")
2. **the hook sync imports every linked package.** `getLinkedRolesWithHooks(context)` takes no
   roles; the held-role filter runs after the import. so the hot path loads each linked role
   package, held or not, and looks up the brain adapter once per role, not once per brain

## .the shape of the fix

1. in the carry step, list the former dir's entries beside the one carried; for each entry not
   carried, add a report row `⚠️ <name> kept in actor.via.repo=ambient, not carried` with the fix
   (move it by hand, or drop it). clamp: a fixture with a second file in the former dir, snapped
2. give `getLinkedRolesWithHooks` a `roles: RoleSlug[] | null` input; filter the refs before the
   import. hoist the adapter lookup to once per brain. clamp: an unheld role whose package import
   throws must not refuse the sync (the module-load count drops)

## .why it is not done in this round

safe, not clean: (1) changes the init report and moves snapshots across the init suites; (2)
changes the signature of a function four sweeps call. both ride the F21 shape-move change.

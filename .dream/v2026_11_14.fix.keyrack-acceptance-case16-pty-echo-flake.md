- kind = fix

- caught 2026-11-14

## .the cue that fired

a full run of `keyrack.vault.awsIamSso.acceptance.test.ts` failed [case16][t0] (`stdout matches snapshot`)
with one extra line: the answer `1`, echoed by the pty, landed under `└─ choice` ahead of the render's own
`└─ 1`. the case passed alone on the next run.

## .the gap, precisely

the pty answer-feeder sends `1` when it sees the prompt; the terminal echo of that keystroke and the
wizard's own render of the choice race. the snap pins one order, so a load spike flips it. the case's
snap predates #656 and this pr does not change it.

## .the shape of the fix

strip the bare echoed answer line from the captured tree before the snap (the render already shows the
choice), or turn off pty echo in the answer-feeder. then run the case under load ten times to prove it.

## .why it is not done in this round

a test harness defect in a case this pr does not touch; the fix belongs to its own change

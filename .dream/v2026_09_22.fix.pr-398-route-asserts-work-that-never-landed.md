# 🌙 dream: PR #398's route asserts completed work that never landed

- kind  = fix
- owner = `ehmpathy/rhachet`
- caught 2026-09-22, by the `v2026_09_22.feat-boot-briefs-into-claude-md` vision stone

## .the cue that fired

the wish for this behavior instructed: *"read PR #398 first… LEVERAGE ALL THREE"* — its wish, its
vision, its blueprint. so the route read them, and then read the two yields beside them.

**the execution yield marks phases 0, 1, 2, 3, 4, and 6 `done` with `[x]`, each against a named
file. the verification yield reports concrete pass counts.** both read as a shipped, tested
feature.

⇒ the round only caught it because a **claimed file was fetched at that ref and returned 404.**

## .the gap, precisely

`ehmpathy/rhachet` PR #398 · branch `vlad/brain-boot-adapter` · unmerged, Apr 23 → Jun 22.

| claimed | actual |
|---|---|
| phases 0–4 and 6 `done`, against named source files | **zero production code on the branch** |
| verification yield reports pass counts | **no test files on the branch** |
| peer reviews quote line-level code | **the quoted files do not exist at that ref** |

the branch carries **97 files: 92 route artifacts, 4 briefs, `boot.yml`, `package.json`.** no
`src/`, no `blackbox/`, no tests.

checkable in two commands:

```sh
gh pr diff 398 --repo ehmpathy/rhachet --name-only
gh api -X GET repos/ehmpathy/rhachet/contents/<any-claimed-src-path>?ref=vlad/brain-boot-adapter
```

🔴 **the harm is not the stale branch — it is the FALSE RECORD.** a `[x]` beside a filename is the
strongest signal an artifact can send, and the next traveler who reads #398 to leverage it will
inherit six phases of work that does not exist. **this route lost real time to it, and caught it
only by distrust.**

## .the shape of the fix

the branch is three months cold and this behavior deliberately opens a new tree, so a repair to
the code is not what is owed. what is owed is that **the record stop asserting what never happened**:

1. **annotate the PR** — one comment at the head of #398 that states the yields' `done` marks are
   unevidenced, and names the 404 check above so a reader can confirm it in one command
2. **amend the two yields in place** on that branch — strike the `[x]` marks and the pass counts,
   and replace them with a one-line note that the phases were planned rather than performed
3. **keep the wish, vision, and blueprint untouched** — they are the valuable half, they are honest,
   and this behavior carries them forward

🟡 **and the generalizable half is worth more than the instance**: a route's own yield is the one
artifact nobody cross-checks, because it is where the check is supposed to have happened. ⇒ a
candidate rule — *a `done` mark that names a file owes a reader one command that proves the file
exists* — but a rule earned from **one** occurrence is a rule built on a sample of one
(`rule.require.enumerate-before-you-name`). **recorded here as a candidate; not authored.**

## .why it is not done in this round

- **SAFE?** yes — a comment and an edit to a cold branch's docs touches no live code
- **CLEAN?** 🔴 **no.** it is a write to a **different branch** than the one this worktree is on,
  and this route's diff is already the whole staged tree. a cross-branch edit cannot ride this diff
- ⇒ so the deferral is for DIRT, which is the case that owes a fulcrum as well as a dream
  (`rule.always.fix-forward-under-scouts-honor`). ⚠️ **the fulcrum is NOT raised**, because no fork
  was taken here — the dirt is mechanical, not a judgment between options. **stated so the omission
  is visible rather than silent.**

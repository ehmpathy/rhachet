# 🌙 dream: the input band anchors on the `❯` row, never on the last rule pair

kind = fix · owner = rhachet (clone/screen) · caught 2026-11-08

## .the cue that fired

case 4 of `.behavior/v2026_11_08.fix-clone-say-labeled-rule`: a box rule `isRuleRow` cannot parse,
beneath plain rules higher on the screen. the cure for #655 widens the predicate to the one
measured label shape, so this cell still mislocates.

## .the gap, precisely

`getInputBand` (`src/domain.operations/clone/screen/computeCloneInputState.ts`) closes the box on
the last bare rule and opens it on the nearest rule above. any box rule the predicate misses — a
new title shape, a `─` inside a label — makes it open on a plain rule higher up. the transcript
between them then reads as the box: `input-region-dirty`, and the hint offers `--force`, which
writes over the real box. the `--what buffer` read shows the transcript, so a careful foreman
catches it; a hasty one does not.

a second residual, inside the box: a rule row in a human's own draft (`❯ draft`, then a
`──…── Notes ─` row) opens the band below it. the band is then empty and reads `clear`, and a say
writes over the draft. a bare 20-glyph divider in a draft did the same before #655.

## .the shape of the fix

anchor on structure, not on one row's shape:

- find the bottom rule (the last rule row)
- walk up from it to the nearest `❯`-led row, then to the nearest row above that which is a rule
  OR a rule-like row (a long `─` run with any tail)
- or: require the band to hold exactly the `❯` row and its continuation rows; a band whose first
  row is not `❯`-led is not a box → `unrecognized`, never `dirty`

the second form is cheaper and fails closed. clamp: the case 4 screen reads `unrecognized`, not
`dirty`; the draft-with-a-rule screen reads `unrecognized`, not `clear`; every extant
`computeCloneInputState.test.ts` case stays green.

the full cost in view: the anchor also retires the bare/labeled split this fix added
(`isRuleRowBare`, `RULE_ROW_BARE`, the closer filter, about 10 lines), since a band that must open
on `❯` cannot be closed by a status line either.

## .why it is not done in this round

safe, but not clean: it changes the band contract that `computeCloneInputContent` and the
`--what buffer` read rest on, and the multi-line and queue cases need a re-walk. the nano wish
asks for the measured shape only.

# 🌙 dream: the husky practice's commit hooks want named args, `set -eu`, a fixture skip, and a clamp

- kind = reseed
- owner = ehmpathy/declapract-typescript-ehmpathy (practice `husky`)
- caught 2026-11-08

## .the cue that fired

peer review of `ehmpathy/rhachet` @ `beav/fix-keyrack-export-single-flight` read the hooks that
`declapract apply --practice husky` (declapract-typescript-ehmpathy@0.50.0) lays down:
`.husky/check.secrets.sh`, `.husky/check.timestamps.lock.sh`, `.husky/check.timestamps.sh`.

## .the gap, precisely

- `check.timestamps.lock.sh` — `timestamps_lock_halt` reads `$1` / `$2` positionally
  (`rule.forbid.positional-args`), and the hook lacks the `set -eu` its two siblings open with
- `check.secrets.sh` — scans every staged blob with no fixture exemption, so a repo whose tests carry
  the aws doc example key (`AKIA` + `IOSFODNN7EXAMPLE`) cannot commit those tests. this repo renamed
  its staged fixture to a non-key shape; other unstaged fixtures in `src/` and `blackbox/` still
  carry the shape and will refuse the commit that next touches them
- none of the three hooks has a test: no case stages a violation and snaps the halt, and none
  proves a duration-only line in `check.timestamps.sh` passes

## .the shape of the fix

in the practice: named locals in `timestamps_lock_halt`; `set -eu` in the lock hook; a documented
allow for the vendor doc example keys (`AKIA·IOSFODNN7EXAMPLE` and its secret twin); and a hermetic
test per hook — a temp repo stages a violation, runs the hook, snaps stderr and exit 2, and one
stages a clean line to prove exit 0.

## .why it is not done in this round

the hooks are the practice's files; a local edit is overwritten by the next `declapract apply`.

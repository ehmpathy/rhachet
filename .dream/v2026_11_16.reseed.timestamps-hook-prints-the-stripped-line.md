# 🌙 dream: the timestamp hook prints its stripped line, and its lock calls an absent hook changed

- kind = reseed
- owner = declapract-typescript-ehmpathy (the `husky` practice)
- caught 2026-11-16

## .the cue that fired

ehmpathy/rhachet's `.husky/check.timestamps.integration.test.ts` and
`.husky/check.timestamps.lock.integration.test.ts` ran the real hooks:

1. a line with a duration and a stamp halts, as it should, but the hook names the line with the
   duration cut out (`ran , done at <stamp>` for a staged `ran <duration>, done at <stamp>`)
2. with `check.timestamps.sh` deleted, the lock halts with `.husky/check.timestamps.sh was changed`
   above `found: absent (on disk)` — a deleted file reads as an edited one

## .the gap, precisely

1. `check.timestamps.sh` pipes the blob through `sed -E "s/$DURATION_PATTERN//g"`, then `grep -n`,
   and prints grep's match. the line a human reads is the stripped copy, so a search of their file
   for that exact text finds no match
2. `check.timestamps.lock.sh` routes every mismatch, absence included, through one halt whose
   header says `was changed`

## .the shape of the fix

1. keep the strip for the decision, and print the source line: take the line number from the
   stripped grep, then print that line from the unstripped content (e.g. `sed -n "${n}p"`)
2. let the halt take its header verb from the caller: `was changed` for a blob mismatch,
   `is absent` for the absent branch
3. pin both in the practice's own tests (rhachet's [case2] tests of each hook are a template)

## .why it is not done in this round

both files are practice-owned, and the hook is locked by `check.timestamps.lock.sh`; a local edit
of the hook halts every commit. the fix lands upstream, then a practice upgrade carries it here.
rhachet's own test fixture puts the duration at the head of its line, so the render it pins reads
clean meanwhile.

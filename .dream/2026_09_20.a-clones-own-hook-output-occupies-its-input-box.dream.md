# 🌙 dream: part the input BOX from a hook PANEL, so a self-say is not withheld every time

- kind  = fix
- owner = ehmpathy/rhachet
- caught 2026-09-20

## .the cue that fired

the first self-say of the cure run returned `withheld` / `input-region-dirty`, and the debug
capture's grid named why — the clone's **own hook output** sat where its input box belongs:

```
19 │────────────────────────────────────────────────────────────────────────────────│
20 │❯ Using Node v22.21.0                                                           │   ← read as the input box
21 │────────────────────────────────────────────────────────────────────────────────│
22 │  🗿 route complete 🌴🤙               2 c                                       │   ← stophook output
```

`--force` landed the say, and the payload arrived as a real turn. so the capability works and the
**pre-check misreads its own screen**.

## .the gap, precisely

`getInputBand` takes the rows between the **last** pair of full-width rules, and
`computeCloneInputState` then classifies the band's content: a placeholder reads `clear`, any other
text reads `dirty`.

a session that ran a `SessionStart` or `Stop` hook has that hook's banner rendered between a rule
pair. so the band the classifier finds is a **hook panel**, and its content is text — which is
`dirty` by construction, forever, for the life of that screen state.

### why this bites the SELF case hardest

| the caller | how often the hook panel is on screen |
|---|---|
| a **peer** clone, freshly enrolled | rarely — a fresh session's foot is a real, clear box |
| **self** | routinely — a driver's own session has run a boot hook and a stophook by definition |

⇒ so the pre-check that exists to protect a human's half-typed text fires on a screen that holds no
human text at all, and it fires on the one caller that can never avoid it.

### 🔴 why it is worse than a false positive

> **a check that fires every time teaches the caller to always `--force`.**

and `--force` is not scoped to this misread: it overrides the `input-region-dirty` refusal outright.
so a caller who learns *"self-say needs --force"* now paves over a **genuine** dirty box too — a
human's real half-typed line — which is the exact defect
`1.vision.experience.case=2.refuse-to-paste-over-a-human-mid-type.md` exists to forbid.

⇒ the safety check is not merely noisy. **it defeats itself**, and the cure run is what proved it.

## .the shape of the fix

the classifier must part a **box** from a **panel**, and both sit between rule pairs — so the
discriminator cannot be the rules alone:

1. 🟡 **measure first, from a real capture.** the `5.1.execution.research.screens.captured.md`
   corpus already holds rendered screens; the fix needs one that carries a hook panel AND a live box
   at once, to know whether the box is above, below, or absent while a panel renders
2. candidate discriminators, cheapest first:
   - the **`❯` position** — a box's marker leads its row; a panel's banner may carry `❯` incidentally
     (the grid above shows a `❯`-led node-version line, so this alone is insufficient)
   - the **placeholder grammar** — a real box in its clear state renders `Try "…"`; a panel never does
   - the **band count** — take the LAST band that satisfies a box shape, rather than the last band
     at all
3. the read belongs in `computeCloneInputState`'s own band selection, never in a caller — the
   classifier owns the question *"which band is the box?"*
4. the clamp grain is **unit**, over a captured grid fixture, plus one acceptance row that self-says
   with a hook panel live and asserts `input: 'clear'` with no `--force`
5. ⚠️ **the hazard: do not widen `clear`.** a predicate loose enough to call a hook panel `clear`
   may also call a human's half-typed line `clear`, which ships the clobber defect. the clamp must
   keep `case=2`'s dirty row red under the new read

## .why it is not done in this round

- **SAFE?** 🔴 no. `computeCloneInputState` gates **every** say's pre-check, so a wrong predicate
  either withholds every dispatch (deaf clone) or pastes over a human's text (the clobber defect
  this wish was partly written to close)
- **CLEAN?** 🔴 no. it needs a new capture, a band-selection change, a unit fixture, and an
  acceptance row — and it must be argued against `case=2`'s assertion rather than beside it
- and the capability it blocks is **already reachable** today via `--force`, so the round's own gate
  measures no defect here

# 🌙 dream: tier-3 live-brain suites run on a cadence

kind = feat · owner = rhachet · caught 2026-10-31

## .the cue that fired

peer review of `v2026_10_30.fix-no-test-bills-the-anthropic-api` (5.1, i006 r010, r011) noted that no workflow sets `BRAIN_LIVE_SCOPE`, so tier 3 runs only when a seat targets it.

## .the gap, precisely

the 19 gated suites prove contracts against a real brain, and no schedule runs them. a supplier change can break one, and it stays unseen until a seat next targets that suite.

## .the shape of the fix

- a `workflow_dispatch` plus a weekly `schedule` workflow that runs `rhx test.brain.live` per tier, on haiku
- a spend bound per run, from the same measure that holds tier 2 under $0.50
- the commander funds it, or declines it, by name; the spend is his to set

## .why it is not done in this round

a scheduled run is new spend, and the rescope set the live budget at tier 2. a cadence is the commander's call on money, not a driver's.

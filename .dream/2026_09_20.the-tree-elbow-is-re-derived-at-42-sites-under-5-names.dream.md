## .the shape of the fix

per site, one call:

```ts
const elbow = getOneTreeElbow({ index: i, length: rows.length });
```

⚠️ **it is NOT a find-and-replace, and the reason is measured rather than asserted.** the glyph
pair is not one literal — it is **five**, and two sites need a signature the transformer does not
have:

| literal | width | sites |
|---|---|---|
| `'└─'` / `'├─'` | 2 | the majority |
| `'└──'` / `'├──'` | 3 | `getAvailableBrainsInWords.ts:61` · `invokeRolesCost.ts:124` · `execNpmInstall.ts:129` |
| `'└── '` / `'├── '` | 4, one space at its end | `invokeList.ts` ×4 · `formatCostTree.ts:79` |
| `'   └─'` / `'   ├─'` | 2, 3-space indent | `invokeKeyrack.ts:408, 2255` · 4 clone views |
| `'   │  └─'` / `'   │  ├─'` | 2, nested continuation | `invokeKeyrack.ts:2398` · `invokeInit.ts:143` |

🔴 **and `formatCostTree.ts:79` is a THREE-way** — `isRoot ? '' : isLast ? '└── ' : '├── '`. the
transformer as declared returns one of two glyphs and has no root arm, so that site needs either a
caller-side root check or a widened signature. **a mechanical rewrite would flatten the root case
into an elbow and change the render.**

⇒ so the repair is ~42 hand edits, plus a decision about whether width and indent belong **in** the
transformer (`getOneTreeElbow({ index, length, width: 3 })`) or stay at the call site. that
decision is the whole of the work; the glyph itself is the easy half.

### the clamp it owes

the extant snapshots already pin every one of these renders — that is what makes the sweep safe
rather than what makes it cheap. 🟡 **no new clamp is owed per site**; what is owed is a **run of
the suites that own those 27 files**, which is most of the repo's acceptance tier.

## .why it is not done in this round

the SAFE/CLEAN test (`rule.always.fix-forward-under-scouts-honor`):

| question | answer |
|---|---|
| **SAFE?** | 🟡 **mostly** — the 2-char sites are a pure substitution, and the snapshots pin them. but `formatCostTree.ts:79`'s root arm and the five width variants each need a judgment, so it is not uniformly safe |
| **CLEAN?** | 🔴 **no.** 42 sites across **12 subsystems** this behavior never opened — keyrack, clone, link, init, upgrade, cli list, cost, context, skill list, repo compile, manifest, enroll |

⇒ the six sites this behavior's diff already owned were repaired in-round, because the budget
readout is one of them. the other 42 ripple into a diff a budget behavior has no business to
carry — which is the CLEAN answer, and it is recorded in `F26` rather than left as a shortcut a
reader must infer.

🟡 **and the deferral is a judgment about ripple cost, so it owes this dream AND a fulcrum** —
`rule.always.catch-dreams-for-followups`: *a dream alone reports the work and hides the call.*

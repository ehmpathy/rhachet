# 🌙 dream: `git.commit.push --auth as-human` must parse the pr number it opened

kind = reseed · owner = ehmpathy/rhachet-roles-ehmpathy (role=mechanic) · caught 2026-11-27

## .the cue that fired

`rhx git.commit.push --mode apply --auth as-human` pushed and opened pr #847, then printed
`pr: pr #847` / `1 (created)` across two lines, and its watch step refused:
`--which must be a pr number; got '847\n1'`.

## .the gap, precisely

on the as-human path the pr number is read with a stray second line, so the pr watch the skill
promises never starts, and the pr line in the tree breaks its shape.

## .the shape of the fix

take only the first integer of the `gh pr create` / lookup output (or read `--json number`),
then pass it to `git.pull.watch set`. clamp: a case on the as-human path that asserts the watch
is set and the tree prints `pr: #N (created)` on one line.

## .why it is not done in this round

the skill is owned by another repo; a tree adopts only what is scoped to itself.

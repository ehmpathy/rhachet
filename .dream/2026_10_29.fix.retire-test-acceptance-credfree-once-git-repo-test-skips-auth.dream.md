review of ehmpathy/rhachet#649 (https://github.com/ehmpathy/rhachet/pull/649#discussion_r4407406485)

## .the gap, precisely

`.agent/repo=.this/role=any/skills/test.acceptance.credfree.sh` exists only because
`rhx git.repo.test --what acceptance` unlocks the whole `test` keyrack env first, so one lapsed sso
key halts every shard, credential-free ones included. it is a second path to run the acceptance
tier, beside the paved one.

## .the shape of the fix

1. wait for ehmpathy/rhachet-roles-ehmpathy#1198 (`git.repo.test --auth skip`) to ship
2. upgrade the mechanic role here
3. check the new mode covers what the skill does: no unlock, `CLAUDE_CONFIG_DIR` unset as ci runs,
   a kept log, `--resnap`
4. delete the skill, and point any brief that names it at `git.repo.test --auth skip`

## .why it is not done in this round

the replacement does not exist yet; it is another repo's work (#1198).

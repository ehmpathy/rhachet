# 🌙 dream: sedreplace's multi-line `--old @stdin` matches far more than the block it was handed

- kind = reseed
- owner = ehmpathy/rhachet-roles-ehmpathy, role=mechanic, skill `sedreplace`
- caught 2026-11-21

## .the cue that fired

in plan mode, a multi-line block piped as `--old @stdin` reported 113 matched lines in one run and 61 in another, where the block occurred once. the apply was never run; the edits went through Edit instead.

## .the gap, precisely

a multi-line `--old` from stdin does not match as one literal block. its plan shows a match count far above the block's own line count, so an apply would rewrite lines outside the intended span.

## .the shape of the fix

- match a multi-line `--old` as one literal string (escape it fully; treat newlines as literal), never line by line
- in plan, report matches as block occurrences, and refuse an apply when a multi-line block matches zero or more than `--expect N` times
- a clamp: a fixture file with the block once, plus lines that share its first line; the plan must report 1

## .why it is not done in this round

the skill ships from another repo; a fix here would be overwritten at the next `rhx upgrade`.

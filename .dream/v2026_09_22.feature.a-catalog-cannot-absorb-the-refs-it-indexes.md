# 🌙 dream: a catalog indexes a set, and the boot still pays a ref line for every member of it

- **kind** = feature
- **owner** = `ehmpathy/rhachet`
- **caught** = 2026-09-22

## .the cue that fired

a budget halt's first remedy is **catalogize** — *"replace a set with one catalog that indexes
it"*. an author takes it, writes the catalog, and the payload **does not shrink**: every member of
the catalogized set still emits its own `<brief.ref path="…"/>` line, because the renderer has no
way to learn that the catalog now stands for them.

⇒ **the remedy the halt recommends first is the one remedy the renderer cannot honor.**

## .the gap, precisely

measured on `repo=.this/role=any`, 2026-09-22:

| quantity | value |
|---|---|
| the ref roster | **276 lines = 8,404 tokens** (57% of the payload) |
| 🔴 of which `domain.terms/term=*` | 🔴 **~200 lines ≈ 6,080 tokens** (~41% of the whole payload) |
| what one catalog would cost instead | one `say` entry — a table of ~200 rows, ~2,000 tokens |

> 🔴 **one catalog replaces ~200 ref lines, and saves ~4,000 tokens on a single boot** — more than
> every resident brief in the role combined.

## .the shape of the fix

**the catalog declares its own set, in frontmatter.** the set is a fact about the catalog, so the
catalog is where it belongs — a declaration in `boot.yml` would be a second, independently-edited
statement of one set, and the two drift the moment a term is added
(`rule.require.a-cue-is-not-a-claim`).

```md
---
catalogizes:
  - 'briefs/domain.terms/term=*'
---

# catalog.of=terms

| term | boundary | what |
|---|---|---|
| `absent` | any | a resource that is not there, where one was expected |
| …         |     |  |
```

the renderer then:

1. expands each `catalogizes` glob **against the role dir** — the same base every `boot.yml` glob
   uses, so an author learns one rule rather than two
2. **absorbs** every match: it emits no ref line of its own
3. **strips the frontmatter** from the emitted payload — it is a directive, never content
4. applies only when the catalog itself is in `say`. a catalog that is merely reffed indexes no
   resident file, so it may absorb naught

⇒ the set stays addressable, because the catalog's rows carry the paths. that is what makes the
remedy **lossless** rather than an elimination under a nicer word.

## 🔴 .the hazard that must be guarded before it ships

> **an absorbed file the catalog does not actually list is a SILENT DELETION.**

the glob says the file is catalogized, so no ref line is emitted; the catalog's body never names
it, so no row points at it. **the file leaves the payload and no record says it existed** — exactly
the shape `rule.forbid.failhide` names, and the author sees only that the boot got cheaper.

⇒ so absorption owes a verify, and `repo introspect` is where it belongs (a fifth peer beside
`assertRegistryHasNoOrphanBriefs`, which already grades the inverse relation):

```
every path a `catalogizes` glob absorbs MUST appear in the catalog's own body, or the build refuses
```

## .the other edges, stated

| edge | the call |
|---|---|
| a brief whose body opens with `---` (a markdown rule) | frontmatter is recognized only at byte 0, closed by a second `---`, and parsed as yaml. a rule at the body's head is a **second** `---`, so it cannot be misread as an opener |
| a file both **absorbed** and `say` | `say` wins. an author who explicitly asked for it resident gets it resident |
| a file both **absorbed** and `not` | no conflict — both remove it from the payload |
| two catalogs that absorb one file | absorb once, and the verify above must pass for **both**. a file indexed twice is not a defect |
| the budget gate | unaffected by order — it counts the final emitted buffer, so absorption is already priced when the gate reads it |

## .why it is not done in this round

**not SAFE.** absorption changes what a boot emits for every role that grows a catalog, and the
silent-deletion hazard above needs its guard **in the same change** — a half of this feature is
worse than none of it.

**not CLEAN.** it adds a **frontmatter parse to the say path**, which today reads bytes and naught
else (`getOneBootSource`), and it adds a new verify at `repo introspect`. two surfaces, neither of
which this behavior's diff has open.

⇒ 🟡 **and the urgent half lands in this round by a cheaper route.** `not:` — a third curation list
beside `say` and `ref` — lets an author drop the term roster from the payload outright, with no
parse surface and no new verify. that closes the 6,080-token bleed **today**; it is merely lossy
where catalogize is lossless, which is precisely the difference the halt's own ladder is sorted by.

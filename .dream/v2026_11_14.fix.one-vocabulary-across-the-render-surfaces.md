# 🌙 dream: one vocabulary across the init, upgrade, boot, enroll and run renders

kind = fix · owner = rhachet · caught 2026-11-14

## .the cue that fired

the 5.3 level-3 lane `enroll-verif-snapshot-blemishes` (i004) read every new mods snapshot side by
side. it found that one event (a refused mod, or a drifted pin) reads differently on each surface.

## .the gap, precisely

- **refusal shape.** `init` and `upgrade` render a tree (`✗ … not written`, `mod =`, `subject =`,
  `did you mean =`, `fix =`). `roles boot`, `enroll` and `run` render prose, a json dump, and a
  comma-joined `[args]` echo that a human cannot paste back.
- **`subject =`.** the key holds a path, `boot.yml`, or `rhx flags.raise`, which collides with
  "subject mode".
- **drift.** the upgrade readout says `mods = 0.9.0` / `now = 1.0.0`. the boot notice says
  `@0.9.0 (installed 1.0.0)`.
- **failed init.** stdout ends on `✨ N role(s) initialized` while stderr says
  `✗ brain://repo=ambient/boot.md not written` and the exit is 2.
- **tokens.** the sweep and the boot price one role differently: 196 vs 440 with no mod (roles.mods
  acceptance case3 vs case12).

- **blank lines.** `invokeUpgrade.ts` prints a bare `console.log('')` on each side of a summary
  that is empty when no role, brain or self upgraded, so three blank lines stack before the next block.
- **empty sweep.** `asBootCostSweepReachLines` emits a `│` spacer under the header even when no
  roster row sits above it (`rule.forbid.treestruct-header-gap`).

## .the shape of the fix

1. one `asRefusalTree` transformer that every surface renders through. the `[args]` echo becomes a
   pasteable command line.
2. rename the `subject =` key per sense (`path =`, `spec =`, `fix =`).
3. one drift phrase, `pinned @0.9.0, installed @1.0.0`, on both surfaces.
4. hold the `✨ initialized` line until the brain block is written, or replace it with a `✗` summary
   when it is not.
5. print the second blank only when the upgrade summary printed a line; emit the sweep `│` only
   below a row.
6. trace the token gap: the boot likely prices the rendered say-set and the sweep the raw globs.
   pick one and document it.

## .why it is not done in this round

it is safe but not clean. each item rewords surfaces that predate #702 and moves snapshots that
have no tie to mods. fulcrum F28 records the decision to defer.

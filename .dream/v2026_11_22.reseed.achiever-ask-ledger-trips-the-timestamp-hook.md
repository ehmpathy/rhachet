# 🌙 dream: an ask the achiever records verbatim can make the branch uncommittable

- kind = reseed (bhrain/role=achiever) + this repo's husky timestamp check
- owner = bhrain achiever role; this repo's pre-commit
- caught = 2026-11-22

## .the cue that fired

`git.commit.set --mode apply` refused: `timestamps are forbidden in tracked files` at
`.behavior/<route>/.goals/asks.inventory.jsonl:5` — the achiever's verbatim record of a peer ask
that named a deadline with a clock time.

## .the gap, precisely

- the achiever writes every peer ask, verbatim, into `.goals/asks.inventory.jsonl`, a tracked file
- the husky check forbids any clock time in a tracked file
- the goal guard forbids a driver to edit or unstage any `.goals/` path
- ⇒ a peer who writes a clock time in an ask makes the branch uncommittable, and no driver lever
  can repair it

## .the shape of the fix

one of: the achiever masks clock times in its verbatim record (keep the date, drop the time); or
the ledger is gitignored as local state; or the husky check exempts the achiever ledger by path.
the first keeps the ledger auditable and the hook universal.

## .why it is not done in this round

the fix lives in another repo's role (achiever) or in a repo-wide hook policy, and the guard
forbids the one local edit that would clear it.

# 🌙 dream: give `--what acceptance` an impact scope, so it is not silently a `--thorough` run

- kind = fix
- owner = ehmpathy/rhachet
- caught = 2026-09-16

## .the cue that fired

`rhx git.repo.test --what acceptance --against local --env test --mode apply` — no `--scope`, no
`--thorough` — ran for **37+ minutes** and was still inflight. the same command shape for the
other three tiers returns in seconds:

| tier | suites matched | wall |
|---|---|---|
| unit | 32 | **5s** |
| integration | 25 | **31s** |
| acceptance | *(all 134)* | **37min+, unfinished** |

## .the gap, precisely

`rule.forbid.local-full-test-sweeps` rests on a stated premise:

> *"`git.repo.test` selects the impacted files for you. that is its default behavior — it matches
> the files your change touched and runs those suites. ⇒ you do not need to reason about blast
> radius."*

that premise holds for unit and integration, and **fails for acceptance** — for a structural
reason, not a bug in the matcher:

- a blackbox acceptance suite does not import the module you changed
  - it spawns the **built binary** (`invokeRhachetCliBinary` → `bin/run`)
- ⇒ so every one of the 134 suites depends on **one** artifact
- ⇒ a change to *any* `src/` file that reaches the binary marks *every* acceptance suite impacted
  - which is correct as a dependency claim, and useless as a scope

⇒ **the tier that most needs an impact bound is the one tier that cannot compute one.** so
`--what acceptance` is a `--thorough` run wearing the default flag, and the rule's protection —
*"`--thorough` on a local run = blocker"* — never fires, because nobody typed it.

### the costs it charges, unasked

- **~40+ min of a human's minutes**, for the same result cicd produces on push
- 🔴 **billed brain clones.** the tier includes 6 `*.realbrain.acceptance.test.ts` suites, each of
  which spawns real claude-cli clones. a local full acceptance run is the single most expensive
  command in the repo, and its cost is invisible at the call site
- **no new fact**, where the two suites that actually grade the change were already run scoped and
  green (`enroll.acceptance` 114/114, `clone.acceptance` 154/154)

## .the shape of the fix

the matcher cannot rank 134 identical dependency claims, so the scope must come from elsewhere.
three candidates, cheapest first:

1. **a `realbrain` opt-in.** the 6 realbrain suites are the whole cost tail and the only billed
   ones. default `--what acceptance` to EXCLUDE them, and require `--realbrain` to include them.
   one flag, and the tier becomes affordable by default
   - ⚠️ must NOT become a silent skip — `rule.forbid.faked-or-quarantined-acceptance`. the skill
     prints the excluded count and the flag that includes them, so the omission is on the page
2. **scope by the CLI SURFACE the change touched.** a change under `src/contract/cli/CloneCommand*`
   maps to `blackbox/cli/clone.*`; one under `KeyrackCommand*` maps to `blackbox/cli/keyrack.*`.
   a coarse path→glob table, declared once, beats a dependency graph that cannot discriminate
3. **make the rule's premise honest for this tier.** if neither bound lands, then
   `rule.forbid.local-full-test-sweeps` owes acceptance an explicit carve-out that says *"a local
   acceptance run is a full sweep; scope it by hand or leave it to cicd"* — so a driver is not
   told a bound exists that does not
   - ⇒ this one is the floor, and it is cheap. it is also the one that prevents the next driver
     from spending the same 40 minutes for the same reason

⇒ **(1) and (3) together are the small, honest round.** (2) is the real fix and the larger one.

## .why it is not done in this round

- the repair is to `git.repo.test`, a `role=mechanic` skill — **a different bounded context** from
  this wish (`v2026_09_11.fix-clone-say`, a clone-say read channel)
- it changes the **default scope of the repo's most expensive command**, which every driver and
  every route depends on. that default is a call worth the wisher's eyes, not a ride-along
- the honest clamp for it needs its own dogfood: prove the default now excludes the realbrain
  suites AND that it says so in stdout

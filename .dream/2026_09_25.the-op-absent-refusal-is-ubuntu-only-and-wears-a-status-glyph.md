## .the gap, precisely

### 1. the refusal wears a STATUS glyph where a blocked root is owed

within one snapshot file, two refusals of the same class render two ways:

```
🔐 keyrack set
   └─ ✋ ConstraintError: 1password exid must be a secret reference uri (op://vault/item/field)
      ├─ exid: invalid-exid-format
      └─ ran: keyrack set --key … --vault 1password --exid invalid-exid-format --json

-- vs, same file, same failure family --

🔐 keyrack set
   └─ ✗ op cli not found

   to install on ubuntu:
   1. install 1password app:
      …
```

both exit **2**. both are constraint refusals. per `rule.require.keyrack-emoji-palette`, `✗` is a
**status leaf** — *"this step failed"* — never a blocked root; and per
`rule.require.unabridged-error-prefix`, a blocked root pairs its glyph with its **error class
name**.

🔴 **the sharp consequence, and it is the half a glyph argument would miss: the `✗` form cannot be
grepped for its error class.** a caller who wants every `ConstraintError` this cli can emit finds
one of these two and not the other.

⇒ and the second render abandons the tree entirely after its root — a loosely-indented numbered
prose block where its peer carries fact leaves and a `ran:` echo.

### 2. the install route is ubuntu-only, with no platform gate

the same block offers four numbered steps of `curl` · `gpg --dearmor` ·
`dpkg --print-architecture` · `apt install`, **with zero platform check**. it fires on any host
where `op` is absent — macOS and non-debian linux included.

that is `rule.forbid.host-specific-cures-in-hints` exactly: *a hint that names a command absent on
a host its row reaches, with no clamped premise*. a caller on macOS meets a recipe they cannot run,
inside a refusal whose whole job is to name the fix.

## 🔴 .the shape of the fix — the blueprint is already in this repo

**`install.age.sh:145-153`, added by this same behavior, demonstrates the correct pattern**: it
checks `command -v apt-get` first and names a `brew install age` fallback plus an upstream link
when it is absent.

| the repair | what it takes |
|---|---|
| 1. the root | `└─ ✋ ConstraintError: op cli not found` — glyph plus class name |
| 2. the body | fact leaves plus a `ran:` echo, in the shape its peer at `[case1]` already holds |
| 3. the route | gate on `command -v apt-get`; name a `brew install 1password-cli` fallback and the upstream link otherwise |
| 4. the pin | resnap `keyrack.vault.1password.acceptance.test.ts` `[case6]` |

# 🌙 dream: modal detection is structural (Q8-grounded), over the 4-marker phrase whitelist

- **kind**: feat
- **owner**: ehmpathy/rhachet (this repo)
- **caught**: 2026-09-14
- **fulcrum**: F11
- **gates**: case=6 / V3 — a say must never answer a permission prompt

## .the cue that fired

r007 (arch-hazards-behavior) b2, restated by r010 (behavior-intent) b2 + b3: `computeCloneInputState`
detects a modal by a 4-marker phrase whitelist (`❯ \d+.`, `❯ Yes,/No,`, `Do you want to`, `to confirm`).
a real permission prompt whose text sits OUTSIDE those four markers reads as `focus: 'input'`, so a
say's `\r` answers a tool call no human approved. the whitelist is a best-guess made with NO measurement
of a real claude-code modal grid.

## .the gap, precisely

the classifier's modal branch is grounded in guessed marker phrases, never in a captured real modal.
two unknowns remain unmeasured:

1. **Q8** — the actual rendered grid of a real claude-code permission prompt (the option rows, the
   footer, the box relationship) vs a real clean-box grid. without it, no structural signal (e.g. "an
   option menu ABOVE the input band" vs "the band itself") can be validated — only phrase-matched.
2. the through-the-brain proof: `clone.screen-dogfood.realbrain.acceptance.test.ts` captures idle/dirty/
   queued/multi-line screens but never drives a real claude to a permission prompt, so V3 has zero
   live-brain proof — only the synthetic `[case10]` modal fixture (author-written screen + author-written
   whitelist, graded against each other).

## .the shape of the fix

1. a realbrain capture that provokes a REAL permission prompt: enroll a clone whose claude requires
   approval for some tool (e.g. a bash tool call), say a message that triggers it, capture the rendered
   grid via `clone get`. this is the Q8 measurement.
2. replace the 4-marker phrase whitelist with a STRUCTURAL signal read off the measured grid — a signal
   independent of the prompt's text (an option menu region distinct from the input band).
3. a realbrain acceptance test that dispatches a say at the live prompt and asserts `withheld` /
   `modal-holds-focus`, so the `\r` never reaches the tool call (the V3 safety proof).
4. keep the phrase whitelist as a fallback for grids the structural signal cannot classify, so a widened
   set never regresses to deaf-always.

## .why it is not done in this round

it clears the ONE bar `rule.forbid.deferrals-short-of-a-dedicated-pr` leaves open — a change gated on a
measurement whose capture is itself new dedicated-PR infrastructure, not a quick additive test:

- the Q8 capture is not a parameter tweak — it needs a realbrain harness capability that does not exist:
  drive a live claude to a DETERMINISTIC permission prompt (configure the clone's approval policy, provoke
  the exact tool call, catch the modal before it times out), against an EXTERNAL product's interactive
  modal whose shape this wish pins to a version. that is new acceptance infrastructure with its own review
  surface (modal provocation determinism, version-pinned grid).
- the structural signal cannot be designed before the grid is measured — a guessed structural default is
  either the markers again or a deaf-always clone (the fulcrum's own conclusion).
- ⇒ it fails the CLEAN test (`rule.always.fix-forward-under-scouts-honor`): the rework ripples into the
  classifier, the realbrain harness, and a new safety acceptance test, and must not land late in this
  stone with no independent review. the decision to defer is recorded as fulcrum F11.

**and the 4-marker whitelist is defensible to ship now:** the vision's synthetic `[case10]` proves the
whitelist DOES refuse the modal shapes it knows, with NO force path (V3 holds for those). the residual —
a prompt outside the four markers — is a bounded, named hazard, safer than the pre-wish state (a say that
answered EVERY prompt), and the structural upgrade is a follow-on PR, not a gap this PR leaves broken.

## 🟡 STATUS 2026-09-18 — three of four steps DISCHARGED, in this stone

the deferral above rested on one premise: *"the structural signal cannot be designed before the grid is
measured."* that premise was then **removed** — a live modal was measured at the 5.3 gate, so the design
became available and steps 1, 2 and 4 landed here rather than in a follow-on PR.

| step | state | what closed it |
|---|---|---|
| 1 — the Q8 capture: a real modal's rendered grid | ✅ **done** | a live modal measured against a real peer, which is what made the rest designable |
| 2 — a STRUCTURAL signal over the phrase whitelist | ✅ **done** | `MODAL_FOOTER_MARKERS` — a selection widget's own footer, read BENEATH the input band |
| 3 — a realbrain say at a LIVE prompt that asserts `withheld` / `modal-holds-focus` | 🔴 **open** | the one step still owed; it needs deterministic modal provocation, which remains new harness capability |
| 4 — keep the phrase whitelist as a fallback | ✅ **done** | `MODAL_MARKERS` is retained and scanned first, so a widened set never regresses to deaf-always |

### 🔴 why step 2 was a SAFETY fix, not a refinement

the measurement found a hole the whitelist could not have covered, because the whitelist read the wrong
rows:

- a selection modal draws a rule pair around **its own option list**
- the box locator takes the **LAST** rule pair, so it captured the **MENU** as the input box
- the modal scan excludes the box band — so it excluded exactly the rows that carry the `❯ 1.` marker

⇒ **the modal's own option menu was read as a clean input box.** the footer detector closes it: it reads
the rows BENEATH the band, where a widget's confirm chrome sits. that is structural — it does not depend
on how the prompt is phrased.

🟡 `Esc to cancel` is deliberately NOT a footer marker — a cancel hint is plausible on a non-modal surface
(a turn in flight offers an interrupt), and a **false `modal` is the worse error**, since
`modal-holds-focus` has no force path and would make a clone deaf with no override.

### the clamp

5 footer-scan tests, mutation-proven — 2 failed when the detector was disabled.

⇒ so V3 now holds on a **measured** structural signal rather than four guessed phrases. what step 3 still
adds is the through-the-brain proof, and until it lands V3's live-brain evidence remains the gap this
dream stays open for.

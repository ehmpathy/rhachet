# 🌙 dream: this repo's pinned hook adapter files a `when: 'after'` hook under PreToolUse, and re-syncs it every run

kind = fix (this repo: the `rhachet-brains-anthropic` devDependency pin, and the legacy acceptance scenes)
owner = whoever bumps the anthropic adapter pin
caught 2026-10-26, on `beav/fix-init-never-writes-outside-repo`, at 5.3's frictionless playtest

## .the cue that fired
a dogfood `npx rhx init --hooks` from this repo's root, run three times, printed
`ehmpathy/mechanic → anthropic/claude/code: ~1` and `✨ hooks / └─ 1 updated` on every run, while
`settings.of.repo.json` ended with the same sha256 each time (`rhx file.fingerprint`).

## .the gap, precisely
- this repo pins `rhachet-brains-anthropic@0.4.3`. its `translateHookToClaudeCode` maps
  `onTool` to `PreToolUse` whatever `filter.when` says, and `translateHookFromClaudeCode` reads
  back `filter: { what }` only (`node_modules/rhachet-brains-anthropic/dist/domain.operations/hooks/translateHook.js`)
- the mechanic role declares `posttooluse.guardBorder.onWebfetch` with
  `filter: { what: 'WebFetch', when: 'after' }`
- so 0.4.3 installs that hook as a **PreToolUse** hook (the wrong moment: it runs before the fetch
  it is meant to inspect), and on readback the `when` is gone. rhachet's comparator
  (`syncOneRoleHooksIntoOneBrainRepl.ts`, `asHookComparable`) drops only `when: 'before'`, so the
  pair never compares equal: one upsert and one `~1` per run, forever
- not caused by this branch: the comparator and the adapter are untouched here. before this
  branch, the same adapter wrote through the grove arrow, so on this box (a 0444 home) init could
  not finish at all, and the gap was hidden behind #661

## .the shape of the fix
1. bump the devDependency to an adapter that maps `when: 'after'` to `PostToolUse` and reads it
   back (the in-repo source at `src/_topublish/rhachet-brains-anthropic` is the place to confirm)
2. the legacy acceptance scenes (`init.hooks.outside-repo` case10, 11, 13) link the root's
   installed adapter and assert it is 0.4.3. after the bump they need 0.4.3 from elsewhere: an
   aliased devDependency (`"rhachet-brains-anthropic-legacy": "npm:rhachet-brains-anthropic@0.4.3"`)
   that `setLegacyAnthropicAdapter` links under the real name
3. optional, upstream: a legacy adapter that cannot express `when: 'after'` should refuse that
   hook loud rather than file it on the wrong event

by the director's instruction), and it rewires the legacy scenes this route's clamp rests on.

# 🌙 dream: one haiku factory for live-brain tests, so the model bound holds by structure

- kind = feat
- owner = rhachet
- caught 2026-10-31

## .the cue that fired

a peer review counted about ten places that build the same live repl by hand, and the brief's
"no model past haiku" is held only by review.

## .the gap, precisely

- `actorAsk`, `actorAct`, `genActor.brain.{caseCollocated,caseAskable,casePublished}` and
  `invokeAct.live` each spell `genBrainRepl({ slug: 'claude/code/haiku' })`, an
  `as unknown as BrainRepl` cast, and `asBrainReplBounded` with `BRAIN_REPL_BOUND_MS`
- `enrollCloneHarness.ts`, `brainDirBootJourney.ts` and `brain-dir-boot.journey` pin `'haiku'` as
  a bare literal
- a change to any one to a larger model passes every check but review

## .the shape of the fix

1. `src/.test/infra/genBrainReplHaiku.ts`: the slug, the bound, the one cast, documented
2. a `BRAIN_LIVE_MODEL` constant read by the harnesses
3. a registry marker for a `genBrainRepl(` call, or a `claude/code/` slug other than haiku,
   outside the factory, so the clamp names a larger model
4. the six suites and three harnesses move to it

## .why it is not done in this round

it touches nine live files whose real-brain runs cost the credit to re-prove, and the bound is
already held at review; the clamp work this round closed reach, not model size.

# 🌙 dream: the mechanic init note names a clone's "config dir"

- kind = reseed
- owner = ehmpathy/rhachet-roles-ehmpathy (role=mechanic, the claude permissions init)
- caught 2026-11-17

## .the cue that fired

a resnap of `blackbox/cli/init.incremental.acceptance.test.ts`, moved by the role package bump
(`rhachet-roles-ehmpathy` 1.39.7 → 1.43.0), printed a new line from the mechanic init:

```
note: this clone's config dir is $REPO_ROOT/.agent/.actors/actor.via.repo=ambient/brain/.claude; …
```

## .the gap, precisely

a clone has no config dir; it reads its actor's brain dir (`rule.forbid.clone-config-misnomer`). the
path the note prints is the repo actor's brain dir, shared by every clone of that actor. the term
asserts the per-clone grain the actor-clone model forbids.

## .the shape of the fix

in the mechanic init that prints the note, say "the repo actor's brain dir is <path>" (or "this
actor's brain dir"), and resnap the consumers that pin it — here,
`init.incremental.acceptance.test.ts.snap`.

## .why it is not done in this round

the text ships from another repo's package; this repo only snapshots it.

# case=2 — an ec2 crew still mints as it does today

> cells c10 (cold) + c11 (warm) + c12 (stale) · happy · critipath (the regression guard)

## .narrative

the camp ec2 grove keeps its run. its host manifest still maps `EHMPATH_BEAVER_GITHUB_TOKEN` to
`aws.params`; at unlock the instance role reads the SecureString, the github-app mech mints, the
daemon caches the `ghs_`, the crew moves on. its later rungs within the hour read the cached token
straight from the daemon — no ssm read, no mint — exactly as they did before. past the 55m expiry
the daemon drops the token, and the next `get --unlock` reads the param and mints a fresh one, as it
has every hour of every day on the camp grove. no host manifest was touched, no blob was moved, no flag
was added to its provision. the cure is an addition beside aws.params, never a replacement of it.

## .the `[tn]` sketch

```
given('[case2] an ec2 box with an aws identity; host manifest maps the key to aws.params')
  when('[t0] the crew asks for the token')
    $ rhx keyrack get --owner ehmpath --key EHMPATH_BEAVER_GITHUB_TOKEN --env prep --unlock
    then('exits 0')
    then('the secret is a ghs_ installation token')
    then('the source vault is aws.params, mech EPHEMERAL_VIA_GITHUB_APP — as before')
    then('the extant aws.params acceptance snapshots are unchanged')
  when('[t1] the crew asks again within the expiry')
    $ rhx keyrack get --owner ehmpath --key EHMPATH_BEAVER_GITHUB_TOKEN --env prep
    then('the daemon returns the cached ghs_; no ssm read, no mint — as before')
  when('[t2] the crew asks after the daemon dropped the expired token')
    $ rhx keyrack get --owner ehmpath --key EHMPATH_BEAVER_GITHUB_TOKEN --env prep --unlock
    then('keyrack reads aws.params and mints a fresh ghs_ (different from t0) — as before')
    then('never hands back the expired ghs_')
```

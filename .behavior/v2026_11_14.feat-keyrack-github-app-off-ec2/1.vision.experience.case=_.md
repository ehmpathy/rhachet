## .forbidden attempts — rejection invariants

| # | the attempt | why forbidden | enforcement |
|---|---|---|---|
| f1 | a minted `ghs_` token filed onto the box as a replica (`os.secure` + `PERMANENT_VIA_REPLICA`) | a 1h token goes stale; the wish forbids a long-lived token on the box, and a short one silently rots | the vision files the blob, never the token |
| f2 | the blob, the private key, or a minted token echoed to stdout, a log, the tree, or the pr | prod is read-only and no credential value is quoted anywhere | the piped set prints slug, vault, mech, and `roundtrip verified` only |
| f3 | an off-ec2 box reads aws.params as a fallback | the grove forbids aws.params off ec2, and the box has no identity to read it with | the cure adds no aws.params fallback; c4 fails fast instead |

# case=6 — a hetzner grove gets unstuck, end to end

> cells c4 → m1 → c1 → c3, one walk · the densest experience: it crosses both actors, both blob
> homes, and the token's cold-warm-stale cycle on one box

## .narrative

`grove-ahbode-hetzner-v20261022` was provisioned yesterday. its rung 4 is red: the beaver token
unlock fails with `aws.params found no AWS identity`, and the hint now names the off-ec2 cure — file
the github-app blob into os.secure on this box, with the command.

the crew halts and hands the hint up. the commander, on their laptop, runs that one command: the blob
streams from aws.params through ssh into `rhx keyrack set --source @stdin` on the box. the screen
shows `roundtrip verified`, never the blob. the box's host manifest now maps the key to os.secure.

the commander re-runs the provision from rung 4. the crew's `get --unlock` decrypts the blob with
`~/.ssh/ehmpath`, mints a `ghs_`, clones the private repos, logs gh in. an hour later a later rung
re-unlocks and gets a fresh token. no aws identity was ever asked for, and no token was ever filed.

## .the `[tn]` sketch

```
given('[case6] a hetzner box: no aws identity, ~/.ssh/ehmpath present, host manifest maps the key to aws.params')
  when('[t0] the crew unlocks the token')
    then('no grant; the refusal is ConstraintError: aws.params found no AWS identity')
    then('the hint names the off-ec2 cure and the set --source @stdin command')
  when('[t1] the commander pipes the blob from aws.params into set --source @stdin on the box')
    then('exits 0; roundtrip verified; no blob in output')
    then('the host manifest now maps the key to os.secure + EPHEMERAL_VIA_GITHUB_APP')
  when('[t2] the crew unlocks the token again')
    then('a ghs_ is granted, sourced from os.secure; no aws sdk call')
  when('[t3] the crew asks after the 55m expiry')
    then('get --unlock mints a fresh ghs_')
```

## .why it is the center

each boundary here broke someone once: the aws identity (the defect), the hint (the dead end), the
pipe (the provision), the ssh identity (the door), the daemon expiry (the stale token). a demo that
walks all five in order is the one the criteria must hold end to end.

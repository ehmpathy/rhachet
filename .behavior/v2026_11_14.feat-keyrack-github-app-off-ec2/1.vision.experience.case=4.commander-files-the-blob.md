# case=4 — the commander files the blob onto an off-ec2 box, in one command

> cell m1 · happy · critipath

## .narrative

the commander reads the pr. it names one command. they run it from a box that can read the blob
where it lives today (their laptop, with the ehmpath aws profile). the blob streams from aws.params,
across ssh, into `rhx keyrack set` on the hetzner box, which reads it from stdin — no tty prompt, no
gh lookup, no pem file on disk. keyrack checks the blob's shape with the github-app mech, encrypts it
to the box's own recipients, proves the roundtrip, and writes the host manifest entry. the screen
shows the slug, the vault, the mech, and `roundtrip verified`. the blob never touched a file, a log,
or the screen.

## .the `[tn]` sketch (sketch flags — not committed)

```
given('[case4] an off-ec2 box with an ehmpath host manifest (keyrack init done); the commander can read the blob in aws.params')
  when('[t0] the commander reads the slug the box already holds')
    $ ssh <hetzner grove> rhx keyrack list --owner ehmpath
    then('it prints the beaver slug, e.g. @all.prep.EHMPATH_BEAVER_GITHUB_TOKEN, vault aws.params')
  when('[t1] the commander pipes the blob into the box, under that slug')
    $ aws ssm get-parameter --profile <ehmpath aws profile> --with-decryption \
        --name <the blob param path> --query Parameter.Value --output text \
      | ssh <hetzner grove> rhx keyrack set --owner ehmpath \
          --key <the slug from t0> \
          --vault os.secure --mech EPHEMERAL_VIA_GITHUB_APP --source @stdin
      # a machine-wide (@all) slug runs from $HOME as is. a repo-org slug needs
      # `cd <a clone of that org's repo> &&` before rhx: set refuses a repo key from a non-repo cwd (a4)
      # the short form `--key EHMPATH_BEAVER_GITHUB_TOKEN --env prep --org @all` files the same @all slug
      # from $HOME (w2); a short key with no --org is refused there, and the hint names --org @all (w3)
      # <the blob param path> defaults to /keyrack/infra/vault/aws.params/v1/ehmpath/<org, @all → _all_>/<env>/EHMPATH_BEAVER_GITHUB_TOKEN
      # (asKeyrackAwsParamName.ts:35). an explicit --exid at set overrides it, so the truth is the exid
      # an ec2 grove's `rhx keyrack list --owner ehmpath` shows for the slug
    then('exits 0')
    then('no prompt is issued and no gh call is made')
    then('the host manifest maps the key to os.secure + EPHEMERAL_VIA_GITHUB_APP')
    then('stdout shows slug, vault, mech, roundtrip verified — never the blob')
  when('[t2] the crew asks for the token on that box')
    then('case=1 holds')
```

## .why a pipe and not a copy

the blob travels from its one home to its second home in a single stream. no intermediate file, no
clipboard, no `scp` of a pem. the source of truth stays aws.params; the box's os.secure holds a
replica of the *blob*, encrypted to the box alone.

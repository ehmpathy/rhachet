# case=1 — an off-ec2 crew mints the beaver token on demand

> cells c1 (cold) + c2 (warm) + c3 (stale) · happy · critipath

## .narrative

dawn on `grove-ahbode-hetzner-v20261022`. the provision crew reaches rung 4 and needs
`EHMPATH_BEAVER_GITHUB_TOKEN`. the box has no aws identity and no gh login — it has its ehmpath ssh
key (`~/.ssh/ehmpath`), and the github-app blob the commander filed once into its os.secure vault.

the crew runs `rhx keyrack get --unlock`. the daemon holds no token yet, so keyrack unlocks: it reads
the box's host manifest (the key lives in `os.secure` under `EPHEMERAL_VIA_GITHUB_APP`), decrypts the
blob with the ssh identity it discovers, and hands the blob to the github-app mech, which asks github
for an installation token. a fresh `ghs_…` lands in the daemon with a 55 minute expiry and comes back
to the crew. it clones its private repos, logs gh in, and its identity checks go green.

twenty minutes later the gh-login rung asks for the token again with a plain `get`. the daemon still
holds the `ghs_`, so keyrack hands it back at once — no decrypt, no call to github. most asks of the
day are this one.

two hours later a second rung asks again. the daemon dropped the expired token, so the same
`get --unlock` mints a new one — the crew never sees a stale token, and no long-lived token ever sat
on disk.

## .the `[tn]` sketch

```
given('[case1] an off-ec2 box: no aws identity, ehmpath ssh key at ~/.ssh/ehmpath, blob filed into os.secure')
  when('[t0] the crew asks for the token, daemon cold')
    $ rhx keyrack get --owner ehmpath --key EHMPATH_BEAVER_GITHUB_TOKEN --env prep --unlock
    then('exits 0')
    then('the secret is a ghs_ installation token')
    then('github accepts it: GET /installation/repositories → 200   (proven on the grove; see q5)')
    then('no aws sdk call is attempted')
    then('the source reads vault os.secure, mech EPHEMERAL_VIA_GITHUB_APP; the secret is never printed unless asked')
  when('[t1] the crew asks again within the expiry')
    $ rhx keyrack get --owner ehmpath --key EHMPATH_BEAVER_GITHUB_TOKEN --env prep
    then('the daemon returns the cached ghs_; no mint')
  when('[t2] the crew asks after the daemon dropped the expired token')
    $ rhx keyrack get --owner ehmpath --key EHMPATH_BEAVER_GITHUB_TOKEN --env prep --unlock
    then('keyrack mints a fresh ghs_ (different from t0)')
```

## .what makes it click

the box carries the *ability to mint*, not a token. that is the same shape an ec2 grove has — the
blob behind a door the box can open — only the door is the box's own ssh key rather than an aws role.

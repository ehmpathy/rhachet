# case=5 — the commander pipes a malformed blob

> cells m2 (malformed) + m7 (absent) · sharp · critipath

## .narrative

the commander's `aws ssm get-parameter` lacked `--with-decryption`, so the pipe carries ciphertext,
not json. or the stdin is empty because the profile expired. keyrack refuses before it writes a
single byte: the error says the source is not a github-app blob and which check failed (not json · no
`appId` · no `privateKey` · no `installationId` · empty stdin). it never prints what it received.
the box's vault and host manifest are untouched, so a retry with the right flag simply works.

another day the commander shells into the box and types the `set … --source @stdin` line by hand,
with no pipe in front of it. a naive stdin read would sit there and wait — and invite them to paste
the private key into the terminal, where it would echo to the screen and the scrollback. keyrack
refuses at once instead: stdin is a terminal, pipe the blob in. no prompt, no wait, no paste.

## .the `[tn]` sketch

```
given('[case5] an off-ec2 box with an ehmpath host manifest')
  when('[t0] stdin carries a non-json value')
    then('exits 2 (ConstraintError)')
    then('the error names the reason: value is not valid json')
    then('the received value is not echoed')
    then('no .age file and no host manifest entry is written')
  when('[t1] stdin carries json that lacks privateKey')
    then('exits 2; the reason names privateKey')
  when('[t2] stdin is empty')
    then('exits 2; the reason names empty stdin and hints at the upstream command')
  when('[t3] --source @stdin is given but stdin is a tty (no pipe)')
    then('exits 2 at once; the reason says stdin is a terminal and hints to pipe the blob in')
    then('it never blocks on a read')
```

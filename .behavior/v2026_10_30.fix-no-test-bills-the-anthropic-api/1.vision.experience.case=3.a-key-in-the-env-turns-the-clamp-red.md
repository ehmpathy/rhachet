# case=3 — a key in the env turns the clamp red

feel = sharp · care = critipath

## .narrative

months later, someone adds `ANTHROPIC_API_KEY` back to a role=test keyrack "to fix auth". or a
human runs the suite from a shell that exports it. claude code would pick the key over the oauth
token and bill the api in silence.

it does not get the chance. jest `globalSetup`, right after `keyrack.source`, checks
`process.env` — the env every suite and every spawn inherits. an `ANTHROPIC_API_KEY` there is a
ConstraintError, loud, before any suite runs:

```
✋ ConstraintError: a test env that spawns claude code holds ANTHROPIC_API_KEY
   ├─ claude code ranks the api key above CLAUDE_CODE_OAUTH_TOKEN, so this run would bill the api
   └─ hint: drop ANTHROPIC_API_KEY from env.test, or unset it in this shell
```

## .timeline (sketch)

```
given('[case3] a test env with CLAUDE_CODE_OAUTH_TOKEN and ANTHROPIC_API_KEY')
  when('[t0] the integration or acceptance tier starts')
    then('globalSetup fails before any suite, with a ConstraintError that names the key')
    then('no request reaches the anthropic api')
given('[case3.1] the same env, without the cure (the clamp reverted)')
  when('[t0] the suite starts')
    then('the spawn env holds ANTHROPIC_API_KEY — the clamp test is red')
```

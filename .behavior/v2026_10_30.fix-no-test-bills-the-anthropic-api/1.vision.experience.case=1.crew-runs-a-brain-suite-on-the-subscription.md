# case=1 — a crew runs a brain suite on the subscription

feel = happy · care = critipath

## .narrative

a crew seat changes `actorAsk` and runs the integration tier. `git.repo.test` unlocks the
ehmpath keyrack for env.test. jest `globalSetup` sources `CLAUDE_CODE_OAUTH_TOKEN` and no
`ANTHROPIC_API_KEY`, since the key is no longer declared. the suite's `genBrainRepl` starts claude
code through claude-agent-sdk, which finds the oauth token and bills the subscription. the seat
sees green, and the api console shows zero new requests.

## .timeline (sketch)

```
given('[case1] a crew box with the ehmpath keyrack unlocked for env.test')
  when('[t0] rhx git.repo.test --what integration --scope actorAsk --mode apply')

    then('the test env holds no ANTHROPIC_API_KEY')
    then('the haiku repl answers; the suite is green')
```

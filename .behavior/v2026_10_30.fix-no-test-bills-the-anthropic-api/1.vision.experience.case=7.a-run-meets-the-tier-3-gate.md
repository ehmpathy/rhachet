# 1.vision.experience.case=7.a-run-meets-the-tier-3-gate

> cells 18–20: a crew seat or a ci runner meets the gate on a tier-3 live-brain suite.

## .narrative

a crew seat runs `rhx git.repo.test --what integration --scope actorAsk --mode apply`. actorAsk
calls a live haiku repl, so it sits in tier 3. no flag is set, so the suite does not run. no call
is made, so naught is billed.

what the seat reads is the sharp part: the summary says `🎉 passed` over `0 passed, 0 failed,
3 skipped`. the skip count is the only sign on its screen. the todo row that names the tier and the
flag, `[gated: tier-3 live brain] actorAsk (integration) — run with BRAIN_LIVE_SCOPE=all`, sits in
jest's own report, which `git.repo.test` keeps in its log and omits on success; `--log always`
keeps it. a seat that reads a green and a skip count as "proven" has proven naught. the summary
that would name the todo row belongs to `git.repo.test` upstream
(`.dream/v2026_10_31.reseed.git-repo-test-summary-names-todo-rows.md`). ci meets the same row in
its raw jest log on every push.

the seat means to prove actorAsk against a live brain. it runs
`rhx test.brain.live --what integration --scope actorAsk --mode apply`. the skill sets the flag
for that one call, and refuses a run with no `--scope`, since each live test spends. actorAsk runs
in full on haiku, under its own title, so its snapshots match.

the seat types the flag by hand as `BRAIN_LIVE_SCOPE=true`. the gate does not read that as off:
the suite fails at collection with
`ConstraintError: BRAIN_LIVE_SCOPE must be 'all' or unset`, and names the fix. a typo never passes
green.

a later change adds a new suite that calls `genBrainRepl` and forgets the gate. the scan
`getAllLiveBrainSuitesUngated` fails on cicd and names the file and its marker, before the suite
can bill a push.

## .bdd

```
given('[case7] a tier-3 suite')
  when('[t0] the run sets no BRAIN_LIVE_SCOPE')
    then('the suite skips under its own title, beside a todo row that names the flag')
    then('no live call is made')
    then('a seat on plain git.repo.test reads a green with a skip count; the todo row is in the log only')
  when('[t1] the run sets BRAIN_LIVE_SCOPE=all, via rhx test.brain.live')
    then('the suite runs in full under its own title')
    then('a run with no --scope is refused, exit 2')
  when('[t2] the run sets BRAIN_LIVE_SCOPE to any other value')
    then('the gate fails loud with a ConstraintError that names the value and the fix')
  when('[t3] a suite reaches a live brain outside the gate')
    then('the scan fails and names the file and its marker')
```

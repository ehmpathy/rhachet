# case=2 — ci runs a brain suite on the subscription

feel = happy ([case2]) · sharp ([case2.1]) · care = critipath

## .narrative

a pr opens. the acceptance shard runs `keyrack firewall --env test`. the firewall reads the
manifest, which now declares `CLAUDE_CODE_OAUTH_TOKEN` and not `ANTHROPIC_API_KEY`, so it lifts only
the oauth secret into `GITHUB_ENV`. the brain-dir-boot journey spawns `claude -p --model haiku`,
which authenticates on the oauth token. the shard goes green, where on #649 it went red on
"Credit balance too low".

the one human act: put the token in the repo's (or org's) secrets, once. a crew cannot mint a
subscription token — `claude setup-token` opens a browser login.

# case=5 — a seat and its review lanes stay on the subscription

feel = happy ([t0]) · sharp ([t1], [t2]) · care = critipath ([t0], [t1]) · alterpath ([t2])

## .narrative

a crew seat is a claude session, launched by `rhx enroll` from a shell. it drives a route, and
its guard runs `rhx review`, which may spawn claude children. none of these run under jest, so the
test clamp does not reach them. what they bill depends on the env of the shell that launched the
seat.

`keyrack unlock` fills the daemon; it exports no key to the shell (`sourceAllKeysIntoEnv.ts:259` is
the only prod write to `process.env`, and it runs in jest, not in unlock). so a seat launched from a
clean shell runs on its `/login`, and its children inherit that env.

a seat whose shell DOES export the key would bill the api, and today it does so without a word.
after the cure, `rhx enroll` sees the key in the env it is about to hand claude, and says so,
loud, before the clone starts:

```
⚠️ this clone bills the anthropic api: ANTHROPIC_API_KEY is set
   ├─ claude code ranks the api key above your /login and CLAUDE_CODE_OAUTH_TOKEN
   └─ to use your subscription: unset ANTHROPIC_API_KEY, then enroll again
```

the clone still starts — a human may mean to pay per call (fulcrum F1 keeps that choice) — but
the choice is now seen, at the moment it is made, with the fix named.

and a seat with no login at all gets a hint that no longer points at the paid path.

## .timeline (sketch)

```
given('[case5] a seat enrolled from a shell with no ANTHROPIC_API_KEY and a /login on the box')
  when('[t0] the seat runs, and its guard runs rhx review')
    then('the seat authenticates on /login')
    then('enroll prints no api-billed notice')
    then('rhx keyrack unlock left no ANTHROPIC_API_KEY in the shell env')
given('[case5.1] a seat enrolled from a shell that exports ANTHROPIC_API_KEY')
  when('[t1] rhx enroll claude')
    then('before the clone starts, stderr names ANTHROPIC_API_KEY and says the clone bills the api')
    then('the notice names the fix: unset ANTHROPIC_API_KEY')
    then('the clone still starts — the human chose the key')
given('[case5.2] a seat enrolled from a shell with no credential and no /login')
  when('[t2] rhx enroll claude')
    then('the no-login hint names /login or CLAUDE_CODE_OAUTH_TOKEN (claude setup-token)')
    then('the hint no longer suggests ANTHROPIC_API_KEY')
```

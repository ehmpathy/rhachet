# case=6 — the subscription hits its rate limit under ci load

feel = sharp · care = critipath

## .narrative

after the cure, every brain test in the fleet runs on one subscription. a pr push starts three
integration shards and five acceptance shards at once (`.test.yml` matrix); a crew on a box runs
its own suite beside them; a second repo's ci fires the same minute. the plan's rate window fills.

the next claude request is refused with a rate-limit reply. the cure must not turn that into a
mystery.

**the claude-spawn path** (`claude -p`, `rhx enroll`): claude prints the vendor's text to stdout
and the test fails on it, the same way #649's acceptance shards surfaced `Credit balance too low` —
loud, named, in the vendor's own words. the reader knows to wait and re-run.

**the repl path** (`genBrainRepl` via claude-agent-sdk): today it hides the refusal behind jest's
180s timeout. the root cure — surface the vendor's text — lives in rhachet-brains-anthropic (the
caught dream `v2026_10_30.reseed.repl-hides-a-brain-error-behind-a-hang`). what rhachet can own is
a backstop: its repl suites wrap each brain call in a bounded wait of 60s. a haiku answer takes
seconds; past the bound, the call fails at once with a MalfunctionError that names what most
likely hides behind it and what to do:

```
💥 MalfunctionError: the repl brain gave no answer in 60s
   ├─ on the repl path, a vendor refusal (rate limit, credit, a dead token) shows as a hang
   ├─ hint: re-run when the plan's rate window clears
   └─ hint: a cli acceptance shard of the same run shows the vendor's own text
```

fast (60s, not 180s per test), loud, and it names the next move. it is declared a backstop in
the inventory's gaps, not a full cure.

what keeps it rare: the explicit acceptance shards already run `--runInBand` (`.test.yml:331`), and
the suites pin haiku (`rule.require.test-claude-cli-against-haiku`), the cheapest model on the plan.

# 3.1.3.research.internal.product.code.prod._ — the prod codepaths this behavior touches

> **the render is per-role and prints to stdout; the corpus is a quantity no operation computes
> today. the enroll path is paved end to end, save one reader: the transcript lookup reads the
> PARENT's `CLAUDE_CONFIG_DIR`, so it goes blind the moment the child's is relocated.**

each pattern carries a verdict — `[REUSE]` · `[EXTEND]` · `[REPLACE]` — and numbered citations
`[Cn]`, quoted verbatim in `.citations`.

blind. the fix is an explicit input, never a parent-env mutation.

## .what the blueprint owes, from this stone

1. eject the body from `bootRoleResources` (P1, P2) — one renderer, two consumers.
2. sort the glob result (P3).
3. `getBrainTranscriptDir` takes the brain dir (P18) — `genCloneHistoryLink`, `invokeCloneGet`.
4. one spawn-env transformer at both sites (P17).
5. `claudeMdExcludes` gains `<home>/.claude/CLAUDE.md` beside the repo's `AGENTS.md` (P15; external E6).
6. the actor's brain dir holds `CLAUDE.md` → `AGENTS.md`, a symlink (external E1; F7).
7. the credential link is absolute (P19).
8. `isRolesBootCommand` is ejected from `findRolesWithBootableButNoHook` before that file is deleted (P24, P25).

# playtest: boot briefs into `CLAUDE.md`

> **what this proves.** a brief corpus reaches a clone through `CLAUDE.md` → `AGENTS.md` →
> `boot.md`, rather than through the `SessionStart` boot hook. that move makes the corpus
> cache-eligible and lifts the `claude-cli` version floor, which is what unblocks
> `claude-opus-5-5`.
>
> **how to use it.** walk the steps in order. each one is copy-pasteable, states its expected
> output literally, and cites the acceptance test that proves it. a step passes only when the
> observed output matches the stated one.

## prerequisites

| # | requirement | how to confirm |
|---|---|---|
| 1 | this worktree, on `beav/feat-boot-briefs-into-claude-md` | `git rev-parse --abbrev-ref HEAD` |
| 2 | a built `dist/` — `bin/run.jit` loads `dist/`, never `src/` | `npm run build` |
| 3 | the local self-link holds (`"rhachet": "link:."`) | `npm ls rhachet` prints `rhachet@… -> ./` |
| 4 | a `claude` on `PATH` at **2.1.277 or above** | step **E1** below |

⚠️ **use `npx rhachet <cmd>` for cli commands.** a bare `rhx <cmd>` routes to
`run --skill <cmd>` and will not reach `init` / `upgrade` / `enroll`
(`rule.forbid.node-modules-bin-rhx`, `howto.test-local-rhachet`).

  collision, a read-only actor dir, an absent credential — are proved by the automated journey in

🟡 **the assertion pins the whole trio, not `boot.md` alone.** `asBrainDirFileContents` (line 138)
reads `AGENTS.md`, `CLAUDE.md` **and** `boot.md`, and line 579 compares all three across a second

| the half | proved by |
|---|---|
| the identity hash is order-free | `…/actor/enrolled/genEnrollmentHash.test.ts` — `[case2]` → line **34** |
| the comparator sorts, on a copy | `…/actor/enrolled/asRoleSlugsInEnrollmentOrder.test.ts` — `[case1]` |

⇒ **that shared comparator is this branch's own contribution to the invariant.** it is what makes

### E5 — a role is unlinked while an actor of it still lives → exit **2**

**do not run byhand** — it unlinks a role package from this worktree.

**expect** — `rhx init` **exits 2**, a *constraint*: the caller must fix the state. it does not
silently render a corpus with a hole in it.

🔴 **the two fixes the stderr offers are `rhx roles link --role lifeguard` and "end the actor's live
clones" — NOT a prune.** the case asserts the absence outright:
`expect(run.init.stderr).not.toContain('prune')`. a prune reaps only a **DEAD** clone
(`define.invariant.clone-prune-safety`), and this actor's clone is **live** — so a prune hint would
be advice that cannot work. the error omits it on purpose, and the test pins that omission.

🟡 **and the run is a MIXED success/refusal.** it exits 2 **and** still re-renders every healthy
actor: `then('the [t3] actor still re-renders')` (line 799). the test's own comment names the shape
— *"the partial-success report, the shape a human reads to learn which actors survived the
refusal."* ⇒ one broken actor does not abort the whole init. a foreman who expects an all-or-nought
refusal would read the healthy actor's census line as a bug.

### gap 1 — this repo's own door is untracked (F49)

**found at** H3 / E8. the worktree holds `.claude` as a symlink and five addable door files; the

**disposition — deferred, and recorded.** the repair fails both halves of the SAFE/CLEAN test: it
replaces a tracked path with a `120000` symlink on the same `moved:` migration path
`init.incremental` snapshots, and it restructures the branch's staged shape from the playtest gate

`rhachet init` on every non-CI clone and rebuilds the door.

⇒ caught as `.dream/v2026_09_25.chore.this-repos-own-door-is-untracked.md`, with a fulcrum for the
council at `.fulcrums/inventory.of=fulcrums.case=F49-this-repos-own-door-is-untracked.md`

### gap 3 — `rhx teesafe` destroys its destination on an early pipe close

**found at** H5 and E2. three independent defects in a skill this fleet steers every redirect
through:

| # | defect | severity |
|---|---|---|
| 1 | it strips a file's terminal newline — `cmd \| teesafe --into f` is not an identity | corrupts a snapshot |
| 2 | an `EAGAIN` on fd 1 reports `💥` although the file landed | a false alarm |
| 3 | 🔴 an early downstream pipe close **truncates the destination and never writes the body** | **data loss** |

defect 3 is isolated and deterministic: with `| head -3` downstream the destination is left at
**zero bytes**; with no downstream pipe the identical call is correct. it destroyed a real file in
step **E2** — the default `AGENTS.md` — and the walk recovered only because `rhx init` regenerates
that exact file.

**disposition — reseeded.** the skill lives in `node_modules/rhachet-roles-ehmpathy/`, so there is
no edit to make in this repo and a vendored patch would be erased by the next `pnpm install`. caught
as `.dream/v2026_09_25.reseed.teesafe-wipes-an-extant-destination-on-upsert.md`, cross-linked to
`.dream/v2026_09_25.reseed.a-skill-whose-pipe-was-truncated-reports-a-malfunction.md` — the same
trigger, graded there as cosmetic. **no fulcrum owed**: the deferral turns on ownership, never on a
ripple-cost judgment (`rule.always.scope-onetime-lessons-to-the-behavior`).

⇒ **this playtest uses `rhx cpsafe` for every snapshot**, which round-trips correctly.

🟡 gap 3 also retroactively closes an older question. an earlier round of this route read two
different `wc -c` counts off `teesafe` snapshots of one render and concluded the render was
nondeterministic. it was byte-stable the whole time — **the instrument was the variable**.

### gap 4 — the version floor's `onAbsent` fork had no step and no acceptance coverage

**found at** the `has-edgecase-coverage` self review, under the guide's *"are boundaries tested?"*
question. the floor has ONE guard and TWO callers that disagree on exactly one question — what an
**absent** `claude` binary means. `rhx enroll` refuses; the boot sweep (`rhx init --roles|--hooks`,
`rhx upgrade`, `rhx roles link`) permits. that fork is this branch's own invention, and the
playtest had **no step for it at all** — so the branch's most consequential new decision was

**disposition — fixed, both halves.** step **E11** now walks it, and two acceptance cases clamp it:

| refuse | `enroll.acceptance.test.ts` `[case12]` → 1167/1187/1193 | the same PATH makes `enroll` refuse, with an install command |

🟡 **the permit half is a real clamp, not a tautology.** `assertBrainCliVersionFloor` is the first,

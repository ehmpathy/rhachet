## .the RESUME REFUSAL is SUSPENDED by F1's reversal (S12)

this case specified two mechanisms. **one is untouched; the other rests on a premise the transport
change removed.**

| the mechanism | status |
|---|---|
| a corpus-identity **warn** at `/compact` | ✅ **holds, unchanged** |
| a corpus-identity **refusal** at `--resume` | **SUSPENDED** |

the refusal was ruled because *"the cli discards the flag on resume"* — *"command-line system
prompt flags are **ignored**"*. **the transport no longer rides a system-prompt flag.**
`CLAUDE_CONFIG_DIR` is an env var, so that sentence does not reach it, and a layer-2 file may
simply be re-injected.

⇒ **the refusal may DISSOLVE entirely**, and it is suspended rather than struck because the claim
that would dissolve it — *a layer-2 file is re-injected on resume* — carries **NO SOURCE FOUND**.
one measurement settles it (`[research]` row 1).

⚠️ **the corpus-identity RECORD survives the reversal regardless**, and its reason changed: it
existed to power a refusal; it now exists so drift is **legible** rather than silent — a need the
re-read transport creates on the other side (two live sessions may observe one rewrite at different
moments, `dimensions.md` invariant 4).

## .why this case is a critipath

the tempting fallback reads correct and is not: *"the next compaction applies the new text, with no
human act owed."* the Anthropic sentence behind it is scoped to a **resume** — *"if you pass a
different `append` or custom prompt when you return to a session with `resume` or `continue` …
the new text takes effect after that compaction"*. it speaks to text a **relaunched** process read
at its own launch, and is silent on a continuous one.

so the fallback fails on both of its assumptions, and the second one is ours:

| the assumption | the fact |
|---|---|
| a live process re-reads its instruction file at compaction | **NO SOURCE FOUND**, either way — and **F1's reversal made this row MORE likely, not less.** a layer-2 file is re-read from disk where a recorded prompt was not, so the first assumption may now be true (`[research]` rows 1 and 1′) |
| even if it did, the file would hold new content | **the row that carries the case now.** true for a **slug** actor, false for a **hash** one — a role change there is a **different path**, so this session's file is byte-unchanged forever |

⇒ **the reversal moved the weight from row 1 to row 2, and the case survived the move.** row 1 was
the stronger bar under S6 and is now open; row 2 was always independent of the transport, because
no re-read can deliver a file the actor no longer writes to.

⇒ `rhx enroll` produces hash actors, which is the fleet's default, so the worse branch is the
common one. **the demonstration below walks it**, and the assertion it specifies is correct for
both branches: a corpus that no longer matches its actor is reported, whatever the reason.

## .part A — the attended walk (cell #8)

Kai enrolled at 9am on `mechanic,driver,learner` and has been on one route since. mid-day the work
turns architectural, so Kai re-enrolls with `+architect` in a **second** terminal and goes back to
the first one to keep the thread.

the first session has been open for hours. it compacts.

**today, that is where the quiet wrongness lands** — and the reason is the **path**, never the
read. `rhx enroll` is hash-identified, so the second terminal's `+architect` minted a *different*
actor at a *different* dir. the first session points at its own `<brainDir>/AGENTS.md`, which holds
the old corpus and always will: **a re-read at this compaction would re-deliver the same bytes.**
Kai asks an architecture question. the clone answers from general knowledge. **it reads plausible.**

the sanctioned outcome — the boundary is where the corpus is re-asserted:

```
🐢 heads up — this session's corpus is older than your enrollment

   ├─ session booted with : mechanic, driver, learner            (corpus 4f1c9a2e)
   ├─ enrollment now reads: mechanic, driver, learner, architect (corpus b07de513)
   └─ drifted             : +architect

   this enrollment minted a NEW actor at a NEW path, so the file this session
   reads will never hold the new corpus — not at this compaction, and not at
   the next one. a re-read would return the same bytes.

   fix — start a fresh session on the current set:
     rhx enroll claude --roles mechanic,driver,learner,architect
```

**the sentence that carries the case is the third one.** the honest fail-safe is not *"we repaired
it"* — it is *"we can prove this session will never repair itself, so do not wait."* a signal that
said *"try another compact"* would be worse than silence, because it would sell a false remedy
(`case=7` `[t8]`).

⚠️ **that proof is the HASH branch's, and the signal must not borrow it for the others.** on a slug
or derived actor the path holds and the file is rewritten, so the honest line is weaker — *"this
session may not pick the new corpus up"* — because whether a live process re-reads the file at a
compaction is unsettled (`1.vision.yield.md` → `[research]` 1). the assertion is identical in both
branches; only the remedy sentence differs.

### where it can fire, and where it cannot

| boundary | can an assertion fire? | how |
|---|---|---|
| `/compact` | ✅ yes | a `SessionStart` hook with `matcher: compact` — **the identical mechanism `case=8` uses**, one matcher over, and it compares rather than re-delivers |
| `--resume` / `--continue` | ✅ yes, **and earlier** | the resume is a **spawn**, and rhachet owns the spawn seam. the check runs before a clone exists |
| a turn mid-session | ❌ no, and it is not owed | ⚠️ **the reason WEAKENED with F1.** it was *a recorded prompt cannot change mid-session*; a layer-2 file can be rewritten under a live session. what still holds is the cost argument: a per-turn check would charge every turn to catch an event whose EFFECT only lands at a boundary, since a rewrite changes no context until a re-read consumes it |

⇒ the two live boundaries are the two this case walks, and **each is an extant seam** — no new
machinery is proposed.

### the resume WAS the sharper of the two — and F1's reversal took its argument away

the argument was a contract, quoted:

> *"When you resume a conversation with `--continue` or `--resume`, the system prompt from the
> original session is reused, and **command-line system prompt flags are ignored**."*
> — `/docs/en/cli-reference`

under S6 that made a resume under a changed role set **guaranteed-stale by contract**, so refusal
was the only honest act: rhachet could not hand over the new corpus even where it wanted to.

**the sentence is scoped to system-prompt FLAGS, and the transport is now an ENV VAR.**
`CLAUDE_CONFIG_DIR` is not a system-prompt flag, so the quote does not reach it, and the
guaranteed-stale premise is gone.

| the branch | what a resume now does |
|---|---|
| **hash** actor | the env var points at the same dir it always did ⇒ the same corpus, stale for the same **path** reason as `/compact`. the assertion still fires; the *"never repairs itself"* line still holds |
| **slug** / **derived** actor | the dir holds and its file was rewritten ⇒ a resume **may deliver the new corpus**, which is the opposite of the refusal's premise |

⇒ **the refusal is SUSPENDED, never struck.** what settles it is whether a resumed process re-reads
its instruction file at all — `NO SOURCE FOUND` either way (`[research]` row 1). ⚠️ **the two
branches disagree**, so a measurement that answers only one of them answers nothing: the blueprint
owes both, and the honest interim act at this seam is the **warn**, which is correct in both.

🟡 **what the reversal did NOT take is the record.** a resumed session must still be able to say
which corpus it carries, because a slug actor's two live sessions may now observe one rewrite at
different moments (`dimensions.md` invariant 4). the identity check survives its own refusal.

## .the bdd sketch — attended

```
given [case10] a live session booted on a known role set, and an enrollment
      that has since changed

  when  [t0] the enrollment is unchanged and the session compacts
  then  no signal fires
  ⇒ the assertion must not cry wolf, or it is tuned out (mirrors case=6 [t5])

  when  [t1] the role set is changed in another terminal, then this session compacts
  then  the session's booted corpus identity and the actor's current one are
        compared
  and   they differ
  and   the drift is named, with both identities and the exact role delta
  ⇒ the identity is the actor ADDRESS plus a digest of the rendered corpus.
    an enrollment hash alone is stable across a slug actor's every rewrite,
    so it would report MATCH on the very drift this fires for

  when  [t2] the signal is read on a HASH actor
  then  it states that this session CANNOT pick the new corpus up, at any
        later compaction
  and   it names a FRESH-SESSION command, never a "wait" or a "retry"
  ⇒ the false-remedy bound. case=7 [t8] proves the wait does not work, so a
    signal that suggests one is a defect rather than a help

  when  [t2b] the signal is read on a SLUG or DERIVED actor
  then  it states that this session MAY NOT pick the new corpus up
  and   it names the same fresh-session command
  ⇒ the path holds and the file is rewritten there, so the hash branch's
    proof does not transfer. the assertion is identical; only the remedy
    sentence weakens, and it must not claim a certainty it lacks

  when  [t3] the human resumes the session with --resume after the set changed
  then  the booted corpus identity is compared BEFORE a clone is spawned
  and   a drift is named, with both identities and the role delta
  and   it names the fresh-session command
  ⇒ WEAKENED by F1's reversal. this step once specified a REFUSAL, on the
    contract that "system-prompt flags are ignored on resume" — a sentence
    that does not reach an env var. the COMPARISON survives that reversal and
    the refusal does not, so the step asserts what is settled

  when  [t3b] the transport's resume behavior is measured  [research row 1]
  then  the verdict is ruled: refuse, or warn-and-proceed
  and   it is measured on BOTH a hash actor and a slug actor
  ⇒ the branches disagree — a hash resume is stale by PATH, a slug resume may
    deliver the new corpus — so a measurement of one answers neither

  when  [t4] the human starts a fresh session on the current set
  then  the corpus holds the added role
  and   the booted corpus identity equals the actor's current one
  and   no drift signal fires
  ⇒ the exit is real and reachable, not merely described
```

## .part B — the unattended walk (cell #20), and the bound that narrows it

Dana's fleet sweep resumes yesterday's forty sessions at 3am to finish their routes. between
yesterday and today, the role set those routes run on gained a brief set.

**nobody is at a terminal.** every `then` in part A is a *printed* block, and part A's whole
remedy evaporates with its reader — the exact result `case=3` `[t5]` first surfaced and #17, #18,
#21 each re-confirmed.

⇒ **so #20's remedy must be an exit code, and its fail-safe is `[t3]` above rather than `[t1]`.**

### the bound — the compaction sub-case CANNOT drift unattended

this is what makes #20 closeable rather than a permanent debt:

```
a compaction drifts only where the role set changed WHILE the session was live
an unattended run has no one to change it mid-run
⇒ in a fleet, an "unattended role change IS an enrollment delta" (cell #19)
```

**the act that changes the set in a fleet is the same act that rebinds it.** so the unattended
drift window does not open at a compaction at all — it opens at a **resume**, where yesterday's
session meets today's set. ⇒ **one seam carries #20 entirely, and it is the spawn seam rhachet
already owns.**

🟡 **this is the mirror of #19's own fallback argument**, applied one moment over: the attended
cell has two boundaries and the unattended cell has one.

## .what this case obliges the blueprint to carry

the fail-safe above rests on one fact the session must know about itself, and **that fact is not
recorded today**:

> **a session must carry the corpus identity it was launched with** — the actor's **address** plus
> a **digest of the rendered corpus**.

⇒ the assertion is then a **string equality** between that record and the identity recomputed from
the actor's current state — no introspection of the context, no canary token in the corpus, no
clone cooperation.

**this requirement is the one part of the case the reversal made STRONGER.** under a recorded
prompt the record powered a refusal; under a re-read file it also answers a question that could not
arise before — *two live sessions on one slug actor may observe one rewrite at different moments*
(`dimensions.md` invariant 4). ⇒ it now serves drift **legibility** as well as the halt, and it is
owed even where `[t3]`'s refusal dissolves.

⚠️ **the enrollment hash alone will not serve, and it is the shortcut a reader reaches for first.**
it is a digest of `{ brain, roles }`, so on a **slug** or **derived** actor it is stable across
every rewrite of that actor's corpus — it would report `match` on exactly the drift this guard
exists to catch. the address alone fails for the same reason; the digest alone loses the actor.
both, or the check lies on two of the three identity forms.

🟢 **the destination for the record already exists.** the actor dir is gitignored and already holds
the clone records, so the session-to-identity record is a field in a namespace this feature does
not have to invent (`catalog.of=actor-clone-design._`).

⚠️ **the honest residual**: a `SessionStart` hook's power to *block* varies by event, so part A's
`[t1]` compaction signal is graded as a **warn a human reads**, never as a halt. that is adequate
for #8 (attended, by definition) and it is **not** what closes #20 — `[t5]`'s spawn-seam refusal
is. the two cells are closed by two different mechanisms, and the census says so.

## .what this case deliberately does NOT do

| it brushes | the spotlight that proves it |
|---|---|
| the role-change drift signal at link time | `case=6` — the `change` moment, one moment earlier |
| the compaction's effect on the **adhoc** corpus | `case=8` — a different corpus, a different remedy |
| the rendered-vs-delivered assertion at first boot | `case=4` `[t8b]` — the `deliver` moment, and where the equality shape was first forced |

⇒ **`case=6` and this case are adjacent and not redundant.** `case=6` catches the drift at the
moment it is *created*; this catches it at the moment the session *survives*. a human who dismissed
the first signal, or who never saw it because the change happened elsewhere, is caught here.

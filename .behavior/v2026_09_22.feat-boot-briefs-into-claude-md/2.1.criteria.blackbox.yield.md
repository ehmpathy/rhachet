# 2.1.criteria.blackbox.yield — boot briefs into the brain dir

each usecase names the seed it traces to. a usecase with no seed is scope creep.

---

## usecase.1 = an enrolled clone holds its roles' briefs — S2 · S3

```
given( a repo with roles to enroll )
  when( a human runs `rhx enroll claude --roles X,Y` )
    then( the actor's brain dir holds CLAUDE.md (a symlink to AGENTS.md), AGENTS.md (@boot.md), and boot.md )
    then( the clone opens with CLAUDE_CONFIG_DIR = that brain dir )

  when( the clone is asked to quote a rule from role X )
    then( it quotes it )
      sothat( "present" is proven by the clone, never by a file's existence )

  when( the clone is asked to quote a rule from a role it was NOT enrolled in )
    then( it reports it does not hold that rule )
      sothat( one brain dir per clone — the repo default does not ride along )

  when( the repo's brain dir opens every door it can — AGENTS.md, a CLAUDE.md, a rules/ file, a hook of an unenrolled role )
    then( a new clone of the actor quotes none of what those doors hold, and no unenrolled hook fires )
      sothat( the repo's brain config never pollutes an actor's )

  when( the clone is asked to quote a rule that lives only in the human's ~/.claude/CLAUDE.md )
    then( it reports it does not hold that rule )
      sothat( the human's user-scope memory never loads into a clone )

  when( the delivered corpus is compared to the rendered corpus )
    then( delivered EQUALS rendered )
      sothat( a truncated corpus and an absent one both fail )

  when( the same clone config opens a second time )
    then( the corpus is billed as a cache read )
```

## usecase.2 = the cli is below the floor — S8

```
given( a host whose claude-cli is below 2.1.277 )
  when( a human runs `rhx enroll` )
    then( it refuses, exit 2 )
    then( the refusal names the binary, its version, the floor, and the fix )
    then( no clone spawns )

  when( the host is upgraded to a cli at or above the floor )
    then( the same enroll succeeds, unchanged )
```

## usecase.3 = init and upgrade render the repo and the actors — S3 · S5 · S6

```
given( a repo with linked roles and enrolled actors, some with a live clone )
  when( a human runs `rhx init` or `rhx upgrade` )
    then( <repo>/.claude is a symlink to .agent/.actors/actor.via.slug=.default/brain/.claude )
    then( <repo>/.claude/boot.md holds the repo's default roles )
    then( <repo>/.claude/AGENTS.md holds @boot.md )
    then( <repo>/.claude/CLAUDE.md is a symlink to AGENTS.md )
    then( boot.md is ignored by git, and AGENTS.md, CLAUDE.md and settings.json are tracked )
    then( every other actor dir under .agent/.actors/ is ignored by git )
    then( each actor with a live clone has its boot.md re-rendered )
    then( an actor with no live clone is left alone, and renders at its next spawn )
    then( the role boot hooks are absent from .claude/settings.json )
    then( a human's own hooks and the adhoc boot hook remain )

  when( <repo>/.claude is a real dir with settings.json and a human's own files )
    then( each entry moves into the default brain dir, and <repo>/.claude becomes the symlink )
    then( stdout names every move )
      sothat( the human commits the moves as renames, and no config is lost )

  when( <repo>/.claude is a real dir that holds its own AGENTS.md, CLAUDE.md or boot.md )
    then( each is dropped, not moved, and stdout names the drop )
    then( the default brain dir's AGENTS.md holds @boot.md alone )
      sothat( rhachet owns the whole boot context of the brain dir )

  when( <repo>/.claude and the default brain dir both hold a file of one name, other than AGENTS.md, CLAUDE.md or boot.md )
    then( init refuses, exit 2, and names each collision )
    then( no file moves )

  when( one actor's render fails )
    then( every other actor still renders )
    then( the failure is named on stderr, and the run exits non-zero — 2 when the human must fix it, 1 otherwise )
```

## usecase.4 = an unenrolled `claude` gets the repo's default — S3 · S9

```
given( a repo after `rhx init` )
  when( a human runs `claude` directly )
    then( the clone quotes a rule from a repo default role )
      sothat( the corpus rides the core .claude/CLAUDE.md door, with no gate to miss )
```

## usecase.5 = a role's content changes — S6

```
given( an actor with a live clone )
  when( `rhx upgrade` brings a changed brief )
    then( the actor's boot.md holds the changed brief )
    then( the live clone holds it after its next compaction )
    then( a new clone of that actor holds it at spawn )
      sothat( clones reference the actor — no drift apparatus is owed )
```

## usecase.6 = a role set changes — S6

```
given( a live clone of an actor with roles X,Y )
  when( a human enrolls X,Y,Z )
    then( a new actor is created, with its own brain dir )
    then( the prior clone still holds X,Y and never Z )
      sothat( a new roleset is a new actor, correctly )
```

## usecase.7 = the same enrollment renders twice — S6

```
given( one set of roles, at one package version )
  when( it is rendered in two worktrees, or on two hosts )
    then( the two boot.md files are byte-identical )

given( the role packages are upgraded )
  when( the same enrollment renders again )
    then( the result may differ )
```

## usecase.8 = a route advances — S4

```
given( a clone driven along a route )
  when( the route advances to a stone that declares briefs )
    then( that stone's briefs arrive via the adhoc hook )
    then( the role corpus in boot.md is unchanged )
      sothat( the cached prefix survives a route advance )
```

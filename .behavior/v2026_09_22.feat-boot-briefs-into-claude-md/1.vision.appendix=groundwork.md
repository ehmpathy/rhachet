## .internal — today's trunk, the seam

- the boot path: a role declares an `onBoot` hook → `syncHooksForLinkedRoles` writes it into
  `.claude/settings.json` as `SessionStart` → the cli runs `rhachet roles boot` → stdout.
- `invokeRolesBoot.ts` → `bootRoleResources()`; `boot.yml` parsed by `parseRoleBootYaml.ts`;
  say/ref partition in `computeBootPlan.ts`.
- `syncHooksForLinkedRoles` also writes each actor's `<actorDir>/brain/.claude/settings.json`
  (`:182-187`); `init.hooks.acceptance.test.ts:297` pins that path.
- `asBrainCliSpawnArgs` emits `--setting-sources local --settings <configPath>`;
  `asBrainCliSpawnArgs.test.ts:39-45` clamps the exact array.
- `genBrainCliConfigArtifact` reads `.claude/settings.json`, filters hooks by enrolled role, and
  writes `.claude/settings.enroll.$hash.local.json` via temp + rename.
- `findRolesWithBootableButNoHook` → `assertRegistryBootHooksDeclared` demands an `onBoot` hook of
  every role with briefs or skills.
- the cli is an ambient host binary: no `@anthropic-ai/claude-code` dependency, no version gate.
  on this host 2.1.87 wins `PATH` ahead of 2.1.278.
- `.agent/.actors/` is gitignored by `findsertAgentEphemeralGitignore`.

# 4.1.roadmap — boot briefs into the brain dir

the build order for `3.3.1.blueprint.product.yield.md` (no factory blueprint was declared). each
phase lists what it depends on, the briefs to read first, the work as a checklist, and the check that
proves it done. a phase is done only when its check passes; the next phase starts after that.

the blueprint stays the source of truth for names, shapes and test cases. this roadmap orders them
and adds the items that review rounds settled after the blueprint was approved (marked `[r011]` and
`[r012]`).

## .the briefs every phase reads

- `3.3.1.blueprint.product.yield.md` — the decisions D1–D13, the filediff tree, the codepaths, and the
  `.by case` rows for the units of the phase
- `3.1.3.research.internal.product.code.prod._.yield.md` — the extant code each phase touches
- `.agent/repo=.this/role=any/briefs/define.brain-dir-repo-vs-actor.md` — which brain dir each command
  writes
- `.agent/repo=.this/role=any/briefs/rule.forbid.per-clone-config.md` — every artifact here is the
  actor's, never the clone's

a phase with tests also reads `3.1.3.research.internal.product.code.test._.yield.md` (aliases,
`envIsolated`, the stub brain, sentinels, `genTempDir`). a phase with acceptance tests also reads
`2.1.criteria.blackbox.yield.md` and `2.2.criteria.blackbox.matrix.yield.md`.

## .the dependency order

```
p0 infra ─┬─ p1 render ── p2 linked refs ─┬─ p4 default brain dir ─┐
          │                               ├─ p5 actor sweep ───────┼─ p6 init · upgrade · roles link ─ p7 hooks + introspect ─ p8 journey ─ p9 dogfood + records
          └─ p3 enroll ───────────────────┴────────────────────────┘
```

p3 needs p1 (the actor render) and p2 (the refs), so it lands after both. p4 and p5 can run in either
order. p6 needs p3, p4 and p5. the journey (p8) needs every product phase.

## .local test rule

each phase runs `rhx git.repo.test` scoped to its own files, never a local full sweep
(`rule.forbid.local-full-test-sweeps`). ci runs the full suite on the pr. after a src change, run
`npm run build` before `npx rhx` (`howto.test-local-rhachet.md`).

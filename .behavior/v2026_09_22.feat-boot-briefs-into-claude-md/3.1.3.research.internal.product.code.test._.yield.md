# 3.1.3.research.internal.product.code.test._ — the test surface this behavior builds on

> **the enroll harness already relocates the config dir: the stub brain reads `CLAUDE_CONFIG_DIR`, and
> the binary invoker takes an env override. no test anywhere names an instruction file — every
> corpus-delivery assertion is new surface.**

test code only. each pattern carries a verdict — `[REUSE]` · `[EXTEND]` · `[REPLACE]` — and
numbered citations `[Cn]`, quoted verbatim in `.citations`.

## .what the blueprint owes, from this stone

1. `@src/` imports in every new unit test; `THOROUGH` in verification (T1, T2).
2. a synthetic role fixture for the `boot.md` snapshot (T10).
3. the stub brain reports its version and the config dir's instruction files (T13).
4. `genCloneHistoryLink`'s suite passes the brain dir, not a parent env (T18).
5. first-run state in a relocated brain dir (T16) — external M3.
6. delete the manifest suites with their subjects (T25).

# case=7 — the dense journey: one session, nine cells, two actors

> **the densest walk this wish implies.** one enrollment, one route, one compaction — and it
> crosses **nine of the twenty-six cells** in a single realistic session.
>
> 🟡 all nine are **attended** cells: this journey has a human in the loop throughout, which is
> what makes it a *journey*. the unattended half of the space is demoed in `case=3`, `case=4`, and
> `case=10` part B.
>
> 🔴 **`[t8]` is dissolved by F21.** the drift it walks is unreachable under the reference model —
> a content change reaches the clone at `/compact`, and a set change is a new actor by design. see
> `case=_` row #8; the proof is blueprint journey `[t4]` and `[t6]`.
>
> **the two actors are Kai (`[t0]`–`[t8]`) and Mira (`[t9]`)**, and the second is not decoration:
> the cache claim is *only* checkable across two humans, since one human's second worktree is
> indistinguishable from their own first one resumed.
>
> it exists because `define.experience._.metric=boundary-density` says the dense path is
> simultaneously the **highest-value** demo (it discharges nine cells' boundary coverage in one
> walk) and the **highest-risk** one (boundaries interact, and defects cluster where they pile up).
>
> **and it earned its keep: it exposed two interactions no single-cell demo could see.** both are
> recorded below.

## .the narrative

it is a saturday. Kai enrolls a clone and drives one route on it, start to finish.

### `[t0]` the bind

```
rhx enroll claude --roles mechanic,driver,learner
```

the role set resolves, the corpus renders, the artifact is written. a second run on the same role
set produces a **byte-identical** file — no timestamp, no absolute path, no set order that drifts.
the session's first request is a cache **write**.

### `[t1]` the delivery

Kai asks a question whose answer lives deep in the corpus — a learner brief, well past the
10,000-character mark that today's hook would have cut at. **the clone answers from the brief's
actual content.** that answer is unavailable to a clone that holds a 2,000-character preview.

### `[t2]` the stone's own briefs

the driver reaches `3.3.1.blueprint`. that stone's manifest names the blueprint practice briefs —
a set the vision stone never needed.

```
rhx roles boot --manifest .behavior/…/boot.3.3.1.yml
```

the payload **appends to the conversation**. the clone has the blueprint briefs this turn. the
cached prefix does not move, so the next turn is still a cache read.

### `[t3]` the gate, mid-route

Kai drafts the manifest for the **next** stone and over-packs it. the boot halts before it emits:

```
   ├─ ✋ over budget
   │  ├─ budget   = 2,000 tokens
   │  ├─ payload  = 3,140 tokens
   │  └─ over by  = 1,140 tokens
   │
   └─ fix — four strategies, cheapest first
      ├─ catalogize · condense · reference · eliminate
```

**the halt lands on the AUTHOR, mid-route, before a clone ever sees a byte.** that is the whole
contrast with `[t7]` below — and it is only visible because both sit in one walk.

### `[t4]` the advance

Kai condenses the manifest to fit; the route advances; the payload appends. **three brief sets have
now entered this session, and the role corpus has been paid for exactly once.**

### `[t5]` the role that does not take

the work turns architectural. Kai links the architect role:

```
rhx roles link --repo ehmpathy --role architect
```

**it does not take, for two independent reasons** — and **the first has no dependence on this
feature at all**: `roles link` materializes a role's directory into `.agent/`; it is not a
`--roles` delta command and it never changes an enrolled set. the second is ours: the corpus was
bound at enrollment, and Kai's is a **hash** actor — so a role change lands at a **different path**
and this session's file cannot change.

the drift signal fires and names the exact re-enroll command. Kai reads it and decides to finish
the stone first rather than restart the session.

⇒ see `case=6` for why the wrong-command half makes the sharp path **sharper**, not weaker.

### `[t6]` `/compact` — the role corpus survives

the conversation fills; the session compacts. the role corpus **re-applies intact**. the clone
still holds every brief it opened with.

### `[t7]` `/compact` — the adhoc corpus does not

the three manifests Kai booted at `[t2]` and `[t4]` were conversation content. at compaction they
are *"summarized with the rest of the conversation."*

⇒ **the clone comes out of the compact with all of its ROLE briefs and a lossy summary of its
STONE briefs — mid-stone.** it does not announce this. it simply gets vaguer about the practice
rules it was booted with, on the stone it is still on.

## .the two interactions this journey exposed — and no single-cell demo could

### interaction 1 — the survival asymmetry is a MID-FLIGHT capability loss

read alone, cell #7 says *"the role corpus survives `/compact`"* (good) and cell #16 says
*"adhoc content degrades at `/compact`"* (a known cost). **read in one walk, they are not two facts
— they are one failure mode:**

> **a compaction silently rolls the clone back to its enrollment-time knowledge, while the route
> insists it is still at stone `3.3.1`.**

| what the clone holds after `[t7]` | what the route believes |
|---|---|
| every role brief, intact | ✅ correct |
| a **summary** of the stone's practice briefs | the route believes the stone's briefs are loaded |

⇒ and the signal profile is the one this whole feature exists to kill: **loud success, quiet
wrongness.** `[t3]` proved the design halts loudly when a corpus is too big at *author* time.
`[t7]` shows it says not one word when a corpus is *lost* at runtime. **the same corpus, the same
session, opposite ergonomics.**

⇒ **this argument promoted cell #16 from alterpath to critipath, and the promotion is now
SETTLED in the inventory.** the reason is here — frequent (long routes compact), costly (the clone
works on without the briefs it was given), silent, and with **no wired fallback**.

⚠️ **and the promotion changed what this journey may claim.** `[t7]` is written to FAIL against
today's behavior, which is legitimate as a report of a gap and **illegitimate as the only demo of
a critipath** — a critipath owes a fail-safe, not merely an exposure.

⇒ **`case=8` is that fail-safe**, authored for exactly this obligation: the `matcher: compact`
re-delivery, shown fast, loud, and it teaches the fix. it closes #16 and its unattended twin #24.

> 🟡 **the division of labor between the two demos is the point: this journey proves the loss is
> REAL; `case=8` proves it is REPAIRABLE.** neither alone discharges a critipath.

### interaction 2 — the drift at `[t5]` outlives the compaction at `[t6]`, and F1 decides whether

case=6 says a mid-session role change is inert *"until the session is compacted."* a reader stops
there and concludes: **`[t6]` fixes `[t5]`.** the walk says it turns entirely on the transport:

| transport | does the `[t6]` compaction pick up the architect role linked at `[t5]`? |
|---|---|
| **layer 1** — a system-prompt **file** | **no.** the cli reads the file **at launch**. compaction re-records the prompt from what it read then, so the corpus is still the enrollment-time one. **Kai must relaunch** |
| **layer 2** — a file re-read from disk | ✅ **yes** — *if* it re-reads, and *if* the file's content changed |

⇒ **this is the sharpest ergonomic consequence of F1**, and it was invisible until `[t5]` and
`[t6]` sat in one journey. the asymmetry is not a minor convenience — it decides whether *"wait for
the next compact"* is a real remedy or a false one.

## .F1 was RULED, then REVERSED — and the answer here did NOT flip with it

S6 took row 1 and this case read off *"relaunch is owed"*. **S12 reversed to `<brainDir>/AGENTS.md`
— a layer-2 file.** a careless propagation would flip this section to row 2. **it does not flip**,
because row 2 has two conditions and this walk fails the second:

| row 2's condition | at `[t5]` |
|---|---|
| the transport re-reads from disk | ⚠️ **unmeasured** — `[research]` row 1 |
| the file's **content changed** | **no.** Kai's actor is a **hash** actor, so a role change is a **different path**. this session's file is byte-unchanged forever |

⇒ **the outcome is identical and the reason is not.** the drift from `[t5]` survives the compaction
on the fleet's default actor form, *"wait for the next compact"* is still a **false remedy**, and a
**relaunch is still owed** — now because the path moved, never because the prompt was recorded.

🟡 **on a slug or derived actor the answer may differ**, and that is a new branch the reversal
opened. it does not disturb this journey: `rhx enroll` produces hash actors.

⇒ **the asymmetry did not vanish with either verdict — it became a requirement.** the drift must be
**detected and named** rather than waited out; that is the `[t5]` fail-safe this case demonstrates.

### `[t9]` the second actor — Mira, in a worktree of her own

Kai's session is still open. across the room, **Mira** clones a second worktree of the same repo
and enrolls the same role set for a parallel piece of the work.

her first request comes back noticeably faster than Kai's did that morning — and the statusline
says why: a cache **read**, not a write. **she paid for none of the corpus Kai's session already
wrote.** it is the only moment in this journey where the feature's cost claim is *felt* rather
than asserted, and the feel is a one-word one: **immediate.**

**and it is only checkable with a second human in it.** one human's second worktree is
indistinguishable from their own first one resumed, so a single-actor walk cannot tell a shared
cache from a warm one. ⇒ **Mira is why this is a journey rather than a session**, and she is the
second of the two actors the header names. she is the same colleague `case=1` casts, for the same
claim at a different grain: `case=1` proves two enrolls render **identical bytes**; this proves
those bytes are **paid for once**.

⚠️ **the whole beat is conditional on one flag** — without
`--exclude-dynamic-system-prompt-sections` the cache is scoped per directory, *"and that includes
worktrees of the same repository"*. ⇒ Mira's fast first request becomes a second full write, and
the fleet pays the cost this feature exists to remove, one layer up.

## 🟡 .what this journey deliberately does NOT do

per the density brief's one guardrail — *"dense journeys for breadth, focused spotlights for each
sharp critipath's fail-safe"* — this walk **brushes** boundaries that other cases **prove**:

| it brushes | the spotlight that proves the fail-safe |
|---|---|
| the version floor (it assumes a machine above it) | `case=3` — fast, loud, names the binary and the fix |
| the budget halt at `[t3]` | `case=4` — the full halt, its four remedies, and today's silent counterpart |
| the compaction loss at `[t7]` | **`case=8` — the matcher-compact re-delivery.** this journey proves the loss is REAL; `case=8` proves it is REPAIRABLE. **neither alone discharges a critipath**, and `[t7]` says so in-row |
| the drift at `[t5]` | `case=6` — why the happy path is forbidden, and `[t0]`–`[t5]` on the signal itself |
| the stale corpus that outlives the boundary at `[t8]` | **`case=10` — the survive-boundary corpus-identity assertion.** identical division of labor to `[t7]`/`case=8`, one corpus over: this proves the drift SURVIVES the boundary, `case=10` proves it is DETECTABLE there |

⇒ **the spotlights are not redundant with this journey.** a boundary crossed is not a boundary
proven safe.

# 1.vision · a live clone takes boot drift at compaction

## .what this builds

#713 boots each clone with its actor's `boot.md` as `--system-prompt-file`, so the boot is a cache
prefix shared by every session of a role set. the cost: the system prompt is recorded once, so a clone
keeps its spawn boot for life.

this work leaves the system prompt alone and carries **only the drift** through the door claude
already re-reads at compaction: a `CLAUDE.md` of the clone's own.

```
.agent/.actors/<actor>/
  brain/.claude/boot.md                       # the boot, re-rendered in place by rhx init (unchanged)
  boots/sha256=<h>/                           # new · one per boot revision a clone spawned on
    boot.md                                   #   the bytes of that revision — the baseline
    CLAUDE.md                                 #   the drift: that revision → the current boot.md
  clones/serial=<uuid>/
    boot.spawned.ref                          # new · sha256=<h> — which revision this run spawned on
    boot.drift.told                           # new · the drift hash the onStop nudge last spoke of
```

## .the shape

| moment | what happens |
|---|---|
| **spawn** | hash `boot.md`; findsert `boots/sha256=<h>/` (bytes + empty `CLAUDE.md`); write `boot.spawned.ref`; add `--add-dir boots/sha256=<h>` before `--system-prompt-file`; the env sets `CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD=1` and drops `CLAUDE_CODE_DISABLE_CLAUDE_MDS`, with the actor's own `CLAUDE.md` excluded by `claudeMdExcludes` so the boot loads once |
| **render** (`setBrainDirBoot`) | after `boot.md` is rewritten, re-write `CLAUDE.md` in every `boots/sha256=*/` of that actor: `asBootDelta(revision, current)`. no drift → empty file. the fan-out sits inside `setBrainDirBoot`, so each of its three callers carries it: `rhx init` (`setRepoActorBrainDir`, `syncActiveActorBrainDirs`) and every `rhx enroll` (`invokeEnroll.ts:555`), which re-renders at spawn. so a peer's enroll after a brief edit also reaches the live clones |
| **compaction** (manual or auto) | the brain cli re-reads memory; the clone reads the drift. the system block is byte-identical, so the boot still reads from cache |
| **resume** (`--resume`, `-r`, `--continue`, `-c`, `--from-pr`) | the resumed session's system prompt is its first spawn's, which this spawn cannot name. so the spawn records no ref, passes no `--add-dir`, and marks the clone `boot.spawned.resumed`: it takes no drift, and the enroll tree, `--of`, and the init readout each say so and name respawn, never "current". the carry-over of the first spawn's ref is the F7 dream (case=4) |
| **stop** | `rhx clone boot drift --when hook.onStop`, declared by a role: over the threshold and not yet told → one block (exit 2) that names the drift and the two ways out; past the 2000 line cap the drift file is a stub with no block, and the nudge names respawn as the one cure; else silent |

the delta is per block (`asBootPartition`): a `<brief.say path=…>` block that changed appears in full under
`## changed`; a new one under `## added`; a gone one by key under `## removed`. a lead says each block
supersedes the block of the same path in the system prompt. a move say → ref reads as one removed, one
added, which is what changed for the reader. a boot whose bytes differ with no block changed (text
outside any `path=` block, such as the cache boundary line or a wrapper) renders a `## outside the
briefs` section that says the boot changed where no brief can carry it, and to respawn to take it;
it counts toward the threshold like any block, so a large one nudges. a byte change never yields an
empty delta. the delta's first line is a marker, `drift=<hash of the delta>`, so any actor can check whether
a compacted clone took it (case=7).

the draft in `rhachet.fix-boot-briefs-cacheable` carries most of this: `asBootBlocks`, `asBootDelta`,
the `--add-dir` arg and the env pair, the render fan-out, and `rhx boot.delta.probe`. the change from the
draft is where the baseline lives (F1) and the onStop half, which the draft lacks.

## .the outcome world

**before.** the editor fixes a rule at noon. the five clones live since dawn keep the old rule until
each is respawned, and a respawn loses the conversation. so either the fix waits, or the work restarts.

**after.** the editor fixes the rule and runs `rhx init`. each live clone meets the new text at its next
compaction, mid-route, conversation kept. a new clone spawns on the new boot with no drift at all. a
clone whose drift has grown large is told once, at a stop, to compact or respawn.

**the aha.** the drift costs the cached prefix naught. the boot in the system block never changes; only
the memory message, which is rebuilt at every compaction regardless, carries the change.

## .evaluation

| goal (wish) | how it is met |
|---|---|
| the spawn boot is kept per clone and the delta is computable | a ref per clone; the bytes once per revision in the actor dir; `asBootDelta` over the pair |
| only the delta lands in `CLAUDE.md`; the cached system prompt stays whole | the system prompt argv is #713's, untouched; the drift rides memory alone (case=1 `[t1]`) |
| an onStop reminder once the delta passes a threshold | `rhx clone boot drift --when hook.onStop`, 200 lines, once per drift hash (case=2) |
| green and up for review by the wish's deadline | the draft carries the core; the new work is the content address, the ref, and the hook command |

**pros.** zero cost to the shared boot cache · no restart for an edit · one delta per revision, shared by
reference · a resume is never told it is current · legacy clones are untouched.

**cons.** the drift is a user message, which Anthropic says carries *"marginally less weight"* than the
system prompt it supersedes (`define.claude-md-vs-system-prompt`) · the clone holds both the old and new
text of a changed brief until it respawns · a clone cannot `/compact` itself.

**edges, and how the contract holds the pit of success.**

| edge | the hold |
|---|---|
| a render lands between the spawn's hash and the brain cli's read of `boot.md` | the baseline is one render older than the prompt: the delta repeats a block the clone already has. redundant, never absent |
| two renders before one compaction | the delta re-computes from the revision each time; it never stacks |
| a hash actor gains a role | a new actor, not drift (forbidden cell 23) |
| `boots/` grows as revisions accrue | one dir per revision a clone spawned on, never per render. a revision no clone refers to, and not the current boot, is reaped by `clone prune --mode apply` |
| the repo actor dir is tracked in git | `boots/` and the clone files are gitignored beside the extant `clones/` rule |
| a ref names a gone revision, or a delta cannot be read | loud, never stranded (case 21): `💥 MalfunctionError` with the path; the hook exits 1, which never blocks a stop; the render marks that revision `✗` and re-writes the rest |
| the drift door never worked, or a brain cli release drops it | never silent (case=7): the measure gates the design before any change lands; the journey's live-brain `[t4]` turns red on a cli bump that drops it; at run time the delta's `drift=<hash>` marker lets the clone, its enroller, or the editor check a compacted clone in one command, and the drift tree names respawn as the cure |

## .the requirement this amends

`inventory.of=requirements.case=11` states that *"a clone already live keeps the boot it spawned with —
through each turn and through `/compact`"*. this wish amends its second half: a live clone keeps its
spawn boot **in its system prompt**, and takes the drift **through memory** at compaction. the first half
(a boot edit reaches every clone spawned after it) stands. the journey `[t4]` assertion that the
compacted clone does NOT quote the new sentinel flips to: it quotes the new sentinel, and its system
block still holds the spawn bytes. the entry is amended in this pr, dated, with the wish as its source.

## .what is awkward

- **a clone cannot compact itself.** the nudge tells a clone what it cannot do alone; it relays to its
  enroller. for an autonomous clone, the drift waits for auto-compaction
- **two copies of a changed brief, in two channels.** the system prompt holds the old text with more
  weight; the drift holds the new with marginally less. the lead's "supersedes" carries the order. a
  respawn is the only full cure, and the nudge says so
- **the hook needs a role we do not yet have.** the mechanism is ready before its declaration site is
  (F2)
- **a block-grain delta is coarse.** a one-word fix to a 3k-line brief carries all 3k lines

## .pushback footnote

- **the spawn boot lives once per revision, under the actor, and a clone holds only a ref to it.** the
  wish places it "beside the clone record"; a full copy per clone is a frozen snapshot of what the actor
  owns, which `rule.forbid.per-clone-config` grades a blocker, and it costs 441,263 chars per clone where
  a ref costs one revision per distinct boot
- **every brain dir door is shut by `claudeMdExcludes`, the actor's own door included, and the
  `CLAUDE.md` env switch is off.** the switch shuts the `--add-dir` load too, so a clone under it reads
  no drift (`rhx boot.delta.probe`, 2026-11-17: the clone answered `NONE` to the drift sentinel); an
  open own door loads the boot a second time (~257k tokens, refused). the exclude keeps both facts:
  the boot loads once, from the system prompt, and the drift loads at compaction
  (`rhx boot.compact.probe --door add-dir` ✓, 2026-11-18). this departs from #713's F14
  (`.behavior/v2026_11_02.fix-boot-briefs-cacheable`), which kept the switch for want of a probe

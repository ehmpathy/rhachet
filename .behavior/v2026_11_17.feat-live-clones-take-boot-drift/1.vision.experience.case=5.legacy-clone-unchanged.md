# case=5 · a clone spawned before this release is left as it was

sharp · critipath. cells: clone, inspector · legacy · * · * · * · n/a · * · n/a · * · n/a.

## .narrative

`@:old` has worked since before the upgrade. the editor fixes a brief and renders. for `@:old` naught
changes: no file appears in its dir, no stop is blocked, no new note reaches it. it compacts later and
still holds the boot it spawned with, exactly as it did under #713. it is never told a half-truth.

its enroller notices the old rule in a reply and wonders why the fix did not reach it. they run
`rhx clone boot drift --of @:old`, and the answer is plain: this clone predates boot drift, so it holds
its spawn boot until a respawn. they respawn it, and it starts clean.

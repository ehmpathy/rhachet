wish =

wish: a live clone takes boot updates at compaction, via the boot drift, the fast follow the commander named on ehmpathy/rhachet#713 (review thread r4598742745).

why: #713 boots each clone via --system-prompt-file, so the boot caches across sessions. but a clone spawned before a brief or skill changed keeps its spawn boot for its whole life. the commander approved #713 with this as the fast follow, p0, due today.

outcome:
- per clone, the boot it spawned with is kept beside the clone record under .agent/.actors/.clones, and the delta between that spawn boot and the current boot can be computed
- only the delta lands in CLAUDE.md, so a compaction picks up what changed and the cached system prompt stays whole
- an onStop reminder fires once the delta passes a threshold, so a long-lived clone knows to compact or respawn
- the pr is green on ci and up for the commander's review by 2026-11-17 [time]

start point: a first draft of this work sits uncommitted in the tree rhachet.fix-boot-briefs-cacheable (asBootDelta, asBootBlocks, setCloneBootDelta, setCloneBootDeltasForActor, setCloneBootSpawned, getCloneBootDir, asBrainCliSpawnArgsWithCloneBootDir, with edits to invokeEnroll, setBrainDirBoot, genCloneOndisk, asBrainCliSpawnEnv). it was kept out of the #713 release on purpose; the director carries it into this tree.


## the shape of the vision and the pr body

this section rides every dispatch; the sprout adds it to the wish.

- the solution is the body. the vision artifact and the pr body lead with what this work builds and why it works
- each ends with a short `## pushback footnote`, placed last: one line per prior decision this work pushes back on
  - the line names the decision, where it was made (a path, a pr, or a brief), and the stat or read that overturns it
  - e.g. `- <the decision> — <where it was made> — overturned by <the stat or read>`
- no prior decision pushed back on → no footnote at all. never an empty section, never a "none" line
- a pushback with no stat or read behind it is no pushback: keep the prior decision, or go get the read

the commander: "the focus should be on the solution" · "the pushback callout should just be a footnote" · "to show proof of thought" · "id rather have the better solution though when its grounded in stats"

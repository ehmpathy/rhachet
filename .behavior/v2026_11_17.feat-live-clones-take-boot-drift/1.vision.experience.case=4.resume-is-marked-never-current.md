# case=4 · a resumed session is marked as one, and never told it is current

sharp · critipath. cells: before · any · resumed-after · any · n/a.

## .narrative

`@:reviewer` was spawned on `sha256=a1`, then died. the boot moved to `sha256=c3`. the enroller resumes
its session (`rhx enroll claude --resume <session>`). the brain cli ignores the `--system-prompt-file`
of a resumed session and sends the system prompt the session first recorded, measured 2026-11-03
(`rhx boot.resume.probe`). so the clone's real baseline is still `a1`, not `c3`.

this release does not carry `a1` into the resumed record: that carry-over is the F7 dream
(`.dream/v2026_11_17.feat.resume-carries-its-session-boot-revision.md`). what it does is refuse to
pretend. a ref to `c3` would claim a boot the clone does not hold, and the readout would then say
"no drift". so a resume records no ref, gets no `--add-dir`, and is marked `boot.spawned.resumed`.
every reader that meets the mark says the clone takes no drift and names respawn.

a resume is any argv the brain cli reads as one: `--resume`, `-r`, `--continue`, `-c`, `--from-pr`,
or an inline `--resume=` / `--from-pr=`. `--session-id` names a new session and is not one.

## .timeline

```
given('[case4] @:reviewer, spawned on sha256=a1, now dead; the actor boot.md now at sha256=c3')
  when('[t0] rhx enroll claude --resume <its session id>')
    then('the new clone record holds boot.spawned.resumed, and no boot.spawned.ref')
    then('the argv names no --add-dir; the boot file is the actor boot.md')
    then('the enroll tree says: "🟡 a resume holds the boot its session first recorded, so it takes no drift at any compaction; respawn to take the current boot"')
  when('[t1] rhx clone boot drift --of @:reviewer')
    then('it says the clone takes no drift at any compaction, and names respawn; never "holds the current boot"')
  when('[t2] the onStop hook runs inside the resumed clone')
    then('it is silent, exit 0: there is no drift it could take')
  when('[t3] the editor runs rhx init')
    then('the drift branch counts it among the clones outside the drift, and names respawn')
```

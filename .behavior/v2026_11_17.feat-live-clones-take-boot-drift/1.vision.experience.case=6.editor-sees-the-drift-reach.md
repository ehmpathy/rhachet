# case=6 · the editor sees where the drift went

happy · critipath. cells: editor, inspector · * · * · live-at-render/dead-at-render · * · * · shared/stacked · * · * · whole.

## .narrative

the editor fixes a brief and runs `rhx init`. the question in their head is not "did the boot
render", which init already answers, but "do my live clones get this?". the boot report answers it in
one branch per actor: how many spawn revisions had their drift re-written, how many clones refer to
them, and how many sit outside the drift's reach. the count is of clones that refer to a revision,
live or dead (F20): a split would need a reach probe per clone at render. to look at one clone, the
editor runs `rhx clone boot drift --of @:reviewer` and sees the same tree the onStop nudge would
print, with no block and exit 0.

## .timeline

```
given('[case6] the repo actor has 3 clones on sha256=a1 or sha256=b2, and 1 resumed clone')
  when('[t0] the editor changes a brief and runs rhx init')
    then('the boot branch of the repo actor gains one subbranch')
    then('  └─ drift
              ├─ 2 spawn revisions re-written
              ├─ 3 clones refer to them; a live one takes the drift at its next compaction
              └─ 🟡 1 clone sits outside the drift, spawned before boot drift or by a resume — respawn a live one to take the boot')
  when('[t1] rhx init runs again with no change')
    then('the drift subbranch reads "no change", and no drift file is rewritten')
  when('[t2] rhx clone boot drift --of @:reviewer')
    then('exit 0, the drift tree: spawn revision, blocks changed/added/removed, lines of drift against the threshold')
  when('[t3] rhx clone boot drift --of @:nobody')
    then('exit 2, ✋ ConstraintError: no clone answers @:nobody, with the hint rhx clone list')
```

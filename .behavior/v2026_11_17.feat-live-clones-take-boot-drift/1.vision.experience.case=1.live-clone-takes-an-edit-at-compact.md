# case=1 · a live clone takes a brief edit at compact

happy · critipath. cells: before · changed · live · compact · under.

## .narrative

`@:reviewer` has run for three hours on a long route. the editor sharpens
`rule.forbid.overzealous-blockers` and runs `rhx init`. the render rewrites the actor's `boot.md`, then
re-writes the delta of every spawn revision a clone of that actor still holds.

`@:reviewer` keeps its turns. its system prompt still holds the boot it spawned with, so each request
reads the boot from cache as before. at its next `/compact`, the brain cli re-reads its memory, and
its memory now holds one block: the new text of that rule, under a lead that says it supersedes the
block of the same path. the conversation summary survives. the next review grades a cosmetic point a
nitpick.

## .timeline

```
given('[case1] @:reviewer, spawned on boot revision sha256=a1, live for hours')
  when('[t0] the editor changes rule.forbid.overzealous-blockers and runs rhx init')
    then('the actor boot.md is re-rendered in place — revision sha256=b2')
    then('boots/sha256=a1/CLAUDE.md holds "# boot drift since this clone spawned" + "## changed" + that one block')
    then('@:reviewer system prompt is unchanged; its next request reads the boot from cache')
  when('[t1] @:reviewer is compacted (/compact)')
    then('the request after the compaction holds the changed block in its messages')
    then('the request after the compaction holds the spawn boot in its system block, byte-identical')
  when('[t2] @:reviewer is asked which rule governs blocker severity')
    then('it cites the new text, not the spawn text')
  when('[t3] the editor removes a brief, then runs rhx init again')
    then('the delta re-computes against sha256=a1: the changed block, plus "## removed" with that path')
```

## .the aha

the clone did not restart, did not lose its conversation, and did not cost a fresh boot cache write.
the change rode in through the one door claude already re-reads at compaction.

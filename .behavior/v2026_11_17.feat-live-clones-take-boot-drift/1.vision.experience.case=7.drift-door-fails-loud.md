# case=7 · the drift door fails, and someone sees it

sharp · critipath. cells: clone, enroller, editor · before · * · live-at-render · compact · under/over ·
* · fails · * · whole.

## .narrative

the editor fixed `rule.forbid.overzealous-blockers` an hour ago and rendered. the init tree said the
drift reached `@:reviewer`. now `@:reviewer`, freshly compacted, grades a cosmetic point a blocker
again, as if the fix never happened.

the editor does not have to guess. they run `rhx clone boot drift --of @:reviewer`. the tree names the
drift the clone should hold, `drift=d9`, and says plainly: a compacted clone that does not hold it did
not take the drift, so respawn it. the enroller asks `@:reviewer` which drift marker its memory holds;
it names none. so the door failed for this clone, and both of them know, in two commands, from their
own seats. the enroller respawns it, and the next review grades the point a nitpick.

the editor never meets the broad form of this failure, a door that does not work at all. that is
ruled out before any release by a measure on a real clone, and a brain cli bump that later breaks the
door turns a test red before it reaches them. the yield carries both guards.

## .timeline

```
given('[case7] @:reviewer on sha256=a1, live; the boot moved to sha256=b2; the delta opens with drift=d9')
  when('[t0] the editor, puzzled by an old-rule reply, runs rhx clone boot drift --of @:reviewer')
    then('exit 0; the tree names spawn revision a1, the drift d9, its counts and size')
    then('it says: "a compacted clone that does not hold drift=d9 did not take the drift — respawn it"')
  when('[t1] the enroller asks @:reviewer which drift marker its memory holds')
    then('a clone whose door works names drift=d9')
    then('a clone whose door failed names none, and the enroller knows to respawn it')
  when('[t2] the enroller respawns @:reviewer')
    then('it spawns on sha256=b2 with an empty delta, and holds the fixed rule in its system prompt')
```

## .why this fails safe

the failure is never inferred from silence. any actor who meets a stale reply can check the clone in
one command, read the cure in the answer, and apply it. the build-time measure and the cli-bump test
(in the yield) keep the door from a failure for every clone at once.

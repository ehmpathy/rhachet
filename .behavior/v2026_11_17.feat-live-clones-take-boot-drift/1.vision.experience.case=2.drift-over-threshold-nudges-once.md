# case=2 · the drift outgrows the threshold, and the clone is told once

sharp · critipath. cells: before · any · live · none-yet · over.

## .narrative

`@:driver` spawned at dawn. since then the editor has landed four brief revisions and a new role
brief. the delta for `@:driver`'s spawn revision has grown past 200 lines, the length the brain cli's
own docs name as the point where a memory file starts to cost adherence.

at its next stop, `@:driver` meets the drift hook once. the hook names how many blocks drifted and how
big the carry is, and gives the two ways out: compact to take it, or respawn to drop it. the clone
relays that to its enroller and stops. the hook does not fire again on the next stop: it has already
spoken about this drift. it speaks again only if the drift changes.

## .timeline

```
given('[case2] @:driver on spawn revision sha256=a1; the drift hook is declared by a role @:driver carries')
  when('[t0] a render grows boots/sha256=a1/CLAUDE.md to 212 lines (5 changed, 1 added)')
    then('no output at render time names @:driver — the render reports per actor, not per clone')
  when('[t1] @:driver stops a turn')
    then('rhx clone boot drift --when hook.onStop exits 2 with one tree on stderr')
    then('  😶 boot drift
            ├─ 6 blocks drifted since this clone spawned (5 changed, 1 added)
            ├─ 212 lines of drift, over the 200 line threshold
            ├─ if you already hold drift = <hash>, a compaction took it; naught is owed
            └─ to take it
               ├─ /compact — reads the drift in, the conversation kept; a clone cannot run it, so ask your enroller to send it
               │  ├─ rhx clone say @:driver --what /compact
               │  └─ after it, you should hold drift = <hash>
               └─ respawn — the new boot loads whole, from the shared cache; the sure cure')
    then('past the 2000 line cap, the tree names respawn as the one cure and offers no /compact (row 26)')
    then('the copy never asserts the drift loaded: the hook reads disk, and cannot see the door (case=7)')
    then('the clone reads it and ends its turn with a line that says so to its enroller')
  when('[t2] @:driver stops again, the drift unchanged')
    then('the hook exits 0, silent — the latch holds this drift hash as already told')
  when('[t3] a render changes the drift again, still over the threshold')
    then('the next stop tells it once more, with the new counts')
  when('[t4] the hook runs in a process that is no clone (no RHACHET_CLONE_SERIAL)')
    then('it exits 0, silent — there is no spawn to drift from')
```

## .why it fails safe

the nudge blocks one stop per drift state, never a loop: the latch is keyed to the drift's own hash.
a process with no serial or no spawn ref has no drift, so the hook exits 0. a real fault (a ref that
names an absent revision, an unreadable delta) prints a `💥 MalfunctionError` and exits 1: loud, yet a
Stop hook's exit 1 never blocks the stop, so a faulty reminder cannot strand a clone.

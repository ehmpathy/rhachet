# case=6 — an install in a tree with a faulty mod

## .narrative

the installer — the commander, or a clone that bumps a dependency — runs `pnpm install` in a
director tree. it ends red: `prepare:rhachet` ran `rhx init`, which rendered every actor and then
exited 2 on a typo'd driver mod (usecase 12). to the installer, a dependency bump failed, and the
true cause sits three tools deep.

with the fix, the install ends green. its output names the skipped driver mod and its fix in the
same words enroll uses. the installer is not stopped; the clone that next boots in the tree is told
at boot and at each stop until the mod is cured.

## .bdd sketch

```
given a tree with role=driver modded (C4) and role=mechanic linked
  when [t0] rhx init --roles mechanic driver
    then it exits 0
    then stderr names role=driver as skipped, with its fix
    then the repo actor boot.md carries the driver as published, with <mod.skipped>
  when [t1] the typo is fixed and init runs again
    then it exits 0, the driver boots modded, and no skip is named
```

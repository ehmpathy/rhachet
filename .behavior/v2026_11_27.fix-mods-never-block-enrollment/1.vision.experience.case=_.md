# 1.vision.experience.case=_ — the inventory

axes: `1.vision.experience.dimensions.md`. feel = happy | sharp. care = critipath | alterpath
(freq × cost). verdict = demoed | itemized | forbidden | impossible.

`enroll · resume` is one D2 position (`dimensions.md`, `.enroll and resume are one position`), so
each row on it covers both. two meta-values, in any column:

- `any` — the row's verdict holds for every legal value of that column, stated once (in the group
  column: every group; in `lands`: every value the group allows, per `dimensions.md`)
- `—` — the column does not apply: either the row is an impossible or forbidden cell that no walk
  reaches, so it has no neighbor, cure, or feel to grade; or the row's subject is no mod fault (row
  31), so no D4, D5, or D6 value describes it

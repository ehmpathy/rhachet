# case=1 — a dev runs the integration and acceptance tiers with no anthropic creds

cells #1, #3 · feel happy · care criti

## .narrative

a clone on a fresh worktree changes how `clone say` frames a bracketed paste. it has no anthropic
login on this box and no reason to want one. it runs the impacted tiers.

before: among the matched suites are `*.realbrain.acceptance` probes (`saybulk-probe` exercises
exactly a bulk paste) and the `actorAsk` / `actorAct` integration suites on
`rhachet-brains-anthropic`. each one either fails loud with
`ConstraintError: real claude found but NOT authenticated`, or — on a box with creds — spends haiku
tokens and a real model round-trip to prove that bytes reach a pty or that a call returns a value.
the clone cannot tell "my change broke it" from "i lack a key".

after: the reach suites spawn the mock claude cli — it boots under the pty, takes the paste, writes
a claude-shaped transcript, and answers. the sdk suites take a mocked repl. the integration setup
no longer demands `ANTHROPIC_API_KEY`, so the tier starts at all. the run spends zero anthropic
tokens and is identical with or without anthropic creds. (keys for other brains — openai, xai — are
outside this wish and still gate the suites that use them.) the only suites that fail on this box are the
smoketests: loud, exit 2, each names itself a smoketest and names the login it needs. the clone
reads that as "not my change", and ci runs them with creds.

the aha: **the key is no longer a precondition to test rhachet.** it is a precondition only to
test claude.

});

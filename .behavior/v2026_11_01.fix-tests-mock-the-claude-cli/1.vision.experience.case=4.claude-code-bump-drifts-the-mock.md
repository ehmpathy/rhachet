# case=4 — a claude-code bump drifts the surface the mock imitates

cells #2, #11 · feel sharp · care criti

## .narrative

ci pins claude-code (2.1.292 today, `.github/workflows/.test.yml:321-322`). a dev opens a pr that
bumps the pin. the new release renames a transcript record field, or moves the transcript dir, or
changes how the tui acks a paste. the mock still writes the old shape, so every mech suite stays
green — correctly, for the mechanism it proves, and blind to the change.

the smoketests are the alarm, and they fire on that same pr, before merge. the smoketest at the
seam that moved goes red: `get` reads an empty history, or `say` never lands. the failure fails
safe: it is loud, it names the seam, and its hint says what a red smoketest beside green mech
suites means — rhachet no longer reads the real cli right, and the mock no longer tells the truth.

the dev fixes both halves: rhachet's reader adapts to the new shape (the smoketest goes green), and
the mock learns the new shape (the mech suites now exercise what real users meet). a mock update
alone would leave the smoketest red, which is the point — the smoketest proves rhachet, not the mock.

a dev whose own box runs a newer claude than the pin meets the same drift sooner, on the smoketest
they run with creds; the pr that bumps the pin is where it is settled.

this is why the wish has two halves, and why neither half may be dropped: the mock makes the bulk
cheap, and the smoketest keeps both rhachet and the mock honest.

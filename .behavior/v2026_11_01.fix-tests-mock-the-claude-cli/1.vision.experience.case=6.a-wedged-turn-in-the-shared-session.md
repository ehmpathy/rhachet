# case=6 — a wedged turn in the shared smoketest session

cell #10 · feel sharp · care criti

## .narrative

ci runs the shared real-haiku session: multi-turn reach, then bulk say, then queued say, then the
screen read. on turn two, haiku stalls — a slow model, or a modal the tui drew. the bulk-say clamp
waits out its bound and fails.

before this wish there was no such cascade, because each clamp booted its own claude: one wedge cost
one suite. the shared session is the price of six boots cut to one, and it brings a new failure
shape. if the later clamps simply ran on, each would read a brain still stuck on turn two and go
red for a cause it does not own. a dev who opens that log sees four red clamps and has to work out
that only one of them is real — the false-alarm shape the wish exists to remove.

so the session fails safe. the wedged turn reports itself: which clamp, which turn, how long it
waited, and the last screen it saw. every clamp after it reports `not reached — prior turn wedged
at <clamp>` rather than a verdict of its own. one red, named; the rest plainly unrun. the dev reads
one cause, not four.

the retry that `sayAndPollForMarker` already carries (up to 3 attempts) stays per turn, so a
transient stall recovers before it cascades at all.

## .[tn] sketch

```ts
given('[case6] the shared real-haiku session, one turn wedges', () => {
  when('[t0] the bulk-say turn stalls past its bound, after its retries', () => {
    then('the bulk-say clamp fails and names its turn, wait, and last screen', ...);
    then('each later clamp reports "not reached — prior turn wedged at bulk-say"', ...);
    then('no later clamp reports a verdict of its own', ...);
  });
  when('[t1] the stall is transient', () => {
    then('the per-turn retry recovers it and the session runs on', ...);
  });
});
```

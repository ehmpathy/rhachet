# 3.3.1.blueprint.product — tests run on a mock claude cli; only the smoketests call anthropic, on haiku

> the wish: every non-essential anthropic api test in rhachet runs on a mock of the claude cli; only
> the essential smoketest acceptance tests call the api, on haiku.
>
> settled before this blueprint: the vision (approved); seed S1 — every real-tui check stays a
> smoketest, in one shared haiku session; seed S2 — the sdk suites take a mocked repl inside rhachet,
> and an exec-path option in `rhachet-brains-anthropic` is a later dispatch to that repo
> (`.dream/v2026_11_02.reseed.brains-anthropic-takes-a-claude-exec-path.md`).

## .summary

five changes. each lands in test code, test infra, a skill, or a brief; no prod code under `src/`
changes.

1. **a smoketest registry** — one file declares every suite that may reach real claude and the seam
   each proves. the fence, the harness, and the drift check all read it
2. **the fence, at both doors** — a harness call reaches real claude through one function,
   `genRealClaudeAccess`: the fence, then the login and the bin, each with a named refusal. a
   child process that finds `claude` on PATH meets the tripwire, which each tier's globalSetup
   puts first on the real PATH, so real claude is reachable only by the access's bin. so an access
   from a suite off the registry is refused, loud,
   by either door; a registered smoketest that uses a mock, or names a model other than haiku, is
   caught by the drift check before merge
3. **one shared smoketest session** — the six `clone.*.realbrain.acceptance` suites fold into one
   suite that spawns one real `claude --model haiku` and runs each real-tui check as one turn, with a
   cascade guard so a wedged turn reports once and the rest read `not reached`
4. **the mock cli carries the mechanism** — each rhachet-behavior case those suites prove moves onto
   the mock cli, whose `busy` mode is first corrected to the real transcript measurement;
   `enroll.shared-brain-auth` keeps only the case where real claude clears the login. the research
   grid that `screen-dogfood` wrote moves into a byhand skill
5. **the sdk suites take a mocked repl** — `genMockedBrainRepl` gains an `output` input and a call
   log; the anthropic integration suites move onto it, and the integration setup stops its hard
   demand for `ANTHROPIC_API_KEY` (F5)

the mock is the default, enforced at two points. `genMockClaudeEnv` replaces
`setupRichStubBrainPath` outright, so the one way to put the mock cli on PATH also hands the child
a fake env token, and no PATH-only twin survives for a new suite to copy. a suite that forgets the
mock entirely does not fall through to the host's real claude: its PATH leads with the tripwire,
which refuses with the fence's text (vision case 3 [t1])

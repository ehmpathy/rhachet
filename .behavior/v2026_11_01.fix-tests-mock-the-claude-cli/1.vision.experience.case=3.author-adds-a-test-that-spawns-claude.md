# case=3 — an author adds a test that spawns claude

cells #4, #16, #17, #18 · feel sharp · care criti

## .narrative

an author writes a new suite for a clone behavior — say, how `clone get` renders a tool call. they
copy the nearest neighbour, which today is a `*.realbrain.acceptance` file, so their test calls
`getRealClaudeOrThrow` + `enrollRealClaudeAndWaitReach` and spends real haiku on every run. no one
notices; the bill and the wall clock creep up one suite at a time. that creep is how the repo got
here.

after: the shared harness hands out the mock by default. the path of least resistance —
`enrollCloneAndWaitReady` on the mock — is the right one for a mech test. to reach a real claude,
the author must go through one gate (the smoketest entry point), and that gate refuses a suite
that is not on the declared smoketest list, loud, with a message that says which backend to use
and why.

the overcorrection is refused too. an author who writes a smoketest and, on a box without creds,
points it at the mock to "get it green" meets the same wall from the other side: a smoketest
never runs on the mock.

and the quiet exit is refused. an author who finds a smoketest slow moves it out of the jest tier —
into a byhand skill, or behind a config that the default gate does not run — so the contract it
proved now has no proof at merge. the fence keeps its own clamp: it asserts that every seam the
smoketest set must cover has a declared suite in the jest tier. that clamp goes red, and names
the seam left with no real test.

# 1.vision.experience.case=_ — the inventory

every cell of [the dimensions](./1.vision.experience.dimensions.md), verdicted exactly once. the
box is D1 × … × D10 = 10368 cells; the six collapses in the dimensions file fold it to the rows below.
`fit` (D4 / D9 under D10) is defined there: valid / ok, or an input the smoketest does not read.

**rows are disjoint.** within a subject, no two rows share a cell: a `*` means "every value of that
axis", and a row carries a `*` only where no peer row names a value on that axis for the same other
coordinates. `—` means the axis does not apply, by the collapse the note names. so each cell has
one verdict.

**the actor column names who meets the cell in the normal flow, and when** — `write` (the author
picks this backend, venue, or session), `run` (a dev or ci runs it). an actor a row omits meets
that cell only from another actor's seat, and meets the same verdict there (collapse 1).

| from | invariant |
|---|---|

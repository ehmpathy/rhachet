# case=2 — ci runs the essential smoketests on haiku

cells #7, #9 (happy) · #12, #13, #14 (sharp) · feel happy + sharp · care criti

## .narrative — the happy half, as ci and the dev who opened the pr see it

a dev opens a pr that touches `clone say`. ci picks it up; it holds an anthropic credential and a
`claude` at the pinned version. the dev watches the acceptance job.

the job log names the smoketests before it runs them — a list short enough to read at a glance.
the bulk of the tier scrolls by on the mock, each suite in a second or two, zero tokens.

then the shared session boots: one real `claude --model haiku`, one trust walk, one ready banner.
the dev sees four clamps land against it, one turn each, in the order the log names:

1. **multi-turn reach** — a first `say` lands and its marker reads back through `clone get`; a
   second `say` to the same clone lands too, so reach holds past the first turn
2. **bulk say** — a long message goes in whole; `get` reads back every byte of it
3. **queued say** — a `say` sent while the brain is still busy lands as a user turn in the real
   transcript at submit, before the brain answers it — the fact the mock's `busy` mode now matches
4. **screen read** — `clone get --screen` returns the real tui's grid, with the last answer on it

each clamp prints its own line, green. the dev knows which seam each one held.

then the three own-session smoketests run, each in its own spawn because each needs its own home,
auth, or entry: a real claude loads the memory files rhachet laid down; a real claude-code clears a
dead login rhachet planted in an isolated home; the sdk door boots its bundled cli and answers. three
more green lines.

the dev reads the bill in the job summary: a handful of haiku turns. the pr merges on a gate that
proved the real seams, not on a gate that skipped them.

## .narrative — the sharp half, as a dev on a local box sees it

the same dev pulls main on a laptop and runs the acceptance tier to check a fix.

- **creds absent** (#13) — no login on the box. the mock-backed bulk passes. each smoketest that
  reads the host's login exits 2 with `✋ ConstraintError`, and the message names the login it
  needs. no smoketest skips; none falls back to the mock, which would make it a fake acceptance
  test (#16). the dead-login smoketest still passes: it reads only the host's bin, never its login
  (#7, `fit`)
- **creds dead** (#12) — claude-code cleared the login on disk weeks ago, after a refresh the server rejected. rhachet's dead-login gate
  refuses before a turn is spent, exit 2, and names the relogin. the dead-login smoketest still
  passes: it plants its own fake dead login in an isolated home, so the host's login is not its input
- **bin short** (#14) — a fresh box, no `claude` on PATH, or one below the floor. each smoketest
  that reads the host's bin exits 2, names each `claude` it found with its version, and the
  upgrade. the bin is checked first, so a box short on both meets this message, not the login one.
  the sdk door smoketest still passes on its own bundled cli (#7, `fit`)

in each case the dev learns, in one line, what the box lacks and how to fix it.

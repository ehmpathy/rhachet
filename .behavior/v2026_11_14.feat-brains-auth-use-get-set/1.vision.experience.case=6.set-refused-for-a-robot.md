# case=6 — set refused for a robot

feel = sharp · care = critipath · cell = `set × clone × absent` (forbidden)

## .narrative

a driver clone, mid-route, decides it needs a fresh account and runs `rhx brains auth set`. there
is no human at a browser. rather than hang on an oauth prompt no one will answer, the command
refuses at once and tells the clone to ask its human to run the login at a real terminal.

## .[tn]

```
given a clone with no tty and no human present
  when [t0] `rhx brains auth set --brain claude`
    then exit 2 at once, no browser opened, no wait
    then `✋ ConstraintError: a first login needs a human at a browser`
    then the hint names the exact command for the human to run
```

## .blueprint

### domain objects (`src/domain.objects/`)

| object | kind | shape |
|---|---|---|
| `BrainAuthAccount` | `DomainLiteral` | `{ brain; accountUuid: string; email: string; orgId: string \| null }` — the compare rests on `accountUuid` (the profile's `.account.uuid`); `orgId` stays nullable until probe r4, since dev-env-setup never reads an org id |
| `BrainAuthUsageWindow` | `DomainLiteral` | `{ slug: 'session' \| 'week'; usedShare: number; resetsAt: IsoTimeStamp \| null; capped: boolean }` |
| `BrainAuthUsage` | `DomainLiteral` | `{ email; account: BrainAuthAccount \| null; status: 'read' \| 'dead' \| 'rate-limited' \| 'unreadable'; windows; savedResets: number \| null; signedIn: boolean }` — keyed by `email` (always known); `account` is null when the token opened none |

### operations (`src/domain.operations/brain/auth/account/`)

| operation | does |
|---|---|
| `genBrainAuthAdapterForClaude` | the per-brain knowledge (F3): `mintAccess`, `getProfile`, `getUsage`, the client id, the pinned user agent |
| `getAllBrainAuthAccountsStored` | every reach of the account key in the keyrack → `BrainAuthAccount[]` |
| `getOneBrainAuthUsage` | mint → write the rotated token back FIRST (case=9) → read usage → classify by status (case=11) |
| `getOneBrainAuthAccountSignedIn` | the grove's account, read with the live access token only; never refreshed (case=9); unverified when expired (case=5 `[t3]`) |
| `setBrainAuthAccount` | isolated login in a temp `CLAUDE_CONFIG_DIR`, profile → (email, orgId), refuse an org clash (a7), file at reach = email (case=1, case=6) |
| `setBrainAuthAccountInUseAtGrove` | lock → verify `before` → mint target → compare-and-swap install → stow prior last → read back `after` (case=3, case=5, case=7, case=8) |

### contract (`src/contract/cli/`)

- `invokeBrains.ts` — `brains auth set | get | use`, registered lazily in `COMMAND_REGISTRARS`
- output via `renderCliOutput` and `--output tree|json`; errors as `ConstraintError` (exit 2) /
  `MalfunctionError` (exit 1)

### tests

- unit: usage classifier, window render, `before`/`after` decision (pure)
- integration: grove swap against a temp home (`.credentials.json` + lock), keyrack round trip, no
  token in any output
- acceptance: `blackbox/cli/brains.auth.acceptance.test.ts`, refusals with no real account; the
  real-account cases need F6

# case=4 — use an account at clone scope

feel = happy · care = critipath · cell = `use × human × clone × fresh × solo`

status = owed with F1. the inject mechanism is the commander's call, so this PR does not build the
clone or tree scope; `--scope clone` and `--scope tree` refuse with exit 2 and point to `grove`
(acceptance `[case3] [t1]`). the `[tn]` below is the proof owed once F1 is ruled.

## .narrative

the human wants one long review clone, @:reviewer, to spend b@ while the rest of the box stays on
a@. they run `rhx brains auth use --account b@example.com --scope clone --clone @:reviewer`. the
output shows @:reviewer pinned to b@, from its next spawn on; a check of the grove shows it still on
a@. (mechanism is fulcrum F1.)

## .[tn]

```
given the grove and all clones on a@, and b@ stored fresh
  when [t0] `rhx brains auth use --account b@example.com --scope clone --clone @:reviewer`
    then @:reviewer reports b@ as before → after
    then the grove and every other clone still report a@
  when [t1] the same, with `--scope tree`
    then clones in this repo report b@; clones in other repos still report a@
```

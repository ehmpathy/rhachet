# case=1 — set a new account

feel = happy · care = critipath · cell = `set × human × absent × solo`

## .narrative

the human just bought a second claude max seat for b@example.com. they run
`rhx brains auth set --brain claude`. a browser opens for the oauth login; they pick b@example.com.
back in the terminal, the output names the account it stored (email, org) and the keyrack slot it
went into. no token is printed. a second run of the same command files the new login over the
held one and reports `renewed` (F8): each login mints a new token, so the held one is never kept.

## .[tn]

```
given a human at a terminal, with no stored credential for b@example.com
  when [t0] `rhx brains auth set --brain claude` and the browser login completes as b@example.com
    then the credential is stored in the keyrack under the brain's account slot
    then stdout names email + orgId + slot, and holds no token value
    then no file under the repo holds the token
  when [t1] the same command runs again for b@example.com
    then stdout reports `renewed`; the keyrack holds one credential for b@example.com, the new one
```

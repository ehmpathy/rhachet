# case=3 — use an account at grove scope

feel = happy · care = critipath · cell = `use × human × grove × fresh × solo`

## .narrative

a@ is nearly spent; b@ has a whole week left. the human runs
`rhx brains auth use --account b@example.com --scope grove`. the output shows the account before
(a@, org …) and after (b@, org …), read back from the grove itself. every new clone in the box now
spends b@. no browser opened.

## .[tn]

```
given the grove is on a@, and b@ is stored fresh
  when [t0] `rhx brains auth use --account b@example.com --scope grove`
    then stdout shows `before = a@ (orgId)` and `after = b@ (orgId)`
    then `after` is read back from the grove, not echoed from the input
    then a new clone enrolled in any repo on this box reports b@ as its account
    then a@'s refresh token is stowed into a@'s keyrack slot, as the last write
    then each refresh token has exactly one holder: b@'s in the grove file, a@'s in the keyrack
    then exit 0 only because before ≠ after and after = target

given the grove on b@, and a@ parked in the keyrack since yesterday (its access token long expired)
  when [t1] `rhx brains auth use --account a@example.com --scope grove`
    then a@ is minted from its stored refresh token, the normal path for any parked account
    then a@'s rotated refresh token goes into the grove file, and a@'s keyrack slot is cleared
    then b@ (the signed-in account) is never refreshed; its token is read and stowed as is
    then before/after shows b@ → a@
```

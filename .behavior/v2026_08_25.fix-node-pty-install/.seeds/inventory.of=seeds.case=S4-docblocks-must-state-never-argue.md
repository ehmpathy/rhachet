## .settled

**a docblock that pre-rebuts an objection nobody raised is accretion, not documentation.**

the quoted block is a defense of a decision, addressed to a reviewer, preserved in a file where
only future readers will meet it. they did not attend the argument, so the rebuttal reads as
noise around the fact — and the fact is one sentence.

the test: **would a reader who never saw the review need this line?**

| the line does | verdict |
|---|---|
| states what the code IS, or the durable why | keep |
| justifies the choice against an alternative nobody proposed | cut |
| narrates a past draft, a review round, or a defect already fixed | cut |
| re-states a rule the repo already declares | cut — cite it instead |

⚠️ **the cue is the phrase *"the value is not X, it is Y"*, and its kin** — every one opens a
rebuttal. a docblock that argues has mistaken its audience.

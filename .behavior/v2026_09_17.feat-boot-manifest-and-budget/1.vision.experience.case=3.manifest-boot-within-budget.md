# case=3 — a custom manifest renders at schema parity

**cell 11** — `custom-manifest` × `valid` × `declared-under` · feel **happy** · care **critipath**

🔴 the new capability. the cell that makes a bespoke hook unnecessary.

---

## .the narrative

Bo is on a route. the route wants three of its own docs resident — the wish, the criteria, the
current blueprint yield — and none of the rest.

**before this wish**, Bo's only path was to hand-write a `SessionStart` hook that `cat`-ed those
files into stdout. that is exactly what happened: a hook injected the whole doc set, it measured
~46% of the session's context, and it was removed by hand. the capability went with it.

**with this wish**, Bo writes a file:

```yaml
# .behavior/v2026_09_17.feat-boot-manifest-and-budget/boot.yml
budget:
  tokens: 8_000
always:
  briefs:
    say:
      - '0.wish.md'
      - '2.1.criteria.yield.md'
    ref:
      - '3.3.1.blueprint.product.yield.md'
```

and names it:

```sh
rhachet roles boot --manifest .behavior/v2026_09_17.feat-boot-manifest-and-budget/boot.yml
```

the payload renders in the same shape a role boot renders — `<brief.say>`, `<brief.ref>`,
`<stats>` — and `<stats>` says `6,120 / 8,000 budget`.

### 🔴 the aha — the capability now has a CONTRACT

the hook and the manifest do the same job. what parts them is that the manifest is **bounded by
construction**:

| the hand-written hook | the declared manifest |
|---|---|
| its payload is whatever the author `cat`-ed | its payload is a declared say/ref set |
| nobody re-reads a hook, so it grows in silence | its cap is a line in a file, on the diff |
| every route re-derives the mechanism | one renderer, reused |
| unbudgeted **by construction** | budgeted **by construction** |

⇒ **this is why requirement 1 says "schema parity" rather than "a way to list files".** a
second, thinner dialect would be a second mechanism to grow unbounded — the very defect
`--manifest` exists to retire.

### 🔴 .the last row of that table is the claim F12 FALSIFIES

*"budgeted **by construction**"* is this cell's whole value proposition over the hook. under `F12`
it is false for exactly the payload shape a route manifest has.

| the shape | the omission |
|---|---|
| a manifest with a few `say` docs | small — the gate is nearly honest |
| 🔴 **a route manifest** — a few say docs plus a **large ref set** (20 experience demos, the fulcrum inventory) | **largest** — every ref line is emitted and uncounted |

⇒ a route manifest is *the* case `--manifest` exists to serve, and *the* case where the gated
number diverges most from occupancy. **the cell's aha and the cell's defect are the same fact.**

### 🔴 .and the before/after compares TWO DIFFERENT QUANTITIES

the hook's indictment is *"it measured **~46% of the session's context**"* — actual **occupancy**.
the manifest's exoneration is *"`<stats>` says `6,120 / 8,000 budget`"* — **say content**.

> 🔴 **so the table convicts the hook on one unit and acquits the manifest on another.** that is a
> unit switch, never a comparison.

⚠️ and it is the wish's own argument, inherited: the wish states *"it caps context occupancy — the
~46% figure — reliably."* `F12` measures that as untrue under the extant sum. ⇒ **this cell is where
that contradiction has product consequences** — the feature's case over the hook rests on it.

🟡 **the fix restores the claim rather than retracts it.** under `F12`'s best-guess (gate the full
rendered payload) *"budgeted by construction"* becomes true, and the two sides of the table speak
one unit. ⇒ **`F12` is not a threat to this cell; it is its precondition.**

## .the bdd sketch

```
given [case3] a manifest at a path inside the repo, with a budget its payload fits
  # .behavior/v2026_09_17.../boot.yml
  #   budget: { tokens: 8_000 }
  #   always: { briefs: { say: ['0.wish.md'], ref: ['3.3.1.*.yield.md'] } }

  when [t0] the manifest is booted
    $ rhachet roles boot --manifest .behavior/v2026_09_17.../boot.yml

    then it exits 0
    then it renders at schema parity with a role boot
      - <brief.say path="..."> full content </brief.say>
      - <brief.ref path="..."/>                  # path only
      - <stats> ... tokens ≈ 6120 / 8000 budget </stats>
    then the say globs are read relative to the manifest's own directory
    then a .md.min variant is preferred, exactly as a role boot prefers it

  when [t1] the manifest declares no budget
    then it renders uncapped                     # requirement 4 — see case=5
```

### 🟡 .why this sketch carries no subject-compose `then`

the step it would take is `when [t1] the manifest declares subject mode` →
`then --subject composes with --manifest   # or refuses explicitly (fulcrum F2)`.

🔴 **that is a hedged `then` — two unchecked branches offered as one assertion** — the same defect
class as `case=1`'s `--format json` hedge. either branch contradicts the coverage contract's
verdict, because the manifest-source subject-scoped path has no cell behind it.

⇒ the `custom-manifest × subject-scoped` cell is **itemized** in the inventory precisely because
`F2` owns the compose-or-refuse fork. **an itemized cell cannot carry a `then`** — to assert either
branch is to settle a fulcrum by side effect, in a bdd sketch, where no council would see it.

🟡 **so the record is unchanged and the assertion is gone**: the inventory itemizes the cell, `F2`
holds the fork, and this sketch asserts only what `case=3` actually demos. `[t2]` renumbered to
`[t1]`.

## 🟡 .the two open contract questions this cell raises

### 1. what are the globs relative TO?

a role boot globs relative to the **role dir** (`bootRoleResources.ts:99` passes
`cwd: roleDir`). a manifest has no role dir.

| option | consequence |
|---|---|
| the **manifest's own directory** | a route's boot.yml names its siblings plainly: `'0.wish.md'`. portable — move the dir, the manifest still works |
| the **repo root** | every path repeats the route dir: `'.behavior/v2026_09_17.../0.wish.md'`. verbose, and breaks on a dir rename |
| the **process cwd** | the same manifest renders differently per caller. 🔴 refuse this outright |

⇒ **best-guess: the manifest's own directory.** it mirrors the role-dir behavior exactly (a spec
globs its own neighbors) and it is the only option where a manifest is portable. fulcrum **F7**.

### 2. what replaces the `repo=/role=` path prefix?

a role boot prints `path=".agent/repo=$r/role=$X/briefs/core.md"` (`bootRoleResources.ts:192-193`).
a manifest has no repo/role coordinates.

⇒ **best-guess: the path relative to the repo root** — `path=".behavior/v2026.../0.wish.md"`. it
stays greppable and a brain can open it. fulcrum **F8**.

🟡 both read as cosmetic and neither is: they are the **contract a consumer reads**, and
`rhachet-roles-bhrain#510` will build against whichever we pick.

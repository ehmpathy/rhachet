# 1.vision.yield — a boot renders from a declared manifest, and is refused when it exceeds a declared budget

the vision implied by `0.wish.md`, testdriven against this codebase.

---

## .the outcome world

### a day in the life

a human opens a route dir and writes one file:

```yaml
# .behavior/v2026_09_17.feat-boot-manifest-and-budget/boot.yml
budget:
  tokens: 5_000
always:
  briefs:
    say:
      - '0.wish.md'
      - '1.vision.yield.md'
    ref:
      - '1.vision.experience.*.md'
```

they run one command:

```
$ rhx roles boot --manifest .behavior/v2026_09_17.feat-boot-manifest-and-budget/boot.yml
```

and a payload renders — the wish and the vision resident, every experience demo addressable by
path. the `<stats>` block closes with a line that was not there before:

```
  └── tokens ≈ 4210 / 5000 budget   (84% used)
```

next round the author adds a fourth `say` entry. the boot **refuses**:

```
🧢 roles boot --manifest .behavior/v2026_09_17.feat-boot-manifest-and-budget/boot.yml
   ├─ ✋ over budget
   │  ├─ budget   = 5,000 tokens   (declared in boot.yml)
   │  ├─ payload  = 7,240 tokens   (full emitted payload, o200k_base)
   │  └─ over by  = 2,240 tokens   (145% of budget)
   │
   ├─ some resources must go — you choose which
   │
   └─ fix — four strategies, cheapest first
      ├─ catalogize    replace a set with one catalog that indexes it
      ├─ condense      author an x.md.min beside x.md
      ├─ reference     move a say entry to ref  (it stays addressable, costs its path line)
      └─ eliminate     delete what does not earn its boot
                       ⇒ or raise budget.tokens deliberately — it lands on the diff
```

🔴 **it names four moves and no file.** the author reads the ladder, picks `reference` for the brief
they know is consulted once, and the boot passes. **the trim happened at authorship, in the
author's own hands, in under a minute — and the choice of WHICH doc was theirs, because they are
the only party who knows what each one carries.**

### 🔴 the gate is wherever the author can write the file — and that is two places, plus a report

> 🔴 **NARROWED 2026-09-23 by `S14`: two gates, not three.** the `hook.onStop` gate is **cut** — *a
> human may sweep; a hook may not*. what covers its population is a **command**, never a gate.
>
> 🔴 **NARROWED again 2026-09-27 by `S18`.** the cut stands for the repo-wide roster, and falls for
> one population: `.agent/repo=.this` specs get a **silent** `onStop` gate, auto-declared by
> `init --hooks`, that halts only over budget. see `.the three gates, and the one report`.

```
1. repo introspect  ─▶  a role package's own `npm run build`, pre-publish
2. roles boot       ─▶  every boot — halt on our spec, warn on a foreign one

   roles cost --all ─▶  a REPORT a human types. it refuses naught
```

⇒ **gate 1 is why the aha-line above is literally true rather than aspirational.** an author who
publishes a role package meets the cap in their own tree, on a git-tracked file, on a command they
already run. gate 2 is the backstop, and the one gate where the spec may not be theirs.

🔴 **and the residue — a repo-local role, a route manifest like the one above — is served by a
report rather than a third gate.** `roles cost --all` renders every spec's arithmetic at a human's
invocation. **`boot` gates; `cost` reports**, and a report that refuses is not a report (`S13`).

🟡 **the struck gate's PREMISE was sound and its INSTRUMENT was not.** the population it named is
real: a route-scoped manifest never reaches introspect. what did not follow is *"therefore a gate
must fire unprompted at every session's close"* — a refusal on a question no session posed.

### the before / after

| | before | after |
|---|---|---|
| a route-scoped payload | a hand-written `SessionStart` hook | a `boot.yml` at a known path |
| its cost | 🔴 **measured at ~46% of a session's context**, discovered after the fact | a number in the file, 🔴 **two gates that enforce it, and a report a human can type** |
| who reviews it | nobody — a hook is not re-read | the author, at authorship; then a reviewer, in the diff |
| how it grows | in silence, without bound | it cannot — the next `say` entry that breaks the cap halts |
| where the refusal lands | — | 🔴 **on a file the halted party can write** — introspect pre-publish, or the boot they ran |
| what the refusal names | — | 🔴 **that** some resources must go, and four ways to do it. never **which** |
| when it was repaired | 🔴 by **deletion** — the capability went with it | by a contract that keeps the capability and bounds it |

### 🔴 the aha

> **the payload becomes a file you can open, and the cap becomes a line you can read.**

*"what does this boot cost?"* was a question nobody could answer without a measurement nobody ran.
it is now the second line of the manifest. and the moment the answer would become a lie, the boot
stops rather than pass.

⇒ the wish's own framing is the sharper form: **a bespoke hook offers no moment at which an author
is asked to trim.** a declared budget manufactures that moment, and puts it at the cheapest point
on the timeline.

### 🔴 what the walk found that a free-list would have missed

**1. the same axis value has OPPOSITE verdicts by source.** `B=absent` is a *legitimate fallback*
for a role — an absent `boot.yml` means say-all, **unconditionally** (`bootRoleResources.ts:76-81`;
`ifPresent` is not consulted there at all) — and a *loud failure* for a manifest, since an explicit
path that points at no file is a caller defect. only the grid puts those two cells side by side.

⇒ and the consequence is a contract decision: **`--if-present` must NOT apply to `--manifest`**, or
a typo'd path boots an empty payload in silence. that is requirement 5.

⚠️ **the extant code leans AGAINST that conclusion, so it is argued rather than derived.**
`ifPresent` gates two things today, and neither is the absent `boot.yml`:

| line | what `ifPresent` gates |
|---|---|
| **41-49** | an absent **role DIRECTORY** → returns silently instead of a throw |
| **116-124** | an **empty payload** → returns silently instead of the `⚠️` warn |

a manifest path *is* the spec, so its closest extant analogue is line 41-49 — the absent **role
dir** — and that case **is** softened by `--if-present`. the argument for the split is therefore
about the flag's purpose, not a symmetry:

> `--if-present` exists because a caller boots a **set** of roles, some of which may not be linked
> in this repo — it means *"boot whichever of these are here."* a `--manifest` names **one** path
> the caller chose deliberately. there is no set to be tolerant across, so tolerance here converts
> a typo into an empty boot rather than an error.

**2. a latent axis the wish never names.** the product of A × B × C left cell **L** unexplained
until a fourth axis surfaced — **selection** (`all` · `subject-scoped`). a spec in subject mode
renders a *subset*, so *"a budget of WHAT?"* has two readings that differ by ~4x. that is `F2`.

**3. one cell is forbidden by nurture** — a `budget` declared *inside* `always:` or `subject.x:`.
it would parse (see the blocker below) and mean a thing the schema cannot honor.

**4. a rectangle of cells is impossible by nature**, and every one collapses to a single fact: **a
budget lives INSIDE the spec.** no spec ⇒ no budget. that is a fact about the domain, not a
decision, and it is why `B=absent`/`malformed` crossed with `C=declared-*` cannot arise.

🟡 the impossible set is `{absent, malformed} × {declared-under, declared-over}` — a clean
rectangle, so its size is **derivable from the axes** rather than tallied by hand. that is why the
count belongs to the inventory and is stated here as a shape.

**🔴 5. the density walk found a defect no single cell could surface.** the halt's first remedy is
*"move a say entry to ref"*. an author who takes it re-boots and the headline `files` count **does
not move** — because `relevantFiles` (`bootRoleResources.ts:105-113`) counts say **and** ref
together, while `totalChars` (`:127-146`) counts say **only**.

⇒ **the recommended remedy is the one remedy whose effect is invisible in the top line of the very
block that reports it.** the author's first read is *"the edit did not take"*.

🟡 **`case=1` and `case=3` each render one payload once, so neither can see this** — the defect
lives in the *difference between two consecutive boots*. that is the value of density, demonstrated
on itself. filed as a nitpick against `F6`, which owns the `<stats>` shape.

## .the mental model

### how a human would describe it to a friend

> *"you write a little file that says which docs the agent should hold in its head, and how many
> tokens it's allowed to spend on them. if you go over, it refuses — and it tells you the four ways
> to get back under, cheapest first. **which** doc goes is your call."*

⇒ note what that sentence does **not** contain: a renderer, a schema, a glob base. the model is
**a shopping list with a spend limit**.

### the analogies that fit

| analogy | what it gets right | where it breaks |
|---|---|---|
| **a carry-on bag at the gate** | a declared limit, weighed at a checkpoint, refused loud | a bag is weighed by someone else; here the author weighs it |
| **a grocery list with a budget** | the trim is the author's choice, made before checkout | groceries have prices you did not set; here the author sets both sides |
| **a `package.json` `engines` field** | a declared constraint that fails the install loud | `engines` is about compatibility, not cost |

🔴 **the carry-on is the one to reach for**, because it carries the right *feel*: the refusal is
mildly annoying, entirely fair, and fixed by a rearrangement rather than a purchase.

### their words vs ours

| they say | we say |
|---|---|
| "how much does this cost" | `budget.tokens` |
| "the docs it holds in its head" | the **resident** payload — `always.briefs.say` |
| "the docs it can look up" | `ref` |
| "it's too big" | over-budget |
| "make it smaller" | 🔴 **catalogize · condense · reference · eliminate** — the four strategies, cheapest first |
| "index a pile of them under one doc" | **catalogize** |
| "write a shorter version beside it" | **condense** — an `x.md.min` |
| "keep it, just don't load it" | **reference** — move a `say` entry to `ref` |
| "drop it" | **eliminate** |

⇒ the gap worth attention: **`say` / `ref` is our word, and it is good.** it maps onto *"in your
head"* vs *"on your shelf"* without a gloss. the halt's `reference` line should use it plainly
rather than explain it.

🔴 **and the four strategy words are the halt's whole vocabulary of remedy** — the halt teaches a
verb per row and names no file, because the author already knows which of their own docs carries the
argument (`F13`).

#### 🔴 .why one gate cannot cover the population — `repo introspect` is blind by construction

`repo introspect` refuses to run anywhere but inside a `rhachet-roles-*` package
(`invokeRepoIntrospect.ts:55-59`, a hard `ConstraintError`). so it sees **only** specs that ship in
a role package:

| the spec | does introspect see it? |
|---|---|
| `src/domain.roles/*/boot.yml` in a `rhachet-roles-*` package | ✅ yes — that is its whole scope |
| `.agent/repo=.this/role=*/boot.yml` — a repo-local role | 🔴 **no.** not a role package |
| 🔴 a route-scoped custom `--manifest` | 🔴 **no.** not a role package, and never published |

🔴 **the third row is the payload that motivated this whole wish.** the ~46% `SessionStart` hook is
a route-scoped custom payload, which is exactly a new manifest — so an introspect-only gate would
miss the one case the wish was written for.

🔴 **that measurement is correct and the inference it once carried is NOT.** the section read:
*"⇒ the gate set is additive by necessity — each gate covers a population the others cannot
reach."* ⇒ what actually follows is that the population owes an **answer**, never that the answer
owes the shape of a **gate**. `S14` supplies the answer as a command: `roles cost --all`.

|---|---|

| component | cost | scales with |
|---|---|---|

| 🔴 **encode** | 🔴 **0.97 MB/s** ⇒ **~46ms** for 44,666 chars | the payload |

🔴 **two operations, and only one of them scales.** *"tokenization costs 1.66s"* named the

| quantity | value |
|---|---|

| true corpus divisor | **3.969** |
| per-file density | min **2.96** · p05 3.59 · p50 3.98 · p95 4.75 |
| 🔴 worst single brief | **−26%** |

> ### 🔴 the error bar the wish asked for
>
> **the error is scale-dependent, and it is worst at the scale `--manifest` serves.**
>
> at corpus scale the divisor is 3.97 and `÷4` is off by under a percent. at **single-file** scale
> the divisor ranges 2.96 → 4.75, so a small dense payload can be undercounted by **26%**.
>
> a route manifest is exactly that shape: few files, glyph-dense prose. ⇒ **`chars ÷ 4` on the

🔴 **and the error bar is a SECOND-ORDER defect.** the divisor is off by 21%; the **scope** is off

| quantity | value | factor |
|---|---|---|
| reported | `chars = 16,427` → `tokens ≈ 4,107` | — |

<summary>the rejected alternatives — a corrected divisor, and a cached tokenizer</summary>

</details>

### 🔴 the blocker the research found

**a top-level `budget:` key is silently swallowed today — twice over.**

```ts
// src/domain.objects/RoleBootSpec.ts:39-43
export const schemaRoleBootSpecSubjected = z
  .object({ always: schemaSubjectSection.optional() })
  .catchall(schemaSubjectSection);
```

## .what is awkward

stated plainly rather than smoothed over.

### 🔴 1. an accurate count is still a count for ONE encoder

requirement 7 buys real tokens under `o200k_base`, so `budget.tokens` is measured against tokens
rather than against a divisor. what remains is narrower and still real: **a payload consumed by a
different model family carries a delta of a few percent**, and the field's name does not say which
encoder it means.

⇒ the disclosure belongs plainly beside the field's documentation — the budget is enforced against
one named encoder. `F1`'s open criteria items carry it.

🟡 **and the general lesson is worth more than the residual**: *"there is no cheap accurate
counter"* read as a settled tradeoff and was a **claim about cost**, which is checkable. it was
wrong twice over — the perf objection named the **unbudgeted** boot path, which needs no counter at
all (requirement 4's lazy load), and the price it quoted was one-time encoder construction (~1.8s)
rather than encode (~46ms, and the only half that scales). **a tradeoff stated as exhaustive earns
the same measurement as any other claim with digits in it.**

### 2. the budget is a context cap wearing a cost cap's clothes

the wish flags this and it is worth restating: `tokens` caps **context occupancy** reliably, and
caps **cash** only while the prompt cache misses. a boot payload is the most cache-friendly object
in the system — byte-identical, at token 0, every session — so its token count **overstates its
dollars**, worst for exactly the payload this budget governs.

the vision keeps tokens as the unit (it is the right unit for a context cap) and names the unit
honestly where documented. 🟡 but a reader who sees `$0.17 at $3/mil` beside `4210 / 5000 budget`
will read two numbers, one of them knowingly overstated (`F6`).

### 3. the label asymmetry, chosen deliberately

a role-sourced resource keeps its synthetic `.agent/repo=…/role=…/` prefix; a manifest-sourced one
gets a real repo-root-relative path. that **reads** as a parity violation against requirement 1,
and it is not — requirement 1 asks for **schema** parity, never an identical label shape.

🟡 the discomfort is real anyway: a reviewer will see two label shapes in one output and have to be
told why. `F8` argues it (a manifest has no coordinates worth a synthetic name) and offers the
belt-and-braces alternative (emit both).

### 4. `F9`'s warn is justified by adoption timing, not by principle

an uncapped manifest warns; an uncapped role boot does not. the principled position is that they
should behave alike. the actual reason for the split is that **every extant role has no budget** (a
warn would fire **15** times on day one, pure noise) while **every manifest is new**.

⇒ that is a weaker base than a rule deserves, and it means the warn may deserve to expire once
manifests are commonplace. 65% confidence, and the lowest-but-one in the set for that reason.

### 🔴 5. the flag ships as a recorded EXCEPTION to the repo's own term rule

`--manifest` violates `term=manifest._.choice._.md:5` — a bare `manifest` is forbidden in a
contract. it is not a defect in the wish, which cannot see the term cluster, and it ships anyway via
the rule's own **dispute** path (`F3`).

🟡 **the residual discomfort is genuine, not a hedge:** a future `rhachet roles link --manifest`
would be ambiguous, which is exactly the hazard the term rule encodes. the dispute does not refute
that hazard; it accepts it **on the record**, which is what parts a sanctioned exception from a
synonym that merely accreted.

### 🔴 6. the halt's first character was a rule violation nobody read

the headline render once opened `🐢 bummer dude — …`, and `rule.prefer.emoji-language` — **booted
into context every session of this route** — grades that a **blocker**: *"a rhachet-generic line
that wears a role-mascot."* `🐢` is the mechanic's mascot, from a supplier package; `roles boot` is
rhachet-generic cli.

⇒ 🟡 **a resident rule is not a read rule.** the first character of the artifact's most-quoted block
is exactly where a glyph contract goes unchecked, because nobody reads a render for its punctuation.

🔴 **and the obvious repair is also wrong**, which is the part worth a note: rhachet's registry
mascot is `🐙`, so *"swap the turtle for the octopus"* reads as the fix. it is not — the same rule
says the framework **has no voice at all**. a registry's mascot belongs to its readme and its roles'
own skills, never to rhachet's generic cli.

⇒ so *"which mascot?"* is the wrong question twice over. **the right question is which SLOT** — and
the answer is `domain-root`, whose whole job is to say which tool speaks with no character attached.
the halt roots on `🧢`, with `✋` to name the fault owner.

🟡 **a catalog read beats a coinage, and it pays twice.** to pick the boot glyph the catalog was read
rather than a glyph coined, and the read found **two glyphs in use with no row** — `🧢`
(`syncHooksForLinkedRoles.ts:174`) and `🥾` (`invokeBriefsBoot.sh:3`), both now registered. ⇒ the
mascot was the trigger; the **arrears** is what the read found.

🔴 **and the same grep found a stale remedy list a prior sweep had missed** — `case=6` still carried
the wish's original *three* fixes in two places. ⇒ **a sweep verified by "I edited every file I
found" is not verified.** a sweep is verified by a fresh grep on the *new* vocabulary, and that
check is what a vocabulary change owes.

## .the fork

`F12` settled that the gate counts the **full emitted payload**, and that settlement is right — a
ref line IS resident context a reader pays for. the dogfood then measured what it implies, on this
repo's own `repo=.this/role=any`:

| quantity | value |
|---|---|
| emitted payload | 14,837 tokens |
| 🔴 the **ref roster** — 276 lines | 🔴 **8,404 tokens (57%)** |
| the whole **say** set — readme + 8 briefs + 9 skills | 5,185 tokens (35%) |
| chrome — 2 `<stats>` blocks, wrappers, `<also>` | ~1,248 tokens (8%) |

**one ref line = 30.4 tokens.** path strings are the densest text a boot emits.

> 🔴 **eliminate EVERY say resource and the payload is still ~9,650 tokens.**

⇒ so a role's budget is dominated by its brief **COUNT** rather than by its **curation** — and that
is not the incentive the budget was built to create.

| option | what it costs |
|---|---|
| **A** — keep it as `F12` settled: a ref line is budgeted, full stop | the incentive above stands. an author with 274 briefs pays ~9,650 tokens per boot to advertise them, whether or not one is ever dereferenced |
| **B** — exclude the ref roster from the budget | the gate stops to measure what the reader receives, which is the whole point `F12` settled. a roster IS context |
| **C** — budget it, and make the split VISIBLE so the author can act on it | the honest middle, and it is **dirty** — see below |
| 🔴 **D** — hand the contract question up, take only the render half that is safe | **taken for this stone** |

## .taken, and why

**taken: D.** the question of *what the gate should measure* is the wisher's, and two prior
settlements (`F12`, `F13`) are theirs. this row hands it up with the measurement attached.

### ✅ .the half that WAS safe and clean, taken on contact

🔴 **the halt's headline was FALSE for a ref-dominated shape**, and that is a
`rule.forbid.failhide` defect at the render grain rather than a preference:

```diff
- ├─ some say resources must go — you choose which
+ ├─ some resources must go — you choose which
```

one word. the narrower claim asserts the breach is closable by a **say** trim, which the
measurement above refutes. the same correction landed in `assertBootWithinBudget`'s `hint`, which
serves an sdk caller who never sees the readout at all.

🟡 **the ladder needed no new rung for this half.** `catalogize` replaces a **set** with one index —
30 refs become 1 line — and `eliminate` reaches either kind. only `condense` and `reference` are
say-only, and neither claims otherwise.

### 🔴 .the half that is NOT safe or clean, and why

the dream's own SAFE/CLEAN test, which this row records because a dream reports the **work** and
hides the **call** (`rule.always.fix-forward-under-scouts-honor`):

| the test | answer |
|---|---|
| **SAFE?** | 🔴 **no.** the class split changes the halt's rendered shape — a human surface pinned by `case=2` `[t0]`, the acceptance tier, and two integration snapshots |
| **CLEAN?** | 🔴 **no.** `calcBootPayloadTokens` counts one emitted string, so a split means the renderer hands the gate a **partitioned** payload rather than a blob — a real change to the `genBootPayload` → gate seam |

the shape it would take, for the council to read:

```
├─ payload  = 14,837 tokens   (full emitted payload, o200k_base)
│  ├─ say    =  5,185         (the resident docs)
│  └─ ref    =  9,652         (274 path lines + chrome)
```

🟡 **a class split does NOT violate `F13`.** that row forbids the halt from a citation of an
individual resource, because the gate sees cost and never value. a **class** total names no file at
all, and it turns *"which of four strategies?"* from a guess into a read.

## 🟡 .the residual — the author still cannot SEE the split

the render is now **true** and it is not yet **useful**. an author over budget on refs reads
*"some resources must go"*, which no longer misleads them, and still has no number that says the
roster is 57% of their payload. ⇒ they must run `rhx cost` — which the halt does name — and read the
batches themselves.

⚠️ **so the failhide is closed and the ergonomic gap is not.** those are two different grades, and
this row states which one was taken.

---

## .what would flip it

- **a wisher verdict on A/B/C** — the whole reason this row exists
- **a second dogfood where the roster dominates**, on a different repo. one measurement on one tree
  is an instance; two is a pattern, and a pattern makes C's cost worth its benefit
- 🔴 **an author who reads the corrected halt and still trims the wrong set.** that would prove the
  truthful headline is insufficient on its own, and promote the split from ergonomics to defect

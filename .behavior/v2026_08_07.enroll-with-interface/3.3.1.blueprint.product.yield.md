## summary

deliver the **actor/clone frame** + the **talk** surface (`list` / `say` / `get`), in scope per the
wisher's answers:

1. **enroll routes through a managed pty.** the extant direct `spawn(..., { stdio: 'inherit' })` becomes a
   **managed-pty spawn** that (a) mirrors the brain to the human's terminal invisibly, (b) stands up a
   per-clone **unix domain socket** for dispatch. a **plain-spawn fallback** covers an absent pty addon, a
   non-capable brain, or a headless `-p` run.
2. **every enroll leaves a durable record** under `.agent/.actors/actor.via.hash=$hash/` — an **anonymous**
   actor (hash namespace only; enroll never consults `actors.yml`), which holds the shared brain config, an
   append-only roles log, and a `clones/` dir. each run is a **clone** with a `serial`, an optional
   `--as @:<slug>` handle, an `identity.json`, a `socket`, and a `history/` of symlinks to the brain-cli's
   own transcripts.
3. **the talk verbs reach a clone** with no keyboard: `rhx actor list`, `rhx clone list [@<actor>]`,
   `rhx clone say @:<slug|serial> --what <m>`, `rhx clone get @:<slug|serial> [--tail N]`, plus
   `rhx clone whoami`. all carry a **`--output tree|json`** flag (default `tree`) — one shared
   `renderCliOutput` seam, so tree + json never drift.
4. **the brain input widens** to three forms — absent (→ default brain), `--brain <b>`, positional `<b>` —
   with a fail-loud on conflict.
5. **config application (init/link) reaches every actor dir**, not the repo root alone.

**bake** (`make`/`fork`/`wake`) and the `actors.yml` slug namespace are **out of scope** (the `rhx clone`
dream). the socket is proven end-to-end by TWO tiers, never a mock: a HERMETIC stub-brain acceptance test
(the fast credential-free CI gate for the mechanism) AND a REQUIRED real-claude external-contract acceptance
test (credential-gated + FAIL-LOUD when absent, never a deferral) — the stub proves the mechanism, the real
claude proves the integration, so BOTH are required.

## filediff — the shape

> one line of intent per file. the exhaustive per-file rationale (with all review-round citations) is in
> `.md.full`. legend: `[+]` create · `[~]` update · `[○]` retain · `[→]` lift/eject · `[←]` reuse.

### domain.objects/
- `ActorEnrolled.ts` `[+]` — the ON-DISK actor record. DomainEntity, unique=['repoPath','hash'] (NO
  surrogate `primary` — the record is content-addressed, so the natural {repoPath,hash} key IS the
  identity; an execution-time refinement of F6, which had proposed a `primary` alias, recorded in the
  object's own `.note`). persists `{repoPath, hash, brain, roles}` — NO `dir` field (derived fresh via
  getActorEnrolledDir). content-addressed + immutable: the hash IS `genEnrollmentHash({brain,roles})`.
  distinct from the extant in-memory `Actor` (runtime brain⊕role). `repoPath` joins the key so two repos
  never collide on a bare ref.
- `Clone.ts` `[+]` — DomainEntity, primary=['serial'], unique=['slug'] (null-ok; two null slugs never
  collide). fields: serial, slug, actor: `RefByUnique<ActorEnrolled>` (composite {repoPath,hash} key —
  RefByUnique, since ActorEnrolled has no surrogate primary),
  socketEligible (NOT a stored path — the path is derived from serial), spawnedAt (IsoTimeStamp), hostHash,
  hostPid, hostPidStartedAt. `actor` + `historyDir` are hydration-derived, never persisted. identity.json's
  persisted shape is `{schemaVersion,serial,slug,socketEligible,spawnedAt,hostHash,hostPid,hostPidStartedAt}`.

### contract/cli/
- `renderCliOutput.ts` `[+]` — the ONE shared `--output tree|json` seam (json = JSON.stringify of the same
  domain result tree renders; unknown value → fail-loud via the human channel). a structured-error arm under
  `--output json`.
- `asCliErrorJson.ts` `[+]` transformer — `{error} → {class, message, hint, reachState, reachCause}` (a
  machine branches on fields, never on stderr prose). `reachState` is read off the thrown error's METADATA:
  the reach invoker (say/get) attaches the `getCloneReachState` value onto the ConstraintError it throws
  (alongside the `computeCloneUnreachableHint` `{message,hint}`), so `asCliErrorJson` reads a field the error
  already carries rather than a re-derivation of reach (i062-r11-nit-1); a non-reach error simply omits the
  field. `reachCause` is the FINER 5-value signal (`DEAF | DEAD-same-host | DEAD-cross-host |
  exited-mid-dispatch | wedged`): the 3-value `reachState` coarsens the two DEAD kinds together AND carries no
  value at all for the two in-flight faults (`sayClone` attaches only `reachCause` for wedged /
  exited-mid-dispatch), so a machine consumer that read `reachState` alone could not tell a same-host dead
  clone (re-enroll here) from a cross-host one (reach from origin), nor see the in-flight faults (they read as
  `reachState: null`). the transformer reads `reachCause` too, which closes that machine-contract gap for the
  wish's cron/comms audience (i012-r010-B).
- `withCliOutputErrors.ts` `[+]` — the HOF that owns the `--output`-aware failure control-flow ONE time
  (all SIX invokers compose it; one catch, one shape).
- `invokeEnroll.ts` `[~]` — optional positional, `--brain`, `--as`, `--no-socket`, `--output`, `--reason`.
  validates `--as` (marker, uuid-shape, path-safety, did-you-mean on sigil typos + the superseded `--alias`).
  `--output json` = the headless machine-serial handoff (mirror suppressed; an interactive-tty notice warns a

### the aws.params credential fix (initial 15 integration failures)

- **symptom:** 15 failures in `keyrack/adapters/vaults/aws.params/*` —
  `TypeError: A dynamic import callback was invoked without --experimental-vm-modules`
- **root cause:** these keyrack tests were pulled into `--changedSince=main` scope transitively
  (this branch modified shared `keyrack/daemon/infra` — the lifted getHomeHash/delFileSync/
  getSocketPeerPid). without resolved AWS creds, the aws-sdk v3 credential chain falls through to
  its SSO provider's lazy `import()`, which jest's default (non-vm-modules) runtime rejects. CI
  passes them via OIDC role creds already in env (`useKeyrack` skips under CI).
- **fix:** added `AWS_PROFILE` to `env.test` in `.agent/keyrack.yml` (it was already in `env.prep`).
  `useKeyrack` sources the profile → `aws configure export-credentials` yields STATIC temp creds →
  the SDK uses the synchronous env provider, no dynamic import, real SSM backend.
- **proof:** `rhx git.repo.test --what integration --scope 'path://…/aws.params' --mode apply` →
  42 passed 0 failed; then full integration → 403 passed 0 failed.

# 2.1.criteria.blackbox — enroll with interface

> the experience that must be delivered to fulfill [`0.wish.md`](./0.wish.md) and
> [`1.vision.yield.md`](./1.vision.yield.md). pure experience bounds — inputs, outputs, usecases,
> edge cases. no mechanism, no implementation.

> **scope note.** this behavior delivers the **frame** + the **talk** surface (`list` / `say` /
> `get`) — enough to prove a clone is addressable and reachable end-to-end. the **bake** lifecycle
> (`make` / `fork` / `wake`) and the `actors.yml` slug surface belong to the `rhx clone` dream and are
> **out of scope** — their criteria are noted only where an in-scope edge case names the fix they will
> later provide.

> **what "on disk" means here.** the wish demands a durable, inspectable record of every enrollment.
> so "a record exists / is reachable / is reused" is an **observable outcome** a user (or a machine)
> verifies — it is experience, not mechanism. the record's *internal shape* (how the stream is
> proxied, how dispatch is carried) is mechanism and is deliberately absent below.

---

# usecase.1 = enroll spawns an addressable clone (the invisible hot path)

> foundation: every enroll still opens the brain exactly as today, and — invisibly — leaves a durable,
> addressable clone behind.

```
given('a repo with roles linked')
  when('the human runs `rhx enroll <brain>`')
    then('the brain opens in the terminal and inherits it, exactly as today')
      sothat('the human notices zero added friction on the hot path')
    then('a clone record exists on disk, identified by a fresh serial')
      sothat('a later process can find and reach this run')
    then('the clone is reachable for observe and dispatch while the brain is active')
      sothat('crons/comms/self-management have an address to talk to')

given('a repo with roles linked')
  when('the human runs `rhx enroll` with no brain argument')
    then('the repo default brain is enrolled')
      sothat('the common case needs no brain flag')

given('a repo whose roles are NOT linked')
  when('the human runs `rhx enroll <brain>`')
    then('enroll fails loud with an error that names the fix (run `rhachet roles link` first)')
      sothat('the human is never left guessing why the brain did not open')
```

# usecase.2 = enroll names the clone with `--as`

> a stable handle assigned at enroll time, so the clone can be reached by name later.

```
given('a repo with roles linked')
  when('the human runs `rhx enroll <brain> --as @:<slug>`')
    then('the spawned clone carries that slug as a stable handle')
      sothat('a later process can reach it by @:<slug>, not only by serial')
    then('the same clone is reachable by BOTH its @:<slug> handle and its @:<serial>')
      sothat('either address points to the one clone')

given('an enroll without `--as`')
  when('the clone is spawned')
    then('the clone is reachable by its @:<serial> alone')
      sothat('a name is optional, never required, on the hot path')

given('an `--as` value NOT in the clone address form (missing the `@:` marker)')
  when('the human runs `rhx enroll <brain> --as <value>`')
    then('enroll fails loud with an error that names the fix (use `--as @:<slug>`)')
      sothat('the clone grain is unambiguous and a slug is never mistaken for an actor')
```

# usecase.3 = the brain input derives from three forms

> one sense, three surfaces: absent (default), a flag, or a positional — and a conflict fails loud.

```
given('a repo with a default brain')
  when('the human runs `rhx enroll` with no brain')
    then('the default brain is enrolled')
      sothat('the bare invocation just works')

given('an explicit brain')
  when('the human runs `rhx enroll --brain <brain>`')
    then('that brain is enrolled')
      sothat('the brain can be named by flag')

given('an explicit brain')
  when('the human runs `rhx enroll <brain>` positionally')
    then('that brain is enrolled')
      sothat('the extant positional form is unchanged')

given('a `--brain` flag and a positional brain that DISAGREE')
  when('the human runs `rhx enroll <brainA> --brain <brainB>`')
    then('enroll fails loud with an error that names both conflicting values')
      sothat('an ambiguous brain is never silently picked as the wrong one')

given('a `--brain` flag and a positional brain that AGREE')
  when('the human runs `rhx enroll <brain> --brain <brain>`')
    then('that brain is enrolled with no error')
      sothat('a redundant-but-consistent input is tolerated')
```

# usecase.4 = enroll derives an anonymous actor identity from the roleset

> enroll is identity-by-roleset: same {brain, roles} → the same actor; a different roleset → a
> different actor. no name, no manifest — purely derived and observable via idempotency.

```
given('a brain and a roleset')
  when('the human enrolls that brain+roleset twice')
    then('both enrollments land on the SAME actor record on disk')
      sothat('clones of one identity share one config and stay in sync')

given('a brain enrolled with roleset A, then the same brain with roleset B')
  when('both enrollments complete')
    then('each lands on a DISTINCT actor record')
      sothat('different rolesets never clobber one another`s config')

given('an ad-hoc roleset that is not declared anywhere')
  when('the human runs `rhx enroll <brain> -r <delta>`')
    then('an anonymous actor is still derived and its clone is still addressable')
      sothat('enroll never requires a pre-declared identity to work')

given('an enroll')
  when('the actor record is inspected')
    then('it is an anonymous (roleset-derived) actor, never a named/slug actor')
      sothat('the enroll surface stays purely anonymous — named actors are the clone surface')
```

# usecase.5 = enumerate actors and clones (talk: list)

> discover who is enrolled and which clones are reachable — from any process, no keyboard needed.

```
given('one or more enrollments have occurred')
  when('a process runs `rhx actor list`')
    then('each enrolled actor appears with its identity')
      sothat('a caller can discover the identities on disk')

given('a live clone exists')
  when('a process runs `rhx clone list`')
    then('the clone appears with its serial, its brain, its roles, and its state')
      sothat('a caller can pick a clone to talk to')

given('a clone that was enrolled `--as @:<slug>`')
  when('a process runs `rhx clone list`')
    then('the clone appears with BOTH its slug and its serial')
      sothat('a caller can address it by either')

given('clones spanning more than one actor')
  when('a process runs `rhx clone list @<actor>`')
    then('only the clones of that actor are listed')
      sothat('the caller can scope the enumeration to one identity')

given('a clone whose brain has since exited')
  when('a process runs `rhx clone list`')
    then('that clone is shown as DEAD')
      sothat('a caller never mistakes a dead clone for a reachable one')
```

# usecase.6 = dispatch a message into a clone (talk: say)

> inject input into an active brain programmatically — the comms/cron primitive.

```
given('a live clone')
  when('a process runs `rhx clone say @:<serial> --what <message>`')
    then('the message is delivered to the brain as if the human had typed it')
      sothat('a cron or comms handler can drive the brain with no keyboard')
    then('the brain acts on the message')
      sothat('the dispatch has a real effect, provably')

given('a clone reachable by slug')
  when('a process runs `rhx clone say @:<slug> --what <message>`')
    then('the message is delivered to the same clone the serial points to')
      sothat('the slug and serial are interchangeable addresses')

given('a clone whose brain has exited (dead)')
  when('a process runs `rhx clone say @:<serial> --what <message>`')
    then('the command fails loud with an error that names the fix — never silently drops the message')
      sothat('a caller always knows a dispatch did not land')

given('two processes that dispatch to one live clone at the same time')
  when('both run `rhx clone say` concurrently')
    then('the messages are delivered whole and one-at-a-time, never interleaved into corruption')
      sothat('concurrent senders cannot garble the brain`s input')
```

# usecase.7 = observe a clone's output (talk: get)

> read what an active brain is doing without stealing its terminal.

```
given('a clone that has produced output')
  when('a process runs `rhx clone get @:<serial>`')
    then('the clone`s recent output is returned')
      sothat('a caller can see what the brain is doing without attaching to its terminal')

given('a clone that has produced output')
  when('a process runs `rhx clone get @:<serial> --tail <N>`')
    then('the last N lines of the clone`s output are returned')
      sothat('a caller can bound how much it reads')

given('a clone reachable by slug')
  when('a process runs `rhx clone get @:<slug>`')
    then('the same clone`s output is returned as by serial')
      sothat('observe honors both address forms')

given('a serial that names no known clone')
  when('a process runs `rhx clone get @:<serial>`')
    then('the command fails loud with an error that names the fix')
      sothat('an unknown address never returns misleading empty output')
```

# usecase.8 = the end-to-end reach round-trip (the named-handle critipath)

> the mandated worked example: enroll a named clone, say into it, get its output — by both address
> forms. this is the whole talk contract, proven together.

```
given('a clone enrolled `rhx enroll <brain> --as @:<slug>`')
  when('a process runs `rhx clone say @:<slug> --what <message>` then `rhx clone get @:<slug>`')
    then('the get output reflects that the said message landed and was acted on')
      sothat('the dispatch→observe loop is proven end-to-end by slug')

given('the same clone')
  when('a process addresses it by `@:<serial>` for both say and get')
    then('the same round-trip succeeds identically')
      sothat('slug and serial are proven interchangeable on the live loop')

given('the same clone')
  when('its on-disk actor record is inspected')
    then('the actor is anonymous (roleset-derived) while the clone wears the @:<slug> handle')
      sothat('the two-grain split is proven — the actor stays nameless, only the clone is named')
```

# usecase.10 = pit-of-success under adverse conditions

> the edge critipaths from the vision — each with a declared, safe, observable behavior.

```
given('a brain-cli that cannot be routed through a managed stream on this host')
  when('the human runs `rhx enroll <brain>`')
    then('enroll falls back to opening the brain directly, with a one-line notice, and never hard-fails')
      sothat('a missing capability degrades gracefully instead of blocking the human`s work')

given('a brain-cli with no capability to be observed or dispatched into')
  when('the human enrolls it')
    then('the brain still opens normally, and list marks it as not reachable for talk')
      sothat('the talk surface is a per-brain capability, not a universal promise that fails loud')

given('a process that tries to escalate a `say` into arbitrary terminal control')
  when('it dispatches anything other than a plain input message')
    then('only the brain`s message-input is affected — never the wider terminal')
      sothat('the scoped-to-one-brain contract holds as the whole safety premise')

given('a repo checked out on a second machine or worktree')
  when('a process on machine B runs `rhx clone say`/`get` against a clone spawned on machine A')
    then('the command fails loud rather than trust a foreign, unreachable run')
      sothat('a cross-host address can never silently target the wrong process')

given('two concurrent clones of the same actor')
  when('each is addressed by its own serial')
    then('each has its own reachable channel and history, with no shared-state clobber')
      sothat('parallel runs of one identity stay independent')

given('the human`s terminal is resized while a clone is active')
  when('the resize occurs mid-run')
    then('the brain re-flows to the new size with no visible degradation')
      sothat('the invisible-stream promise holds under a resize')
```

# usecase.11 = the talk surface is machine-consumable, and a clone is self-discoverable

> addendum (2026-08-08) — ratifies two surfaces the `3.3.1` blueprint derived from the wish's own motives
> (machine consumption + discoverability), so the blackbox contract and the blueprint agree rather than
> leave a scope leak into execution (raised by the i009 peer review). both trace directly to the wish:
> "so that subsequent usecases can power actions like crons, comms… via observation of the clone's ipc"
> (machine consumption) and the vision's least-astonishment discoverability.

```
given('a process (a cron / a comms webhook) that consumes the talk surface programmatically')
  when('it runs `rhx clone list` / `rhx clone get` / `rhx clone say` / `rhx actor list` with `--output json`')
    then('the command emits machine-parseable JSON — no human tree-glyphs, no stray lines to parse around')
      sothat('a machine consumer reads fields, not box-glyph characters, and never scrapes a human layout')

given('the same process')
  when('it consumes that JSON output')
    then('the output is the same information the human tree shows, in a stable machine shape')
      sothat('the human and machine views never disagree about what exists')

given('a human who runs a bare `rhx enroll <brain>` with no `--as` name')
  when('the clone spawns')
    then('the human is shown their own clone`s address so they can reach it later, without a second command')
      sothat('a bare enroll is not a dead end — the human can `say`/`get` their own clone by its shown address')
```

> addendum (2026-08-09) — ratifies a third blueprint-derived surface: git-style hash-PREFIX reach on an
> `@<actor>` scope (raised by the i011 peer review, same discipline as the two above). a full actor hash is
> unusable at a human keyboard, so a prefix is the natural reach — exactly as `git` addresses a commit by a
> short prefix. this is a derivation of the vision's own "copyable hash" render.

```
given('an enrolled anonymous actor whose full hash is long')
  when('a process runs `rhx clone list @<hash-prefix>` with a prefix that UNIQUELY names one actor')
    then('the actor is resolved and only its clones are listed')
      sothat('a human can reach an actor by a short prefix, not a 64-char hash')

given('a hash-prefix that matches MORE THAN ONE enrolled actor')
  when('a process runs `rhx clone list @<ambiguous-prefix>`')
    then('the command fails loud, names the candidate actors, and asks for a longer prefix')
      sothat('an ambiguous reach never silently picks the wrong actor')
```

> addendum (2026-08-09) — ratifies a fourth blueprint-derived surface: the `enroll --output json`
> headless-supervisor handoff (raised by the i039 r11/r12 peer reviews, same discipline as the three
> above — its siblings all got a ratification line, this one, arguably the wish's LEAD usecase, had not).
> traces directly to the wish: "so that subsequent usecases can power actions like crons, comms… via ipc
> programmatic access of clones." also ratifies the orphan-cost field in the machine view, the precise
> machine-consumption hole both l3 lenses named.

```
given('a supervisor / cron that spawns `rhx enroll <brain> --output json` non-interactively')
  when('the clone spawns')
    then('the command emits a machine-parseable handoff (the clone`s serial + reachability) to stdout')
      sothat('the supervisor reads the address it needs to `say`/`get` the clone, with no second command and no race')

given('the same supervisor spawn that FAILS (a brain conflict, a global slug collision, no linked roles)')
  when('it ran with `--output json`')
    then('the failure is a machine-parseable structured error (not human prose), with a non-zero exit')
      sothat('the machine branches on error fields the same way it does for the talk verbs — symmetric everywhere')

given('a cron that consumes `rhx clone list --output json` to watch for cost hazards')
  when('a clone is a suspected SIGKILL-orphan (a live, still-billed brain that reads DEAD)')
    then('the machine output carries a structured orphan field the cron can read, not only a human advisory line')
      sothat('the wish`s headline machine consumer detects the credit-drain hazard by a field, never by a regex')
```

> ⚠️ deferral note (2026-08-10) — the orphan-field scenario above (the third of this addendum's three) is
> **DEFERRED in v1, awaited wisher sign-off** (open-decisions ledger row 11, i027). the `computeCloneOrphanVerdict`
> classifier is built + unit-tested, but its delivery into the `--output json` list view needs a live `/proc`
> process-start-time probe AND a spawn-path change (`genClone.ts` records `hostPidStartedAt: now()`, a wall-clock
> stamp that is NOT comparable to a kernel `/proc` start-time, so the pid-reuse guard cannot fire until the spawn
> record captures the true `/proc` start-time). that spawn-path change is the v1-scope call reserved for the
> wisher. this note aligns the contract with the blueprint's ledger so the two agree; the FIRST TWO scenarios of
> this addendum (the machine handoff + the structured error) ARE delivered and clamped — only the orphan-field
> `then` awaits sign-off. once the wisher greenlights, the staged classifier is connected to satisfy this `then`.

> addendum (2026-08-09) — ratifies a FIFTH blueprint-derived surface: `rhx clone whoami` + the
> self-identification env-vars (`RHACHET_CLONE_SERIAL` / `RHACHET_CLONE_SOCKET` injected at spawn), by the
> SAME discipline as the four surfaces above (the i046 peer review named whoami as a new subcommand AND a
> new env-injection mechanism that had skipped the criteria backfill its three siblings each got). traces
> directly to the wish's LEAD motive: "a clone can enumerate and message its peer clones… instead of
> full-terminal control" — a clone must be able to name ITSELF (and its actor scope) to reach its peers.

```
given('a process spawned as an enrolled clone (its env carries its own serial)')
  when('it runs `rhx clone whoami`')
    then('the command returns THIS clone`s own address — its serial, its slug if any, its reach-state')
      sothat('a clone that self-manages learns its own address in one read, never a fragile pid/cwd match')

given('the same clone')
  when('it runs `rhx clone whoami --output json`')
    then('the output carries the clone`s own actor scope (a hash it can pass to `clone list @<actor>`)')
      sothat('the clone can enumerate its SIBLING clones — the wish`s self-management motive, end-to-end')

given('a process run OUTSIDE any enrolled clone (a plain shell, no clone env)')
  when('it runs `rhx clone whoami`')
    then('the command fails loud with an error that names the cause and the fix')
      sothat('a caller is never handed a false or fabricated self-identity')
```

> addendum (2026-08-10) — ratifies a SIXTH blueprint-derived surface: the `rhx enroll --reason <text>`
> audit-motive flag, by the SAME backfill discipline as the five surfaces above (the i050 peer reviews named
> `--reason`, added at i046 alongside `whoami`, as the ONE peer surface that never got its criteria
> addendum — the exact scope-leak pattern this backfill exists to catch). traces DIRECTLY to the wish, which
> names `enrollment.jsonl` as the record of "the history of WHY and which roles were enrolled" — so `--reason`
> closes a real spec gap (a caller-supplied "why"), not an invented flag.

```
given('a human or cron that runs `rhx enroll <brain> --reason <text>`')
  when('the enrollment produces a real event (a fresh clone or a rebind)')
    then('the supplied reason is recorded in the actor`s enrollment history')
      sothat('the audit trail answers WHY this enrollment happened, not only that it did')

given('a bare `rhx enroll <brain>` with no `--reason`')
  when('the enrollment is recorded')
    then('the reason is recorded as absent, never a fabricated motive')
      sothat('the audit "why" is truthful whether or not a reason was given')

given('a `--reason @stdin`')
  when('the human pipes the motive on stdin')
    then('the piped text is captured as the reason')
      sothat('a payload-heavy or multi-line motive has a clean CLI path, the same as `say --what @stdin`')
```

> addendum (2026-08-10) — ratifies a SEVENTH blueprint-derived surface: the `rhx enroll` soft ACCRUAL WARN,
> by the SAME backfill discipline as the six surfaces above (the i059 peer review named the accrual-warn — a
> real observable stderr advisory + `accrualWarn` json field, built at i049 — as a CLI surface that slipped
> the criteria backfill its siblings each got). traces DIRECTLY to the wish's headline caller class: "so that
> subsequent usecases can power actions like crons" — a bare `rhx enroll` is create-always, so a cron that
> retries accrues billed brains unbounded; the WARN is the status-feedback that makes the accrual visible. the
> THRESHOLD value + the soft-warn-vs-hard-cap choice remain the wisher's (a flagged council fulcrum); the
> EXISTENCE of the surface is ratified here regardless of what that value is decided to be.

```
given('an actor that already has many live clones (its live-clone count crosses a soft threshold)')
  when('a human or cron runs `rhx enroll <brain>` and the clone spawns')
    then('the enrollment still succeeds, and a one-line advisory names the live-clone count and the triage move')
      sothat('a cron that retries can accrue billed brains, and the accrual is made visible before it compounds')

given('an actor below the soft threshold')
  when('the enrollment produces a fresh clone')
    then('no accrual advisory is emitted')
      sothat('a legitimate small parallel-clone burst is never nagged')

given('a machine consumer that runs `rhx enroll <brain> --output json`')
  when('the live-clone count crosses the threshold')
    then('the machine handoff carries a structured accrual field the consumer can read')
      sothat('a cron detects the accrual by a field, not by a regex over a human advisory line')
```

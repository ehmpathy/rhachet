# experience dimensions — fix-config-blend

vocab: **roles** ambient · specific. **actors** repo · hash · slug. one brain dir layout for every actor.
every reader is an enrolled clone (`claude` is aliased to `rhx enroll claude`).

the wish holds two behaviors — (1) the brain dir settings layout and the ambient route, (2) the rhachet intro
atop every boot — so the axes cover both.

## the axes

| axis | values | orthogonal because… |
|---|---|---|
| **roles source** | bare (no `--roles`) · `--roles …` · `actors.yml` | how the human named the roles — independent of the box, the dir, the writer, and trust |
| **roleset equals ambient?** | yes · no | the latent axis. a `--roles` list can equal the ambient set or not; bare is always yes |
| **roleset size** | empty · non-empty | how many roles the render carries — independent of how they were named (the ambient set itself can be empty in a repo with no roles linked) |
| **writer** | `rhx init` · `rhx upgrade` · `rhx roles link` · `rhx enroll` · `rhx clone` · claude itself (`/config`) · a human by hand | which process touches the dir — independent of what the dir held before |
| **render** | first · repeat | whether this `boot.md` render follows a prior one for the same roleset — independent of which roles |
| **grove file** | present · absent | a fact about the box (`~/.claude/settings.json`), before any rhachet run |
| **prior actor dir** | none · exists under a legacy name (`actor.via.slug=.default`) · exists under the current name | the latent axis: whether the dir the writer targets exists before this run, and under which name |
| **prior settings.json** *(only when the dir exists)* | absent · real file (legacy all-roles) · arrow · forked (an arrow a writer replaced with a real file) | what sat at that name — any value can meet any writer, since a fork persists from a past session. undefined when the dir is none: see R19 |
| **stale enroll file** *(only when the dir exists)* | none · present | a leftover inside that dir from an old enroll — independent of what `settings.json` holds. undefined when the dir is none: see R19 |
| **hash twin of the ambient roles** | none · present (e.g. `actor.via.hash=bb10e9fb`) | a leftover actor from the pre-fix route — independent of the repo actor's own state |
| **trust** | repo actor trusts the repo · does not | a fact of the human's history, independent of every rhachet axis |
| **concurrency** | solo · two writers on one actor dir at once | order in time, independent of content |

**derived, not axes** — each is a function of the axes above:
- **actor** = f(roles source, roleset equals ambient?): equals ambient → **repo**; else `--roles` → **hash**;
  else `actors.yml` → **slug** (reached by writer = `rhx clone`). the collapsed state: the actor is never
  chosen, only derived
- **conflict** (grove vs repo on one key) exists only when grove file = present — a sub-case, see R6

## the walk — every region carries a verdict

barred cells name their kind: **forbidden** = attemptable, and the behavior rejects it (a guard is owed);
**impossible** = no attempt can be made (no guard needed).

| region | cells | verdict | why |
|---|---|---|---|
| R1 | roleset equals ambient = yes × any source | **demoed** — lands in the repo actor | case 7 [t0, t1] |
| R2 | source = `--roles` × equals ambient = no | **demoed** — lands in a hash actor | case 2, case 7 [t2] |
| R3 | source = `actors.yml` × equals ambient = no | **itemized** — lands in a slug actor with the one layout; the slug path is not reshaped by this wish | the one-layout rule covers it; init does not resync slug actors today (out of scope) |
| R4 | source = bare × equals ambient = no | **impossible** | bare means ambient by definition |
| R5 | writer ∈ {init, upgrade, roles link} × prior actor dir × prior settings.json × stale enroll file | **demoed**: none (case 9 [t0]), legacy + real file + stale file (case 1 [t0]–[t3.1]), forked (case 6 [t1]); **itemized**: current + arrow is a no-op (case 1 [t6]) | every prior state converges to the one layout |
| R5e | writer ∈ {enroll, clone} × prior actor dir × prior settings.json × stale enroll file | **demoed**: none → a new actor with the layout (case 2 [t0], case 9 [t2]); exists + real file, no grove (case 4 [t2]); legacy name, before any init → a bare enroll moves the dir before it mints any actor dir, and repoints `<repo>/.claude` (case 10 [t0], found at verification); **itemized**: exists + arrow is a re-enroll — the layout is already whole, so no file changes; exists + forked — enroll relinks as init does (case 6); stale enroll file present — enroll leaves it, only init prunes it, and only once no clone lives (case 1 [t3.1]) | enroll and clone run the same one-layout writer as init, for their one actor |
| R5d | writer ∈ {init, upgrade, roles link} × actor = hash, enrolled by delta (`--roles -abc`) × ambient set changed since its enroll × clone live / none | **demoed**: the actor's roles and `settings.repo.json` re-derive from the new ambient set ⊕ its delta (case 11 [t1]); with a live clone its `boot.md` re-renders too, and the clone is untouched (case 11 [t1]); a re-enroll of the same delta lands in the same actor (case 11 [t2]); **itemized**: with no live clone the `boot.md` renders at the next spawn | the delta is the actor's identity, so the actor holds still while its roles follow the repo (`inventory.of=requirements.case=2`; found at verification) |
| R6 | grove file = present × conflict (key, deny) | **demoed** key (case 2 [t3]) · **itemized** deny | lists merge across scopes; deny wins (docs) |
| R7 | grove file = absent × any writer | **demoed** | case 4 |
| R8 | trust = trusts / not × a fresh actor | **demoed** | case 8 |
| R9a | concurrency = two × writer = enroll × enroll | **itemized** | a same-target `EEXIST` on an arrow reads as `unchanged` |
| R9b | concurrency = two × writer = init / upgrade / roles link, twice | **itemized** | each writes `settings.repo.json` by temp + rename; the content is a pure function of the roles, so the last writer wins with identical bytes |
| R9c | concurrency = two × writer = init × claude `/config` | **itemized** | if claude's write lands over the arrow mid-init, it is a fork; the next init detects, keeps it aside, and relinks (case 6) |
| R9d | concurrency = two × writer = a human by hand × any | **itemized** | a hand edit at the target races as any edit does; the arrow is untouched |
| R10 | writer = claude itself × prior settings.json = arrow | **demoed** | case 6 |
| R11 | writer = a human by hand × any arrow | **itemized** — the edit lands at the target; `ls -l` shows it | accepted |
| R12 | hash twin of the ambient roles = present × writer = upgrade | **itemized** — the twin is an orphan: no enroll routes to it again, its live clones finish, and prune reaps it once DEAD | the clamp stops new twins; old ones age out |
| R13 | roleset size = empty / non-empty × render = first / repeat × any actor | **demoed** — every `boot.md` opens with the intro; an empty roleset still carries it; a repeat render is byte-identical | case 5 [t0], [t1], [t2] |
| R14 | any writer × a write to `~/.claude/settings.json` by rhachet | **impossible** | the writer names only `settings.repo.json`; no code path names the grove (case 3) |
| R15 | any clone × a read of another actor's dir | **impossible** | a clone is spawned with the `user` source only; no read of another dir is ever issued |
| R16 | any code × the ambient roleset handed to the hash-actor derivation | **forbidden** | attemptable by a future caller; the clamp rejects it loud (case 7 [t3]) |
| R17 | any writer × a file or arrow in one actor dir that another lacks | **forbidden** | attemptable by a writer; `rule.forbid.brain-dir-layout-divergence` rejects it, and a layout test guards it |
| R18 | any writer × a file placed in `<repo>/.claude` | **impossible** | `<repo>/.claude` is a symlink into the repo actor's dir; a write there lands in that actor dir |
| R19 | prior actor dir = none × prior settings.json ≠ absent, or × stale enroll file = present | **impossible** | no dir, so no file can sit in it — the contents axes are defined only when the dir exists |

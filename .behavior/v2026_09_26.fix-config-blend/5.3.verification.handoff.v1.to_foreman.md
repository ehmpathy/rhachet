# handoff v1 → foreman: ten codex-gated skips

## .what is blocked

ten `given.skip` / `when.skip` cases in `src/` need a live brain **repl** to run:

- `src/domain.operations/actor/actorAsk.integration.test.ts`
- `src/domain.operations/actor/actorAct.integration.test.ts`
- `src/contract/cli/invokeAct.integration.test.ts` [case4]
- the repl cases of `genActor.brain.*.integration.test.ts`

all of them sat in `src/` before this branch (merge-base `4216d590`), and this branch does not touch them.

## .what was tried

1. **unskip with the declared brain, `openai/codex`.** every codex slug the supplier offers
   (`rhachet-brains-openai@0.3.1`: `openai/codex`, `/5.1`, `/5.2`, `/mini`, `/max`, `/mini/5.1`, `/max/5.1`)
   resolves to one of three models: `gpt-5.1-codex-max`, `gpt-5.1-codex-mini` or `gpt-5.2-codex`. all three
   return **404, model not found** for the test openai key (`rhx keyrack unlock --owner ehmpath --env test`).
   the key itself works: the two weave cases unskipped at 5.3 call the plain openai api with it and pass
   10/10
2. **another supplier's repl.** only openai (codex) and anthropic ship a `BrainRepl`. anthropic is ruled out
   by the wisher's constraint for this route: zero anthropic api credit
3. **a stub repl.** this would change what the tests prove. they exist to prove that a real repl answers
   `actor.ask` / `actor.act`, and a stub only proves the stub (zero fake tests)

## .why this needs the foreman

the 404 is an access grant on the openai org. it is not a code path and not a credential the driver
holds: the key is valid, but its org has no codex model access. only an org admin can grant that.

## .the lever

- grant codex model access (`gpt-5.1-codex-max` at least) to the openai org behind
  `ehmpath/test`'s `OPENAI_API_KEY`, **or**
- lift the zero-credit constraint for anthropic, so the cases can run on `anthropic/claude/code`

once either is in place, the driver unskips all ten and runs them with
`rhx git.repo.test --what integration --scope 'actorAsk|actorAct|invokeAct|genActor.brain' --mode apply --env test`.

## .rewind

if the foreman wants this stone held until the skips are cleared:
`rhx route.stone.set --stone 5.3.verification --as rewound`

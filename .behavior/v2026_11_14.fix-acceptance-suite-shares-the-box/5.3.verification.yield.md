## .a defect verification found, and fixed

`enroll.acceptance` went red on 4 tests (a kept log under `.log/role=any/skill=test.acceptance.credfree/`):
`enroll --await -p` with no tty runs attached, and its stdin ends at once. lever 5's loss watch read that end as
"the terminal went away" and ended the brain before it answered. the fix reads an input end as a loss only on a tty
(`genHostLossWatch` [case6]; a pipe's brain still ends on parent death). red before, green after (207/207). the experience inventory's case 10 [t1] row, which called this cell
impossible, is corrected.

## .a flake verification found, and fixed at its cause

`enweaveOneRoute` › imagine stitchers went red once in the impacted integration run: the model answered in
prose and asked for the code it was meant to diff. the cause was no model variance. the test's stub read
returned a bare string, while the real read (`genStitcherCodeFileRead`) returns `{ path, content }`, and the
imagine stitcher reads `.content` — so the prompt carried `undefined` where the code belonged, and the model
was asked to diff code it was never shown. the stub now returns the real shape and is typed
`OutputFileRead`, so a bare string fails `types` (the clamp). after the fix: 5 of 5 runs green
(`rhx git.repo.test --what integration --mode apply --scope 'path://enweaveOneRoute' --scope 'name://imagine stitchers'`),
and the kept stdout log shows `sdkOpenMeteo` in the prompt and a
`<<<<<<< ORIGINAL` / `>>>>>>> MODIFIED` diff of it in the answer.

## .two paths a live walk found rough, and fixed

- **the residue notice named no cure for the dirs.** it said `safe to delete` and stopped, which left a
  human to write a bare `rm -rf` glob that would also take a live run's dir from a peer checkout. the
  notice now prints `find <tmp> -maxdepth 1 -name 'rhachet-test-*' -mmin +1440 -exec rm -rf {} +`, and
  `asResidueNotice.integration.test.ts` runs that exact line on a temp root: the old dir goes, a fresh one
  and an old dir of another name stay. with the age bound at 0 the fresh-dir case goes red, so the bound
  is clamped
- **the measure ran minutes in silence.** it now prints a line per phase, to stdout: `rhx` holds a skill's
  stderr back until it fails, so stderr progress never reached the human (found on the live walk)
- **the header's go-wide hint failed on the common entry.** `rhx test.acceptance.credfree … --maxWorkers 100%`
  was refused as an unknown option. credfree now passes the width to jest and echoes it; the header reads
  `(asked)` and names the way back; an absent value for `--scope` or `--maxWorkers` refuses at exit 2
  with an example (it was bash's own `line 46` at exit 1)

## .the residue notice told a truth it could not know

the dir count in the residue notice rose from 3984 to 4081 between two runs of this checkout. the dirs carry no
checkout id, so the count is box-wide: a peer checkout that predates the fix still adds to it. the notice read

checkout's. `genTestTempRepo.integration.test.ts` proves, with no host read, that this checkout mints no repo
in the os temp root.

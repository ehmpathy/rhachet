# case 9 — a hung export fails every caller loud, within a bound

**narrative (the caller).** 33 suites ask for one profile with the cache absent, and the aws cli hangs —
a network that drops packets, a dead sso endpoint. the holder's export passes the 2 min hang guard, which
kills the cli; the holder writes no cache, frees the key, and throws. the next waiter takes the key, finds
no cache, and runs its own export, which hangs the same way. the waiters are serialized, so after two such
hangs the rest pass their 5 min wait bound and throw a ConstraintError.

every caller fails loud inside 5 minutes; none hangs in silence. today's raw export has no hang guard, so
33 hung clis would hold 33 cores with no bound at all.

**fail safe — fast, loud, teaches the fix:** the holder's error names the profile and the hang guard; a
waiter's error names the profile and the wait. the wait bound is the one backstop it owns: since a dead
holder's lease lapses before it (case 4), a wait can pass the bound only behind exports that ran long in
turn. so the waiter's hint names that cause — the aws cli is slow or hung; check the network or the sso
endpoint, then retry. no cache is written, so a retry once the cli answers exports anew.

**the bound:** a short failure marker that would let waiters fail at once, rather than in turn, is not
built (fulcrum F4).

```
given('[case9] 33 callers ask for one profile, and the aws cli hangs')
  when('[t0] all 33 call genAwsProfileExport together')
    then('each holder\'s export is killed at the 2 min hang guard')
    then('every caller throws within the 5 min wait bound')
    then('a waiter\'s error names the profile, the wait, and a hint that the export hangs')
    then('no cache file was written')
    then('no two exports overlapped')
```

# case 2 — a warm read spawns no cli

**narrative (the human).** ten minutes after one unlock, a second shell runs `rhx keyrack unlock` for the
same aws key. the cache holds creds that expire in 50 minutes. keyrack's pre-warm and its expiry read
both find the file valid, take no lock, run no export, and answer in the time a file read takes rather
than two python startups.

```
given('[case2] a cached export 50 minutes from its expiry')
  when('[t0] a caller asks for the profile')
    then('the aws cli did not run')
    then('the result equals the cached value')
```

# experience catalog — aws export single-flight

axes and their collapses: `1.vision.experience.dimensions.md`. actors are a view over the cells, not an
axis (see there).

## .actors × feel

| actor | happy | sharp |
|---|---|---|
| the caller (a jest env, an `rhx` call) | a burst yields one export and identical creds (case 1) · a warm read spawns no cli (case 2) · near-expiry creds re-export once, alone or in a burst (case 3) | the export fails → every caller fails loud, taught the fix, no cache written (case 6) · the export hangs → every caller fails loud within 5 min (case 9) · a temp `AWS_CONFIG_FILE` gets its own creds, never the default config's (case 8) |
| the human at a loaded box | a second unlock answers in a file read, not two python startups (case 2) | a ctrl-c mid-export → the next caller waits out the lease and proceeds, no lock file to delete, and its notice says when the hold lapses (case 4) · a re-login → the cache holds the new user's creds at once, and no reader in the meantime gets the old ones (case 7) · a root-owned cache dir → the unlock row names the dir to fix, exit 2 (c11) |
| the on-call who reads a fault | — the on-call meets this behavior only through a fault, so it has no happy path | an incomplete export names the profile and the keys it found, never a value, and says how to look; the cache is owner-only (case 5) |

  - identity = profile + `AWS_CONFIG_FILE` + `AWS_SHARED_CREDENTIALS_FILE` (or their defaults);
    file and key are `profile=$profile.$sha8`, the sha over both paths and both files' content, so

- [x] `.agent/repo=.this/role=keyrack/briefs/define.aws-export-cache.md` — where the cache rests, what
  keys it, the margin, what drops it, how to purge it
  - read → valid (> 15 min left, the botocore refresh window) returns before the key; else take
    the key, re-read, export, write (F3)
  - `refresh: true` drops the entry before it queues and under the hold; finds none (F2)
  - export under a 2 min hang guard (the cli is killed); lease 3 min; wait bound 5 min
  - the profile reaches the shell as one single-quoted word, so no `$(…)` in a name runs
  - cache file 0600 in a 0700 dir (re-asserted on an extant dir), temp + rename; a fault of the
    dir ensure, the read, the drop, or the write throws a ConstraintError whose hint names the path
    to make readable and writable and the disk's error, temp removed (collapse 11); the unlock row
    shows it as `— fix: make <path> …`
  - a corrupt file, a file short a key, a file with a bad expiry or credentials shape, or a file
    of another identity counts as absent
  - the cli runs under the env its identity was read from (`env: process.env`)
  - every bound is an `IsoDuration`; raw ms appear only at the hand-off to `setTimeout` and
    `with-simple-mutex`
  - a wait on a peer's export is announced once per wait, on stderr; it names the profile, the
    wait bound, and the lease in which the wait ends on its own if the other process was killed,
    never a value (F6)
  - a cli failure carries the cli's own stderr as `cliError`, never the exec wrapper's text
  - every hand-run hint quotes the profile and prefixes each config override this process
    carries, so a human reruns the same config; the wait-bound hint says the killed process's
    hold lapses on its own within the lease; a file at the cache dir path reads `a file blocks the
    aws export cache dir`

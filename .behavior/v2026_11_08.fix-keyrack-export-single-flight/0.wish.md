# wish: keyrack aws export runs single-flight (ehmpathy/rhachet#656)

## outcome
`aws configure export-credentials` for one profile runs once at a time on a box: a disk lock serializes concurrent callers, and a disk cache serves the exported credentials until near their expiry. a jest env that asks for the same profile 33 times per run, on a box at load 70, reads the cache after the first export and never times out on the export.

## done means
- a test clamps: N concurrent callers for one profile yield one export and N identical results; a cached value near expiry re-exports; a held lock from a dead process does not wedge the next caller
- the cache never prints or logs a credential value; its file is readable only by its owner
- pr open to the commander's review; never released or merged

## bounds
- nano. no change to which profile or key a caller gets

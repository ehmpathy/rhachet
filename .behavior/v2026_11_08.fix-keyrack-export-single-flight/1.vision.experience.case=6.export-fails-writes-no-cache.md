# case 6 — an export that fails writes no cache

**narrative (the caller).** the sso session behind a profile went stale. the first caller holds the
mutex, and its export fails. it writes no cache, frees the key, and throws. each waiter then takes the key
in turn, finds no cache, and runs its own export, which fails the same way. the exports are serialized
rather than concurrent, so the box spins one core at a time, not N. every caller fails loud.

**fail safe — teaches the fix:** the error names the profile and the cli's own message, and its hint names
the next move: re-run `rhx keyrack unlock`, which re-logs in a stale sso session.

**the bound:** a single shared read of a stale session, handed to every waiter (#652), is out of scope.

```
given('[case6] two callers at once, and an export that fails')
  when('[t0] both call genAwsProfileExport')
    then('both throw')
    then('the error names the profile, with a hint to re-run rhx keyrack unlock')
    then('the exports never overlapped')
    then('no cache file was written')
```

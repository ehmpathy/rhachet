## .the narrative

before: a reviewer's rubric says "run the peer review". it runs `rhx review --brain …`.
`rhx review` never calls `rhx enroll`; it calls `genContextBrain` → `brain.repl.ask`, and the
anthropic supplier spawns `claude` via claude-agent-sdk with the reviewer's own `process.env`.
no check ran. each rubric the review skill runs starts one more brain, so one reviewer becomes N
brains. they read the reviewer's depth and serial, so each reads as the reviewer itself. the
guard's `-p` waits on all of them; tokens burn; the peer review times out.

after: the repl seam reads the caller's leaf mark before it calls the supplier. a reviewer
(a `-p` child, or a repl brain) is refused with the same message case=1 renders:

```
✋ ConstraintError: a reviewer clone may not spawn

  via:  a repl brain (`rhx review`, `rhachet ask`, `rhachet act`)
```

`rhx review` exits nonzero; the reviewer reads one loud line and writes its verdict from its own
read. one refusal, zero grandchildren.

a worker at depth 1 that runs `rhx review` carries no leaf mark, so it is admitted: its review
brain boots at depth 2, a leaf.

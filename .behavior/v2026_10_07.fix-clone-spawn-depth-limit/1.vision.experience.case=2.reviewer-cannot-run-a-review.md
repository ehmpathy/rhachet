# case=2 — a depth-1 clone (e.g. a guard's reviewer) cannot run a review skill that spawns a brain

**cell:** depth1 × repl → refused
**feel × care:** 🗡️ · 🔴 critipath — the defect the wish exists for

## .the narrative

today: a depth-1 reviewer's rubric says "run the peer review". it runs `rhx review --brain …`.
`rhx review` never calls `rhx enroll`; it calls `genContextBrain` → `brain.repl.ask`, and the
anthropic supplier spawns `claude` via claude-agent-sdk with the reviewer's own `process.env`.
no budget is checked. each rubric the review skill runs starts one more brain, so one reviewer
becomes N brains. they read depth 1 and the reviewer's serial, so each reads as the reviewer
itself. the guard's `-p` waits on all of them; tokens burn; the peer review times out.

after: the repl seam reads the caller's depth before it calls the supplier. a depth-1 caller is
refused with the same message case=1 renders:

```
✋ ConstraintError: clone spawn depth limit reached

  depth: 1 (the limit to spawn is depth 0)
  hint:  a clone at depth 1 may not spawn another — ask the clone that spawned you, or a human
```

`rhx review` exits nonzero; the reviewer reads one loud line and writes its verdict from its own
read. one refusal, zero grandchildren.

## .the sketch

```
given('[case2] a reviewer clone a guard enrolled at depth 1')
  when('[t0] the reviewer runs `rhx review --brain claude/code`')
    then('it sees "✋ ConstraintError: clone spawn depth limit reached", exit 2')
    then('the message names its depth (1) and the limit (depth 0)')
    then('no review brain starts — the supplier `ask` is never called, so no grandchild exists')
  when('[t1] the reviewer runs a skill that drives a brain via repl act')
    then('it sees the same refusal')
  when('[t2] the reviewer runs a skill that calls one atom (no process, no tools)')
    then('the skill completes — an atom is not a clone')
```

impl note: the refusal is thrown at `asBrainReplWithContextBound` before the supplier `ask`/`act`;
`atom.ask` passes `asBrainAtomWithContextBound` unchecked (F3).

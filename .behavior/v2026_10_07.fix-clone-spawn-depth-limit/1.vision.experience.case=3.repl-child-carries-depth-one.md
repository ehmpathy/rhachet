# case=3 — a depth-0 driver's review brain carries depth 1

**cells:** depth0 × repl (solo and concurrent) → spawned; child at depth 1, no parent serial
**feel × care:** 😊 for the driver, 🗡️ for the child · 🔴 critipath — the propagation half

## .the narrative

a depth-0 driver runs `rhx review`. the repl seam allows it (child depth 1 ≤ limit). for the
duration of the supplier call, the env the supplier hands its brain carries
`RHACHET_CLONE_DEPTH=1`, and no `RHACHET_CLONE_SERIAL` / `RHACHET_CLONE_SOCKET` — those name the
driver, and the review brain is not the driver.

inside the review brain, an attempt at `rhx enroll` or a nested `rhx review` reads depth 1 and
is refused (case=1, case=2). the marker went down; it was never reset to 0.

after the call returns, the driver's own `process.env` reads depth 0 and its own serial again.

**why this matters even though review uses `ask`:** the anthropic supplier denies `Bash` to an
`ask` brain (`genBrainRepl.js:56,179`), so today's review brain cannot shell out at all. but an
`act` brain may (`TOOLS_ALLOWED_FOR_ACT`), and another supplier may grant tools to `ask`. rhachet
cannot rely on a supplier's tool list to hold the depth bound; the marker must ride down
regardless.

## .the sketch

```
given('[case3] a driver clone at depth 0, serial S')
  when('[t0] the driver runs a brain via repl that holds a shell (an `act` brain), and that brain runs `rhx enroll`')
    then('the brain sees "✋ ConstraintError: clone spawn depth limit reached", exit 2 — fast and loud')
    then('the message names "depth: 1 (the limit to spawn is depth 0)" and the hint "a clone at depth 1 may not spawn another — ask the clone that spawned you, or a human" — it teaches the fix')
    then('the brain finishes its task from its own read; the driver gets its answer')
  when('[t1] the driver reads its own env after the review')
    then('the review brain was handed no serial and no socket, so no clone but the driver answers to serial S')
    then('the driver still reads as depth 0, serial S — its own spawns still pass')
  when('[t2] the driver runs several such brains in parallel, and each runs `rhx enroll`')
    then('every one of the N parallel calls is allowed — none reads depth 1 from a peer scope still open')
    then('every brain is refused the same way — none reads depth 0 because a peer finished first')
  when('[t3] a caller with no tty and no depth var (a cron job, or a raw claude tool shell) runs N repl calls in parallel')
    then('every child carries depth 1 — the first call and the last read the same held caller depth, 0')
    then('every call is allowed — a depth-0 caller is never refused')
```

impl note: the probe for [t0]–[t2] is a supplier stub that records the env it was handed —
`RHACHET_CLONE_DEPTH=1`, no `RHACHET_CLONE_SERIAL` / `RHACHET_CLONE_SOCKET`; the scope is
refcounted and restored after the last concurrent call returns (F2, F5). the scope holds the
caller depth it read when it first opened; a call that joins an open scope checks against that
held value, not the env the scope wrote.

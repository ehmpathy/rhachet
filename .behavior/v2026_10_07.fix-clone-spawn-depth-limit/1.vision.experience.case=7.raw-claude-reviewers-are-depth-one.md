# case=7 — a raw `claude`'s guard reviewers are depth 1, and leaves

**cells:** notty-unmarked × enroll.await → spawned @ 1, a leaf · notty-unmarked × repl → brain @ 1,
a leaf · raw-claude-inherited × enroll.await → spawned @ inherited + 1, a leaf
**feel × care:** 😊 for the raw `claude`, 🗡️ for its reviewers · 🔴 critipath — the wish's headline
path: "i open a new claude from my terminal — it should be able to run reviews"

## .the narrative

a human opens `claude` by hand in a terminal pane — no `rhx enroll`. it is a top-level clone,
the same as one `rhx enroll` starts (S1). it drives a route and arrives a guarded stone. its
guard runs `rhx enroll claude -p '…'` through the `claude` tool shell, which has no tty, no depth
var and no leaf mark. so the reviewer is minted at depth 1, a leaf. the reviewer reads, judges,
returns. when it tries `rhx enroll` or `rhx review`, it is refused.

on main that reviewer is minted at depth 0, unmarked, and may spawn once more — the over-spawn
the wish names.

the same `claude` may also run `rhx review` itself. its review brain is depth 1, a leaf, for the
same reason.

**the inherited pane.** the human opens `claude` in a pane split from inside a clone, so the pane
carries `RHACHET_CLONE_DEPTH=1`. its guard's reviewer is depth 2, a leaf — admitted, since depth
refuses no one. on main that enroll is refused and the stone stalls. a session-start depth reset
(F8) would make the record exact; it is not built here.

🟡 a pane that inherited `RHACHET_CLONE_LEAF` — one split from inside a reviewer — makes every
spawn from that raw `claude` refused. that pane is a reviewer's shell, so the refusal is correct;
its hint names a fresh terminal.

## .the sketch

```
given('[case7] a human opens a raw `claude` in a clean terminal pane')
  when('[t0] the claude arrives a guarded stone, and its guard runs `rhx enroll claude -p …`')
    then('the reviewer spawns and returns its verdict — the top-level clone is never refused')
    then('the reviewer carries depth 1 and the leaf mark')
  when('[t1] that reviewer runs `rhx enroll` or `rhx review`')
    then('it sees "✋ ConstraintError: a reviewer clone may not spawn", exit 2')
  when('[t2] the claude itself runs `rhx review`')
    then('the review runs to its verdict; its brain carries depth 1 and the leaf mark')

given('[case7] a human opens a raw `claude` in a pane that inherited RHACHET_CLONE_DEPTH=1')
  when('[t3] its guard runs `rhx enroll claude -p …`')
    then('the reviewer spawns at depth 2, a leaf, and returns its verdict — no refusal')
```

proof: [t0], [t3] `blackbox/cli/enroll.acceptance.test.ts` "rhx enroll reviewer leaf" [case2],
[case5] · [t1] [case1] · [t2] `blackbox/cli/askAct.spawnDepth.acceptance.test.ts` [case3].

impl note: no new mark is needed for a raw `claude` — the no-tty rule and the door that mints a
reviewer cover every row.

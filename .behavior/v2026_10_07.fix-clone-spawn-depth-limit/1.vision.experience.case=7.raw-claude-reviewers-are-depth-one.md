# case=7 — a raw `claude`'s guard reviewers are depth 1

**cells:** notty-unmarked × enroll.await → spawned @ 1 · notty-unmarked × repl → brain @ 1 ·
raw-claude-inherited × enroll.await → spawned @ 1
**feel × care:** 😊 for the raw `claude`, 🗡️ for its reviewers · 🔴 critipath — the wish's headline
path: "i open a new claude from my terminal — it should be able to run reviews"

## .the narrative

a human opens `claude` by hand in a terminal pane — no `rhx enroll`. it is a top-level clone,
the same as one `rhx enroll` starts (S1). it drives a route and arrives a guarded stone. its
guard runs `rhx enroll claude -p '…'` through the `claude` tool shell, which has no tty and no
depth var. a no-tty caller with no var counts as depth 0, so the reviewer is minted at depth 1.
the reviewer reads, judges, returns. when it tries `rhx enroll` or `rhx review`, it is refused.

today that reviewer is minted at depth 0 and may spawn once more — the over-spawn the wish names.

the same `claude` may also run `rhx review` itself. its review brain is depth 1 for the same
reason.

**the inherited pane.** the human opens `claude` in a pane split from inside a clone, so the pane
carries `RHACHET_CLONE_DEPTH=1`. when the session starts, the repo brain dir's settings set
`RHACHET_CLONE_DEPTH=0` for it, so its tool shell reads a depth-0 caller and the guard's
reviewer is depth 1 — not 2, not refused. today that guard's enroll is refused and the stone
stalls.

## .the sketch

```
given('[case7] a human opens a raw `claude` in a clean terminal pane')
  when('[t0] the claude arrives a guarded stone, and its guard runs `rhx enroll claude -p …`')
    then('the reviewer spawns and returns its verdict — the top-level clone is never refused')
    then('the reviewer carries depth 1')
  when('[t1] that reviewer runs `rhx enroll` or `rhx review`')
    then('it sees "✋ ConstraintError: clone spawn depth limit reached", exit 2')
  when('[t2] the claude itself runs `rhx review`')
    then('the review runs to its verdict; its brain carries depth 1')

given('[case7] a human opens a raw `claude` in a pane that inherited RHACHET_CLONE_DEPTH=1')
  when('[t3] the session starts')
    then('its tool shell reads RHACHET_CLONE_DEPTH=0 — the inherited 1 is overridden (Q11)')
  when('[t4] its guard runs `rhx enroll claude -p …`')
    then('the reviewer spawns at depth 1 and returns its verdict — no refusal')
```

impl note: [t0]–[t2] need no new mark — the no-tty rule alone covers them. [t3]–[t4] rest on the
session-start reset; if a settings `env` does not override an inherited var (Q11), the
SessionStart `CLAUDE_ENV_FILE` hook is the fallback, and [t3] is its test.

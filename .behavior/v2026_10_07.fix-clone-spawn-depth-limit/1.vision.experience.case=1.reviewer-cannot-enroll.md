# case=1 — a work clone's guard enrolls a reviewer (allowed, at any depth); that reviewer cannot enroll its own

**cell:** depth0 × enroll.await → spawned @ 1, a leaf · then leaf × enroll.watch → refused ·
then depth1 (work) × enroll.await → spawned @ 2, a leaf
**feel × care:** 😊 then 🗡️ then 😊 · 🔴 critipath (the floor that must hold, and the worker review

## .the narrative

a driver clone (depth 0) arrives at a guarded stone. the guard runs
`rhx enroll claude --roles reviewer,… -p '<review this stone>'`. the reviewer boots at depth 1,
with `RHACHET_CLONE_LEAF=1` in its env, because a print-mode enroll mints a reviewer. it reads
the stone. its rubric tempts it to get a second opinion, so it runs
`rhx enroll claude --roles mechanic -p '…'`. that enroll reads the leaf mark and refuses before
any brain spawns:

```
✋ ConstraintError: a reviewer clone may not spawn

  hint: a reviewer is a leaf: it answers, and spawns no clone of its own. … — the full text is
        snapped beside assertCloneSpawnAllowed
  via:  a clone enroll (`rhx enroll`)
  why:  this process is a reviewer: a print-mode enroll (`rhx enroll -p`) or a repl brain …
```

the reviewer reads the refusal, answers from its own read, and the review returns in one pass.

elsewhere in the fleet, a storefront worker — a session-mode clone the driver enrolled, so depth
1 and no leaf mark — arrives at its own guarded stone. its guard runs the same `rhx enroll … -p`.
on main that enroll is refused and the worker's stone stalls; here it is admitted, and its
reviewer boots at depth 2, a leaf, refused in turn if it tries to spawn.

## .the sketch

```
given('[case1] a depth-0 driver whose guard enrolls a reviewer')
  when('[t0] the guard runs `rhx enroll -p`')
    then('the reviewer clone reads RHACHET_CLONE_DEPTH=1 and RHACHET_CLONE_LEAF=1')
  when('[t1] the reviewer runs `rhx enroll claude`')
    then('exit 2, stderr names "a reviewer clone may not spawn"')
    then('no clone dir is created, no brain is spawned')
  when('[t2] a depth-1 worker clone (no leaf mark) runs `rhx enroll -p`')
    then('it is admitted; its reviewer reads depth 2 and the leaf mark')
```

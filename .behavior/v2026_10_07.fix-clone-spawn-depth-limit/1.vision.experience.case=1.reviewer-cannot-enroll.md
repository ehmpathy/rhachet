# case=1 — a depth-0 clone's guard enrolls a reviewer (allowed); that depth-1 reviewer cannot enroll its own

**cell:** depth0 × enroll.await → spawned @ 1 · then depth1 × enroll.watch → refused
**feel × care:** 😊 then 🗡️ · 🔴 critipath (the floor that already holds; it must keep to hold)

## .the narrative

a driver clone (depth 0) arrives at a guarded stone. the guard runs
`rhx enroll claude --roles reviewer,… -p '<review this stone>'`. the reviewer boots at depth 1
and reads the stone. its rubric tempts it to get a second opinion, so it runs
`rhx enroll claude --roles mechanic -p '…'`. that enroll reads `RHACHET_CLONE_DEPTH=1`, mints
child depth 2, and refuses before any brain spawns:

```
✋ ConstraintError: clone spawn depth limit reached

  depth: 1 (the limit to spawn is depth 0)
  hint:  a clone at depth 1 may not spawn another — ask the clone that spawned you, or a human
```

the reviewer reads the refusal, answers from its own read, and the review returns in one pass.

## .the sketch

```
given('[case1] a depth-0 driver whose guard enrolls a reviewer')
  when('[t0] the guard runs `rhx enroll -p`')
    then('the reviewer clone reads RHACHET_CLONE_DEPTH=1')
  when('[t1] the reviewer runs `rhx enroll claude`')
    then('exit 2, stderr names "clone spawn depth limit"')
    then('no clone dir is created, no brain is spawned')
```

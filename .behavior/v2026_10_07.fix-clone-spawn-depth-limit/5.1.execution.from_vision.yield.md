# 5.1.execution.from_vision — yield

the rule built is the ehmpathy/rhachet#577 vision, amended into `0.wish.md`: a work clone may
spawn at any depth; a reviewer clone is a leaf and may spawn no one; depth is a recorded fact.

## .todos

### one read of depth
- [x] `asCloneSpawnDepth({ env, isTty, door })` — a tty enroll with no parseable depth var mints 0; else caller + 1, so a tty that carries a var (a pane or a pty a clone opened) records the clone below the clone that opened it (F13); an absent or smudged var reads as a depth-0 caller; the repl door never mints 0
- [x] `CLONE_ENV_KEYS.depthMinted` (`RHACHET_CLONE_DEPTH_MINTED`) — the `--async` caller's decided depth, replayed by the detached host and deleted before it spawns
- [x] `asCloneSpawnDepth.test.ts` — data-driven cases over door × tty × var × minted

### the leaf mark
- [x] `CLONE_ENV_KEYS.leaf` (`RHACHET_CLONE_LEAF`) — `'1'` on a reviewer; a work clone carries no key at all
- [x] `isCloneSpawnChildLeaf({ door, isPrintMode })` — every repl child is a leaf; an enroll child is a leaf only from a print-mode (`-p`) enroll. the door is the mark, never the roleset: the ambient actor carries `reviewer` and must stay a work clone (F23)
- [x] `isCloneSpawnCallerLeaf({ env })` — the caller reads its own mark
- [x] `asCloneSpawnPlaceEnv({ env, depth, leaf })` — the one owner that writes depth and the mark into a child env, for both enroll spawn branches (pty and plain)
- [x] the detached `--async` host re-derives the mark from the argv it replays, so a detached session child is a work clone and a detached `-p` child is a leaf

### two doors, one check
- [x] `assertCloneSpawnAllowed({ isCallerLeaf, door })` — `ConstraintError('a reviewer clone may not spawn', { hint, via, why })`. the hint speaks to a reviewer (do not retry, answer from your own read) and to a human in a shell a reviewer opened (a fresh terminal). it never names the var. `via` names the door; `why` names why the caller is a leaf
- [x] `invokeEnroll.ts` — calls the shared assert before any dir or child exists
- [x] `asBrainReplWithSpawnDepthScope` — wraps a repl's `ask` and `act` in `withCloneSpawnDepthScope`; an atom passes through (`isBrainRepl` checks for both `ask` and `act`, F3)
- [x] `asBrainReplWithContextBound` — the context binder hands every repl through the wrapper
- [x] `actorAsk` / `actorAct` — the actor ops behind `rhachet ask`, `rhachet act` and `clone.ask/act` reach a repl without the binder, so they wrap the brain too
- [x] `asBrainReplWithSpawnDepthScope.fitness.integration.test.ts` — any prod module that holds a repl and calls `.ask(`/`.act(` must import a scope wrapper; the allowlist carries a reason per entry and a stale entry fails
- [x] the dead `brainRepl/askViaBrainRepl.ts` and `actViaBrainRepl.ts` (no callers, no exports) deleted, so no raw door survives unwrapped

### propagation at the repl door
- [x] `withCloneSpawnDepthScope` — a refcounted `process.env` scope over `CLONE_ENV_KEYS_IDENTITY`: sets the child depth and the leaf mark, drops the parent serial + socket (F5), restores after the last call. the leaf check runs only when the scope opens, so a parallel peer never reads the mark another call wrote. the state is anchored on `globalThis` under `Symbol.for('rhachet.cloneSpawnDepthScope.v1')`, so two copies of rhachet in one process share one count
- [x] `withCloneSpawnDepthScope.test.ts` — a work caller's child reads depth + 1 and the mark; parallel calls all run; a leaf caller is refused with no logic run and env untouched; two module copies share the held scope
- [x] `cloneEnvKeys.ts` — `CLONE_ENV_KEYS_IDENTITY` (serial, socket, depth, leaf) and `CLONE_ENV_KEYS_HANDOFF` (depthMinted, hostDetached); `cloneEnvKeys.test.ts` proves the two groups partition every key
- [x] `asBrainReplWithContextBound.test.ts` / `.integration.test.ts` — through both `ask` and `act`, in process and across a real child process, the child reads depth + 1, the mark, and no parent serial; a leaf caller is refused with no brain run

- the search for a consumer: `depthRequested|depthMax\b|enroll depth budget` returns 0 rows in `src` and in `node_modules/**/*.js`. the pr body names the change for any reader outside the org

### critical paths — captured i/o from the built cli

the refusal at the enroll door, a leaf caller (`RHACHET_CLONE_LEAF=1`), exit 2:

```
✋ ConstraintError: a reviewer clone may not spawn

{
  "hint": "a reviewer is a leaf: it answers, and spawns no clone of its own. a reviewer clone, spawned to answer a review: do not retry — answer from your own read. a human in a shell a reviewer opened: run the same command from a fresh terminal",
  "via": "a clone enroll (`rhx enroll`)",
  "why": "this process is a reviewer: a print-mode enroll (`rhx enroll -p`) or a repl brain spawned it, or it runs in a shell or a job that such a reviewer started"
}
```

the repl door renders the same block with `via` = `a repl brain (\`rhx review\`, \`rhachet ask\`, \`rhachet act\`)`.

against `def.frictionless` and `def.ergonomic`:
- **no surprise** — one class, one message, one hint at every door; `via` names which door
- **no stall** — the refusal fires before any dir, brain or claude process starts; a work clone is never refused
- **errors name the fix** — the hint speaks to a reviewer and to a human in a reviewer's shell; it never names the env var
- **safe** — the mark is set by the door that mints a reviewer, so no flag passes it; the one way past is to unset the var by hand, named in the vision's awkward section

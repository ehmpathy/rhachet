## .amended 2026-10-20 — the ehmpathy/rhachet#577 vision governs

the commander settled the depth fork (seed S68): **the ehmpathy/rhachet#577 vision is the intent
that governs this wish.** it supersedes the depth line quoted under `.what` below
(*"so depth up to 1 is allowed to spawn, but not beyond that"*), which stays for the record only.

the rule, per #577:

- **a work clone may spawn** — one level below itself, at any depth. no absolute cap
- **a reviewer clone is a leaf** — it may spawn no one. the enroll that mints a reviewer marks
  the child a leaf
- the attempt of a leaf to spawn is refused loudly, with a message that names the reviewer rule
- the leaf mark survives every path a clone is spawned by — a tty, a pty wrap, a detached host —
  so a reviewer never reads as a work clone and fans out again
- depth is still carried to every child, as a recorded fact of the chain, never as a limit
- tests prove all of it: a work clone spawns at depth 1 and beyond, a leaf is refused, and the
  mark propagates

## .what

in `ehmpathy/rhachet`, a clone's spawn depth is carried to every clone it spawns, and a clone
may spawn only while its depth is 0. *(superseded by the amendment above)*

> the wisher, verbatim: *"it needs to be fixed within rhachet. i.e., the toplevel clone should be
> able to spawn its own clone. (e.g., run a review skill). but those review clones should not be
> able to spawn their own. so depth up to 1 is allowed to spawn, but not beyond that."*

## .the outcome

*(the original outcome; the amendment above governs where the two differ)*

- **depth 0** — the top-level clone — can spawn clones, e.g. run a review skill
- **depth 1** — a clone that a depth-0 clone spawned, e.g. a reviewer — cannot spawn its own;
  the attempt is refused loudly, with a message that names the depth limit
- the depth marker survives every path a clone is spawned by — it is never reset to 0 on the
  way down, which is the defect today: a review clone can read as top-level and spawn again
- tests prove both halves: depth 0 spawns, depth 1 is refused, and the marker propagates

## .why now

review clones that spawn their own clones blow up the review conversation and the token spend,
so peer reviews time out and long routes stall across the fleet. the depth-1 cap that first
answered this also stopped every worker clone from a review of its own, which gates the
storefronts and the gads L10 lane — hence the #577 rule: reviewers are leaves, workers are not.

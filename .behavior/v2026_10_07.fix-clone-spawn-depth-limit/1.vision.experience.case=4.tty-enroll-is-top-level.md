# case=4 — a human enrolls at a terminal; the clone is top-level unless the env carries a depth

**cell:** tty × enroll.watch / enroll.async → @ depth 0 with no depth var · @ inherited + 1 with one
**feel × care:** 😊 · 🔴 critipath — the reported block: reviewers refused for a clone a human
meant as top-level

🟡 depth refuses no one, so this case gates no spawn. it holds the depth the chain records: a tty with no depth var is depth 0; a tty whose env
carries a depth var is a pty a clone opened, and reads that var + 1 (F13). the one refusal at a tty
is the leaf mark, which is read at any tty.

## .the narrative

a human types `rhx enroll claude --roles mechanic` at a fresh terminal. the enroll sees an
interactive tty on stdin and no `RHACHET_CLONE_DEPTH` in the env, so it mints the clone at depth 0.
the human drives a route with it. at the first guarded stone, `route.stone.set --as arrived` runs
the guard's `rhx enroll claude -p '…'` with no tty; that enroll reads depth 0 and mints the reviewer
at depth 1, a leaf — allowed. the guard gets its verdict.

a tty whose env carries a depth var is a pty a clone opened with its env kept. it reads that var + 1,
as a no-tty spawn does, so the chain records the clone below the clone that opened the pty. the
enroll is admitted at any depth. at the same pty, a caller that carries `RHACHET_CLONE_LEAF` — a
reviewer that wrapped its enroll in a fresh pty — is refused:

```
✋ ConstraintError: a reviewer clone may not spawn
```

and the refusal hint sends a human in that shell to a fresh terminal.

the block this case answers: a pane that inherited `RHACHET_CLONE_DEPTH=1` refused every guard's
reviewer, so stones stalled (reproduced 2026-10-07 with
`RHACHET_CLONE_DEPTH=1 rhx enroll claude --roles -driver -p '…'`). under #577 that enroll is
admitted, wherever it runs.

## .the sketch

```
given('[case4] a human at a fresh terminal, no depth var in the env')
  when('[t0] they run `rhx enroll claude`')
    then('the clone boots at depth 0, and its guard may enroll a reviewer at depth 1')
  when('[t1] that clone arrives at a guarded stone and its guard runs `rhx enroll claude -p "<review>"` (no tty)')
    then('the reviewer boots at depth 1, a leaf, and returns a verdict')
  when('[t2] the human instead runs `rhx enroll claude --async` at the same tty')
    then('the detached host spawns the clone at depth 0 — the foreground decided it, the host does not re-read')
given('[case4b] no tty (stdin is a pipe — a brain's tool shell), env RHACHET_CLONE_DEPTH=1')
  when('[t0] it runs `rhx enroll claude`')
    then('the clone boots at depth 2 — a worker may spawn (#577)')
given('[case4c] a tty whose env carries RHACHET_CLONE_DEPTH=1 (a pty a work clone opened)')
  when('[t0] it runs `rhx enroll claude`')
    then('the clone boots at depth 2 — it stays below the clone that opened the pty')
given('[case4d] a tty whose env carries RHACHET_CLONE_LEAF=1 (a pty a reviewer opened)')
  when('[t0] it runs `rhx enroll claude`')
    then('exit 2, "a reviewer clone may not spawn"; the hint names a fresh terminal')
```

proof: `blackbox/cli/enroll.reach.acceptance.test.ts` "an enroll on a fresh pty a clone opened"
[case1]–[case2] and "an `--async` enroll at a terminal" [case1]–[case2] ·
`blackbox/cli/enroll.acceptance.test.ts` "rhx enroll reviewer leaf" [case2].

impl note: `asCloneSpawnDepth({ env, isTty, door: 'enroll' })` returns 0 when `isTty` and the env
holds no parseable depth var; else the var + 1. `invokeEnroll` passes `process.stdin.isTTY`. for
`--async`, the foreground computes the depth and hands it to `genCloneEnrollDetached` as
`RHACHET_CLONE_DEPTH_MINTED`, so the host, which has no tty, replays the depth the foreground
decided (F6), then drops the key before it spawns.

# case=5 — a human at a plain terminal always spawns a top-level clone

**cells:** tty-clean × enroll.watch → spawned @ 0 · tty-clean × repl → brain @ 1
**feel × care:** 😊 · 🔴 critipath — the regression guard

## .the narrative

a human opens a plain terminal (no depth var) and runs `rhx enroll claude`. the clone boots at
depth 0, exactly as today. it may run `rhx review`, enroll peers, and so on — one level. at a
terminal that inherited a clone's env, the tty read opens it the same way (case=4).

the human may also run `rhx review` straight from that terminal. the review runs; its brain is a
spawn, not a top-level clone, so it carries depth 1 and may not spawn again (S1, Q8).

## .the sketch

```
given('[case5] a human at a plain terminal')
  when('[t0] the human runs `rhx enroll claude`')
    then('the clone boots at depth 0: it reads `RHACHET_CLONE_DEPTH=0`, and its own guard may enroll a reviewer')
  when('[t1] the human runs `rhx review` from that terminal')
    then('the review runs to its verdict — no refusal')
    then('the review brain carries depth 1 — a nested `rhx enroll` inside it is refused')
  when('[t2] the depth-0 clone from [t0] runs `rhx review`')
    then('the review runs to its verdict — a top-level clone keeps its one level')
```

impl note: `asCloneSpawnDepth` returns 0 for an enroll with a tty on stdin; the repl door reads
the caller as depth 0 and mints 1, which the seam allows.

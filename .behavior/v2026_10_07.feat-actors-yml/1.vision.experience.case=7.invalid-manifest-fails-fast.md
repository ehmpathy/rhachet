# case=7 — an invalid manifest fails fast, before any write

sharp · critipath · see `1.vision.experience.case=_.md` row 7

## .narrative

a maintainer types `@ehmpathy/buidler`. or adds `+bhrowser/playwrite`. or writes two actors that
extend each other. or mixes a bare role with a delta. each is caught before a single symlink is
touched, by one validator that every reader shares (prepare, enroll, clone), and each error names
the fix.

## .the sketch — `[tn]`

```
given('[case7] an actors.yml with a defect', () => {
  when('[t0] a base names no published actor', () => {
    then('exit 2; ConstraintError names the ref and lists the actors that package publishes')
  })
  when('[t1] a role names no role in any installed package', () => {
    then('exit 2; names the role and the nearest match')
  })
  when('[t2] a ref names a package that is not installed', () => {
    then('exit 2; names the package to add')
  })
  when('[t3] two actors extend each other', () => {
    then('exit 2; names the cycle: @builder → @base → @builder')
  })
  when('[t4] one actor mixes bare roles and +/- deltas (an @base first, then deltas, is fine)', () => {
    then('exit 2; the same rule getRoleDeltas already enforces for --roles')
  })
  when('[t5] an unknown key', () => {
    then('exit 2; names the key and the allowed keys')
  })
  then('in every case, .agent/ is byte-identical to before the run')
})
```

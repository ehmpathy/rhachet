# case=4 — a bare enroll honors the repo actor

happy · critipath · see `1.vision.experience.case=_.md` row 4

## .narrative

a repo declares its repo actor, a `builder` for day work, beside a second actor (`scholar`,
reached by slug in case=8):

```yaml
# .agent/actors.yml
ambient: '@builder'

actor:
  - slug: builder
    roles: ['@ehmpathy/builder']        # brain propagates up from @ehmpathy/builder (F11)
  - slug: scholar
    brain: anthropic/claude/code
    roles: [bhrain/librarian, bhrain/learner, ehmpathy/architect]
```

a human types `rhx enroll`. on main that reaches the repo actor `actor.via.repo=ambient`, whose
ambient roles are **every** linked role — librarian and learner included (`term=ambient`). now
`ambient: '@builder'` makes `@builder` the repo actor: the bare enroll boots `@builder`'s roles on
`@builder`'s brain, in `actor.via.slug=builder`. `<repo>/.claude` points at that same brain dir,
so a bare `claude` and `rhx clone @builder` are one actor, not twins (F12).

the inline form is unchanged for a one-off: `rhx enroll claude --roles mechanic,learner` spells
out a composition with no name and lands in a hash dir, as main ships it. a delta
(`rhx enroll claude -driver`) re-derives over the ambient roles — now `@builder`'s roles.

## .the sketch — `[tn]`

```
given('[case4] actors.yml with ambient: @builder and a second actor @scholar', () => {
  when('[t0] rhx enroll (no actor, no brain)', () => {
    then('the clone is enrolled as @builder, on the brain it inherits from @ehmpathy/builder and its roles, not the union')
    then('it lands in actor.via.slug=builder (F7, F12)')
    then('<repo>/.claude links to actor.via.slug=builder/brain/.claude; no actor.via.repo=ambient dir is written')
  })
  when('[t1] rhx enroll @builder -driver', () => {
    then('the delta applies on top of builder; the clone lands in the derived actor builder._.delta=<hash>')
  })
  when('[t2] rhx enroll claude --roles mechanic', () => {
    then('the inline form: today\'s behavior, hash-identified')
  })
  when('[t2b] rhx enroll claude -driver', () => {
    then('hash-identified over the ambient roles, which are @builder\'s roles; re-derived at init')
  })
  when('[t3] the file omits ambient: (one actor or many)', () => {
    then('the manifest is invalid: every reader fails fast and names the ambient: key — it never picks one, not even a sole actor')
  })
})
```

# case=1 — adopt a published roleset by name

happy · critipath · see `1.vision.experience.case=_.md` row 1

## .narrative

a maintainer of `rhachet-roles-bhrain` opens `package.json` and finds a shell string of roles
that three peer repos also carry, each a little different. she deletes the `--roles` list,
and writes:

```yaml
# .agent/actors.yml
ambient: '@builder'

actor:
  - slug: builder                 # brain propagates up from @ehmpathy/builder (F11)
    roles:
      - '@ehmpathy/builder'     # a published actor — its roleset, by name
```

the prepare line keeps its build and loses only the `--roles …` list. `pnpm prepare` reads the manifest,
expands `@ehmpathy/builder` to the roles ehmpathy declared, links them, and prints what it did.
she never typed `mechanic` or `behaver` — ehmpathy owns that list.

## .the sketch — `[tn]`

```
given('[case1] a repo with actors.yml whose builder is @ehmpathy/builder', () => {
  when('[t0] pnpm prepare → rhachet init --hooks', () => {
    then('the manifest is read; no --roles flag is needed')
    then('@ehmpathy/builder expands to the roles ehmpathy published in rhachet.repo.yml')
    then('each expanded role is linked under .agent/repo=*/role=*')
    then('stdout names the actor, its base, and each role it linked')
  })
  when('[t1] pnpm prepare again', () => {
    then('naught changes — idempotent; stdout says in sync')
  })
})
```

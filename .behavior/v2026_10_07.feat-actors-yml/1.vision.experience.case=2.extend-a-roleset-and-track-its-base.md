# case=2 — extend a published roleset, and track its base

happy · critipath · the densest cell · see `1.vision.experience.case=_.md` row 2

## .narrative

ahbode's repo carries ehmpathy's builder list plus `playwright`, copied by hand
(`ahbode/rhachet-briefs-ahbode` `package.json:39` vs `ehmpathy/rhachet-roles-ehmpathy`
`package.json:62`). with actors.yml it says what it means:

```yaml
# .agent/actors.yml
ambient: '@builder'

actor:
  - slug: builder                 # brain propagates up from @ehmpathy/builder (F11)
    roles:
      - '@ehmpathy/builder'     # the base, by reference — never a copy
      - +bhrowser/playwright    # ahbode's addition
```

a month later ehmpathy adds `learner` to its builder and ships a minor. ahbode bumps
`rhachet-roles-ehmpathy` in its routine upgrade, runs `pnpm prepare`, and its builder gains
`learner` — no one at ahbode edited a list. stdout says so, so it is never a surprise.

the same holds one level up: a role package may publish its own actor as an extension of another
package's — `@ahbode/builder = @ehmpathy/builder +bhrowser/playwright` — and every consumer of
`@ahbode/builder` inherits both changes.

## .the sketch — `[tn]`

```
given('[case2] ahbode builder = @ehmpathy/builder +bhrowser/playwright', () => {
  when('[t0] pnpm prepare at rhachet-roles-ehmpathy@1.39', () => {
    then('builder = the roles of @ehmpathy/builder ∪ { bhrowser/playwright }')
  })
  when('[t1] rhachet-roles-ehmpathy upgrades to a version whose builder adds learner', () => {
    then('pnpm prepare links learner with no edit to actors.yml')
    then('stdout lists learner as linked, and names @ehmpathy/builder as its source (A5)')
  })
  when('[t2] the extension says -dreamer and the base already lacks dreamer', () => {
    then('a warn, not a failure — the intent already holds')
  })
  when('[t3] after the upgrade, a human runs a bare rhx enroll', () => {
    then('the new clone boots with learner — the base growth reached the clone')
    then('a live @builder clone reads learner at its next read; it shares actor.via.slug=builder (F7)')
  })
})
```

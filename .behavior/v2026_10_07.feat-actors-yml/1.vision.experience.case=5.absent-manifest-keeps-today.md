# case=5 — an absent manifest keeps today's behavior

happy · critipath · see `1.vision.experience.case=_.md` row 5

## .narrative

every repo that runs `rhachet init --hooks --roles mechanic behaver …` today has no
`actors.yml`. they upgrade rhachet, run `pnpm prepare`, and see the same result as before — byte
for byte on disk. adoption is one repo at a time, whenever its maintainer chooses: no flag day.

the one change they may see: a single dim hint line that `actors.yml` exists, shown only when
`--roles` is used and no manifest is present.

## .the sketch — `[tn]`

```
given('[case5] a repo with no .agent/actors.yml', () => {
  when('[t0] rhachet init --hooks --roles mechanic behaver', () => {
    then('the same roles are linked as before this change')
    then('the same hooks and boot are rendered as before this change')
    then('one dim hint line names .agent/actors.yml, the only output that differs from today')
  })
  when('[t1] rhx enroll claude', () => {
    then('the clone boots with the ambient roles, in actor.via.repo=ambient, as main ships it')
  })
})
```

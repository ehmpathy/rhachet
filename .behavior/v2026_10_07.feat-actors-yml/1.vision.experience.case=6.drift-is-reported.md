# case=6 — drift between declared and installed is reported

sharp · critipath · see `1.vision.experience.case=_.md` row 6

## .narrative

a human, mid-experiment, linked `ghlitch/observer` into `.agent/` by hand. another removed the
`dreamer` link to quiet a noisy hook. neither touched `actors.yml`.

today, `pnpm prepare` silently re-links dreamer and silently keeps observer — `init --roles`
links what is named and never unlinks what is not (`initRolesFromPackages.ts:35-82`), and no
step compares the two sets. with a manifest, prepare **computes the diff first**, then acts by a
stated rule, and says what it did:

- **short** (declared, not linked) → linked, and named as restored
- **extra** (linked, not declared by any actor) → kept, and named as undeclared, with both fixes

no edit is silently kept; no edit is silently reverted.

## .the sketch — `[tn]`

```
given('[case6] actors.yml declares builder; disk has +observer and -dreamer vs declared', () => {
  when('[t0] pnpm prepare', () => {
    then('stdout lists bhuild/dreamer as short → restored')
    then('stdout lists ghlitch/observer as extra → kept, undeclared, with both fixes named')
    then('exit 0 — drift is a report, not a failure')
  })
  when('[t1] rhachet init --mode plan  (sketch — a could, not a must; see the contract row "drift")', () => {
    then('the same diff is printed and naught is written')
    then('exit 2 when any drift exists, so a hook or ci can gate on it')
  })
})
```

```
🎭 actors
   ├─ @builder (repo actor)
   │  └─ …
   └─ drift
      ├─ bhuild/dreamer     ↺ short → restored
      └─ ghlitch/observer   ⚠ extra → kept, undeclared
         ├─ to keep it: add +ghlitch/observer to an actor in .agent/actors.yml
         └─ to drop it: rm .agent/repo=ghlitch/role=observer
```

the drop fix is the hand link undone by hand, never `rhachet init --roles -ghlitch/observer`: a
manifest refuses `--roles` beside it (inventory row 19), so a fix that names the flag would itself
be refused.

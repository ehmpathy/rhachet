# S1 — actors.yml lives at the `.agent/` root

## .said

> yep, .agent/actors.yml, just like .agent/keyrack.yml ; cause actors can be defined for a repo even if theres no roles in that repo

## .settled

the manifest path is `.agent/actors.yml`, a peer of `.agent/keyrack.yml`. an actor is a property of
the repo, not of any role the repo hosts: a repo can declare actors with no native roles at all, so
the file cannot sit under `.agent/repo=.this/`.

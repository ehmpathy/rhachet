# case=8 — any declared actor is reached by slug, on its own brain

happy · critipath · see `1.vision.experience.case=_.md` row 9

## .narrative

the repo from case=4 declares a second actor, a `scholar` that only reads and writes briefs, with
its own brain:

```yaml
# .agent/actors.yml
ambient: '@builder'

actor:
  - slug: builder
    roles: ['@ehmpathy/builder']        # brain propagates up from @ehmpathy/builder (F11)
  - slug: scholar
    brain: anthropic/claude/code
    roles: [bhrain/librarian, bhrain/learner, ehmpathy/architect]
```

the scholar is not the repo actor, so a bare `rhx enroll` never reaches it. the human types
`rhx clone @scholar` — or `rhx enroll @scholar`, its alias. no brain is typed and no `--roles`:
the actor names both. the clone lands in `actor.via.slug=scholar`, so a second clone of the
scholar shares its config, and an edit to the scholar's roles reaches both.

a human who wants the scholar on another brain for one job types `rhx clone @scholar --brain <brain>`
(the flag, since a positional token after `@<slug>` passes through to the brain-cli as a prompt —
F20); one who
wants it with the mechanic role types `rhx clone @scholar +mechanic`. either override spawns a
delta clone: a derived actor `scholar._.delta=<hash>`, tethered to the scholar, so an edit to the
scholar still reaches it. a plain role list (`@scholar --roles mechanic`) would replace the
scholar wholesale — that is the inline form — so it is refused and names `rhx enroll`.

## .the sketch — `[tn]`

```
given('[case8] actors.yml with ambient: @builder and a second actor @scholar on its own brain', () => {
  when('[t0] rhx clone @scholar', () => {
    then('the clone is enrolled in scholar\'s roles on anthropic/claude/code')
    then('it lands in actor.via.slug=scholar (F7)')
  })
  when('[t1] rhx enroll @scholar', () => {
    then('the same clone shape as [t0]: enroll @<slug> aliases clone @<slug> (F8)')
  })
  when('[t2] rhx enroll @scholar --brain <brain>', () => {
    then('the clone runs scholar\'s roles on that brain; it lands in the delta clone scholar._.delta=<hash> (F10, F20)')
    then('a later edit to scholar\'s roles reaches it: the delta rides on a live base')
  })
  when('[t2b] rhx clone @scholar --roles mechanic (a plain list)', () => {
    then('refused before any spawn: a plain list replaces the actor; names the inline form')
  })
  when('[t3] rhx clone @scholar +mechanic', () => {
    then('the delta applies on top of scholar; the clone lands in scholar._.delta=<hash>')
  })
  when('[t4] the file declares two actors and no ambient:', () => {
    then('rhx clone @scholar fails fast too: a manifest with no ambient: is invalid in every reader, and the error names the key')
  })
})
```

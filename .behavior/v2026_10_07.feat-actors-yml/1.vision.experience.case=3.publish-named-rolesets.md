# case=3 — a role package publishes named actors

happy · critipath · see `1.vision.experience.case=_.md` row 3

## .narrative

the ehmpathy maintainers decide what a "builder" is — once. they declare it beside their roles,
in the same shape a consumer writes, and `rhachet repo introspect` (already run in their build,
`build:complete:repo`) emits it into the published `rhachet.repo.yml`, beside `roles:`.

```yaml
# rhachet-roles-ehmpathy — the declared source (the consumer shape; no ambient:)
actor:
  - slug: builder
    brain: anthropic/claude/code
    roles: [mechanic, architect, ergonomist, bhuild/behaver, bhrain/driver, bhrain/reviewer]
  - slug: scholar
    brain: anthropic/claude/code
    roles: [architect, bhrain/librarian, bhrain/learner]
```

```yaml
# rhachet.repo.yml — what introspect emits (published in the tarball)
slug: ehmpathy
roles: [ … as today … ]
actors:
  - slug: builder
    brain: anthropic/claude/code
    roles: [ehmpathy/mechanic, ehmpathy/architect, ehmpathy/ergonomist, bhuild/behaver, …]
```

a bare slug means *this* package's role; a role from another package is written
`repo/role`. the published actor is a **reference to roles**, never a copy of their briefs or
skills. an older rhachet that reads this `rhachet.repo.yml` strips the unknown `actors:` key
(zod `z.object`, `getRoleRegistryManifest.ts:15-81`), so a publish never breaks an old consumer.

## .the sketch — `[tn]`

```
given('[case3] a role package declares builder and scholar', () => {
  when('[t0] rhachet repo introspect', () => {
    then('rhachet.repo.yml gains an actors: list with builder and scholar')
    then('bare role slugs are qualified to this package; foreign refs stay as written')
  })
  when('[t1] a declared actor names a role this package does not have', () => {
    then('introspect fails fast and names the unknown role — it never publishes a broken set')
  })
  when('[t2] an older rhachet reads the new rhachet.repo.yml', () => {
    then('roles load as before; actors: is ignored')
  })
})
```

## .the rules each row applies

- **top name, source a file** → our arrow, whatever held the name (a file or another arrow is swapped
  by one `rename(2)`; a dir is removed first). one answer, as for the grove (fulcrum F2)
- **top name, no source file** (absent or not-a-file) → only **our** arrow is removed. a foreign
  arrow, a real file, or a dir is not rhachet's, so it stays
- **home name** → `.home/` is rhachet's own namespace: the layout owns every name in it. a hand or a
  stray write may leave an entry there, and the layout reclaims it. source a file → our arrow; no
  source file → whatever holds the name is removed, as the grove's home link is (`delEntryIfPresent`)
- `unreadable` is decided as `absent` for the writes, with a distinct `UNLINKED` reason and one
  enroll notice (the notice row)
- `not-a-file` is decided as `absent`: an arrow to a dir would make claude log
  `Couldn't read keybindings.json` and drop every user key. a bare claude on that box fails the
  same read, so the clone matches it

  its home-name twin) · 44 itemized · 0 forbidden · 0 impossible

- densest boundary: `file × none` (top) with `file × none` (home) — one walk that crosses enroll, the
  layout findsert, git, the clone's boot, and the pane the human reads; the one walk that changes
  what the human sees
- no sharp critipath: the wish fixes a wrong hint, and its one failure mode (no source) is a silent
  skip by mandate. every sharp row is a rare alterpath, and each fails safe: the clone falls back to
  claude's defaults, never to a broken key

## .rejection invariants

- an arrow never aims at a source that is not a file
- the top name never names this box. only the home name does
  (`rule.forbid.machine-names-in-committed-config`)
- with no source file, the findsert never removes an entry at the top name that is not its own arrow
- the findsert never writes into the human's `~/.claude/keybindings.json`

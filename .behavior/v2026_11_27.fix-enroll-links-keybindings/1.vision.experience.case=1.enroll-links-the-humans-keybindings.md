# 1.vision.experience.case=1.enroll-links-the-humans-keybindings

> critipath · happy · cell `file × none`

## .narrative

kai rebound submit in `~/.claude/keybindings.json` months ago. a bare `claude` hints `ctrl+enter
to send`. kai runs `rhx enroll claude --roles mechanic` in a fresh repo. the enroll stands up the
actor's brain dir and, beside the settings arrows, lays two more:

```
<brainDir>/keybindings.json             -> .home/.claude/keybindings.json
<brainDir>/.home/.claude/keybindings.json -> /home/kai/.claude/keybindings.json
```

the clone boots with `CLAUDE_CONFIG_DIR=<brainDir>`, reads `keybindings.json`, follows both arrows
to kai's file, and hints `ctrl+enter to send` — the same hint as the bare claude. no new stdout:
the link is a precondition of the spawn, like the settings arrows, and success says naught.

`git status` in the repo stays clean: the brain dir `.gitignore` is an allowlist, and neither name
is on it.

# case=4 — a brain dir that points out of the repo is left alone

**feel × care** = sharp × critipath · cell: g.writable × b.outside × a.enrolled × f.none × k.solo × c.init — the demo of the 135-cell forbidden slice (`case=_` slice 1); [t1] walks a.repo-current

## .narrative

sam keeps claude config in a dotfiles repo, and once symlinked an actor's `brain/.claude` dir to
`~/dotfiles/claude`. init now meets a write whose real target sits outside the repo. it skips that
write and prints:

```
⚠️ skipped a write outside the repo
   ├─ path = .agent/.actors/actor.via.hash=7dcf1989/brain/.claude
   ├─ lands at = /home/sam/dotfiles/claude
   └─ hint = point that dir back inside the repo, then rerun `rhx init --hooks`
```

init exits 0. sam's dotfiles are untouched. the warn tells sam which link to fix.

## .fail-safe

- fast: one realpath before the write; no partial write lands
- loud: a `⚠️` block with the path and where it lands
- teaches: the hint names the link and the rerun

## .bdd sketch

```
given a temp repo with a hash actor whose brain/.claude is a symlink to a dir outside the repo
  and that outside dir holds a settings.of.repo.json with known bytes
  [t0] when sam runs `rhx init --hooks`
    then it exits 0
    then the outside settings.of.repo.json is byte-identical
    then stdout holds `⚠️ skipped a write outside the repo` with the path and `lands at`
    then no file was created or replaced in the outside dir — not settings.of.repo.json, not the
      layout arrows, not boot.md (init's boot render and layout findsert write this dir too)
  [t1] when sam's repo actor dir (`<repo>/.claude`'s target) is the one linked out, and init runs
    then the pre-init layout and the root sync skip it the same way — the guard inside
      `setBrainDirSettingsLayout` and `writeClaudeCodeSettings` refuses the dir
    then the outside dir is untouched
  [t2] when sam's repo pins a legacy adapter (a.repo-legacy) and the same dir is linked out
    then the guard inside `withBrainDirSettingsShield` refuses before the shield swaps the arrow
    then the outside dir is untouched
```

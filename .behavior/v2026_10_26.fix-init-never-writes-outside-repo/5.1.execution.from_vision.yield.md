## .deviations from the vision

- `writeClaudeCodeSettings` sits in the published brain adapter, so it cannot see the repo root.
  it guards its own bound instead (`<to>/.claude` must land inside `<to>`). every init phase
  that reaches it passes a repo-guarded entry first (`setActorSettingsDerived` →
  `setBrainDirSettingsLayout`; the root sync → `withBrainDirSettingsShield`). clean to rework
- a skipped actor whose boot also renders this run, because a clone of it is active, prints the
  skip warn in both phases: each phase names its own skip. clean to fold into one, if wanted
- the wish asks every hook sync error to print with its actor, role and path. an actor's row
  carries all three. a discover row and a root row carry the role and the error class, and no
  path: neither has an actor, and the root's path is the repo actor's dir, which the class
  message names. a known gap, left to the followup (F9)

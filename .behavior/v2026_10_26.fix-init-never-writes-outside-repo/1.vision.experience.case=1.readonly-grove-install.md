## .narrative

kai keeps `~/.claude/settings.json` at 0444. they clone app-storefronts-web, which holds a hash
actor `7dcf1989` enrolled with five roles, and run `pnpm install`. `prepare` runs
`rhachet init --hooks`. the actor row reads `hash=7dcf1989: +3` — three hooks added to the
actor's `settings.of.repo.json` this run (the count is of hooks, not roles; the other roles' hooks
were already there). below it, one note:

```
⚠️ left a read-only file outside the repo untouched
   ├─ path = .agent/.actors/actor.via.hash=7dcf1989/brain/.claude/settings.json
   ├─ lands at = /home/kai/.claude/settings.json (read-only)
   └─ rhachet never writes outside the repo; the actor's hooks live in its settings.of.repo.json
```

the install finishes. kai's home settings file is the same bytes it was, and the note tells them
so. no EACCES ever prints, because no write ever aimed there.

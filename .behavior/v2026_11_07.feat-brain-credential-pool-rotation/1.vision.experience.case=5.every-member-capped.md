# case 5 — every-member-capped · clone · cron · sharp · critipath

**narrative**

a heavy afternoon: alice and bob are both at their 5-hour cap. a new spawn must not draw a capped
account (S2: a capped credential is never chosen while a peer has headroom — and here none has).
it refuses fast and loud, names the soonest reset, and names the lever: a new pool member. the
hourly rotate, when it finds no headroom, moves no clone (a move from one capped account to another
spends a restart for naught) and logs the same reset time.

critipath: a pick that hands out a capped token produces a clone that idles at once and reads as
healthy — the exact failure the wish names.

```
✋ ConstraintError: every member of pool 'default' is capped
   ├─ alice@ahbode.com  5h 100%  resets in 1h
   ├─ bob@ahbode.com    5h 100%  resets in 2h10m
   └─ next headroom in 1h (alice)
      └─ to grow the pool: claude setup-token, then rhx keyrack set … --reach <email>
```

```

```

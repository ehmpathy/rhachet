# 1.vision.experience.case=6.ambiguous-role-name — sharp critipath (fails safe)

## .narrative

the repo links two role packages that each ship a `mechanic`: `ehmpathy/mechanic` and
`acme/mechanic`. both boot, each as its own `repo/role` (case 10). the mod dir is
`.agent/repo=.mods/role=mechanic/` — the dir name alone cannot say which mechanic it mods. that is
why `of:` is required: it names the role as `repo/role`, the same specifier
`rhx roles boot --repo … --role …` already speaks.

an `of:` that is absent, bare (`of: mechanic` where two repos ship it), or names no linked role is
refused with the linked forms listed. the mod never lands on a guessed role.

**why critipath**: a guess here applies one supplier's mod to another supplier's role — a silent,
wrong boot.

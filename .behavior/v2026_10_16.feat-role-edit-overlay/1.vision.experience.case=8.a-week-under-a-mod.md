# 1.vision.experience.case=8.a-week-under-a-mod — sharp critipath, the dense journey

## .narrative

this is the walk a real author takes, where each seam between two single-boundary cases is a place
the contract can cut them.

monday, vlad shadows short-sentences (case 1) while a clone `@:early` is already live. his
colleague's typo'd addition fails the render for every actor that carries the mechanic, and only
those (case 3). tuesday he enrolls `@:experiment`, which boots the mod; `@:early` still runs on the
boot it read at session start. wednesday a reviewer reads the pr diff and the boot notice (case 4).
the next week ehmpathy ships 1.40.0; `rhx upgrade` moves the role and pesters, and each boot's
notice names the drift until the pin moves (case 5).
he folds the upstream caveat in, bumps `of:` to `@1.40.0`, and later promotes and drops the shadow (case 7).

**why critipath**: each case is correct alone; this walk is where they must compose — a live clone
under a new mod, a refusal scoped to one role, a pester after an upgrade, a drop that restores the
published view.

## .bdd `[tn]` timeline

```
given a repo on ehmpathy/mechanic@1.39.5, and a live clone @:early enrolled before any mod

  when [t0] vlad adds a short-sentences shadow and a mod boot.yml with of: ehmpathy/mechanic@1.39.5
    then `rhx init` re-materializes the mechanic's view
     and stdout notes that a live clone keeps the boot it read at session start

  when [t1] a colleague adds briefs/lang.prose/x.md, unheld and unsaid
    then the render of each actor with the mechanic fails, and names the nearest held path
     and an actor without the mechanic renders as usual

  when [t2] the typo is fixed, and vlad enrolls @:experiment
    then @:experiment's boot.md holds the shadow, tagged mod="shadow"
     and @:early's context is unchanged until it is re-enrolled

  when [t3] a reviewer opens the pr
    then the diff shows the mod dir's files and boot.yml; the boot notice counts the mods

  when [t4] `rhx upgrade` lands 1.40.0
    then the upgrade exits 0, names 1.39.5 → 1.40.0, and lists the shadow for review
     and the next boot's mod notice reads `@1.39.5 (installed 1.40.0)`; the session stop is silent

  when [t5] vlad folds the caveat in and sets of: ehmpathy/mechanic@1.40.0
    then the boot notice drops the drift

  when [t6] upstream later ships his change; he deletes the shadow, the mod dir, and runs `rhx init`
    then `rhx roles cost` shows the mechanic with no `[~]` marker, and the boot is as published
```

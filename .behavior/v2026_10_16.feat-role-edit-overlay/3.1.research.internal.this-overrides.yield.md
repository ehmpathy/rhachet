## .gaps

- **a `.this` role dir with no `boot.yml` is not counted.** the census keys on `boot.yml`, the file `getAllLinkedRoleRefs.ts:24-36` itself keys on: a native role with no `boot.yml` is not a native ref today, so it overrides naught and a1 changes naught for it. a brace glob (`{boot.yml,readme.md}`) returned 0 files across every repo — `git.repo.get` does not expand braces — so no wider pass was run
- **default branch = the local `origin/main` ref**, as of each clone's last fetch. a repo whose remote moved since is measured as of its fetch
- **only repos cloned on this host.** a repo of these orgs that is not cloned here is unmeasured. no repo was unreachable among the 141
- **uncommitted work is unmeasured** — nheuron's `learner` is the known case

## .what the blueprint owes

- the F11 test: a fixture with a `.this` role and a same-slug linked package role boots both, each its own section (the rhachet architect shape — disjoint paths)
- the release notes line: rhachet clones gain `ehmpathy/architect` after a1
- an order note for the commander's release review: the nheuron stone 6 move should land before, or with, the a1 release

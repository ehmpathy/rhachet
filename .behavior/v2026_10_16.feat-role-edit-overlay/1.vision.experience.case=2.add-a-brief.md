# 1.vision.experience.case=2.add-a-brief — happy critipath

## .narrative

vlad wants the mechanic to derive a commit scope from the diff. no mechanic brief says so. he writes
a new one in the mod dir, and says it in the mod's `boot.yml`, with the same `say:` key a role's
own `boot.yml` uses:

```yaml
# .agent/repo=.mods/role=mechanic/boot.yml
of: ehmpathy/mechanic@1.39.5

always:
  briefs:
    say:
      - briefs/rule.require.commit-scope-from-diff.md
```

the next clone boots the mechanic with his brief beside the role's own, in the `say` slot he named.

**why critipath**: the wish names an addition as one of the two first moves. without it, a repo can
only rewrite what a role already says, never teach it a rule it lacks.

# 2.1.criteria.blackbox — mod an extant role in place, via `.agent/repo=.mods/role=<role>/`

> experience boundaries only. each usecase traces to a vision case (`1.vision.experience.case=*`);
> every critipath in `1.vision.experience.case=_.md` holds one usecase here, the alterpath (case 7) too.
> **author** = a human or supervisor clone who writes the mod dir · **clone** = an enrolled brain that
> boots the role · **reviewer** = a pr reader · **render** = any command that writes an actor's boot
> (`rhx enroll`, `rhx init`, `rhx upgrade`).

## .trace

| usecase | vision case | care |
|---|---|---|

# usecase.1 = shadow a brief

```
given(a repo links ehmpathy/mechanic, which holds briefs/practices/lang.prose/rule.prefer.short-sentences.md)
  given(the author copies that brief to .agent/repo=.mods/role=mechanic/ at the same path, and changes it)
  given(the mod's boot.yml declares of: ehmpathy/mechanic)
    when(a clone with the mechanic role is enrolled)
      then(its boot renders the mod's content in the original's place)
        sothat(the clone reads the experiment, never the original)
      then(the original's content appears nowhere in the boot)
        sothat(no clone reads two contradictory rules)
      then(the shadow keeps the original's say or ref slot)
      then(the shadow is tagged as a mod shadow)
      then(every other mechanic brief renders as published)
        sothat(upstream content the mod does not touch still arrives)

  given(the role ships a .min peer for that brief, and the mod ships only the .md)
    when(a clone is enrolled)
      then(the boot renders the mod's .md, never the published .min)
        sothat(a shadow can never silently render the original)
      then(the boot notice says the shadow's minification was dropped)

  given(the mod ships both the .md and its own .md.min)
    when(a clone is enrolled)
      then(the boot renders the mod's .md.min)

  given(the mod ships a .md.min with no .md beside it, at a path the role does not hold)
    when(a render runs)
      then(it fails loud with a ConstraintError that names the orphan, as an orphan .min does today)
```

# usecase.2 = add a brief

```
given(a repo links ehmpathy/mechanic)
  given(the author writes briefs/rule.require.commit-scope-from-diff.md in the mod dir, a path the role does not hold)
  given(the mod's boot.yml says that path under always.briefs.say)
    when(a clone with the mechanic role is enrolled)
      then(its boot renders the addition in full, beside the role's own briefs)
        sothat(a repo can extend a role without a release)
      then(the addition is tagged as a mod add)

  given(the mod's boot.yml refs the addition, rather than says it)
    when(a clone is enrolled)
      then(the boot lists the addition as a ref, content not inlined)

  given(the mod's boot.yml says a glob, briefs/local/**/*.md, and three files sit under it)
    when(a clone is enrolled)
      then(all three render as additions)
        sothat(a glob is an explicit rule, by intent)

  given(the mod's boot.yml says a path the role already holds and refs)
    when(a clone is enrolled)
      then(that brief renders as said, since the mod's sections are read first)

  given(the mod's boot.yml refs a path the role says)
    when(a clone is enrolled)
      then(that brief renders as a ref)
```

# usecase.3 = a typo is never an addition

```
given(a mod dir file sits at a path the role does not hold, and no say or ref glob in the mod's boot.yml names it)
  when(a render runs for an actor with that role)
    then(it fails loud with a ConstraintError)
      sothat(a typo never becomes a silent addition)
    then(the error names the file, the nearest path the role holds as a "did you mean", and the say line that would add it)
    then(no boot is written for that actor)

given(the mod's boot.yml holds a not glob that matches no file of the role)
  when(a render runs)
    then(it fails loud with a ConstraintError that names the glob and the nearest held path)
      sothat(a typo never removes naught in silence)

given(the author fixes the path, or adds the say line)
  when(a render runs again)
    then(it succeeds and the boot holds the shadow or the addition)
```

# usecase.4 = see what is modded

```
given(ehmpathy/mechanic@1.39.5 is modded with 2 shadows, 1 add and 2 nots)
  when(a clone is enrolled)
    then(the mechanic section of its boot opens with a notice that names the role, its version, and the counts)
      sothat(the clone knows its role differs from the published one)
    then(the notice lists each not by path, since a not leaves no resource to tag)
    then(each shadow carries a mod shadow tag, each addition a mod add tag)

  when(a human runs rhx roles cost)
    then(the mechanic row is marked [~] modded, with the shadow, add and not counts)
    then(an unmodded role's row carries no mark)
    then(the modded role's token cost is computed over the modded payload)

  when(a reviewer reads the pr that adds the mod)
    then(every mod is a plain file in the diff, and the mod's boot.yml shows every add and not)
      sothat(the review of the diff is the gate)
```

# usecase.5 = upgrade under a mod

```
given(the mod's boot.yml declares of: ehmpathy/mechanic@1.39.5)
  given(the installed mechanic is 1.39.5)
    when(the stop hook sweep runs)
      then(it passes in silence)

  given(the repo upgrades the mechanic to 1.40.0)
    when(rhx upgrade moves the role)
      then(it prints a notice that the modded role moved, and exits 0)
        sothat(a ci upgrade is never blocked by a mod)
    when(the next stop hook sweep runs)
      then(it fails with a ConstraintError: the modded role moved)
      then(the error names the role, the declared version, the installed version, and every shadow, add and not by path)
        sothat(a release is the one moment the author re-reads each mod)
      then(the error names the fix: set of: ehmpathy/mechanic@1.40.0)
      then(the mods still render for every clone)
    when(the author sets of: ehmpathy/mechanic@1.40.0 and the sweep runs)
      then(it passes)

  given(the release removed a path the mod shadows)
    when(the next stop hook sweep runs)
      then(the shadow is refused as a file at an unheld path, as in usecase.3)

  given(the release removed a path the mod nots)
    when(the next stop hook sweep runs)
      then(the not is refused as a glob that matches naught, as in usecase.3)

given(the mod's of: names no version)
  when(the role moves and the sweep runs)
    then(no version pester fires)
    then(the refusals of usecase.3 still apply)

given(the stop hook sweep ran once and naught has changed since)
  when(it runs again)
    then(it answers from its memo, at no new cost)
```

# usecase.6 = name the role a mod is over

```
given(a mod dir with no of: key)
  when(a render runs)
    then(it fails loud with a ConstraintError that names the linked repo/role forms of that slug)

given(of: names a bare slug, mechanic, and two linked repos ship mechanic)
  when(a render runs)
    then(it fails loud, and names both repo/role forms)
      sothat(a mod never lands on the wrong role)

given(of: names a repo/role no package links)
  when(a render runs)
    then(it fails loud, and names the linked roles of that slug)

given(of: ehmpathy/mechanic, while acme/mechanic is also linked)
  when(a clone with both is enrolled)
    then(the mods apply to ehmpathy/mechanic alone)
    then(acme/mechanic boots as published)

given(two same-slug roles are both linked and the author wants to mod both)
  when(the author looks for a way)
    then(there is one mod dir per slug, so only one can be modded in v1)
```

# usecase.7 = promote or drop a mod

```
given(a shadow earned its keep, and upstream released the same content)
  when(the author leaves the shadow in place)
    then(the boot renders the same content as published, still tagged as a shadow)
      sothat(a redundant mod is harmless until dropped)
  when(the author deletes the shadow file)
    then(the next render boots the published brief, untagged)

given(an addition the author no longer wants)
  when(the author deletes its file and its say line)
    then(the next render boots the role without it)

given(every mod of a role is deleted, with its boot.yml)
  when(a render runs)
    then(the role boots exactly as published, with no notice and no mark)
```

# usecase.8 = a week under a mod

```
given(a clone is live, enrolled before the author writes a shadow)
  when(the author writes the shadow)
    then(the live clone keeps the boot it read at session start)
    then(the render the author runs says that live clones keep their prior boot until re-enrolled)
  when(a new clone is enrolled)
    then(it boots the shadow)

given(the author edits the content of an extant shadow)
  when(a clone is enrolled)
    then(it boots the edited content, with no other step)

given(the author adds a new mod file and its say line, and no render has run since)
  when(the next stop hook sweep runs)
    then(it reports that the modded view lags the mod dir, and names the render that fixes it)

given(the author makes a typo mid-week)
  then(usecase.3 holds: the next render or stop refuses it, and no clone boots a guessed mod)

given(the role is upgraded mid-week)
  then(usecase.5 holds: the next stop names every mod to review, and the mods still render)

given(the mod is promoted upstream and released)
  then(usecase.7 holds: the author drops the shadow, and the role returns to published)
```

# usecase.9 = shadow and not a skill

```
given(the mechanic skill skills/git.commit/git.commit.sponsor.sh sources peer files from its own dir)
  given(the author shadows that skill in the mod dir)
    when(a clone runs rhx git.commit.sponsor)
      then(the shadow runs, and finds every peer file it sources)
        sothat(a skill shadow behaves as the original would, but with the change)
      then(rhx reports no ambiguity between the shadow and the original)

  given(the author also shadows a peer file, output.sh)
    when(the skill runs)
      then(it sources the shadowed peer)

given(the mod's boot.yml nots skills/declapract.upgrade.sh)
  when(a clone runs rhx declapract.upgrade)
    then(the skill is not found, as for any absent skill)
  when(a human runs rhx list)
    then(the skill is not listed)

given(the mod's boot.yml nots a skill that one of the role's own hooks invokes)
  when(a render runs)
    then(it fails loud with a ConstraintError that names the hook and the skill)
    then(the error names the fix: shadow the skill rather than not it)
      sothat(a hook never fails at a later event, far from the mod that broke it)

given(the modded view is stale: a mod file was added, removed or renamed and no render has run)
  when(a clone boots or runs a skill of that role)
    then(the stale view is caught loud at boot or at the next render, never booted in silence)
      sothat(no clone boots the un-modded role, or a skill shadow without its peers, unaware)
```

# usecase.10 = two repos ship one slug

```
given(acme/mechanic and ehmpathy/mechanic are both linked)
  when(a clone is enrolled with --roles mechanic)
    then(its boot holds both, each as its own repo/role section with its own tags)
      sothat(no role is dropped because another repo shipped its slug)
    then(each role's hooks are its own)
  when(a clone is enrolled with --roles ehmpathy/mechanic)
    then(its boot holds ehmpathy/mechanic alone)
  when(an extant actor that was enrolled with --roles mechanic is enrolled again)
    then(it keeps the same actor dir)
      sothat(no extant identity moves)
  when(a human runs rhx roles boot --role mechanic)
    then(it refuses the bare slug as ambiguous, and names both repo/role forms, as today)
  when(a human runs rhx roles cost)
    then(both roles appear, one row each)

given(this repo has .agent/repo=.this/role=mechanic, and ehmpathy/mechanic is linked)
  when(a clone is enrolled with the mechanic role)
    then(both boot, the .this role beside the package role, never in its place)
    then(the release notes name this change, and the repair: move the divergence into repo=.mods, or unlink the package role)
```

# usecase.11 = out-of-scope kinds and keys

```
given(the mod dir holds a readme, an inits/ file, or a keyrack.yml)
  when(a render runs)
    then(it fails loud with a ConstraintError that names the file and why its kind is out of scope)
    then(the error names the fix: a .this role, or an upstream pr)
      sothat(a mod never changes actor config, hooks, or a credential manifest)

given(the mod's boot.yml holds a budget key)
  when(a render runs)
    then(it fails loud, and names the fix: delete the key)
      sothat(the budget stays the role's, checked over the modded payload)

given(a role's own boot.yml holds an of key)
  when(a render runs)
    then(it fails loud: of belongs only in a mod's boot.yml)

given(the repo holds .agent/repo=.mods/role=mechanic)
  when(rhx upgrade, rhx init, rhx list, rhx roles cost, or any scan of linked roles runs)
    then(none treats repo=.mods as a role supplier)
      sothat(no command tries to install rhachet-roles-.mods, or lists a mod as a role)
```

# usecase.12 = a refusal is scoped to its actor

```
given(the mechanic mod holds a refused file)
  given(the repo also has actors whose roles do not include the mechanic)
    when(a clone without the mechanic is enrolled)
      then(it enrolls, unaffected)
        sothat(a bad mod never blocks unrelated work)
    when(a clone with the mechanic is enrolled)
      then(the enroll fails with the refusal, and writes no boot)
    when(rhx init or rhx upgrade renders every actor)
      then(every other actor is rendered)
      then(each refused actor is reported by name, with its refusal)
      then(the command exits 2 once the others are rendered)
```

# 1.vision.experience.case=10.two-repos-ship-one-slug — sharp critipath

## .narrative

the repo links `rhachet-roles-ehmpathy` and `rhachet-roles-acme`, and both ship a `mechanic`. today
a clone enrolled with `mechanic` boots `acme/mechanic` alone — acme sorts first — and
`ehmpathy/mechanic` is dropped from its `boot.md` with no word said
(`getAllLinkedRoleRefs.ts:42` → `asRoleRefsFirstSeenPerRole.ts:7-13`). meanwhile
`rhx roles boot --role mechanic` refuses the same name as ambiguous. two answers to one question.

after this wish, roles boot apart: each `repo/role` is its own role. a clone enrolled with
`mechanic` boots both mechanics, each in its own section, each tagged by its repo. vlad can pin one
with `--roles ehmpathy/mechanic`. a mod `of: ehmpathy/mechanic` mods that one, and
`acme/mechanic` boots as published beside it.

a `.this/role=mechanic` with a `boot.yml` is a role of this repo, and it boots apart too — it no
longer replaces `ehmpathy/mechanic` whole. the targeted override is the mod dir (F11).

**why critipath**: a silent drop means a clone runs without a role its human believes it holds.
every rule that role carries is gone, and naught says so.

## .bdd `[tn]` timeline

```
given the repo links ehmpathy/mechanic and acme/mechanic

  when [t0] vlad enrolls a clone with --roles mechanic
    then its boot.md holds two role sections: repo=acme/role=mechanic and repo=ehmpathy/role=mechanic
     and each section's tags carry their own repo path
     and the clone loads the hooks of both, matched by author `repo=X/role=mechanic`

  when [t1] vlad enrolls with --roles ehmpathy/mechanic
    then its boot.md holds only repo=ehmpathy/role=mechanic
     and only ehmpathy's mechanic hooks load

  when [t2] both mechanics ship a skill named git.commit.set, and a clone runs `rhx git.commit.set`
    then run --skill refuses the ambiguity, as today, and names both `--repo` forms

  when [t3] the repo also holds .agent/repo=.this/role=mechanic/boot.yml
    then a clone enrolled with mechanic boots three sections — .this, acme, ehmpathy
     and none replaces another

  when [t4] an actor was enrolled with mechanic before this wish, and a role sync runs
    then its enrollment hash is unchanged — a bare slug hashes as before
     and its boot.md gains the role it used to drop
```

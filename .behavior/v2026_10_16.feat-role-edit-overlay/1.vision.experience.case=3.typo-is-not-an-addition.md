# 1.vision.experience.case=3.typo-is-not-an-addition — sharp critipath (fails safe)

## .narrative

maria means to shadow `briefs/practices/lang.prose/rule.prefer.short-sentences.md`. she types the
path by hand and drops `practices/`. the file lands at a path the mechanic does not hold, and her
`boot.yml` names no such path.

without a rule, that file would boot as a new brief beside the original — two contradictory rules,
and her mod silently doubled rather than applied. so a file at an unheld path that no `say:` /
`ref:` glob names is refused, loud, with the path she meant.

the same guard covers a removal: a `not:` glob that matches no original would otherwise remove
naught, in silence.

**why critipath**: the wish says outright that a typo must not silently turn a shadow into an
addition.

## .bdd `[tn]` timeline

```
given the mechanic holds briefs/practices/lang.prose/rule.prefer.short-sentences.md
  and no briefs/lang.prose/rule.prefer.short-sentences.md

  when [t0] maria writes .agent/repo=.mods/role=mechanic/briefs/lang.prose/rule.prefer.short-sentences.md
   and her mod boot.yml names no such path
    then the next render of an actor with the mechanic fails, exit 2
     and the error names the file, says it is neither a shadow nor an addition,
         and names the nearest held path
     and an actor without the mechanic renders as usual

  when [t1] maria writes `not: [briefs/practices/lang.tones/rule.forbid.buzzword.md]` (one letter short)
    then the render fails the same way, and names the nearest held path

  when [t2] maria writes `say: [briefs/local/**/*.md]` and puts the file under briefs/local/
    then it renders as an addition — a glob is an explicit rule, by intent
```

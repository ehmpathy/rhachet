# 1.vision.experience.case=1.shadow-a-brief — happy critipath

## .narrative

vlad thinks the mechanic's `rule.prefer.short-sentences` cap of ~20 words is too loose for commit
bodies. he wants clones in this repo to try 12, for a week, before he asks ehmpathy to change it.

he copies the published brief to the same path under the mod dir, and writes the mod's `boot.yml`
with the one key a role's `boot.yml` lacks — `of:`, the role and the version he mods against:

```sh
rhx cpsafe .agent/repo=ehmpathy/role=mechanic/briefs/practices/lang.prose/rule.prefer.short-sentences.md \
           .agent/repo=.mods/role=mechanic/briefs/practices/lang.prose/rule.prefer.short-sentences.md
```

```yaml
# .agent/repo=.mods/role=mechanic/boot.yml
of: ehmpathy/mechanic@1.39.5
```

a shadow needs no line in the plan: the path is one the role holds, so the file replaces the
original in the original's slot. he changes `~20` to `~12`, and enrolls a clone. it boots the
mechanic with his brief in place of the published one, tagged as a mod; every other mechanic brief
is the published one.

**why critipath**: this is the wish's core move. if a shadow cannot land, the only fallback is the
full release roundtrip the wish exists to remove.

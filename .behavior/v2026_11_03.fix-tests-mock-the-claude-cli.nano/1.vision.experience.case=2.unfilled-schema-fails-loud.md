# case 2 — a schema the mock was not told to fill fails loud

feel = sharp · care = criti

## .narrative

a contributor adds a skill whose output is `{ verdict }` and calls `act` on a mocked repl that was
only told to fill `{ summary }`. the mock hands `{ summary }` to the caller's schema; zod refuses it
at parse, and the test goes red with the zod path `verdict` named. it never passes on a default.
the cure is plain from the error: give the mock an `output.act` of that shape.

## .timeline

```
given('[case2] a mocked repl told to fill { summary }')
  when('[t0] act is called with a schema that wants { verdict }')
    then('fast: the call rejects at the parse, before any output is returned — no default slips through')
    then('loud: the rejection is thrown to the test, never swallowed into a pass')
    then('teaches the fix: the zod error names the absent key verdict, so the cure is an output.act of that shape')
```

fail-safe: fast (no network), loud (a thrown parse error), teaches the fix (the absent key is named).

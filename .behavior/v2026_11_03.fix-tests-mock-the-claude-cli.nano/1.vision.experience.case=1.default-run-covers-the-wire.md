# case 1 — the default run covers the actor ↔ brain wire

feel = happy · care = criti

## .narrative

a contributor changes `actorAsk`. they run `rhx git.repo.test --what integration --scope actorAsk
--mode apply` with no flag. the suite runs — it is no longer a todo row. the mocked repl records
what it was handed: the tester role's briefs and the prompt `say hello`. it answers `{ answer }`,
and the test reads that answer back off `actorAsk`. no anthropic key is read; the run is a few
seconds.

## .timeline

```
given('[case1] the tester role, and a mocked repl brain that records each call')
  when('[t0] actorAsk is called with a prompt')
    then('the brain is asked once, with the role briefs and the prompt')
    then('the answer the brain returned flows back on result.output')

given('[case1] the tester role, and a mocked repl brain told to act { echoed, reviewed }')
  when('[t1] actorAct is called with the echo.review skill and { content }')
    then('the brain is asked to act once; the prompt names echo.review and the args')
    then("the output, parsed by the skill's schema, flows back")

given('[case1] invokeAct, with two mocked repls under the haiku and codex refs')
  when('[t2] act runs with no --brain')
    then('only the default (haiku ref) records the call')
  when('[t3] act runs with --brain openai/codex')
    then('only the codex ref records the call')

given('[case1] a genActor clone with a mocked repl')
  when('[t4] clone.run is called on a solid skill')
    then('the skill executable answers, and no brain records a call')

given('[case1] a genActor clone whose allowlist puts a mocked atom before a mocked repl')
  when('[t5] clone.ask is called with a prompt')
    then('the atom records the call, handed the prose brief and the prompt')
    then("the atom's answer flows back on result.output")
    then('the repl records no call')
```

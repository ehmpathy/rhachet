# 1.vision — tests mock the claude cli (nano)

## .the outcome world

a contributor runs the integration tier with no `BRAIN_LIVE_SCOPE` flag. the six src suites that
drive an actor through a brain — `actorAsk`, `actorAct`, `invokeAct` (its brain cases),
`genActor.brain.case{Askable,Collocated,Published}` — run, every time, on a mocked repl. they prove
that the role's briefs reach the brain, the prompt names the skill and args, and the brain's output
flows back through `ask`, `act`, and `run`. no anthropic key is read; no credit is spent.

only the smoketests call the api, on haiku: the real-tui `*.realbrain` acceptance suites, the
brain-dir-boot journey, and the sdk door (`replDoorRealSupplier.realnode`).

| | before | after |
|---|---|---|
| default run (cicd, crew box) | the six suites are skipped by the live-brain gate: zero coverage of actor ↔ brain wire | the six suites run on a mocked repl: the wire is covered every run |
| `BRAIN_LIVE_SCOPE=all` | the six suites spend haiku credit to prove a wire a mock proves | unchanged for the smoketests; the six no longer reach for a real brain |
| a credit lapse | ~6 sdk suites red with no named cause | only the smoketests can redden |

aha: the gate kept the bill down by test absence. the mock keeps it down with the test present.

## .mental model

"a stunt double for claude": the scene (actor, role, skill) is shot for real; only the brain is a
double, and the double notes what it was handed.

## .evaluation

- pros: coverage restored on every run; no key, no cost; one shared mock (`genMockedBrainRepl`)
- cons: a mock cannot prove the anthropic supplier's own behavior — that stays the sdk door
  smoketest's job
- edge: a suite that asks for a schema the mock was not told how to fill fails loud at parse, never
  passes on a default

# case 3 — the smoketests reach real haiku, and refuse loud with no key

feel = happy (the walk) + sharp (the absent key) · care = criti

## .narrative

before a release, a human wants proof that rhachet still drives a real claude. they unlock the test
keyrack and run the acceptance tier with `BRAIN_LIVE_SCOPE=all`. the gated smoketests — the
brain-dir-boot journey, the sdk door (`replDoorRealSupplier.realnode`), the real-tui
`*.realbrain` suites — spawn the real claude cli on haiku and pass. these are now the only suites
that spend credit.

had they forgotten the unlock, the real-tui suites stop at once: `getRealClaudeOrThrow`
(`blackbox/.test/infra/enrollCloneHarness.ts:361`) throws a `ConstraintError` that names the cure:
a claude login, `ANTHROPIC_API_KEY`, or in ci `rhx keyrack unlock --owner ehmpath --env test`. no suite passes on an absent key, and no
mock stands in.

this fix does not change these suites; the case pins the boundary the six mocked suites sit
beside, so the line "only the smoketests call the api" has a demo on the far side too.

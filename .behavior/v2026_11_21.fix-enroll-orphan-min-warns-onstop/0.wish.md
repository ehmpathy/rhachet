# wish: an orphan .md.min never refuses rhx enroll

`rhx enroll claude` refused a clone birth on two orphan `.md.min` briefs (a `.md.min` with no `.md` source beside it). a clone that cannot be born cannot repair the defect that refused it.

## .done means

- an orphan `.md.min` never refuses `rhx enroll`; it warns at onStop, the way the boot budget check does, so a clone always starts and can repair it
- the class never recurs: a rule in this repo own briefs states that no boot-time content check (on briefs, skills, or roles) may halt enroll; such a check warns, never blocks a clone birth
- a test goes red when any boot-time content check refuses enroll, and green once each one warns instead; the clamp is shown red without the fix, green with it
- pr green


## the shape of the vision and the pr body

this section rides every dispatch; the sprout adds it to the wish.

- the solution is the body. the vision artifact and the pr body lead with what this work builds and why it works
- each ends with a short `## pushback footnote`, placed last: one line per prior decision this work pushes back on
  - the line names the decision, where it was made (a path, a pr, or a brief), and the stat or read that overturns it
  - e.g. `- <the decision> — <where it was made> — overturned by <the stat or read>`
- no prior decision pushed back on → no footnote at all. never an empty section, never a "none" line
- a pushback with no stat or read behind it is no pushback: keep the prior decision, or go get the read

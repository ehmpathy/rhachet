# case=1 — an owned orphan births the clone, then the stop holds

## .narrative

a human renames `rule.require.foo.md` to `rule.require.bar.md` in `.agent/repo=.this/role=any/briefs/`. the `rule.require.foo.md.min` beside it is left behind. the next day they run `rhx enroll claude`. the clone is born; one 🟡 row names the orphan. the human ignores it and asks the clone for unrelated work. the clone finishes and tries to stop. the sweep holds: `✋ ConstraintError: 1 role content defect`, with the path and two fixes. the clone deletes the orphan and stops again. the stop is silent.

## .timeline

```
given a repo whose `.this/role=any` declares budget.tokens (sweep armed)
  and an orphan `.agent/repo=.this/role=any/briefs/rule.require.foo.md.min`

when [t0] `rhx enroll claude`
  then exit 0; the clone is born
  then boot.md exists and holds no content of the orphan
  then stderr shows `🟡 1 content defect set aside` with the orphan path

when [t1] the clone's session stops
  then `roles cost --all --when hook.onStop` exits 2
  then stderr names `orphan .md.min` + the path, and the fix branch (restore · delete)

when [t2] the clone deletes the orphan and stops again
  then the fingerprint moved, the sweep reruns, exits 0, prints naught
```

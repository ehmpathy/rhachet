# case=6 — mixed defects: one birth, one stop, every fix named once

## .narrative

a repo holds three defects at once: an owned orphan in `role=any`, an unparseable `boot.yml` in `role=user`, and a linked orphan in `repo=ehmpathy/role=mechanic`. `role=any` is also past its budget. the human runs `rhx enroll claude`. the clone is born. the birth row lists all three defects, each with its kind, path and owner. the linked one also lists its levers. the clone works, then stops. the sweep prints two readouts on the one stop. the content readout names the two owned defects; the linked one is absent, since this repo does not own it. the budget readout names `role=any`. the stop holds once, exit 2. the clone fixes the spec and deletes the orphan. the next stop shows only the budget readout. a trim of `role=any` makes the stop silent.

## .timeline

```
given an owned orphan in role=any, an unparseable boot.yml in role=user,
  a linked orphan in repo=ehmpathy/role=mechanic, and role=any over budget (sweep armed)

when [t0] `rhx enroll claude`
  then exit 0; the clone is born
  then the 🟡 row counts 3 content defects, one child each: kind · path · owner
  then role=user renders refs-only; the orphans are absent from boot.md

when [t1] the clone's session stops
  then exit 2, held once
  then the content readout names the 2 owned defects and omits the linked one
  then the budget readout names role=any
  then the ConstraintError metadata carries both `defects` and `specsOver`

when [t2] the clone fixes role=user's spec and deletes the owned orphan, then stops
  then exit 2; only the budget readout prints

when [t3] the clone trims role=any under budget, then stops
  then exit 0; the stop prints naught
```

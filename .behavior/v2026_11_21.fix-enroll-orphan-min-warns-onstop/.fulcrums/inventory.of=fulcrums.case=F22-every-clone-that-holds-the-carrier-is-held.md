# F22 — every clone that holds the carrier is held on an owned defect

- **fork**: hold every clone whose settings carry the sweep, or hold only the first, or the attended ones, so parallel clones do not each race to edit one file
- **taken**: hold every clone that carries the sweep, as the budget hold already does
- **why**: the hold is the repo's signal that an owned file is broken, and every clone whose stop releases on a broken file ships a boot that file degrades. a pick of one clone needs a lock or an election across clones the stop cannot see; the budget hold has run on this shape since it shipped, with no race report. two clones that repair one orphan both reach a clean tree (a delete, or the restored `.md`), so the race converges
- **counter (i005 r10)**: parallel and print-mode clones all race to edit the same file, and a content repair is cheaper to race than a budget trim
- **answer**: a cheap repair is the case where a race costs least: each repair is idempotent on the file, and the first stop that sees a clean tree releases. a leaf clone that should never repair is enrolled `--roles -<carrier>`, and its receipt now says the receipt is its one notice (`isCloneStopSweepArmed`)
- **rework**: clean. a hold election can wrap `invokeRolesCostForHook` later with no change to the readout

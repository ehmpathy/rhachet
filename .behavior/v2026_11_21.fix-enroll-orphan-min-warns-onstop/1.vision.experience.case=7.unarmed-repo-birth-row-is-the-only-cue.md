# case=7 — an unarmed repo: the birth row is the only cue

## .narrative

a consumer repo declares no `.this` budget and no mod, so no stop sweep is armed. its own `.this/role=any` holds an orphan `.md.min`. today `rhx enroll claude` exits 2 there, the sharpest form of the incident. after this work the clone is born. the 🟡 birth row names the orphan and its fix, and it adds one line: no stop will repeat this, because the repo arms no sweep. the human sees the row, or the clone reads its own enroll output and deletes the file. if neither looks, the orphan lingers. it costs naught, since the boot is byte-identical to the boot after its deletion.

## .timeline

```
given a repo with no `.this` budget and no `.agent/repo=.mods` (sweep unarmed)
  and an orphan `.agent/repo=.this/role=any/briefs/rule.foo.md.min`

when [t0] `rhx enroll claude`
  then exit 0; the clone is born
  then the 🟡 row names the orphan, the fix (restore · delete), and a note:
       `no stop sweep is armed in this repo; this row is the one notice`

when [t1] the clone's session stops
  then no rhachet hook fires; the stop is unaffected

when [t2] a human runs `rhx roles cost --all`
  then role=any's row carries a 🟡 mark; exit 0
```

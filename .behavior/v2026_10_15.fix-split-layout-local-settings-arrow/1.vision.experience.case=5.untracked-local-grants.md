# case=5 — an untracked real local file is replaced

sharp × critipath

## .narrative (the human)

an older layout ignored `*.local.json` at the repo root, so my `settings.local.json` was never committed.
`rhx upgrade` replaces it with the arrow, and the report shows a `replaced` row that names it (S2). git has no prior copy, so my
hand grants from that file are gone. the next prompt i meet, a "don't ask again" holds for that session
only — no file keeps it (S4). to make a grant durable i add it to a role's settings, or to my own
`~/.claude/settings.json`; to write it into the tracked `settings.of.repo.json` from the prompt, i launch
with the explicit opt-in `CLAUDE_CONFIG_DIR=<repo>/.claude`.

## .bdd sketch

```
given('[case5] a real, untracked settings.local.json')
  when('[t0] the layout is findserted')
    then('settings.local.json is the arrow')
    then('the effects hold a REPLACED row for settings.local.json')
    then('no copy of the old file remains')
```

## .fail-safe
loud: the REPLACED row names the file, in the effects and in the `rhx init` / `rhx upgrade` stdout. not lossless: an untracked grant does not survive. this is the
cost of one answer (requirement case 7), and it is fulcrum F2.

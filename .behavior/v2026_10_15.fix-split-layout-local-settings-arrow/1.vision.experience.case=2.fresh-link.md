# case=2 — a split-layout repo with no local file gets the arrow

happy × critipath

## .narrative (the human)

my repo is already on the split layout (rhachet 1.49.2). there is no `settings.local.json`. i run
`rhx upgrade`. no file was lost, so the brain dir report says naught of it, and from then on a plain
`claude` loads the repo's allows and hooks. `git status` shows the one new tracked arrow.

(a fresh arrow is silent in stdout; only a lost file earns a row — fulcrum F8.)

## .bdd sketch

```
given('[case2] a brain dir with no settings.local.json')
  when('[t0] the layout is findserted')
    then('settings.local.json is a relative arrow to settings.of.repo.json')
    then('the effects hold one LINKED effect, for settings.local.json')
    then('the report holds no replaced row')
  when('[t1] the layout is findserted again')
    then('there is no effect')
```

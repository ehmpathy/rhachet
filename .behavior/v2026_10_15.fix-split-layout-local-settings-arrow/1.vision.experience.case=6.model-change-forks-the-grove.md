# case=6 — a `/model` change in a clone forks the grove into the actor's brain dir

sharp × critipath · guards criterion 4 of `define.invariant.brain-config-grove-vs-repo`

## .narrative (a human who talks to a clone)

i type `/model sonnet` in my enrolled clone. the switch takes hold for that actor. my other boxes, my
other repos, and a plain `claude` anywhere else still use the model my `~/.claude/settings.json` names:
claude follows `settings.json` one link, to `settings.of.grove.json`, and renames its temp over that
name, so the grove arrow becomes a real file in the actor's brain dir. the home file is never touched.

the next `rhx init` or `rhx enroll` puts the grove arrow back, so the choice does not last. a durable
default goes in `~/.claude/settings.json` (the box) or a role's settings (the repo).

## .bdd sketch

```
given('[case4] a clone enrolled via rhx enroll claude')
  when('[t2] it changes its model via /model')
    then('the change is held in the brain dir: settings.of.grove.json forks')
    then('~/.claude/settings.json is unchanged (4)')
    then('the grove after the switch, locked to a snapshot (4)')
```

`blackbox/cli/brain-config.grove-vs-repo.realbrain.acceptance.test.ts` [case4][t2], on a real claude.

# 1.vision.experience.dimensions

## .actors
- **human** — opens a plain `claude` at the repo root, or runs `rhx upgrade` / `rhx init`
- **clone** — an enrolled brain (`rhx enroll claude …`)

## .dimensions

| dimension | positions |
|---|---|
| D1 — occupant of `settings.local.json` before the findsert | absent · the arrow · a real file (tracked) · a real file (untracked) · another arrow · a dir |
| D2 — which actor dir | repo actor · hash or derived actor |
| D3 — the launch that reads the dir | plain `claude` at the repo root · enrolled clone · enrolled clone with `--setting-sources local` forced through |
| D4 — the grove on this box | present · absent |
| D5 — a session writes its settings | no · "always allow" · `/model` (a settings change) |
| D6 — where a plain `claude` launches | the main checkout's root · a worktree's root · a subdir |
| D7 — the command that lays the layout | `rhx init` · `rhx init --roles` · `rhx upgrade` · `rhx roles init` · `rhx roles link` · `rhx enroll` |
| D8 — the repo's prior layout | fresh (no `.claude`) · split, as 1.49.2 left it · old real `<repo>/.claude` dir |
| D9 — the box's home dir | under `/home/*`, `/Users/*`, `/root` or `/github/home` · elsewhere (`/var/home`, `/srv`) |
| D10 — what a plain session loads beside the settings | home `CLAUDE.md` / `CLAUDE.local.md` · the grove via the `.home` mirror · the rendered `boot.md` |
| D11 — a hand-broken state the layout meets | none · `.home` mirror holds a symlink · `settings.of.repo.json` is a symlink or a dir · `settings.of.repo.json` is broken json · `<repo>/.claude` is a file · `settings.of.repo.json` holds a hand `claudeMdExcludes` entry |

## .the walked product

D1 × D2 × D3 × D4 × D5 = 6 × 2 × 2 × 2 × 2 = 96 cells, × D6 for the plain-claude rows. most collapse:

- **D3 = enrolled clone** collapses D1, D4 and D5's "always allow": a clone spawns with user-only config
  sources plus `--settings`, so it never reads the local layer. one cell covers the clone rows (case=4).
  a human who forces `--setting-sources local` through is refused by the clone settings guard — one row
- **D5 = `/model`** does not collapse: claude follows `settings.json` one link and renames a temp over
  `settings.of.grove.json`, so the change forks into the actor's brain dir and never reaches
  `~/.claude/settings.json` (criterion 4). one row, demoed (case=6)
- **D2 = hash/derived actor** with D3 = plain `claude` is **impossible**: a plain `claude` reaches the
  repo actor's dir alone, via `<repo>/.claude`. a hash actor's dir is never a cwd's `.claude`
- **D4** does not move the local arrow: its target `settings.of.repo.json` is findserted before the
  grove branch. D4 = absent is one itemized row
- **D1** positions differ only at the findsert; after it, every D1 yields the same arrow
- **D6** moves only the plain-claude rows (a clone's `--settings` names a path, never a cwd). in the main
  checkout claude reads `<cwd>/.claude`, so a subdir launch reads the subdir's own `.claude` — the same
  before the split as after, and no layout in the repo actor's dir can reach it. a worktree reads the
  main checkout's arrow as canonical and its own beneath it (read from the cli source, F9)

- **D7** moves only WHO reports the layout. `init`, `init --roles` and `upgrade` lay it before the role
  inits and print that step's own tree at once, so an abort in a role init never hides the migration;
  the boot sync prints a second tree after the inits. `roles init` reports its own, `roles link` reports
  the sync's. `enroll` lays the enrolled actor's dir and names a replaced file on stderr; a clone never
  reads the local layer (D3). so D7 is one row per reporter, not per cell
- **D8** collapses into D1: a fresh repo is D1 = absent, a 1.49.2 split repo is D1 = absent (no local
  arrow), an old real dir moves its `settings.local.json` in first, then meets D1 = a real file
- **D9** moves only the home `CLAUDE.md` exclude: a home under the four roots is excluded portably;
  one elsewhere is not matched (F11)
- **D10** rides on the plain-claude rows; each position is one row
- **D11** is orthogonal to D1–D10: each hand-broken state is met by one guard, the same for every actor
  dir and every reporter. one row per state

what remains to verdict: D1 (6 rows, at the findsert), D2 = hash (1 row), D3 = plain (1 row), D3 = clone
(1 row), D3 = forced local (1 row), D4 = absent (1 row), D5 = "always allow" and `/model` (2 rows), D6 =
worktree and subdir (2 rows), D7 (one row per reporter), D8 = split 1.49.2 (1 row), D9 = elsewhere (1
row), D10 (3 rows), D11 (5 rows) — see `1.vision.experience.case=_.md`.

# 2.1.criteria.blackbox — the brain config: auth, grove, repo

source: seed S4. the human holds two settings files, each the one home of its kind, so the two stay
clearly apart:

- `~/.claude/settings.json` — the machine-global settings (the grove), the human's own
- `settings.of.repo.json` in the repo actor's brain dir — the repo's settings, tracked in git

how a claude session reaches each file is mechanism, and lives in the blueprint and in
`define.invariant.brain-config-grove-vs-repo`, never here.

## usecase.1 = auth pulls from global

```
given('a repo after rhx init, and a claude login on the machine')
  when('a plain claude starts at the repo root')
    then('it is authenticated by the machine-global login')
  when('an enrolled clone starts')
    then('it is authenticated by the machine-global login')
      sothat('one login serves every session, and no repo holds a login of its own')
```

## usecase.2 = machine-global settings reach a session only from the grove

```
given('an allow set only in ~/.claude/settings.json')
  when('a plain claude starts at the repo root')
    then('the allow applies')
  when('an enrolled clone starts')
    then('the allow applies')
  when('the human reads the tracked brain dir')
    then('it names no home path, and reads the same on every box')
      sothat('the human sets a machine-wide preference once, in the one file they already own')
```

## usecase.3 = repo settings are sourced at settings.of.repo.json

```
given('an allow and a boot hook a repo role declares, so they land in settings.of.repo.json')
  when('a plain claude starts at the repo root')
    then('the allow applies')
    then('the hook fires')
  when('an enrolled clone starts')
    then('the allow applies')
    then('the hook fires')
  when('rhx init or rhx upgrade meets a hand-made settings file at a name rhachet owns')
    then('its stdout names the file, and says its content is gone')
  when('rhx init or rhx upgrade runs again')
    then('its stdout reports naught new, and no file changes')
      sothat('every session at the repo root, enrolled or not, works under the repo`s own rules')
```

## usecase.4 = an actor's change to its settings never reaches the machine-global settings

```
given('an enrolled clone')
  when('it changes a user-layer option (/model, /config)')
    then('~/.claude/settings.json is unchanged')
      sothat('one actor cannot rewrite the machine for every repo')
```

## usecase.5 = an actor's "always allow" never reaches the repo's settings

```
given('a plain claude at the repo root, or an enrolled clone')
  when('the human answers "yes, and don`t ask again"')
    then('the grant holds for this session')
    then('~/.claude/settings.json is unchanged')
    then('settings.of.repo.json is unchanged')
    then('the screen names no failed save')
      sothat('a repo change is an explicit opt-in: rare, and never a side effect of a prompt')
given('a claude launched with CLAUDE_CONFIG_DIR=<repo>/.claude — the explicit opt-in')
  when('the human answers "yes, and don`t ask again"')
    then('the grant lands in settings.of.repo.json')
    then('the next plain claude at the repo root still reads the repo`s settings')
      sothat('a human who means to change the repo has one sanctioned door to do so')
```

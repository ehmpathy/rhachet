# case=1 — an old-layout repo upgrades, then a plain claude loads the repo's roles

sharp × critipath · densest

## .narrative (the human)

my repo came from the old layout. its `.claude/settings.local.json` is a real file with a handful of
allows i granted by hand, committed long ago. i run `rhx upgrade`. the brain dir tree shows a `replaced`
row: `.claude/settings.local.json → settings.of.repo.json — a real file was here; rhachet owns this name`
(S2). i check `git status`: the file now shows as a type change, from a file to a symlink, so i see that
my hand grants are gone from it. if i want them, they are one `git show HEAD:…` away, and the mechanic
role already pre-approves the common ones.

i open a plain `claude`. `npm run test:types` runs with no prompt, and the mechanic SessionStart
notice appears. a new command prompts me, and i pick "always allow". it holds for this session; no file
changes (S4). to keep it for the repo, i put it in a role's settings, or launch with
`CLAUDE_CONFIG_DIR=<repo>/.claude` — the explicit opt-in, where the grant lands in `settings.of.repo.json`.

## .bdd sketch

```
given('[case1] a repo actor brain dir with a real, committed settings.local.json')
  when('[t0] rhx upgrade runs')
    then('settings.local.json is an arrow to settings.of.repo.json')
    then('the report holds a REPLACED row for settings.local.json')
    then('settings.of.repo.json holds no key of the old file — no merge')
    then('git shows a type change on settings.local.json')
  when('[t1] a plain claude at the repo root runs a command the repo pre-approves')
    then('it runs with no prompt')
  when('[t2] a plain claude answers "always allow"')
    then('no file changes, and settings.local.json is still the arrow')
```

## .proof

## live proof — open

the done clause names `ahbode.camp.AWS_PROFILE`. on this box (owner `ehmpath`) that key is `PERMANENT_VIA_REPLICA` in `os.direct`, and so is every `AWS_PROFILE` here. no key on this host uses `EPHEMERAL_VIA_AWS_SSO`, so the renew has no subject here. the wish's evidence came from a grove where camp sits behind aws sso.

the shared daemon was not restarted (F6). the proof path is paved and checked here:

```sh
rhx keyrack.private --dir /tmp/krp --repo-key ahbode.camp.AWS_PROFILE -- unlock --owner ehmpath --env camp
rhx keyrack.private --dir /tmp/krp -- status --owner ehmpath    # watch across two expiries (~2h)
rhx keyrack.private --dir /tmp/krp -- daemon prune --owner ehmpath
```

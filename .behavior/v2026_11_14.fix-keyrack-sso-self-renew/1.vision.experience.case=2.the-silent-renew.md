# case=2 · the silent renew

## .narrative

the camp key reads `expires in: 9m`. the renew window opens. the daemon proves the portal session
silently, re-reads the role creds' expiry, and stores the grant again. the consumer never sees a
gap. `status` now reads `expires in: 59m` and `renewed = 1x`.

## .timeline

```
given('[case1] an sso grant in the daemon, portal live, cap ahead')

    then('the grant expiry moves past the old expiry')
    then('the browser login is never invoked')

    then('the key branch shows renewed = 1x')
```

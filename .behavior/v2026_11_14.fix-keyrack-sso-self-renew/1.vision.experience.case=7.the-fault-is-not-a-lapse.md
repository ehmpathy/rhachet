# case=7 · the fault is not a lapse

the seam the wish's bug turns on, from both sides: a blip must not halt the renew, and a stall
must not go quiet.

## .narrative

**a blip.** the tunnel's key enters its renew window. the renew's call to aws fails with a network
timeout. the daemon logs it and does not mark the key; the tunnel notices naught, since the grant
still has 8 minutes. a minute later the next tick renews it. the human, later that hour, sees
`renewed = 3x` and no mark.

**a stall.** on another night, the renew's call fails with an error the silent proof does not
recognize, every minute. the grant expires in the small hours and the tunnel's next reconnect
fails. at the tenth failed tick in a row the daemon stops to retry and marks the key `halted`, with
the last error. (after a late wake the same ten tries apply, so a blip at wake never halts a key.)
at dawn the human runs `keyrack status`:

```
🔐 keyrack status
   ├─ owner: ehmpath
   ├─ daemon: active ✨
   └─ ahbode.camp.AWS_PROFILE
      ├─ env: camp
      ├─ org: ahbode
      ├─ expired
      └─ halted
         ├─ renew failed 10 ticks in a row
         ├─ aws configure export-credentials failed with unexpected error
         └─ cure
            └─ rhx keyrack unlock --owner ehmpath --env camp
```

the cure is the same unlock; if the cause persists, the unlock surfaces it loudly at a terminal,
where a human can act on it.

## .fail-safe

- **a blip never halts the renew** — only the silent proof's `{ valid: false }` marks a lapse; every other error retries next tick.
- **a stall is bounded** — at most one try per tick, and one mark after 10 consecutive failures; past expiry the same 10 tries apply, so a blip at wake is retried, not halted.
- **loud** — the mark names the last error on the key's own branch.
- **teaches the fix** — the cure is a copy-paste command.

## .timeline

```
given('[case1] an sso grant inside its renew window, portal live')
  when('[t0] the renew fails with an unclassified error')
    then('the key is not marked')
    then('keyrack get still returns the profile')
  when('[t1] the next tick renews it')
    then('expiresAt moves out and renewed counts one')
given('[case2] an sso grant whose renew fails on every tick')
  when('[t0] the ticks inside the window fail')
    then('each tick tries once; the key is not marked')
  when('[t1] the tenth consecutive tick fails')
    then('the key is marked halted, with the last error')
    then('no further renew is tried')
  when('[t2] keyrack status runs')
    then('the key branch names halted, the error, and the cure')
given('[case3] an sso grant past its expiry after a sleep')
  when('[t0] the first tick after wake fails with a blip')
    then('the key is not marked')
  when('[t1] the next tick succeeds')
    then('the grant is renewed and keyrack get returns it')
```

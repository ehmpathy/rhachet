# case=4 · the lapse

the sharp critipath. it must fail safe: fast, loud, and it must teach the fix.

## .narrative

the portal session lapsed. at the next renew window the silent proof answers "lapsed" within
seconds. no browser opens, and the daemon never waits. it marks the key lapsed, once, and stops to
retry it. the grant still lives out its last minutes; then it expires as today.

the human runs `keyrack status` and sees the cause and the one command that cures it:

```
🔐 keyrack status
   ├─ owner: ehmpath
   ├─ daemon: active ✨
   └─ ahbode.camp.AWS_PROFILE
      ├─ env: camp
      ├─ org: ahbode
      ├─ expires in: 8m
      └─ lapsed
         ├─ sso session ended, no renew until the next unlock
         └─ cure
            └─ rhx keyrack unlock --owner ehmpath --env camp
```

hours later the grant is long gone, yet the lapse mark keeps the daemon alive (fulcrum F5), so the
key still shows, with its cause:

```
🔐 keyrack status
   ├─ owner: ehmpath
   ├─ daemon: active ✨
   └─ ahbode.camp.AWS_PROFILE
      ├─ env: camp
      ├─ org: ahbode
      ├─ expired
      └─ lapsed
         ├─ sso session ended, no renew until the next unlock
         └─ cure
            └─ rhx keyrack unlock --owner ehmpath --env camp
```

(the extant `env:` / `org:` / `expires in:` leaves keep their form; every new leaf takes the tree
form, per `rule.forbid.colons-in-stdout`.)

## .fail-safe

- **fast** — the silent proof alone; no `aws sso login`, so no browser wait of any length.
- **loud** — `status` names the lapse on the key's own branch, and keeps it named until the human acts.
- **teaches the fix** — the cure is a copy-paste command, built from the key's own owner and env.

## .timeline

```
given('[case1] an sso grant, portal lapsed')
  when('[t0] the grant enters the renew window')
    then('the renew fails within seconds, without the browser login')
    then('the key is marked lapsed')
  when('[t1] the next renew ticks run')
    then('no second renew attempt fires')
  when('[t2] keyrack status runs')
    then('the key branch names the lapse and the cure command')
  when('[t3] the grant expires and the idle window passes')
    then('the daemon stays alive; keyrack get reads the key as locked')
    then('keyrack status still names the lapse, marked expired')
  when('[t4] the human runs the cure, or relocks')
    then('the lapse mark is gone, and the daemon may exit as today once idle')
```

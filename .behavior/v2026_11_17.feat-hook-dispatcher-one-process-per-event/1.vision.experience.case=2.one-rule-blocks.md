# case=2 — one rule blocks

`seat × PreToolUse × {shell, rhx-skill} × one-blocks` · sharp · critipath

## .narrative

a seat writes `ls src/` — unpaved. the mechanic's `pretooluse.check-permissions.sh` refuses it.
today the seat reads:

```
PreToolUse:Bash hook error: [bash .agent/repo=ehmpathy/role=mechanic/inits/claude.hooks/pretooluse.check-permissions.sh]:
✋ ConstraintError: this command is not paved
   ├─ blocked: ls src/
   ...
```

after: the same `✋ ConstraintError` body, byte for byte, exit 2. the only change is the bracket
label — claude now names the dispatcher command, since that is the process it ran. the seat still
learns the rule, the reason, and the paved fix, because every one of those lives in the body.

for an `rhx-skill` rule (bhrain's `route.mutate.guard` on a sealed `.guard` read), the body still
opens with the frame `rhx` prints today — `🪨 run solid skill repo=bhrain/role=driver/skill=route.mutate.guard`
then `└─ ✋ blocked by constraints` (`src/contract/cli/invokeRun.ts:202-212`) — now printed by the
dispatcher from the slugs it resolved at sync time, with no `rhx` boot.

## .[tn] sketch

```
given('a PreToolUse:Bash payload for `ls src/`')
  when('[t0] piped to pretooluse.check-permissions.sh directly (today)')
    then('exit 2, stderr = S_today')
  when('[t1] piped to the dispatcher')
    then('exit 2')
    then('stderr === S_today')          # the bytes a rule writes hold
given('a PreToolUse:Read payload for a sealed .guard on a bound route')
  when('[t0] piped to `rhx route.mutate.guard --mode hook` (today)')
    then('exit 2, stdout = O_today, stderr = S_today')
  when('[t1] piped to the dispatcher')
    then('exit 2, stdout === O_today, stderr === S_today')
    then('zero rhx processes are exec-ed')
given('a Stop payload on a branch whose route has a stone left')
  when('[t0] piped to `rhx route.drive --when hook.onStop` (today)')
    then('exit 2, stderr = D_today — the stone, which keeps the seat at work')
  when('[t1] the Stop event is dispatched, with the two foreign Stop rules beside it')
    then('exit 2, stderr === D_today')
    then('the foreign rules ran, as today')
```

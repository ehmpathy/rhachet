# case=11 — a rule keeps its own process, inside the dispatcher

`roleauthor × shell × {$0, BASH_SOURCE, set -e, trap EXIT, exit, stdin}` · sharp · critipath

## .narrative

a role author wrote `pretooluse.forbid-tmp-writes.sh` as a standalone process: it reads stdin with
`$(cat)`, finds peer libs via `BASH_SOURCE[0]`, sets `-euo pipefail`, and traps EXIT so a crash
fails closed with `💥 MalfunctionError: ${0##*/} crashed …`. the author changes naught.

after the upgrade, the author's rule behaves as it always did. its tests, which call the `.sh` by
path, stay green with no edit. when it refuses, the seat reads the same refusal text. when it
crashes, its own trap still names it by its own file name and still fails closed. the author never
learns a dispatcher exists, which is the point; on a mac with bash 3.2 that holds too, at a little
more cost.

why the author can trust that: the dispatcher runs the rule as a sourced subshell with its own copy
of stdin and `BASH_ARGV0` set to its path, and unsets its own names first, so `$0`,
`BASH_SOURCE[0]`, the trap, and `exit` act per rule. `rhx hooks.dispatch.probe --what idioms` on
bash 5.2.21 shows stdout, stderr, and exit code match between the standalone and the subshell run.

## .[tn] sketch

```
given('a probe rule that echoes $0, BASH_SOURCE[0], stdin, a set -e guard, traps EXIT, exits 2')
  when('[t0] run standalone with a payload')
    then('stdout O, stderr E, exit 2')
  when('[t1] run by the dispatcher with the same payload')
    then('the rule's part of stdout === O; its part of stderr === E; the merged exit is 2')
  when('[t2] the rule crashes on an unbound var under set -u')
    then('its EXIT trap fires and names the rule by its own file name, as alone')
  when('[t3] the rule tests a name the dispatcher uses internally')
    then('it reads unset, as alone')
  when('[t4] the host bash is < 5.0 (macOS /bin/bash is 3.2), so BASH_ARGV0 is absent')
    then('the dispatcher runs each rule as `bash <path>` instead of a sourced subshell')
    then('the rule's bytes and exit code still match its standalone run')
    then('the call is never blocked for the bash version; it only costs one bash exec per rule')
```

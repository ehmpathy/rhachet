# 1.vision.experience.dimensions

> the axes the hook-dispatch experience varies over. each is a small closed set; no value on one
> implies a value on another, save the one latent axis named below.

## .the axes

| # | axis | values | why it is its own axis |
|---|---|---|---|
| A | **actor** | `seat` (a claude brain-cli whose tool call fires the event) · `human` (runs `rhx init` / `rhx upgrade`, reads a refusal) · `roleauthor` (ships a rule in a role package) · `measurer` (reads processes + cpu per call) | each meets a different face: the seat meets the verdict, the human the sync, the author the registry, the measurer the cost |
| B | **event** | `PreToolUse` · `PostToolUse` · `PermissionRequest` · `SessionStart` · `UserPromptSubmit` · `Stop` | each event has its own output contract (exit 2 blocks a tool vs blocks a stop vs stdout lands in context vs a json decision) |
| C | **rule kind** | `rhx-skill` (`rhx <skill> …`; today a full rhx boot) · `rhx-init` (`rhachet run --repo … --role … --init …`; same boot, `💪 init role` frame) · `shell` (`bash <path>.sh`) · `foreign` (any other command, e.g. `rhachet roles cost …`, `node -e …`) | the dispatcher reaches each kind by a different path; only the first three can skip a boot |
| D | **verdict set** (of the rules that fit the call) | `none-fit` · `all-allow` · `one-blocks` · `many-block` · `one-emits` (stdout context or a json decision) · `one-crashes` (exit ∉ {0,2}) · `one-hangs` (past its timeout) | the merge of N verdicts into one is where the dispatcher can drift from today |
| E | **sync state** | `fresh` (settings hold the one dispatcher entry per event) · `stale` (settings still hold one entry per rule, from before) · `mid-sync` (`rhx init` rewrites the actor dir while hooks fire) · `orphan` (an entry names a rule whose role is no longer linked, or whose `.sh` is absent) · `corrupt` (the manifest is present but unreadable: a version this dispatcher does not read, a truncated or overlong row, an unresolved merge conflict; or the per-call files cannot be made) | the shape on disk decides what claude runs, independent of what the rules say |
| F | **load** | `solo` (one seat) · `fleet` (~79 seats on 12 cores) | the cost the wish exists for shows only at fleet; a solo read is the measurement baseline |
| G | **attempt** | `first` · `retry` (the same call again) | a rule may decide by its own memory of prior calls: `check-permissions.sh` blocks a first unpaved call (exit 2) and answers the retry with an `ask` json (exit 0) |

## .the latent axis — does the actor fire events?

the walk surfaced that the actor axis is not orthogonal to B, D, and G. a `seat` is a **session
actor**: its tool calls fire events, so every B × D × G tuple can reach it. `human`, `roleauthor`,
and `measurer` are **sync or study actors**: none fires a hook event by its own act. a human's
`rhx init` runs in a shell claude does not hook; an author ships a file; a measurer replays a
payload by hand. so:

- `{human, roleauthor} × B × D × G` is **impossible** by nature — recorded once, as a block, in the
  inventory, rather than dropped
- `measurer × B × D` is reached only through the payload the measurer replays: one cell per payload,
  not a cross
- the session actor is crossed with every axis, E and F included

## .attempt (G) is absorbed into D, on purpose

the dispatcher holds no state across calls. an attempt changes which rule verdict arises — the same
`check-permissions.sh` yields `one-blocks` on `first` and `one-emits` (json) on `retry` — and the
dispatcher merges whichever arises. so G is walked by the pair `case=2` (first) / `case=8` (retry),
and needs no cell of its own beyond that pair. a dispatcher that held cross-call state would make G
its own axis; this one does not.

## .the product

4 × 6 × 4 × 7 × 5 × 2 × 2 = 13440 tuples. after the latent axis:

- `seat × B × C × D × E × F × G` — walked in the inventory, grouped where one merge rule serves
  every event that shares an output contract; each E and F value crossed with the seat explicitly
- `{human, roleauthor} × B × D × G` — impossible, one recorded block
- `human × E`, `roleauthor × C`, `measurer × E × F` — walked as their own rows

the walked cells and their verdicts live in `1.vision.experience.case=_.md`.

## .the label the seat reads

walk `seat × PreToolUse × many-block`: today claude runs each hook as its own process and shows
each blocker's stderr under its own `[<command>]` label. one dispatcher has one label. the bytes a
rule writes hold; the frame claude draws around them moves. that is fulcrum `F3`.

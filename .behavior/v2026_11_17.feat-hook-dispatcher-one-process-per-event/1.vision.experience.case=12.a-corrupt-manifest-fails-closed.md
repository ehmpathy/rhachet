# case=12 — a corrupt manifest fails closed

`seat × any B × E=corrupt` · sharp · critipath

## .narrative

two branches each re-synced the roles, and the merge left conflict markers in the tracked
`hooks.dispatch.manifest`. the seat's next Bash call starts the dispatcher, which meets a file it
cannot read row by row.

a dispatcher that skipped the rows it could not parse would run no rule, and every gate those rules
held would open at once, silently. so it does the opposite: it runs no rule, and refuses the call
with the fix named.

```
✋ ConstraintError: hook dispatch manifest holds an unresolved merge conflict
   ├─ manifest = .claude/hooks.dispatch.manifest
   └─ fix = take either side, then run `npx rhx init --hooks` to rewrite it from the roles
```

the human takes either side, runs the one command, and the next call decides as before. the same
holds for a manifest written by a newer rhachet (a version this dispatcher does not read), a row cut
short or with fields past v1, a rule matcher that is no valid regex (that rule reads as a crash), and
a TMPDIR the dispatcher cannot write its per-call files into: each refuses or crashes loud, never
allows.

## .[tn] sketch

```
given('a repo whose manifest the dispatcher cannot read')
  when('[t0] the manifest holds an unresolved merge conflict')
    then('no rule runs; exit 2; the refusal names `npx rhx init --hooks`')          // [t21b]
  when('[t1] the manifest declares a version this dispatcher does not read')
    then('no rule runs; exit 2; the refusal names the rhachet this repo installs')  // [t13]
  when('[t2] a row is truncated, or holds more fields than v1')
    then('no rule runs; exit 2; the refusal names the row kind')                    // [t15] [t21]
  when('[t3] a rule matcher is no valid regex')
    then('that rule reads as a crash, named; the others still decide')              // [t11]
  when('[t4] TMPDIR cannot be written, and a rule would block')
    then('exit 2 with the TMPDIR fix; never an allow')                              // [t19]
  when('[t5] a name is planted ahead at the per-call path')
    then('the dispatcher takes a fresh name; the planted target is untouched')      // [t20]
```

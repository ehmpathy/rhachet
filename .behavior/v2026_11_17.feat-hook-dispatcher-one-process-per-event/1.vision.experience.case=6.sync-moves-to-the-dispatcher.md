# case=6 — a sync moves a repo to the dispatcher

`human × {stale, fresh, orphan}` · happy / happy / sharp · critipath / critipath / alterpath
`seat × E=mid-sync` · sharp · critipath — a seat never meets a dispatcher with no manifest
`seat × E=orphan` · sharp · alterpath

## .narrative

**stale.** a human runs `rhx upgrade` (or `rhx init`) in a repo whose actor dirs hold today's shape:
ten PreToolUse entries, one per rule. the hook sync rewrites every actor's `settings.of.repo.json`:
the entries rhachet authored go, one entry per event takes their place, and the actor's rule
manifest is written beside it. if both shapes ever lived side by side, every rule would run twice —
so the replace is one write, and a test pins "no rule command appears outside the dispatcher".

```
🐙 attached!

✨ hooks
   ├─ PreToolUse        11 rules → 1 dispatcher
   ├─ PermissionRequest  1 rule  → 1 dispatcher
   ├─ SessionStart       4 rules → 1 dispatcher
   └─ Stop               1 rule  → 1 dispatcher
```

**orphan.** a role is unlinked by hand and its `.sh` vanishes before the next sync. the dispatcher
reaches that rule, finds no file, and reports it as that rule's crash (`case=4`); every other rule
still decides. the next `rhx init` rewrites the manifest without it.

**mid-sync, on a busy box.** ~79 seats fire hooks while `rhx upgrade` rewrites the actor dirs. a
seat must never meet a dispatcher with no manifest, or half of one. so the sync writes the manifest
first, by temp file and rename, and only then the settings that name the dispatcher. a dispatcher
that still finds no readable manifest fails **closed** on a blockable event — exit 2,
`💥 MalfunctionError: hook manifest absent at <path>; run rhx init` — the same stance the mechanic's
rules take on their own crash, so a sync race can never open every gate at once.

## .[tn] sketch

```
given('an actor dir whose settings.of.repo.json holds per-rule hook entries')
  when('[t0] rhx init runs')
    then('each event that had rules now has exactly one entry: the dispatcher')
    then('no rule command remains as its own entry')
    then('a hook entry rhachet did not author is kept as is')
    then('the manifest lists every rule, with its matcher and resolved path')
  when('[t1] rhx init runs again')
    then('no file changes')
given('rhx init runs while a seat fires PreToolUse in a loop')
  then('no call ever meets a settings hook that names an absent or partial manifest')
  then('no call ever runs a rule twice')
given('settings name the dispatcher and the manifest is absent')
  when('[t0] PreToolUse is dispatched')
    then('exit 2 with a MalfunctionError that names the manifest path and `rhx init`')
given('a manifest that names a rule whose .sh is absent')
  when('[t0] the event is dispatched')
    then('that rule reports a crash; the others decide as usual')
```

# case=1 — a Bash call that every rule allows

`seat × PreToolUse × {rhx-skill, shell} × all-allow` (+ a tool no rule names) · happy · critipath

## .narrative

a seat runs `pwd`. claude fires PreToolUse:Bash. today that starts ten processes: three `rhx`
boots (each a bun binary that then forks bash for its skill) and seven `bash` hooks. all ten exit
0, and ~2 cpu-seconds are gone.

with the dispatcher, claude starts one entry: `bash <dispatcher> --event PreToolUse`. the
dispatcher reads stdin once, reads the actor's rule manifest (written at `rhx init`), and runs each
rule whose matcher fits `Bash` in its own subshell — no `rhx` boot, no fresh `bash` exec per rule.
every rule exits 0. the dispatcher exits 0; its stdout holds what the rules print today (the
`🪨 run solid skill …` header each `rhx` rule writes), which claude keeps in the transcript only.
the seat sees naught, which is the point.

then the seat runs `TodoWrite`. no rule names that tool, so the dispatcher's matcher (the union of
its rules' matchers) does not fit it, and claude starts no hook process at all — as today, where no
per-rule matcher fit it either.

## .[tn] sketch

```
given('a repo whose actor enrolls driver, learner, mechanic')
  given('rhx init has synced hooks')
    then('settings.of.repo.json holds ONE PreToolUse entry, not ten')
    when('[t0] a PreToolUse:Bash payload for `pwd` is piped to the dispatcher')
      then('exit 0')
      then('stdout === the rules' stdouts today, in manifest order; stderr is empty')
      then('zero rhx processes are exec-ed (strace -f -e execve)')
      then('the rules that fit Bash each ran once (a probe rule records its run)')
    when('[t1] the same payload is piped to each of the ten pre-dispatcher commands, one by one')
      then('each exits 0 with empty stderr; the three rhx commands print their 🪨 header on stdout')
      then('the concat of those stdouts, in manifest order, === the dispatcher's stdout at t0')
    when('[t2] the settings matcher is tested against `TodoWrite`')
      then('it does not fit; claude would start no hook process for that call')
```

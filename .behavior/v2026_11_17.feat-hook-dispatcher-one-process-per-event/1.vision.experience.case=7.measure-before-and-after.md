# case=7 — the before/after read

`measurer × E={stale, fresh} × solo × PreToolUse:Bash` · happy · critipath

## .narrative

the commander wants proof, and wants it the same way twice. they run one command in a repo on the
shared laptop:

```
rhx hooks.dispatch.cost --event PreToolUse --tool Bash --command pwd --runs 5
```

a minute later they read two columns side by side: today's shape and the dispatcher's, for the same
`pwd`. the rhx count drops from 3 to 0. the cpu per call drops from ~2.2 s to well under the 1.2 s
bar #764 set. the rss peak drops with it. they paste the block into the pr and run it again after
the merge, on the same box, to see it hold.

```
🐢 righteous!

🐚 hooks.dispatch.cost --event PreToolUse --tool Bash --command pwd --runs 5
   ├─ before (10 entries)
   │  ├─ processes = <n> (rhx = 3, bash = <n>)
   │  ├─ cpu = <ms> ms
   │  └─ rss peak = <mb> MB
   └─ after (1 dispatcher)
      ├─ processes = <n> (rhx = 0, bash = 1)
      ├─ cpu = <ms> ms
      └─ rss peak = <mb> MB
```

the numbers above are sketch slots; the real read goes in the pr body, taken on this laptop. the bar
is #764's done bar: a Bash call starts 0 rhx and spends ≤ ~1200 ms cpu and ≤ ~55 MB in hooks, down
from ~2010 ms / 207 MB. the commander's own `rhx claude.hooks.cost` lives outside this repo; the
repo skill makes the same read reproducible here, and the pr names both.

what the skill does under the hood, so the read can be trusted: it replays the same payload into
(a) each per-rule command the pre-dispatcher sync would write and (b) the one dispatcher, counts
processes with `strace -f` in traced passes, and reads cpu and rss with `/usr/bin/time` in untraced
passes — `strace` inflates cpu many-fold, so the two never share a pass. medians of 5.

## .[tn] sketch

```
given('the cost skill on a repo with driver, learner, mechanic enrolled')
  when('[t0] run with --runs 5')
    then('it prints before and after: processes, cpu ms, peak rss')
    then('after.rhx === 0')
    then('after.cpu < before.cpu')
    then('after.cpu ≤ ~1200 ms and after.rss ≤ ~55 MB — #764's done bar')
  when('[t1] run with strace absent')
    then('exit 2 with a ConstraintError that names how to install strace')
```

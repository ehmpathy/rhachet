# case=2 — a row on an event no row held before fires with no respawn

`seat × {UserPromptSubmit, Stop} × C=after × F: none → some` · sharp · critipath

## .narrative

a human works in a seat on a repo whose roles have never cared about prompts. at ten, the team ships
a role update: on each prompt, remind the seat which route it is bound to. the human runs `rhx init`
in a side pane and goes back to the seat.

today the human types the next prompt and the seat answers with no reminder. and the next, and the
next. the reminder sits in the manifest, but the seat's settings never had a prompt hook, so claude
starts naught on a prompt. the human has to quit and respawn the seat to see it.

after, the human types the next prompt and the reminder lands in the seat's context at once. naught
was restarted. the seat had held a prompt wire since its init, idle, and the new row rode it.

## .the mechanism, for the reader who asks

today the dispatcher list is built from the events the rows hold, so a repo with no `onTalk` row has
no UserPromptSubmit entry (`asHookDispatchersOfRules.ts:26`). after, all four mapped events are wired
regardless of rows (F3).

## .[tn] sketch

```
given('a manifest with no UserPromptSubmit row')
  when('[t0] the settings are written')
    then('UserPromptSubmit holds one dispatcher entry, matcher `*`')
  when('[t1] a UserPromptSubmit payload is dispatched')
    then('exit 0, empty stdout')
  when('[t2] a UserPromptSubmit row that prints a line is appended, then a payload is dispatched')
    then('the line lands in stdout; exit 0; no settings write')
```

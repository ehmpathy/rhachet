# case=5 — a narrowed clone holds a wire on each event, quiet where it has no rows

`narrowed × Stop × F=none` · happy · critipath

## .narrative

a human enrolls a peer with `--roles -driver`. the driver role owns the only Stop row, so the
clone's derived manifest holds no Stop row.

today the clone's settings hold no Stop entry at all. after, they hold one, matcher `*`, which
starts the dispatcher at each stop; it finds no row, prints naught, exits 0. the peer stops as it
does today.

if a later re-derive gives that actor a Stop row (a base role gains one), the clone's wire is
already in place; only its manifest changes.

## .[tn] sketch

```
given('a repo actor manifest whose only Stop row is authored by driver')
  when('[t0] a clone is enrolled with --roles -driver')
    then('its manifest holds no Stop row')
    then('its settings hold one Stop dispatcher entry, matcher `*`, that names its own manifest')
  when('[t1] a Stop payload is dispatched against its manifest')
    then('exit 0; stdout and stderr empty')
```

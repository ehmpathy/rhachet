# 1.vision.experience.dimensions

> the axes the experience space varies on. `1.vision.experience.case=_.md` walks their product.

| axis | name | positions | orthogonal because |
|---|---|---|---|
| A | who meets it | `seat` (a clone of the repo actor) · `narrowed` (a clone enrolled with `--roles -x`) · `human` (runs `rhx init` / `rhx enroll` / `rhx upgrade` at a terminal) · `system` (a ci job or cron that runs the same sync, no human present) · `roleauthor` (ships a new hook in a role) | who feels it varies apart from what the manifest or settings hold; any actor meets any manifest state |
| B | claude event | the four a manifest row can name — `SessionStart` · `PreToolUse` · `UserPromptSubmit` · `Stop` (`constants.ts:7-13`) — and `other`: every claude event outside those four, a closed catch-all, since no row can name any of them | the event a call fires is set by claude, not by the manifest, the settings, or the actor |
| C | when the row lands, relative to the seat | `before` the seat's settings were written · `mid-write` (an event fired while the sync writes) · `after` the write, the seat already up | a seat's age is independent of which event fires or what the row names |
| D | tool fit (asked only where B carries a matcher key: SessionStart, PreToolUse) | `named` (some row's matcher fits) · `unnamed` (no row fits) | which tool a seat calls is its own choice, apart from the rows present; on Stop and UserPromptSubmit claude reads no matcher, so D is not asked there |
| E | settings shape | `union` (written by a prior rhachet: one entry per event the rows hold, matcher = their union) · `whole` (one `*` entry per mapped event) | the shape is set by which rhachet last synced, apart from the manifest's state |
| F | rows on the event | `some` · `none` | a manifest can hold rows on one event and none on the next |
| G | manifest state | `present` (rows, readable) · `empty` (readable, zero rows) · `absent` (no file) · `corrupt` (a merge conflict, a version it cannot read, a malformed row) | the file's state is set by the last sync or a stray edit, apart from which event fires or which actor meets it |

## .correlations, stated

- A × C: `human` and `system` drive the write; C is read from a seat's side. so A ∈ {human, system}
  sits at C=`mid-write` by construction, and C=`after` is felt by A ∈ {seat, narrowed}. the walk reads
  C only for seats; the sync actors get their own section
- F × G: F=`some` needs G=`present`. G=`empty` implies F=`none` on every event. G ∈ {absent, corrupt}
  leaves F unread, since the dispatcher refuses before it reads a row
- D × F: F=`none` forces D=`unnamed` (no row, so no row fits). D=`named` needs F=`some`. the walk asks
  D only under F=`some`; F=`none` cells carry no D

## .forbidden and impossible combinations

- B=`other` × any → forbidden by the role contract: no row can name it, since
  `asClaudeEventOfBrainHookEvent` maps only the four (`BrainHookEvent.ts:11`), and a hand-typed row is
  rewritten by the next `rhx init --hooks`. a choice of the contract, not a law of the domain: a new
  `BrainHookEvent` would lift it (F1)
- E=`whole` × C=`after` × the new row's timeout ≤ the floor × a settings write → forbidden: such a row
  must need no settings write; that is the outcome the wish names. a row over the floor still moves
  the wire (itemized, alterpath)
- G=`absent` × a dispatcher wire → forbidden: a wire named at a file that is not there refuses every
  call (case=9)

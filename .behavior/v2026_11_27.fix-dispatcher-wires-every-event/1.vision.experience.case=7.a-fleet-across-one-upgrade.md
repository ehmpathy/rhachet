# case=7 — a fleet across one upgrade, end to end

`human + seat + narrowed + roleauthor × E: union → whole × C=after × all four events` · happy / sharp · critipath

the densest walk: six boundaries in one forenoon — the shape migration, a re-init, a new tool row,
a new event row, a narrowed clone, and an unnamed tool.

## .narrative

monday, at the start of the day. the repo sits on the union shape. the human runs `rhx upgrade`; each actor's settings
lose their union entries and gain one `*` wire per mapped event (case=6). the swap report reads
`12 rules → 4 dispatchers` with a leaf per event. a second `rhx init` writes naught (case=4).

minutes later, the human enrolls a seat, `@:driver`, and a peer, `@:peer1 --roles -driver`. the peer's
manifest holds no Stop row; its Stop wire runs naught at each stop (case=5).

mid-forenoon, a role author ships two hooks: an `onTool` guard on `Agent`, and an `onTalk` reminder. the
human runs `rhx init` in another pane. the manifests gain both rows. no settings file changes: each
wire is already `*`, at the floor timeout.

a minute on, `@:driver` reaches for a nested `Agent`. the dispatcher starts, reads the new row, and
refuses the call (case=1). the human types the next prompt; the reminder lands in context (case=2).
`@:peer1` lacks the driver role but not the author's role, so it gets both rows too, on its next
event.

all day, each `TodoWrite` and `ToolSearch` starts the dispatcher, which runs naught and exits 0
(case=3). no seat was respawned.

## .[tn] sketch

```
given('a repo on the union shape, with roles that declare no Agent and no onTalk hook')
  when('[t0] rhx upgrade runs')
    then('each actor settings hold one `*` dispatcher entry per mapped event; no union entry remains')
  when('[t1] rhx init runs again')
    then('all settings byte-equal to [t0]')
  when('[t2] a clone is enrolled with --roles -driver')
    then('its settings hold four `*` entries; its manifest holds no driver row')
  when('[t3] an Agent row and a UserPromptSubmit row land in each manifest via rhx init')
    then('all settings byte-equal to [t0]')
    then('an Agent payload dispatched against either manifest is refused; exit 2')
    then('a UserPromptSubmit payload dispatched against either manifest prints the reminder')
  when('[t4] a TodoWrite payload is dispatched')
    then('exit 0; stdout and stderr empty')
```

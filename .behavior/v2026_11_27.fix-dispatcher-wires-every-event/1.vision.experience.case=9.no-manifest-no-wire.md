# case=9 — no manifest, no wire: a sync never points a seat at an absent file

`human × rhx init × G ∈ {absent, empty}` · sharp · critipath

## .narrative

a human starts a fresh repo whose roles declare no hooks yet. they run `rhx init`, then spawn a seat
and ask it to list the files. the seat runs `Bash`, and it just works — as it should for a repo with
naught to guard.

the danger this case clamps: had the sync wired the four events with no manifest behind them, every
tool call of that seat would meet a refusal — "hook dispatch manifest not found" — on the first
`ls`. a repo with no hooks would become a repo where no tool runs, and the human would not know why.

a week later the team adds its first role hook and runs `rhx init`. now the manifest exists, empty
or with rows, and the seat gains its four wires. the next guard added to that manifest fires in a
live seat with no settings write.

## .the mechanism, for the reader who asks

the repo sync reads an absent manifest as zero rules (`setHookDispatchManifestRederived.ts:27`).
today zero rules yield zero dispatchers, by accident of the union design. once every mapped event
gets a wire regardless of rows (F3), the wire count must key on the manifest's presence, not its row
count. the clone derive already guards this (`setActorHookDispatchManifestDerived.ts:58-59`); the
repo sync gains the same guard. the dispatcher fails closed on an absent manifest
(`hooks.dispatch.sh:81-88`), which is why the guard matters.

.note = how often a sync meets an absent manifest is not settled here: the migration step
(`setHookDispatchManifestMigratedFromSettings.ts:26-36`) findserts a manifest, empty or not, where
the sync reaches it. the guard is owed either way — it is the one line between "rare" and "every
tool refused", and the execution stone should pin which paths reach it.

## .[tn] sketch

```
given('a brain dir with no hooks.dispatch.manifest')
  when('[t0] rhx init runs')
    then('the settings hold no rhachet dispatcher hook')
    then('a Bash call in a seat is not refused')
  when('[t1] a manifest with zero rows is written, then rhx init runs')
    then('the settings hold four `*` dispatcher entries')
    then('a Bash payload dispatched against the empty manifest exits 0')
  when('[t2] the manifest is removed, then rhx init runs')
    then('every rhachet dispatcher hook leaves the settings')
```

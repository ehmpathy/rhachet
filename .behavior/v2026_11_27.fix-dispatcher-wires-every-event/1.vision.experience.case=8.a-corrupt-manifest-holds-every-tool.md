# case=8 — a corrupt manifest now holds every tool, and names its fix

`seat × any B × manifest corrupt × D=unnamed` · sharp · critipath

## .narrative

a merge leaves conflict markers in `hooks.dispatch.manifest`. today, a seat's `Bash`, `Read`, and
`Write` calls already meet the dispatcher, which refuses each with `✋ ConstraintError: hook
dispatch manifest holds an unresolved merge conflict` and names `npx rhx init --hooks`
(`hooks.dispatch.sh:181-189`). a `TodoWrite` call slips past, since the union never named it.

after, every tool call meets the dispatcher, so every one is refused the same way. the reach of a
corrupt manifest grows from the union's tools to all tools. it fails closed on every PreToolUse and
SessionStart; on UserPromptSubmit it exits 1, so the human's prompt is never erased; on Stop the
second hold passes (`hooks.dispatch.sh:69-79`). the fix is unchanged and printed on each refusal:
the human runs `npx rhx init --hooks` from a shell, which claude does not hook.

the recovery path is extant and unchanged by this work (`.behavior/v2026_11_17.feat-hook-dispatcher-one-process-per-event/1.vision.experience.case=12.a-corrupt-manifest-fails-closed.md`);
[t2] re-asserts it under the new wire, not a new mechanism.

no path became darker. a call that slipped past a broken guard now stops at it — the guard design
the dispatcher already chose.

## .[tn] sketch

```
given('a manifest with an unresolved merge conflict, and `*` wires')
  when('[t0] a TodoWrite payload is dispatched on PreToolUse')
    then('exit 2; stderr names the merge conflict and `npx rhx init --hooks`')
  when('[t1] a UserPromptSubmit payload is dispatched')
    then('exit 1; the same refusal on stderr; the prompt is not held')
  when('[t2] `npx rhx init --hooks` runs, then the TodoWrite payload is dispatched again')
    then('exit 0')
```

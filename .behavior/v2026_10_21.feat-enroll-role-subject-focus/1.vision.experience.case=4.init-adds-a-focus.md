# case=4 — init adds a focus

cells: **P7** (form `add`, command `init`), **T1** (`[t1]`), **D1**, **U1**, **S3** (= E1), **E3**
(`[t5]`). feel happy × care criti (P7, T1, E3), sharp → happy (D1, S3), sharp (U1).

## .narrative

a repo's ambient roles are `any,driver`. the commander wants every plain `claude` session in the
repo to carry mechanic's rails and its flow briefs, and no more. they run `rhx init --roles
+mechanic::flow`.

init links mechanic whole, because a link is a directory and a focus is no reason to link half of
one. `prepare:rhachet` records the token as typed, so the next install keeps the focus. the
ambient actor's `boot.md` renders mechanic at `flow`, and its `settings.of.repo.json` gains every
mechanic hook.

`[t5]` is the re-tune: a delta atop a focused entry replaces the focus (`F6`, one entry per
role). a caller who wants both subjects types the exact set, which is a union (S2).

🔴 `[t4]` is the case the first `[t0]` hid: it assumed mechanic was not yet ambient. today's merge
(`computeBrainCliEnrollment.ts:69-91`, `asPrepareRhachetRolesDelta.ts:64-70`) would hold both
tokens, which S1 refuses, so the wish's delta form would fail in exactly the repos it was written
for. the upsert rule is fulcrum `F6`.

🔴 `[t3]` is the seam where a role author's change meets a commander's seat: the focus lives in
the actor (`ActorOndisk.roles`), the subject lives in the role package, and an upgrade moves only
the second.

🔴 `[t2]` guards a silent drop found in research: `asActorRolesRederived.ts:19-34` filters each
re-derived delta by `rolesLinked.includes(delta.role)`, and `mechanic::flow` is not a linked slug.
a seat would lose mechanic, rails included, with no line of output.

# case=2 — an other-user say is still denied

feel = sharp · care = critipath · verdict = forbidden (the rejection is what this case demos)

## .narrative

a process under another unix user reaches a clone's socket (say its file perms were widened). it
runs `rhx clone say @:reviewer --what 'hi'`. the gate's lookup returns a uid that is not the
clone's. the gate denies, the server replies `rejected (auth-denied)` and ends the socket. the
caller sees:

```
💥 MalfunctionError: the caller is not the same unix user as the clone — a clone socket accepts
   only its own user; run the say as the user that enrolled the clone
```

exit 1. the copy (`CLONE_OPERATIONAL_REJECT_COPY['auth-denied']`,
`computeCloneOperationalRejectClass.ts:65-66`) tells the caller why and hands the next move: run
the say as the user that enrolled the clone. not one byte reached the clone.

it fails safe on all three counts:
- **fast** — as soon as the lookup settles; a quiet box denies in tens of ms
- **loud** — a classed error and a non-zero exit, never a silent drop
- **teaches the fix** — the copy names the user to run as

the longer bounds change naught here: a fast lookup denies at once, a slow one denies once it
settles. no path through a longer wait turns a foreign uid into a pass.

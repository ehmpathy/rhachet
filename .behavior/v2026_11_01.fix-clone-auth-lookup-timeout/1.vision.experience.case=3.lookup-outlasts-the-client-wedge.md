## .narrative

the box is so loaded that `ss -xp` takes 45s. the human runs a short `clone say`. the client waits
30s for any ack, sees none, and exits 1 with a wedge `MalfunctionError` (`sayClone.ts:180`): `acksSeen: []`, `silentMs: ~30000`.
server-side the gate is still within its 65s bound; at 45s it passes, then finds the caller gone,
so it drops the frames and traces `clone socket frames dropped`. not one byte reaches the brain,
so the retry the wedge report invites lands the message once, never twice.

this is no false deny: the report names a silence before the first ack, which points at the
accept path, which is where the slow lookup sits. but it is not a delivery either. the wish's
outcome holds for lookups the client will wait for (< ~30s); this cell is the honest remainder.

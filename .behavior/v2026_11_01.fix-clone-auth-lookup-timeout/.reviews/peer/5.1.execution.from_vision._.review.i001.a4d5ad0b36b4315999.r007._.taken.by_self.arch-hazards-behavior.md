# taken — arch-hazards-behavior — r007

## blocker.1 — the PATH restore is not exception-safe · [REPAIR]

a fault in `genServerWithCapture()` after the swap now restores PATH before it rethrows, so the
slow `ss` can never outlive the scene that set it:

```ts
      const slowSs = genSlowSsOnPath({ delaySeconds: SS_DELAY_SECONDS });
      try {
        return { ...(await genServerWithCapture()), slowSs };
      } catch (error) {
        // a bind fault after the swap must not leave the slow `ss` on the worker PATH
        slowSs.restore();
        throw error;
      }
```

and the teardown no longer dereferences a scene that never built (`scene?.slowSs?.restore()`).

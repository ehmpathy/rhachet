│  │  - `net.Server` defaults to `allowHalfOpen: false`. A client that writes its frame and then sends FIN, as `nc -U` does, makes the server auto-end its writable side. `!socket.writable` is then true when the gate settles, so the say is dropped and only traced. Before this PR it was delivered, without an ack.
│  │  - Every in-repo client (`connectToClone`, `isCloneLive`) holds the socket open until it gets an ack, so I found no in-repo victim. Callers outside the repo are unverified.
│  │  - `socket.destroyed ||` is redundant, because a destroyed socket is never writable.
│  │  - **Fix:** either state "the client holds the socket open until it gets an ack" in the frame contract, or narrow the guard to hard hangups. Add a case for send-then-FIN either way.

# blocker.1: changed `clone get` unreadable renders (predates-content, unrecognized focus) have no snapshot at any grain

**rule**: .agent/repo=bhuild/role=behaver/briefs/practices/behavior.verification/rule.require.contract-snapshot-exhaustiveness.md

**locations**:
- src/domain.operations/clone/cli/asCloneInputSurfaceText.ts:93
- src/domain.operations/clone/cli/asCloneInputSurfaceText.ts:102
- src/domain.operations/clone/cli/asCloneInputSurfaceText.test.ts:105

This PR rewrites `asCloneInputSurfaceText` so every unreadable branch renders through the new `asUnreadableSurfaceText` shape (the `cause`/`fix` labels gained subbranches; the old inline `cause: …` / `fix: …` colons are gone). Two of the rewritten branches have NO snapshot at any grain:

- `reply.content === undefined` (an older daemon that answers a probe but predates the content read)
- `reply.state.focus !== 'input'` on the `unrecognized` focus value

The unit test for both (`asCloneInputSurfaceText.test.ts`, `'🔴 an older daemon that predates the content field'` and `'🔴 an UNRECOGNIZED screen'`) asserts only `toContain('could not be read')` / `toContain('predates')` / `toContain('re-enroll')` — it never calls `toMatchSnapshot`. The only live `clone get` unreadable snapshot that exists is the MODAL one (`blackbox/cli/__snapshots__/clone.say.withheld.acceptance.test.ts.snap` `[case10][t2]`), which this PR did update. So the modal shape change is visible in a diff, but the sibling `unrecognized` and `predates` shape changes — reachable from the same user-facing `rhx clone get --what buffer|queue` command — are not reviewable in any snapshot.

The rule is explicit that every variant a caller could encounter must be snapped, and that a render change invisible to a snapshot is a blind spot. Fix: add `toMatchSnapshot()` rows for the `predates-content` and `unrecognized` renders (and let the acceptance `clone.say.withheld` suite carry the `rhx clone get` unrecognized tree live, matching how the modal was handled), so each changed variant lands in a snapshot diff.

**snippet**:
```ts
  if (reply.content === undefined)
    return asUnreadableSurfaceText({
      address,
      what,
      cause: 'this daemon answers a probe but predates the content read',
      fix: 're-enroll the clone to pick up the current daemon',
    });
```

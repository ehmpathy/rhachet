# case=2: a fresh peer clone commits clean

## .narrative

a driver stands up a peer in a terminal: `rhx enroll claude --roles mechanic`. the roleset is
new, so a new hash actor dir is made and its `settings.of.repo.json` is written for the first time.
that first write already holds the attribution-off key. the peer's first commit is clean.

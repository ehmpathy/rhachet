# wish: no enrolled clone ever adds a Claude Code footer or a Claude co-author trailer

the commander forbids, fleet-wide, the "🤖 Generated with Claude Code" footer in PR bodies and the "Co-Authored-By: Claude" trailer in commits. one landed on ehmpathy/rhachet#641.

rhachet enroll spawns every clone with `--system-prompt ''` (asBrainCliSpawnArgs), so the vendor system prompt is gone. but the attribution instruction does not ride the system prompt: Claude Code injects it as a mid-session system-reminder, which `--system-prompt ''` cannot reach. - no enrolled clone receives the attribution instruction, and so none adds the footer or the trailer

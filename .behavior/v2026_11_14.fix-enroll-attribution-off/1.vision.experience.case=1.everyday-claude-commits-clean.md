# case=1: everyday `claude` commits clean

## .narrative

a human types `claude` in a repo. the shell alias runs `rhx enroll claude`, which spawns a clone of
the repo actor. the human asks for a commit and a PR. claude composes both. no
`Co-Authored-By: Claude` trailer lands in the commit; no `🤖 Generated with Claude Code` footer lands
in the PR body. the clone never hears an attribution reminder, so it has no instruction to obey.

## .timeline (sketch)

```
given a repo with .agent/ and the repo actor's settings.of.repo.json
  when [t0] the human runs `claude` (→ rhx enroll claude)
    then [t0] the repo actor's settings.of.repo.json holds "attribution": { "commit": "", "pr": "" }
    then [t0] the spawn args pass that file via `--settings`
  when [t1] the clone composes a commit and a PR
    then [t1] no attribution reminder reached the clone
    then [t1] the commit message carries no Co-Authored-By: Claude trailer
    then [t1] the PR body carries no Claude Code footer
```

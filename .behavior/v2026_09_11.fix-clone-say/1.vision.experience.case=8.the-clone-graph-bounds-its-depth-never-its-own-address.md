## 🔴 .what this case REPLACES — and why the replacement matters more than the correction

this cell was authored as *"the clone graph refuses its own cycles"*, and it demoed a **refusal** of a
self-say beside the depth refusal, on the argument that *"both bound the same graph, and both refuse
before any effect."*

**half of that was wrong, and it was the half that closed a capability.** the self-say refusal rested
on two mechanisms labelled `nature`, and both were refuted by this wish's own later measurements:

| the claimed mechanism | what refutes it |
|---|---|
| **the deadlock** — *"it polls its own transcript for a rise its own blocked poll prevents"* | the brain writes each user turn to the jsonl **at submit time**, client-side, before any reply (`getCloneSubmittedCount.ts:12-14`). the rise never waited on a brain turn |
| **the baseline collision** — *"its own screen already renders the tool call"* | a baseline that already holds the text is the case a **count** parts and a boolean cannot. a pre-write count of 1 that ticks to 2 is as observable as 0 → 1 |

⇒ **so the shape of this case changed: it is one BOUND and one CLAMP, never two bounds.** the depth
budget refuses; the self-address does not. that asymmetry is the case's subject now, and it is a
sharper lesson than the symmetry it replaced — ⇒
`define.invariant.clone-say-to-self-is-await-clamped-never-refused`.

## .why the bound and the clamp are ONE demo

they are different verbs — an `enroll` and a `say` — and they belong together for a reason the retired
version had inverted:

> **the graph has exactly ONE runaway mode, and exactly one bound answers it.**

a clone graph could run away two ways: an **unbounded depth** (a node spawns a node that spawns a
node) and a **cycle** (a node points at itself). only the first is real:

- **depth is a resource claim.** each level costs a brain-cli and a pty, and the host runs out before
  anyone notices what built it. ⇒ a hard refusal, before any spawn
- **a self-address is not.** a self-say consumes one message slot in a queue the clone already owns.
  it terminates, it is observable, and it is how a clone drives its own next turn

⇒ **the demo carries both so a reader sees where the line actually falls** — and a case that showed
only the depth refusal would leave the self-say read as an unexamined gap rather than a settled
capability.

## .the narrative

a clone drives a route. it holds a list of work and it reaches for the three moves every driver reaches
for: **fan out** (enroll a peer to take half), **nudge** (say to a peer that has gone quiet), and
**self-nudge** (hand itself the next step, or a slash command its own client owns).

**it says to its own serial.** the dispatch lands. the message arrives in its own input box, submits,
and shows up as a new user turn on its very next read — which is what a self-driven loop needs. one
knob is quietly lowered, and it is told so:

```
ℹ a self-say awaits `enqueue`, never `release` — your own queue cannot drain while this say runs
```

exit 0. `delivered: true`, `verdict: enqueued`, `probe: capable`. the clone reads the notice, learns
that `released` is unreachable from inside its own turn, and proceeds — the clamp costs it a line of
stderr rather than a bound of poll time.

**it enrolls a peer to take half the work.** it is a clone, so it sits at depth 1, and its peer would
sit at depth 2. the enroll is refused before any process spawns — because the alternative is an
unbounded tree, where each level costs a brain-cli and a pty.

so the clone does the two things the bound leaves open: it says to a peer that **already exists**, and
it says to **itself**. both are the move the whole wish is about.

⇒ **the refusal tells the clone what shape the graph is; the clamp tells it what shape its own turn
is.** neither is an error in the ordinary sense — no state was corrupted, and no act must be undone.

## .the bdd

```
given  a clone at depth 1, with its own serial in RHACHET_CLONE_SERIAL

[t1]   when it says to its OWN address
       then the say LANDS — exit 0, `delivered: true`, verdict `enqueued` or `released`
       and  `probe: capable` — the self-say read its own screen, so no mechanic degraded
       and  the retired refusal copy is absent from the surface
       and  the machine twin carries the verdict trio, so a daemon can branch on it

[t1b]  when it says to its own address with `--await release`
       then the target is CLAMPED to `enqueue`, and a notice states so on stderr
       and  the exit is still 0 — a clamp is not a refusal
       and  the bound is NOT burned on a poll for a drain that cannot happen

[t2]   when it enrolls a peer — which would sit at depth 2
       then the enroll is refused, exit non-zero
       and  NO brain-cli process spawned
       and  the refusal names the depth budget, so the caller knows it is not a transient

[t3]   when it instead says to an EXTANT peer at depth 1
       then the say proceeds normally — the bound closed a spawn, never a dispatch
```

🔴 **`[t1b]` is the step that makes the clamp a guarantee rather than a silent downgrade.** a clamp
that fired with no notice would hand a caller an `enqueued` where they asked for `released`, and let
them read it as the strongest verdict available. the notice is what keeps the lowered knob honest.

## .the retry contract this cell adds

the two halves now sit in **different** retry classes, which is itself the correction:

| verdict | re-send? | why |
|---|---|---|
| a self-say `enqueued` / `released` | **no — the brain has it** | identical to a peer say at the same verdict. the `enqueued` abort bound applies too: a ctrl-C or a prune kills the hold |
| the depth refusal | **no — say to an extant peer** | no spawn happened, and the depth does not change while the process lives |

⚠️ **the retired version put the self-say in `withheld`'s class** (*"no — fix the address"*), and that
row was the retry contract's one false entry: it told a daemon that a self-address is permanently
un-dispatchable. a daemon that learned that rule would never build a self-driven loop.

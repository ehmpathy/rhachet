## the debug instrument — the read channel's own read channel

⚠️ built during this verification, for the reason `F15` predicted and the 2026-09-16 dogfood measured:

### ✅ CURED — a clone could adopt its PARENT's live transcript, so `released` could be FORGED

the gate's own dogfood found it. a `rhx clone get @:loopcheck4 --tail 30` returned **the enroller's

**the mechanism**, and the file argues against itself two lines apart:

```ts

//   "a transcript CREATED before this clone spawned cannot be ours"
return input.transcriptMtimeMs >= spawnedAtMs - CLONE_SPAWN_WINDOW_TOLERANCE_MS;
```

**created** is `birthtime`; the code reads `mtime`. a live parent session is appended to on every
turn, so its `mtime` is always `now` — **permanently in-window, for every clone.** and both guards in
`genCloneHistoryLink` miss it: the window filter for the reason above, and the ambiguous-refuse
because it fires only at `>= 2` while the clone's own transcript did not exist yet, so the parent's
stood as the **only** candidate.

**the proof is on disk** — every clone has one history link; one has two:

```

  T+2h29m  9351d10b-b63e-41f3-ab59-d07464ce6a2f.jsonl   ← 🔴 the ENROLLER's session
```

⇒ linked **2.5 hours after** the clone's own spawn, by the per-episode re-link poll. 🟡 the two mtimes
are rendered as an offset rather than as wall clocks: what the proof rests on is the **gap**, and a
clock literal in a committed record reads as a reproducible value it is not.

🔴 **why it is this wish's business.** `released` is defined as *the transcript count rose*. if the

input.transcriptBirthtimeMs > 0 &&                         // and keeps one

### ✅ CURED — a fresh enroll died at spawn, and my first diagnosis of it was WRONG

### ✅ CURED — a self-directed say burned the full poll bound; it now LANDS, with one knob clamped

## 🔴 cure 22 — an unknown flag is refused, never dropped: the invariant, its clamp, and the contract defect the drop was hiding

### the invariant

an unknown flag token has exactly three legitimate fates, and a fourth that is a defect:

| fate | what it is |
|---|---|
| `recognized` | the verb owns the flag and acts on it |
| `forwarded` | the verb hands it to a named child, and says so |
| `refused` | the verb names the token and exits non-zero |
| 🔴 `dropped` | the verb consumes it, names naught, exits **0**, and answers under a default |

⇒ `forwarded` is **first-class**, not a carve-out — `enroll` forwards its passthrough to the brain-cli,
and that is correct. what is forbidden is the silent consume.

### the defect

`countNeedleInLines` matched with `indexOf` over rows joined by `\n`, and its docblock asserted the
premise that made that sound: *"a SINGLE-line needle holds no `\n`, so it can never span the inserted
separator."*

🔴 **it can — the RENDERER breaks it.** two mechanisms split one logical message across rendered rows,
and only the first had a cure:

| mechanism | handled |
|---|---|
| an interior `\n` — `asCloneDispatchFrame` lands each as a real row | ✅ since r010 |
| a terminal **soft-wrap** — a message wider than `cols` breaks at a word boundary | 🔴 never |

⇒ so a 147-char self-say at `cols=98` rendered across two rows, `indexOf` of the unbroken needle found
naught, no count rose, and the say reported `absent` — **the R1 false failure this wish exists to kill,
arrived at from the opposite direction.**

🔴 **the dangerous half is `buffered`, not `absent`.** a wrapped message in the input box that counts 0

and wedge it"* — **unreachable**. the say falls to `absent`, whose advice is still "verify, never re-send

a whitespace collapse on **both** sides of the match, so neither mechanism can hide a needle that IS on
the screen. whitespace is the right equivalence class precisely because the **renderer** inserted it:
two messages that differ only in whitespace now collide, which is sound for a rise detector — the screen
cannot part them either.

**beside** a wrapped message in the queue, where both reads must answer on their own region.

⇒ the last two are the wisher's ask verbatim: *"include also the case where theres a apartial input in
the input field too."* they are the bound on the cure — a collapse that normalized too far would forge a

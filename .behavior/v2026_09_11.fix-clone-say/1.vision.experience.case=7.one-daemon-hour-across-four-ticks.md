# case=7 — one daemon hour, four ticks, five boundaries

`unattended × {input-dirty → mid-turn → modal} × {withheld → enqueued → released → withheld} ×
probe-capable` · **feel** sharp · **care** critipath (freq: every daemon's normal hour · cost: a
duplicated nudge, or a nudge lost with no retry anywhere)

⇒ **the dense journey. rank 1 by boundary-density, and the demo the catalog centers.** it is not a
new cell — it is one actor's walk **across** cells in sequence, which is where the cell spotlights
are blind.

## .why a journey is owed beside the six spotlights

`define.experience._.metric=boundary-density` says the dense walk is at once the highest-value demo
(it discharges many boundaries at once) and the highest-risk one (*"defects cluster where boundaries
pile up"*). case=1 … case=6 each pin **one cell** and walk it — which is not the same claim as
*"one boundary"*: case=4 crosses 3 and case=1/3/6 cross 2 apiece. what a spotlight cannot cross is a
**cell seam**, because it stands still. so the seams were undemoed:

- case=1 asserts *"my retry policy can now be correct"* and never walks a retry
- case=2's t3 gestures at a second tick (*"the daemon ticks again"*) and stops there
- no case anywhere dispatches a **second** say

⇒ so the one benefit the vision advertises most loudly — a correct retry policy — had no demo behind
it. this case is that demo, and the walk exposed a real hole at t2 (below).

## .the narrative — the RouteReminder daemon's pov, over one hour

i tick every 60s at a driver deep in a long route. one hour is four ticks, and no two of them find
the clone in the same state — that variety is my normal, not my edge.

**tick 1.** my driver's human is mid-thought in the input box. i probe, see the box is dirty with
text i did not author, and refuse. i mark the nudge **unsent**. nobody's words are harmed and i lose
no ground but a minute.

**tick 2.** the human has submitted; the driver is now deep in a tool chain. i probe clear, write,
and the transcript stays empty through the bound. the post-bound probe says the line is clear and my
needle is on screen — so the brain holds it. i get `enqueued`, exit 0, and i mark the nudge **sent**.

**tick 3.** the driver's turn still has not ended, and my nudge still has not appeared in the
transcript. **this is the moment my old self would have re-sent** — and the driver would have read
the same encouragement twice, which reads as a malfunction to a human. i do not re-send, because
`enqueued` already told me the brain has it.

**the turn ends.** the brain dispatches my nudge as the next turn. the driver reads it **once**.
t3's restraint is proven correct after the fact.

**tick 4.** now the driver is parked on a permission prompt. i probe, see a modal holds focus, and
refuse — my `\r` would have *answered* it. i mark unsent and tick again.

so my hour: one nudge delivered exactly once, two refusals that cost a minute each, and zero harm
to a human — and at no point did i have to guess.

no `[tn]` step of its own, so it does not count as a boundary. **the rank is 1**: five boundaries

### 🔴 .and t6's stale echo is NOT a sixth row either — by that same standard

t6 does not count as a sixth boundary — the same standard, applied against the case that would have
benefited from a higher count:

| what t6 holds | crossed? |
|---|---|
| at t4 the earlier tick's echo IS on screen, and this tick's text equals it — a **factual** line | the **state** is entered ✅ |
| the verdict divergence (`enqueued` against `absent`) needs tick 4 to find `input` focus, which it does not | only **counterfactually** ❌ |

and never **resolves** it. by the struck row's own test — *is it a boundary this walk crosses?* — the
answer is no, and a rank of 6 would be bought with a counterfactual. **the rank stays 5.**

🟡 t6 stays in the timeline regardless, because its value is not the rank: it is the one place in the
catalog where a reader can see the presence test and the count test give **opposite verdicts on the
same screen**. ⇒ an honest `[tn]` that earns no boundary is still the cheapest place to demo an
invariant (`case=_` invariant 6).

⇒ it **coverage-subsumes** case=1, case=2, and case=6's t1
(`define.experience._.metric=boundary-density`'s coverage-subsumption). those three keep their files,

## .how it fails safe — fast · loud · teaches the fix

| property | how |
|---|---|
| **fast** | every refusal lands at the probe, before any write. across four ticks, zero partial states to unwind |
| **loud** | each tick ends in a named verdict on a declared channel. the daemon never infers an outcome from silence (`rule.forbid.failhide`) |
| **teaches the fix** | the two refusals each name the move that lifts them (submit your line · answer the prompt), and each lifts in the normal course, so a plain 60s retry is the correct policy |

## 🔴 .the hole this journey exposed — `brain-queued` is not a terminal fate

t2 is the demo's payload, and it cuts both ways:

- a caller that **re-sends** on `enqueued` doubles the nudge — the defect t2 forbids
- ⇒ so a caller must treat `enqueued` as delivered
- **but a queued message can still be lost.** the turn it waits behind can be aborted — a ctrl-C, a
  crash, a `clone prune` — and the brain's queue dies with the process
- so the one caller who would ever retry has been told not to, and the nudge is gone with **no
  retry anywhere**

⇒ the matrix verdicts `mid-turn × brain-queued` as though `brain-queued` were terminal. it is not: it
is a **waypoint** with two exits, and only one of them is demoed (t3, the dispatch).

**the bound, stated rather than papered over:** `enqueued` promises the brain **holds** the message,
never that it will **deliver** it. so:

- `say` is correct to return exit 0 — it made a true claim about a state it observed
- a caller that needs at-least-once delivery must verify later, and the contract must say so in the
  verdict's own documentation
- 🟡 an *automatic* re-verify is out of scope here: it would require `say` to outlive an unbounded
  turn, which case=1's t4 non-wait forbids for exactly the right reason

⇒ itemized in `case=_`'s invariant 5 rather than demoed as an eighth cell, per
`rule.require.experience-catalog-evolution`'s proportionality clause — the bound is a statement, not
an absent mechanism.

## 🟡 .the honest bound on this case

the daemon's retry **rule** is the caller's code, not `say`'s. what this case demonstrates is the
half `say` owes: that its verdict set is sharp enough for a correct rule to exist at all, and that
two refusals in one hour each lift themselves rather than stick. a caller free to write a wrong rule
is no defect in the contract — a contract too coarse to write a right one is, and that is what
today's single `delivered` boolean was.

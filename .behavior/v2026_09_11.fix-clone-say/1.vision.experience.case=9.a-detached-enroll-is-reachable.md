# case=9 — a detached enroll is reachable

| | |
|---|---|
| **dispatcher** | unattended — a caller with no tty (a daemon, a CI step, a clone) |
| **borne by** | the peer that was enrolled, and every caller that later says to it |
| **feel** | happy |
| **care** | **criti** |
| **cells** | E1 `depth-0` × E2 `detached` |
| **invariant** | 10 — attendance is a MODE, never a REACH |
| **boundaries** | 1 — the attendance-vs-reach seam |

## .why a HAPPY path earns a critipath grade

every other criti cell in this catalog is **sharp** — a refusal, a degrade, a false report. this one
is a success path, and it outranks most of them, because:

> 🔴 **it is the loop directive's own precondition.** a clone has no tty. so if a no-tty enroll mints
> an unreachable peer, *"spawn a peer clone and say to them"* is unreachable by construction — the
> goal fails before any `say` code is consulted.

⇒ the sharp cells protect a caller from a wrong answer. **this cell is whether the caller can ask at
all.**

## .why nobody found it for so long

the defect fired only for callers that cannot report it:

| the caller | has a tty? | what it saw | could it file a defect? |
|---|---|---|---|
| a human at a terminal | ✅ always | a reachable clone, every time | yes — and had no cause to |
| a daemon | 🔴 no | `socketEligible: false`, then a dead `say` | no |
| a CI step | 🔴 no | the same | no |
| a clone driving its own work | 🔴 no | the same | no — and it is the case the loop needs |

🔴 **so the read was correct from every seat that could speak.** and the test suite inherited the same
blind spot: every extant reach case enrolled through `spawnRhachetCliBackground`, which allocates a
real pty, so **the whole cube was walked with `tty: true` pinned** and the one value that broke was
unreachable by construction.

⇒ *"our acceptance tests should have caught this already"* is the human's line, and the honest answer
is that the suite was exhaustive over the wrong cube.

## .the narrative

a daemon has work that needs two hands. it enrolls a peer:

```
rhx enroll claude --as @:helper --output json
```

no tty is attached, so the enroll takes the **async** mode: it re-execs itself as a detached host,
stands the brain up inside it, and hands the address straight back on stdout. the daemon is not
blocked on a brain that never exits — it gets its answer and continues.

```json
{ "serial": "…", "slug": "@:helper", "socketEligible": true }
```

🔴 **`socketEligible: true` is the whole cell.** the clone has no human at a terminal, and that was
never the question the field answers:

| the property | the question it answers | who decides it |
|---|---|---|
| **attendance** — a MODE | is a human watched over by this clone's output? | the tty |
| **reach** — a CHANNEL | can a peer be heard by this clone? | the socket |

the two are orthogonal, and to conflate them is to make a human's presence a precondition of a
machine's address. ⇒ so the daemon says to its peer, and the peer answers.

## .the bdd

```
given  a linked repo and a live brain, enrolled through a PIPED stdio spawn
       (so the child's `process.stdout.isTTY` is undefined)

[t1]   when `enroll claude --as @:helper --output json` runs
       then it terminates on its own, exit 0 — it does NOT block on a brain that never exits
       and  the caller is handed the clone address on stdout

[t2]   then the machine handoff carries `socketEligible: true`
       and  the verdict is INDEPENDENT of any attendance signal

[t3]   when a `clone say` is dispatched to that address
       then the say returns exit 0 and reports `said to` or `enqueued for`
       ⇒ reach is PROVEN, never asserted — see below
```

🔴 **`[t3]` is the step that makes this a guarantee.** `[t2]` asserts a **flag the enroller writes
onto its own handoff** — it states *"i intended a socket"* and no more. a clone whose brain-cli had
already exited still satisfies it, because the flag is written before the death.

⇒ **measured 2026-09-16: the whole acceptance tier was green (3606 tests) on the same day four
consecutive `--async` enrolls each handed back an address and each was dead within seconds.** a flag
assertion cannot catch a dead clone. a real say can.

| step | grain | instrument |

| t1 | unit | `computeCloneEnrollMode` — a no-tty enroll takes `async`, never `watch` |
| t2 | acceptance | the same case — `socketEligible: true`, plus its machine-shape snapshot |
| t2 | unit | `isCloneSocketEligible` — the attendance input was removed from the predicate's domain |
| t3 | acceptance | the same case — a real `clone say`, asserted on exit 0 and its stdout verb |
| t3 | unit | `getBrainCliPassthroughArgs` — the flag-strip list, tied to enroll's consumed set |

⇒ the two mutations that make it bite are recorded at the case: `isCloneSocketEligible` reads
attendance again → red on `socketEligible` · `computeCloneEnrollMode` returns `watch` with no tty →
red, and the caller blocks until its cap fires.

## .the seam this cell owns

E2's two values meet D4's `feed-not-live` at exactly one point: **a detached clone's first `say`
arrives before its screen feed has attached.** so case=9 hands off to case=4 — this cell proves the
peer is reachable; case=4 proves the first dispatch to it is not withheld for want of a readable
screen (V13, fulcrum F17).

⇒ that hand-off is why the two boxes are one catalog rather than two.

# case=4 — a probe-blind daemon degrades honestly instead of a hard break

`unattended × (any target) × (any fate) × probe-blind` · **feel** sharp · **care** critipath
(freq: once per human per upgrade, and 100% of clones alive at release · cost: every say to a
pre-upgrade clone breaks, or worse, lies)

⇒ **rank 2 by boundary-density** (3 boundaries), and the densest of the six spotlights. the one cell
that crosses a **version** seam rather than a state one — and the one case=7 does not subsume, since
a probe-blind peer has no probe for a journey to walk.

## .the narrative — the operator's pov

i have a clone i enrolled at dawn and do not want to lose — it holds an hour of context. at lunch i
`pnpm upgrade rhachet`, so my `rhx` binary is new and my **clone daemon is still the old one**,
because a daemon is a live process and an upgrade does not reach into it.

i run `rhx clone say @:beav-1 --what "drive on"`.

the new `say` asks the old daemon to probe. the old daemon has one verb and answers
`rejected: request is not a say { message }`.

**the break i must not get:** `say` treats that rejection as a dispatch failure and refuses to send
at all. now every say to every pre-upgrade clone is dead, and my only remedy is to kill a clone
that holds an hour of context.

**the lie i must not get:** `say` treats the rejection as `clear` and proceeds as if it had probed.
now an `enqueued` verdict is asserted on evidence that does not exist — a green claim about the future
with no read behind it.

**what i get:** `say` notes the daemon cannot answer, dispatches anyway, verifies by transcript
exactly as it does today, and says so in one line:

```
😶🎙️ said to @:beav-1
   └─ 🟡 this clone predates the screen read — verified by transcript only
      └─ a busy target may still report a false `not submitted`; re-enroll to get the full read
```

🟡 the degrade marker is `🟡`, not `⚠️`: `U+26A0` is `East_Asian_Width=Ambiguous`, so a terminal
reserves one cell where an emoji font paints two and every column to its right shifts
(`rule.forbid.width-ambiguous-glyphs`). the blueprint picks the final mark from the repo's palette;
what this case fixes is that the mark must render at a known width.

so i keep my context, i keep today's behavior, and i know precisely which guarantee i am short.

## .how it fails safe — fast · loud · teaches the fix

| property | how |
|---|---|
| **fast** | one rejection on the probe; no retry loop, no probe ladder. the degrade decision costs one round-trip |
| **loud** | the notice rides EVERY render, success included — a degraded guarantee is stated, never inferred from an absent line |
| **teaches the fix** | names the remedy (`re-enroll this clone`) and the cost to skip it (a busy target may still report a false failure) |

## 🟡 .the verdict this case adds — `unreadable`

a probe-blind bound-elapsed outcome is **not** `buffered` and **not** `absent`: both of those
claim a position, and with no read channel `say` knows no position. so it is `unreadable` — the
message was delivered to the pty, whole, and where it went is undetermined.

⇒ that is strictly more honest than today's text, which asserts *"the brain never submitted it"* on
the same evidence. **the probe-blind path is improved by this wish even though it gains no read
channel**, because the claim is cut back to what the evidence supports.

## 🔴 .the write-side consequence — the precheck did not run, so the paste is UNGATED (fulcrum F17)

the bdd's t3 declares *"the pre-check is SKIPPED and declared skipped"* — but that speaks to the READ
side (the verdict is `unreadable`, the confidence is degraded). the WRITE side has a sharper
consequence a reader must not miss: a probe-blind (`feed-not-live`) dispatch does not merely lose its
read channel — it writes with **no dirty-box + modal precheck at all**
(`genCloneSocketServer.ts:112-133`: only the `screen.live` branch runs `computeCloneDispatchPrecheck`;
`feed-not-live` falls through and writes ungated).

so a probe-blind clone whose human is **mid-type (case=2)** or **parked at a permission prompt
(case=6)** receives the paste ungated — the exact defects the precheck exists to stop, silent on this
one branch. today's V7 / case=4 choice (dispatch-blind + verify by transcript) makes this the
deliberate behavior; whether a `feed-not-live` write should instead REFUSE (as `feed-faulted` does)
is the V7 ↔ V3/case=6 collision, itemized as **fulcrum F17** and folded into the F06 / F07 wisher
decision — **unruled**. this note exists so the write-side hole is not read as decided by case=4's
read-side degrade narrative.

## .the alternative rejected — probe the daemon's version

a `{ kind: 'version' }` handshake before the probe was weighed and dropped: an old daemon rejects
that verb too, so it is the same rejection one round-trip earlier. the probe's own rejection is the
capability answer, so a separate probe buys no fact and adds a round-trip.

# case 2 — a dead login refuses the spawn, and one `/login` recovers the fleet

feel: sharp · care: critipath · cells: `shared` × `dead` × any; the event `shared` × `live` × `cured` × `window` where the server revokes the login

## .the narrative

the server revokes the human's login. the next refresh meets `invalid_grant` and claude-code clears the one file — correctly, since the login is dead for every clone. every pane shows `Login expired` together.

a supervisor tries to enroll a fresh crew. enroll reads the shape of `~/.claude/.credentials.json` — empty secrets beside a live `refreshTokenExpiresAt` — and refuses before the spawn, exit 2: `✋ ConstraintError: the box's login is dead`, with the cure `/login` (or `rhx git.grove.auth`) and a note that live clones recover on the refill.

the human runs `/login` once. the file refills; every live clone re-reads it and recovers, no respawn (S7). one human step heals the whole fleet.

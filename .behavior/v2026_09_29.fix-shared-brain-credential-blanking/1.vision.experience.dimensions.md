# 1.vision.experience.dimensions

the experience space of "a clone authenticates, and stays authenticated, beside its peers".

## .the dimensions

| # | dimension | positions |
|---|---|---|
| D1 | **source** — the highest-ranked credential rhachet can observe, by claude-code's precedence | `key` — `ANTHROPIC_API_KEY` / `ANTHROPIC_AUTH_TOKEN` · `env` — `CLAUDE_CODE_OAUTH_TOKEN` · `shared` — `~/.claude/.credentials.json`, via the shared store · `none` |
| D2 | **health** | `live` · `dead` — revoked, or blanked (empty secrets beside a live `refreshTokenExpiresAt`) |
| D3 | **peers** — the other live processes on the box that refresh the login | `solo` · `cured` — on the shared store: clones after the fix, the human's `claude`, trees on pre-1.48.0 rhachet · `precure` — 1.48.0 clones, each on its own lock set |
| D4 | **phase** — of a refreshable, live login | `fresh` · `window` · `past` |
| D5 | **who spawns** | `human` · `machine` — grades the sharp cells: a machine must get an exit code, never a parked pane |

`none` has no health. D4 is flat wherever no refresh can happen (`key`, `env`, `dead`).

## .the walked product

`key`, `env`, `shared`: 3 × 2 × 3 × 3 = 54 cells; `none`: 3 × 3 = 9; 63 in all.

- `key` × `live` → flat on D3, D4 → case 2 `[t2]` (9)
- `key` × `dead` → itemized, claude-code's own auth error (9)
- `env` × `live` → flat → case 2 `[t1]` (9)
- `env` × `dead` → itemized, claude-code's own auth error; rhachet neither mints nor judges an env token (9)
- `shared` × `live` × `solo` · `cured` → case 1 (6)
- `shared` × `live` × `precure` × `fresh` · `past` → case 3 `[t0]` (2)
- `shared` × `live` × `precure` × `window` → case 3 ⚠️, the residual race until respawn (1)
- `shared` × `dead` → case 2 `[t0]` (9)
- `none` → itemized, the absent line (9)

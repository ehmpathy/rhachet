# case=4 — a sweep under a member org 🟢 criti

**cell** — B=`member` × D=`sweep`

## .narrative

before a long aether session, vlad unlocks the whole camp env for aether at once:

```sh
rhx keyrack unlock --owner ehmpath --env camp --org aether
```

today a sweep FILTERS: it builds slugs from `manifest.org` (`ahbode.camp.*`) and keeps those whose
segment is `aether` — zero rows, a silent empty rack. narrowed to one key (`--key AWS_PROFILE --org aether`,
the very line case=8's fix hands out) it is loud and wrong instead: `assertKeyrackKeyAskSurvivedOrgFilter`
computes "held" from the DECLARED slugs, which carry `manifest.org`, so it says
`key excluded by --org filter … IS held (under ahbode)` and its fix reads `--org ahbode` — the default
org, the one the human did not ask for. with the allowlist, a member value on a sweep
re-slugs the DECLARED keys under that member first (`aether.camp.*`), then sweeps them. the set of
key NAMES is the manifest's; the org is the ask's.

each re-slugged key keeps its declared spec — `is-optional-if-has`, `reaches`, grade — because the
spec belongs to the declaration, not to the org. `status --org aether` and `list --org aether`
read the same set.

## .[tn]

```ts
given('[case4] manifest org [ahbode, aether]; env.camp declares AWS_PROFILE, GH_TOKEN (is-optional-if-has: GITHUB_TOKEN)', () => {
  when('[t0] unlock --env camp --org aether', () => {
    then('aether.camp.AWS_PROFILE and aether.camp.GH_TOKEN are unlocked', ...);
    then('no ahbode.* slug is touched', ...);
  });
  when('[t1] the same sweep with GITHUB_TOKEN set in env', () => {
    then('aether.camp.GH_TOKEN is waived — the spec flag carried across the re-slug', ...);
  });
  when('[t2] status --org aether --env camp', () => {
    then('the rows list aether.camp.* — never an empty rack for a member', ...);
  });
  when('[t3] unlock --env camp (no --org)', () => {
    then('ahbode.camp.* only — case=1 still holds', ...);
  });
  when('[t4] unlock --env camp --key AWS_PROFILE --org aether (a keyed member unlock)', () => {
    then('aether.camp.AWS_PROFILE is unlocked — the re-slug happens BEFORE the filter-miss guard, so the guard sees aether slugs', ...);
    then('never "key excluded by --org filter", and never a fix that names ahbode', ...);
  });
  when('[t5] two grove clones of this repo overlap: one runs unlock --env camp, the other unlock --env camp --org aether', () => {
    then('the daemon holds ahbode.camp.AWS_PROFILE AND aether.camp.AWS_PROFILE — the slug carries the org, so neither grant overwrites the other', ...);
    then('each clone reads back its own org value, never its peer\'s', ...);
  });
});
```

## .why criti

without it, a member works keyed and reads empty swept — one flag, two answers by verb
(`rule.forbid.surprises`). the spec-carry clamp guards a silent drop: specs are keyed by full slug
(`decideIsKeyStrictlyRequired:33`), so a naive re-slug would lose every flag.

# 1.vision.experience.dimensions — keyrack org allowlist

the experience space of one repo that may address several orgs. nine axes; each a small closed set.

## .the axes

| # | axis | values | n |
|---|------|--------|---|
| A | **manifest shape** — what `org:` holds | `scalar` · `list=1` · `list=n` (n ≥ 2) · `malformed` (empty list, duplicate member, sigil member `@all`/`@this`, non-string) | 4 |
| B | **org asked** — what the caller names | `omitted` · `@this` · `org[0]` (the default, by name) · `member` (any other entry) · `nonmember` · `@all` | 6 |
| C | **named by** — where the org arrives | `flag` (`--org`) · `slug` (the segment of a full `org.env.KEY`) | 2 |
| D | **verb arity** — what `--org` does on the verb | `keyed.read` (`get --key`, `source --key`) · `keyed.mutate` (`set`, `del`) · `sweep.repo` (`unlock`, `source`, `get --for repo` — re-slug the manifest's declared keys) · `sweep.host` (`status`, `list` — narrow the host rack, no manifest read) · `sweep.noorg` (`fill`, `relock`, `firewall` — `--org` refused) | 5 |
| E | **extends** — what the chain declares | `none` · `foreign` (an extended manifest declares an org outside the root's list) | 2 |
| F | **actor** — who asks | `human` (terminal) · `skill` (a route skill, e.g. `git.grove.*`, passes `--org` from a record) · `cron` (no human to read a hint) · `sdk` (a program that imports rhachet and calls `keyrack.get({ org })`, no cli in between) | 4 |
| G | **rack holds** — where the asked key actually lives | `asked` (under the org asked) · `other` (only under another org) · `none` | 3 |
| H | **time** — how this call meets other calls | `first` (alone) · `concurrent` (another keyrack call, or a human edit of `keyrack.yml`, overlaps it) · `retried` (the same call again, e.g. a fix line run twice) | 3 |
| I | **owner** — whose rack the call reads | `default` (no `--owner`) · `named` (`--owner ehmpath`, a robot's rack) | 2 |

## .why each is orthogonal

every one of the 36 pairs, grouped by the reason it holds. a pair that is conditioned rather than free is said so, and its void cells are named in the walked product.

- **A ⟂ B** — the caller names an org with no knowledge of how the manifest spells its list. a `member` ask against a `scalar` manifest is a real cell (it is a `nonmember` there), not a correlation.
- **B ⟂ C** — the same org can arrive as a flag or as a slug segment; the guard sits at both (`getOneKeyrackGrantByKey:71` flag, `asKeyrackKeySlug:59` slug).
- **B ⟂ D** — the same value means SELECT on a keyed verb and FILTER on a sweep verb (`asKeyrackSelectorOrg` vs `asKeyrackFilterOrg`). that split is extant and is why D is its own axis. the sweep side splits again: a repo sweep reads the manifest, so the allowlist gates it; a host sweep reads only the host rack, which may hold keys of any org, so it does not (fulcrum F8).
- **B ⟂ E** — `E=foreign` puts a lure on disk (`org: ehmpathy` in an extended file), but it does not force the ask: a caller under `E=foreign` may ask `member` or `omitted`, and a caller under `E=none` may still ask a `nonmember` by typo. case=7 is the one cell where they meet.
- **A ⟂ C, A ⟂ D, A ⟂ E** — the manifest's shape constrains neither the syntax of the ask, nor the verb, nor what the chain extends. extends expands before the list is read, so a root of any shape can extend a manifest of any org. (`A=malformed` is refused at parse before C or D are read — a collapse, below, not a correlation.)
- **C ⟂ D — conditioned.** a slug arrives only through `--key`. every keyed verb carries one; a sweep carries one only when narrowed by `--key`; `sweep.noorg` refuses `--org` and its narrow is off this axis. so `C=slug` × `D=sweep.noorg` is void, and `C=slug` × `D=sweep` exists only as the narrowed form. the axes stay separate because on every verb that carries a key, both syntaxes reach the same guard question.
- **C ⟂ E, D ⟂ E** — what the chain declares is fixed before the call is parsed; it shapes neither syntax nor verb.
- **F ⟂ every other axis** — any actor runs any verb with any manifest, ask, syntax, chain, rack, or time; the actor changes only who reads the refusal. a `cron` cannot act on a hint, so for it a refusal must be the WHOLE answer (exit 2, no prompt). an `sdk` caller reaches the same grant operation the cli does, so a member read must re-slug there too, and a nonmember must throw rather than fall back to the default org.
- **G ⟂ A, B, C, D, E** — the rack's contents are host state; neither the manifest nor the ask carries knowledge of them. `G=other` is the cell the wish was born in: the key sits under `aether` while the ask names `ahbode`.
- **H ⟂ every other axis** — when a call runs, and what else runs beside it, is independent of what the call says. H bites only where state is shared: the manifest file (written by `D=keyed.mutate` and by `rhx init --roles`) and the daemon (written by `unlock`). it is walked in the inventory's slice H.
- **I ⟂ every other axis** — any owner's rack can be read with any manifest, ask, or verb; the owner picks the rack, never the org. I bites only where a call prints a command for a human to run: a fix line or a tip that drops `--owner` lands on the default rack. it is walked in the inventory's slice I.

## .the walked product

4 × 6 × 2 × 5 × 2 × 4 × 3 × 3 × 2 = **34560 cells**. most collapse by rule, and each collapse is stated in the inventory with its reason:

- **G collapses to `asked` everywhere the gate admits the ask** — the allowlist changes which asks reach the rack, not what the rack holds. `G=none` renders the extant `absent` and fill hint; `G=other` matters in exactly two cells: `omitted` × keyed.read (the #518 silence, out of scope) and an empty `status --org` narrow (slice G).
- **F collapses** — the actor never changes the verdict, only the reader. walked once (`case=_` §F) and held constant elsewhere.
- **H collapses to `first` off the shared state** — a read under any org touches no shared write; only the writers and the daemon are walked (slice H), once each.
- **C collapses on `omitted`** — no org asked means no slug segment to compare. `C=slug` × `B=omitted` is impossible by nature. `C=slug` × `D=sweep.noorg` is void by the same reason (the C ⟂ D note above).
- **A=`scalar` ≡ A=`list=1`** — a scalar is a one-member list (wish §the shape, 1). walked once as an equivalence proof, then held as `list=n`.
- **A=`malformed`** — refused at parse, before any verb runs; B, C, D never reach it. one row per malformation.
- **D=`sweep.noorg`** — `--org` is refused on these verbs today, independent of the allowlist; walked once.
- **D=`sweep.host`** — the allowlist is never consulted, so B collapses to "the org narrows the host rack"; walked once per B value that differs (slice D.host).
- **I collapses off the printed commands** — the owner never changes a verdict or a slug; only the fix lines and tips that echo it are walked (slice I).

⇒ the core matrix is **B × D** (6 × 3 live arities = 18 cells, `sweep` = `sweep.repo`) under `A=list=n`, `C=flag`, `E=none`, `H=first`, `I=default` — plus the slices that vary C, A, E, F, G, H, I and D.host one at a time.

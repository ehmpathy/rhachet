# 1.vision.experience.case=_ — the inventory

the coverage contract. axes in `1.vision.experience.dimensions.md`. the example manifest throughout:

```yaml
# .agent/keyrack.yml
org:
  - ahbode    # org[0] — the default
  - aether    # a member
env.camp:
  - AWS_PROFILE
```

feel: 🟢 happy · 🔴 sharp. care: **criti** · alter.

every **forbidden** cell is **nurture**: an actor can attempt it, and the behavior refuses it, so it is a checkable rejection invariant. every **impossible** cell is **nature**: no input can reach it.

## .slice H — time: concurrent and retried calls

every manifest writer (`daoKeyrackRepoManifest` set, del, init; `initKeyrackRepoManifest`) holds `withKeyrackManifestWriteLock` — a dir lock beside the file — over its read-edit-write, and writes via `setFileAtomic` (temp + rename). the daemon keys each grant by its full slug.

| cell | verdict |
|---|---|
| two `unlock`s overlap, one `--org ahbode`, one `--org aether` (two grove clones of one repo) | **demoed** case=4 [t5] · 🟢 criti — both grants land and coexist; a slug carries its org, so neither overwrites the other. this is the fleet the wish exists for |
| a fix line run twice (case=8) | itemized · 🟢 alter — `unlock` re-grants the same slug; `set` is findsert and no-ops on a present key (`index.ts:154`). the second run changes naught |
| two writers overlap — two `set`s, a `set` and a `del`, or a `set` and `rhx init --roles` | **tested** `daoKeyrackRepoManifest/index.integration.test.ts` [case6c] · 🟢 alter — the second writer waits on the lock, then reads the first writer's file, so no env key line drops. a lock held past the wait refuses loud, file untouched. no writer edits `org`; each copies it through as read, so the list order holds (case=3's order clamp) |
| a human edits `org:` while a writer runs | itemized · 🔴 alter — a hand edit takes no lock, so a writer that read before the edit can write back the old `org`, and a member the human just added is lost. loud on the next ask (`--org aether` is refused as a nonmember) and visible in `git diff`; never a silent repoint of a read that worked a moment before |
| a read overlaps a write | **tested** `src/infra/setFileAtomic.integration.test.ts` · 🟢 alter — the write is temp + rename, so a read sees the whole prior file or the whole next one, never a torn one |

the one 🔴 alter row left is a hand edit, which no lock can cover; it fails loud on the next ask.

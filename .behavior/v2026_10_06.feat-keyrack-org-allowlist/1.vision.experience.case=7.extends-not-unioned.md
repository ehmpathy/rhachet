# case=7 — an extended manifest's org does not join the list 🔴 criti

**cell** — E=`foreign` · B=`nonmember` (an org only an extended manifest declares)

## .narrative

`dev-env-setup` lists `[ahbode, aether]` and extends three role manifests that each say
`org: ehmpathy`. vlad sees `org: ehmpathy` in one of them and tries his luck in the repo:

```sh
rhx keyrack get --owner ehmpath --org ehmpathy --env prep --key XAI_API_KEY
✋ ConstraintError: --org 'ehmpathy' is not on this manifest's org allowlist
   └─ hint: use one of 'ahbode', 'aether'; or add 'ehmpathy' to org: in .agent/keyrack.yml; or, for a key that belongs to no org, pass --org @all
```

the refusal names only the root's two orgs, which tells him the extended line did not count. those
role manifests declare WHICH keys a role needs, not whose. root-org inheritance already re-slugs
their keys under the root, so a bare `get --env prep --key XAI_API_KEY` hands him
`ahbode.prep.XAI_API_KEY`: ahbode pays its own invoices. if the repo truly needs ehmpathy, vlad
writes `ehmpathy` into the root `org:`, as a visible, reviewed line, never an inherited one.

## .[tn]

```ts
given('[case7] vlad, in a repo whose root org [ahbode, aether] extends a manifest with org: ehmpathy', () => {
  when('[t0] vlad runs get --org ehmpathy --env prep --key XAI_API_KEY', () => {
    then('exit 2; the refusal lists ahbode, aether — ehmpathy is absent, so the extended org did not join', ...);
  });
  when('[t1] get --env prep --key XAI_API_KEY (no --org)', () => {
    then('reads ahbode.prep.XAI_API_KEY — the extended key, re-slugged to org[0]', ...);
  });
  when('[t2] get --org aether --env prep --key XAI_API_KEY', () => {
    then('reads aether.prep.XAI_API_KEY — an extended key is reachable under every root member', ...);
  });
});
```

## .why criti

the wish leans toward a union (§the shape, 4: "presumably UNION"). this case pins the opposite,
because a union would silently admit `ehmpathy` into every repo that extends an ehmpathy role —
the cross-org leak `define.root-org-inheritance` exists to prevent. this is fulcrum F1.

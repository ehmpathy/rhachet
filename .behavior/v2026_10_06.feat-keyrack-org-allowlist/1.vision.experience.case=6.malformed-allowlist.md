# case=6 — a malformed allowlist fails at parse 🔴 criti

**cell** — A=`malformed` (empty, duplicate, sigil member)

**care, per cell** — the file is criti because two of its cells are: `org: []` (`[t1]`) and a sigil
member (`[t3]`). the duplicate (`[t2]`) is alter, and rides along here because it shares the parse
refusal. the per-cell verdicts match the inventory (`case=_` §slice A).

## .narrative

vlad adds aether to `dev-env-setup` by hand, late, between two other tasks. he types three
manifests over a week, and each one is wrong in a different way. each time, his very next keyrack
call refuses at parse with the line to fix. keyrack never collapses the typo and never guesses
around it:

- he deletes `ahbode` to retype it and forgets to finish: `org: []`. `rhx keyrack get --env camp
  --key AWS_PROFILE` stops before any prompt: the list names no org, so there is no default for
  `@this` to mean.
- he means to type `aether` and pastes the line twice: `org: [ahbode, ahbode]`. keyrack refuses
  and names the repeat. if it deduped the list, the org he meant would vanish with no trace.
- he reads `--org @all` in a hint and writes it into the list: `org: [ahbode, '@all']`. keyrack
  refuses: `@all` means "belongs to no org", so it cannot be a member, and the hint says to pass
  it at ask time instead. `@this` is refused the same way, because it means "this list".

## .[tn]

```ts
given('[case6] vlad hand-authors a malformed org: line', () => {
  when('[t1] org: [] — criti', () => {
    then('exit 2: `keyrack manifest org: lists no org`, hint names the file + a scalar example', ...);
  });
  when('[t2] org: [ahbode, ahbode] — alter', () => {
    then("exit 2: `org 'ahbode' is listed more than once`", ...);
  });
  when('[t3] org: [ahbode, @all] — criti', () => {
    then("exit 2: `'@all' cannot be an org: member — it names no org`, hint: pass --org @all at ask time", ...);
  });
  when('[t4] any verb, any of the above', () => {
    then('the refusal fires before any vault, daemon, or passphrase prompt', ...);
  });
});
```

## .why criti

a list that admits `@all` would let one manifest line waive the org boundary for every ask, and
an empty list leaves `@this` with naught to name. the parse refusal is the only enforcement point
for both. the duplicate is alter: it cannot leak an org, it can only hide the one vlad meant.

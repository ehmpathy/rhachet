## .one call that differs from the vision, and why

the vision said `AGENTS.md` would stop its `@boot.md` import in every actor dir. the build keeps the brain
dir layout and turns the door off at the clone (`CLAUDE_CODE_DISABLE_CLAUDE_MDS=1`). a clone reads only
user-source memory, so the switch drops the boot's second copy and no other file. any reader outside a
clone still finds `CLAUDE.md → AGENTS.md → @boot.md`.

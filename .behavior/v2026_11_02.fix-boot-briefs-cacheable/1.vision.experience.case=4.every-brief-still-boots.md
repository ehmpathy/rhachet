# 1.vision.experience.case=4.every-brief-still-boots

> cell `* × drop.brief` · actor maintainer · feel sharp · care critipath

## .narrative

the cheapest way to shrink a cache-write figure is to boot less. the wish forbids it: the gain is cache,
never deletion. a maintainer who moves the boot, reorders it, or changes how the brain-cli reaches it must
not lose one `say` brief, one `ref` path, one readme, or one skill header.

the extant `setBrainDirBoot` snapshot already holds the full corpus. the clamp: the set of
`<brief.say path>`, `<brief.ref path>`, `<skill.*>` and `<readme>` entries after the change equals the
set before, and the brief bodies are byte-equal. a reorder is allowed (case 5); a loss is red.

## .[tn] sketch

```
given a fixture role set
  [t0] the boot renders through today's door; its entry set and say bodies are recorded
  [t1] the door moves to the system prompt; the boot renders again
    then every entry path from [t0] is present
    then every say body is byte-equal to [t0]
    then the boot reaches the brain once, never through both doors
  [t2] a maintainer's change drops one brief from the render
    then the clamp fails and names the absent path
  [t3] the brief is restored
    then the clamp is green
```

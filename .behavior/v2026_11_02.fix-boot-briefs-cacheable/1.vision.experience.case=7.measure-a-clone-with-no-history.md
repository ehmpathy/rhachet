# 1.vision.experience.case=7.measure-a-clone-with-no-history

> observer row `measure.no-history` (a clone with no transcript) · actor driver · feel sharp · care alterpath

## .narrative

found this round, not imagined: three `-p` probe clones left no clone dir or history under their actor,
while the two interactive probes did. a driver who points the measure at such a clone, or at a typo'd
path, must not get an empty table that reads as "zero usage" — that would be a false before/after.

the skill fails loud, exit 2, and names the fix: for a one-shot `-p` run, read `.usage` from its own
`--output-format json`. a typo'd dir names the glob that lists the real ones.

measured: both paths run this round (`--clone .agent/.actors/actor.via.hash=2e77f741` → no history;
`--clone .agent/.actors/absent` → not found), each exit 2 with its fix.

## .[tn] sketch

```
given a driver with a before figure to take
  [t0] the driver enrolls a `-p` clone; it answers and exits, and its history/ holds no .jsonl
  [t1] the driver runs `rhx clone.cache.usage --clone <dir>`
    then it exits 2
    then stderr says the clone holds no history transcript
    then stderr names `rhx enroll claude -p '<prompt>' --output-format json` as the way to read usage
    then no empty table is printed that could read as zero usage
  [t2] the driver mistypes the path and runs it again
    then it exits 2 and names the glob that lists clone dirs
  [t3] the driver re-runs with `--output-format json` per the hint
    then `.usage` holds the figure the measure needed
```

🟡 why `-p` clones keep no history is not yet known; the vision records it, the blueprint may ask whether a
`-p` clone should keep one. the skill's message stays true either way.

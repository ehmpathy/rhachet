# case 1 — a fresh cloud tree boots a crew (happy × criti)

## .narrative

i am the commander. i open a fresh rhachet tree on the cloud grove, where `~/.claude/settings.json` is
the box's and i may not write it. `pnpm install` runs the prepare. each role links and inits; the
mechanic init writes its allows into `.claude/settings.of.repo.json` by name and leaves the grove file
alone. the hook sync writes the hooks of the roles that linked. i run `rhx enroll claude --as
@:mechanic`, and a clone bakes. i never touched a settings file.

## .timeline

```
given('[case1] a fresh tree whose grove settings file is read-only (0444)')
  when('[t0] rhx init --hooks --roles mechanic behaver driver')
    then('exit 0')
    then('the mechanic allows sit in settings.of.repo.json')
    then('settings.json is still the arrow to settings.of.grove.json')
    then('the grove file is byte-equal and still 0444')
  when('[t1] rhx enroll claude --as @:mechanic')
    then('a clone bakes; no refusal on hooks')
```

## .what makes it so

the `rhachet-roles-ehmpathy` pin at `>= 1.39.5` (vision cause 1). before it, [t0] dies on the
same-second backup collision.

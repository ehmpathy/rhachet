# case 4 — a `.claude` link that aims elsewhere refuses before any role writes, and names both ends (sharp × criti)

## .narrative

i am a director. my tree's `<repo>/.claude` is a link, and init refuses it. today two things go
wrong. the refusal shows the link text and the wanted text, but not where each lands — so a link
through another hop, or into another worktree, reads as identical to the wanted one and i cannot see
why it was refused. and the refusal comes late: the layout step defers it, the role inits run and
write through `.claude` into the place the link aims at, and only the boot sync reports it.

after: the preflight — the same gate as the case 2 write probe — checks the link before any role
links. it refuses at once, and prints the realpath it found and the realpath it wanted. no role init
has run, so no write went through the link. i see that the link lands in the main checkout, not this
tree, and i know what to remove.

## .timeline

```
given('[case4] <repo>/.claude is a link whose realpath is outside the repo actor brain dir')
  when('[t0] rhx init --roles tester')
    then('the preflight refuses: ✋ ConstraintError: <repo>/.claude is a symlink to another place, exit 2')
    then('the error names found + wanted link text, and found + wanted realpath')
    then('no role was linked and no role init ran; the place the link aims at is byte-for-byte as before')
    then('the link itself is left as found — init never rewrites a link that aims elsewhere')
  when('[t1] the director removes the link and reruns rhx init --roles tester')
    then('the link is created relative; init completes')
```

🟡 [t0]'s "before any role" is fulcrum F6 (open question 9). the alternative is today's path: the
refusal is deferred to the boot sync and the role inits run first. under that alternative [t0]'s first
and third `then` change to "reported at the boot sync, after the role inits wrote through the link".

## .fail-safe

- **fast** — refused in the preflight, before any role links or writes (F6)
- **loud** — exit 2, a classed `ConstraintError`
- **teaches** — both realpaths named, so the director sees where the link lands and what to remove

the refusal itself stays for a link that truly aims elsewhere (the wish).

# case 7 — a global rhx that differs from the pin is named (sharp × alter)

## .narrative

i am any actor. my `PATH` holds a global `rhx` at `1.50.1`, and the tree pins another version. the
tree's own steps — `prepare:rhachet` and this repo's hooks — call `node_modules/.bin`, so they run the
pin. a bare `rhx` that i or a peer tree's hook types runs the global, and its output gives no sign
which one ran.

after: a step that can tell names the skew, so a fault under the global is not read as a fault of the
pin. this pr does not refuse the global — that is the commander's call (fulcrum F3, open question 3).

## .timeline

```
given('[case7] a global rhx whose version differs from the tree pin')
  when('[t0] the human runs bare rhx init in the tree')
    then('the output names the rhx version that ran and the tree pin, as a note')
    then('init proceeds; no refusal (until F3 rules otherwise)')
  when('[t1] the tree runs pnpm install')
    then('prepare:rhachet runs the pin from node_modules/.bin; no skew to name')
```

## .fail-safe

named, never silent; no behavior change rides on it until the commander rules. the exact place the
note renders is a blueprint call.

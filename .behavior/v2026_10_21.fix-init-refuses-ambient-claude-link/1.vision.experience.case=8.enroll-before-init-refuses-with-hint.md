# case 8 — enroll before any init refuses, with the init hint (sharp × alter)

## .narrative

i am a commander. i clone a fresh tree and run `rhx enroll claude` before `pnpm install`. no role is
linked yet, but the tracked `settings.of.repo.json` already holds hooks for driver, behaver, learner,
dispatcher and mechanic. enroll refuses, and it tells me to run `rhx init --hooks`. i run the install;
init links the roles and syncs the hooks; enroll then passes.

this is extant and kept: it is the runtime guard of inventory case=9. this pr does not change it; the
demo exists so the catalog shows case 3's prune does not weaken it.

## .timeline

```
given('[case8] a fresh clone; no role linked; the tracked settings carry hooks of five roles')
  when('[t0] rhx enroll claude')
    then('refuses: a clone would load hooks from roles it is not enrolled in')
    then('the hint names rhx init --hooks')
  when('[t1] pnpm install, then rhx enroll claude')
    then('init links every role and syncs hooks to them; enroll bakes a clone')
```

## .fail-safe

fast (before a brain spawns), loud, teaches (names the init command).

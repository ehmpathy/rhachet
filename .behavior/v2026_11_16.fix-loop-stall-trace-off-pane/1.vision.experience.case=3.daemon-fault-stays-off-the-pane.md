# experience case=3: a daemon fault fires in an attended pane, and stays off the pane

feel × care = happy × critipath. the wish says "no daemon trace line", not only the stall.

## .narrative — the human's pov

a human works in an attended clone. a peer's malformed frame trips a socket fault in the daemon,
or the screen feed meets an ansi sequence its emulator throws on. before, the fault's trace line
painted into the pane mid-render. now the pane is undisturbed. the fault is in the trace log; if it
cost a `say` its delivery, the caller of that `say` gets the NACK or wedge verdict with its cause.

## .bdd sketch

```
given('[case3] an attended pty host, its screen feed and socket server built with the daemon sink')
  when('[t0] the screen feed retains a parse fault')
    then('the fault line lands in the trace log')
    then('the host stderr receives zero bytes')
  when('[t1] the socket server emits a server error after ready')
    then('the fault line lands in the trace log')
    then('the host stderr receives zero bytes')
  when('[t2] the write queue traces a write fault')
    then('the fault line lands in the trace log, not stderr')
```

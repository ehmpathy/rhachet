# experience inventory: daemon trace lines vs the pane

cells from `1.vision.experience.dimensions.md` (# = its row number). every cell carries exactly one
verdict: demoed · itemized · forbidden · impossible.

## .how care is graded

one basis for every cell: **care = what an actor loses if the cell goes wrong.**

- on an **attended** host, any traced line that goes wrong paints a pane — the hazard the wish
  exists to remove — so every attended traced cell with a real line class is critipath
- on a **detached** host, no pane exists, so the only loss is a diagnostic the log-reader cannot
  read. that is critipath only for the stall line, the read the wish names ("the stall line still
  lands in the trace log, with its drift"); for liveness and fault it is alterpath
- liveness is alterpath on both hosts: it is already log-only today and this behavior does not move it

⇒ where an attended cell and its detached twin differ in care, it is this basis, not a second model.

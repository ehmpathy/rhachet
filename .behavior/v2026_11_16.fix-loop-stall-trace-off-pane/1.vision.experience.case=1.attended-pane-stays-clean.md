# experience case=1: a stall fires in an attended pane, and the pane stays clean

feel × care = happy × critipath. crosses the most boundaries of any case: event loop → lag watch →
daemon sink → (not) the tty → the trace log.

## .narrative — the commander's pov

the commander scans the grove's tmux panes. the box is loaded; the gads mechanic's daemon starves
for 2.5s. before, its pane would show `clone daemon event loop stalled 2497ms` across claude's
input row, and the commander would stop to ask: did the clone type that? is it queued? now the pane
shows claude's screen and only that. the commander moves on. the stall is in the log, if anyone
asks.

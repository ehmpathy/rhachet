# experience case=2: an operator reads the trace log and parts starvation from self-block

feel × care = happy × critipath. the reader the line exists for.

## .narrative — the operator's pov

a `clone say` to the gads mechanic wedged for 30s. the operator opens
`.agent/.cache/repo=rhachet/skill=clone-say/daemon.2026-11-16.log` in that clone's repo and finds,
at the wedge's time:

```
<iso> pid=<n> clone=@:e8ced08b clone daemon event loop stalled 2497ms (cpu 38ms, loop active 2480ms)
```

`loop active` is the tell. it counts the span the loop spent in a callback, so it says whether the
daemon held its own loop:

- **loop active near the drift** — the daemon held its own loop. its cpu then says how:
  - cpu near the drift → it burnt the span in its own sync work
  - cpu far below the drift → it sat in a blocked sync call, such as a tty write to a pane that
    does not drain (the mirror stall this behavior cured)
  - either way, a defect for the daemon, not the box
- **loop active far below the drift** — the loop was idle, never called; the box starved it (load,
  or a stopped process). the operator looks at box load

the line above reads loop active near the drift with cpu far below: a blocked sync call, the
daemon's own.

## .bdd sketch

```
given('[case2] an operator who opens a daemon day log after a deaf spell')
  when('[t0] the daemon held its own loop on-cpu (sync work) at that time')
    then('the operator reads one stall line whose cpu and loop active sit close to its drift')
    then('so they conclude the daemon ran its own sync work — a daemon defect')
  when('[t1a] the daemon held its own loop off-cpu (a blocked sync call) at that time')
    then('the operator reads one stall line whose loop active sits close to its drift, its cpu far below')
    then('so they conclude the daemon sat in a blocked sync call — a daemon defect, not box load')
  when('[t1b] the host starved the loop (load, or a stopped process) at that time')
    then('the operator reads one stall line whose cpu and loop active both sit far below its drift')
    then('so they conclude the loop was idle and the box starved it — they look at box load')
  when('[t2] the operator greps the day log for "event loop stalled"')
    then('they see each stall as one line, with drift, cpu, and loop active, in time order')
```

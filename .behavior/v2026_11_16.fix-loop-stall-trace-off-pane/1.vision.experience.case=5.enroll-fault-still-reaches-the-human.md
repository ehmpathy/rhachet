# experience case=5: an enroll fault before stand-up still reaches the human

feel × care = sharp × critipath. the over-cure this behavior must not commit.

## .narrative — the human's pov

a human types `claude` (aliased to `rhx enroll claude`). the socket path's parent dir is absent, so
the bind fails. or the host refuses a pty device. neither is a trace — each is the enroll's
failure, and the human must see it with its fix named. each still prints on the terminal as a
qualified error with a hint, exactly as today: the bind fault is rethrown after the child is killed
(`genBrainCliPtyClone.ts:223-226`); the pty refusal is re-reported by `genCloneOndisk` with
`--no-socket` named (`genBrainCliPtyClone.ts:75-86`); `withCliOutputErrors` renders both. the
log-only rule covers what the daemon traces, never what the enroll throws.

the bind fault leaves one trace line too, `clone socket ready rejected with a bind fault`, written
as the daemon gives up. it is a traced fault, so it goes where every fault line goes: the repo's
trace log (or the fallback, if that log is unwritable), never the screen. the human reads one
framed report; an operator who reads the log later finds the same fault, named.

## .bdd sketch

```
given('[case5] an attended enroll that will fault before the daemon serves')
  when('[t0] the socket bind faults')
    then('the enroll exits non-zero')
    then('stderr holds the qualified error header and its hint')
    then('no "clone trace" or "clone daemon" trace line appears on stderr')
    then('the "ready rejected" trace line lands in the repo trace log, named as a bind fault')
  when('[t1] the host refuses a pty device')
    then('the enroll exits non-zero')
    then('stderr holds the qualified error header, with --no-socket named as the fix')
    then('no "clone trace" or "clone daemon" trace line appears on stderr')
```

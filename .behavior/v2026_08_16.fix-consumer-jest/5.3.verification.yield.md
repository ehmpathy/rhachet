### zero skips verified

- note: this change REMOVED a silent skip. `sshPrikeyToAgeIdentity`'s passphrase-protected path
  shells out to the `age` system binary; the test formerly did `console.log('test skipped'); return`
  when `age` was absent — a `rule.forbid.failhide` (a silent pass without verification). this change
  replaces it with a fail-loud `throw new ConstraintError('age CLI required ...', { hint })`
  (`rule.require.failfast`: an absent required binary is a caller-fixable setup constraint, not a
  reason to pass). because the test now hard-requires `age` and crosses real fs + CLI boundaries, it
  was renamed `sshPrikeyToAgeIdentity.cli.test.ts` → `sshPrikeyToAgeIdentity.integration.test.ts`
  (`rule.forbid.unit.remote-boundaries`: fs/process-i/o tests belong in the integration tier, which
  provides the `age` binary and keeps the fast/deterministic unit tier green on boxes without it).

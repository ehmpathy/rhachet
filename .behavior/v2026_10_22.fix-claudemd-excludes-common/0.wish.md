# wish: claudeMdExcludes without per-machine paths

## .the defect

when rhachet enrolls a clone, it writes `claudeMdExcludes` into the committed claude settings with one absolute home path per machine. a committed settings file today reads:

```json
"claudeMdExcludes": [ "/home/camper/.claude/CLAUDE.md", "/home/vlad/.claude/CLAUDE.md", "**/CLAUDE.local.md" ]
```

each machine that enrolls adds its own path, so the committed file grows one entry per machine and leaks each machine's username into git.

## .the outcome

1. rhachet writes ONE common, machine-agnostic pattern that excludes the home `~/.claude/CLAUDE.md` on any machine. no absolute path that names one machine.
   - first prove what claude code's `claudeMdExcludes` actually matches against (an absolute path? does `~` expand? does a `**` glob reach outside the repo?). a pattern that does not exclude on a real machine is no fix. record the proof.
2. the extant per-machine entries are cleaned on the next enroll: an absolute home-path CLAUDE.md entry that rhachet itself wrote is removed, and the common pattern kept. idempotent: a second enroll changes naught.
3. a rule — a brief plus a check that fails loud — that forbids a committable config flag that names one machine (a home dir, a hostname, a username). the check runs where it bites: on what rhachet writes into committed config, so a regression fails a test, not a review.

## .bounds

- one PR in ehmpathy/rhachet, `--watch` to CI green. no merge and no release until the commander approves; on his approval, the driver runs `rhx git.release --into prod --apply --watch` and reports the npm version.
- clamp every fix: a test red without the fix, green with it.
- no footer, no Co-Authored-By trailer in the PR body or commits.
- best-guess any fulcrum and itemize it; never halt.

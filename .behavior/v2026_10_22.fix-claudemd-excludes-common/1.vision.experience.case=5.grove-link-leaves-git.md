# 1.vision.experience.case=5 — the grove link leaves git

seam G · cell `tracked × any` · happy × critipath

## .narrative

a repo upgraded to an rhachet from before this fix still tracks
`.agent/.actors/actor.via.repo=ambient/brain/.claude/settings.of.grove.json`, a link whose target
is `/home/camper/.claude/settings.json` — camper's username, in git. vlad pulls, and his box
relinks it to `/home/<user>/…`, so the link churns in every diff.

vlad runs `rhx upgrade`. the brain dir allowlist drops the grove re-include, and the sync removes
the link from git's index; the file stays on disk, now ignored. the upgrade's `🧠` tree names the
untracked link, so he commits its deletion on purpose. his next pr shows one deleted link. from
then on no box's home rides into git, and no diff carries a grove line.

camper pulls that pr. his box had relinked the tracked link to his own home, so git refuses the
pull: it would overwrite a local change. the pr body names the cure — `git checkout -- <link>`,
then pull. the link leaves his tree; his next `rhx init` relinks it, now ignored, and his
`git status` stays clean.

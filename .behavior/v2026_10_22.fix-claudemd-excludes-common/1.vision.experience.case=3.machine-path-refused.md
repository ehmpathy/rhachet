# case=3 — a machine name in committed config turns a test red (sharp, forbidden cell)

## narrative — the mechanic's walk

months later, a mechanic tidies `getClaudeMdExcludesList` and, to be "precise", writes back
`join(home, '.claude', 'CLAUDE.md')`. they run the integration tests before they push. one goes red; its
diff shows `/home/fixturehuman/.claude/CLAUDE.md` and its title names
`rule.forbid.machine-names-in-committed-config`. they read the rule, restore the glob, and the
leak never reaches a pr. another day a different mechanic adds a hook that bakes in `os.hostname()`
— the same test catches the host. no human's `claude` launch is ever blocked: the check lives in
the test, never in the writer.

## timeline

```
[t0] given  the machine is faked: HOME=/home/fixturehuman, user=fixturehuman, host=fixturehost
[t1] when   the repo actor's settings.of.repo.json is written by genBrainCliConfigArtifact
[t2] then   getAllMachineNamesInConfig(file, machine) is empty          ← the green path today

[t3] given  a regression: getClaudeMdExcludesList returns `${home}/.claude/CLAUDE.md`
[t4] then   the scan finds `/home/fixturehuman/.claude/CLAUDE.md` (home dir) → the test is red

[t5] given  config that holds the host in a host position, e.g. "ssh fixturehuman@fixturehost"
[t6] then   the scan finds `fixturehost` (after `@` or `//`, or a qualified name's left label) → red

[t7] given  config that holds `/Users/fixturehuman/notes` (user as a path segment, a home not this box's)
[t8] then   the scan finds it (username segment, and the /Users/<x>/ shape) → red

[t9] given  config that holds `/home/camper/.claude/CLAUDE.md` (another machine's home)
[t10] then  the shape scan finds `/home/camper/` → red

[t11] given this repo's own committed settings.of.repo.json, as checked in
[t12] then  the shape scan finds no `/home/<x>/` and no `/Users/<x>/`
```

fails safe: fast (the scan helper at unit grain; the writer and repo checks at integration grain,
which a mechanic runs before a push and ci runs on every push), loud (red, the offender in the
diff), teaches the fix
(the rule names the machine-agnostic glob). a refusal at write was weighed and rejected: were it
ever wrong, it would block every `claude` launch on every box (fulcrum F3).

# 5.1 execution — from vision

## .the upstream contract

test-fns **1.17.0** (autoprune since 1.16.0, ehmpathy/test-fns#67) provides:

| piece | contract |
|---|---|
| the run id | `globalSetup: 'test-fns/autoprune.setup.jest'` mints it before the workers fork |
| the reclaim | `globalTeardown: 'test-fns/autoprune.teardown.jest'` removes every dir this run stamped |
| the stamp | a run slot of its own in each dir name: `{timestamp}.{run}.{slug}.{8hex}` |
| the hold | `TEST_FNS_KEEP=1` keeps a run's dirs, and says where |
| the backstop | a 24h age gate, `TEST_FNS_MAX_AGE_MS` to widen it |
| the root | `getOneTempDirRoot()` → `{ pathPhysical, pathSymlink }` |

main pins 1.17.0 and wires the setup + teardown into all three jest configs (integration and
acceptance through a composed `./jest.*.globalSetup.ts` that also sources keyrack). this behavior
owns what that wire-up alone leaves open: the call sites, the signal path, the rule, and the clamps.

## .open — for the wisher

1. **the clamp removes no dir of its own** (fulcrum F002). two clamp cases leak on purpose: the
   hooks-removed control's dirs carry the clamp run's own stamp, so its teardown reclaims them; the
   `TEST_FNS_KEEP` hold is released to test-fns' own teardown. `rule.forbid.reads-outside-the-repo`'s
   exception stays a count, as granted.
2. **socket runtime dirs** stay hand-rolled (path-length cap), marked and self-removed.
3. **residue bound.** SIGKILL / an OOM kill / a host crash run no handler; those dirs fall to the
   24h age gate (the rule's `.known bound`).

### del — now really destroys the SSM param (post-cut, wisher-directed)

the cut replaced the no-op del + residual-warn with a REAL delete via a computed param name:

- `delKeyrackAwsParam({ slug, owner, region })` computes the managed name via
  `asKeyrackAwsParamName` (the SAME template `set` wrote to) and calls declastruct's
  idempotent, type-guarded `delSsmParameterSecure` (no-op if absent; refuses a non-SecureString).
- mech-gated in `vaultAdapterAwsParams.del`: an owned (`EPHEMERAL_VIA_GITHUB_APP`) key destroys
  the blob keyrack wrote; a `PERMANENT_VIA_REFERENCE` key is a creds-free no-op (keyrack wrote
  no value — the param is operator-owned out-of-band).
- because del targets the COMPUTED name only, a foreign explicit `--exid` param is NEVER
  touched (it derives a different name) — proven by the integration [case2].
- proof: `delKeyrackAwsParam.integration.test.ts` (3/3 real-SSM) + `vaultAdapterAwsParams.test.ts`
  (reference-mech no-op clamp, creds-free, 1/1 unit).

## a session note — the fillKeyrackKeys regression this PR introduced, then fixed

the PR's earlier phase added a no-TTY guard to the SHARED `inferKeyrackMechForSet` (c40:
unattended `set` must not hang on a mech prompt). that guard `throw`s when `!process.stdin.isTTY`
BEFORE the mech prompt — which broke `fillKeyrackKeys.integration.test.ts` (unchanged from
main), because that test mocks `promptLineInput` to inject mech answers, and the guard fired
ahead of the mock in the non-TTY runner (5 cases red).

FIX (this session): the shared mock factory `genMockPromptLineInput()` now sets
`process.stdin.isTTY = true` — a file that mocks the line prompt stands in for an interactive
human who answers it, so it must present an answerable terminal. this is the sole consumer of
that mock (grep-verified: only `fillKeyrackKeys.integration.test.ts`), and it went 5-red → all
green. the real acceptance no-TTY guard (c40) is unaffected — it runs a real subprocess with
stdin from `/dev/null`, never mocks the prompt, so isTTY stays false and the guard fires as
designed.

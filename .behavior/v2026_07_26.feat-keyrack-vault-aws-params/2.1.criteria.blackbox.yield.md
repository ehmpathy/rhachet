# blackbox criteria — keyrack `aws.params` vault (set → unlock → get)

> experience boundaries only: the observable `rhx keyrack` surface — inputs a human types,
> outputs they see, errors surfaced. NO mechanism (declastruct, daemon internals, AWS SDK)
> and NO build detail. those live in the blueprint.
>
> the vault kind `aws.params`, the flags (`--vault --mech --exid --owner --env --org
> --max-duration`), the mech names, the autocompute path, and each error message ARE
> observable, so they belong here.

---

# usecase.1 = register a reference key — path autocomputed, mech chosen by prompt

given('a keyrack for org=ehmpathy, and an SSM SecureString placed out-of-band')
  when('the human runs `keyrack set --key ANTHROPIC_API_KEY --vault aws.params --owner mechanic --env prod --org ehmpathy` with no --mech and no --exid')
    then('keyrack asks "which mechanism?" and lists the two aws.params options with plain descriptions')
      sothat('the human recognizes the choice instead of a recall of mech names')
    then('after the human picks the reference option, keyrack registers the key and echoes the computed path /keyrack/infra/vault/aws.params/mechanic/ehmpathy/prod/ANTHROPIC_API_KEY')
      sothat('the human sees exactly where the value is referenced, with no path typed')
    then('keyrack writes no secret value for a reference key')
      sothat('a reference points at a value placed out-of-band, never re-stored by keyrack')

# usecase.2 = register a reference key — explicit --exid overrides the convention

given('a keyrack for org=ehmpathy, and a param that lives at a foreign path')
  when('the human runs `keyrack set ... --vault aws.params --exid /legacy/anthropic/token`')
    then('keyrack registers the key against /legacy/anthropic/token, not the computed path')
      sothat('a prior/foreign param is usable without a rename')

# usecase.3 = persist a github-app key — keyrack writes the credential into the vault

given('a keyrack for org=ehmpathy and a present, authorized AWS identity')
  when('the human runs `keyrack set --key EHMPATHY_SEATURTLE_GITHUB_TOKEN --vault aws.params --mech EPHEMERAL_VIA_GITHUB_APP --owner mechanic --env prod --org ehmpathy`')
    then('keyrack guides the human through the github-app credential input')
      sothat('the human supplies the app credential once, at set time')
    then('keyrack persists the credential into the vault at the computed path and confirms success')
      sothat('the credential lives in the vault, exactly as os.secure persists it locally')
    then('the credential value is never echoed back in any later read or list')
      sothat('a write-once secret cannot leak through a subsequent read')

# usecase.4 = --mech is explicit — no prompt

given('the human already knows the mechanism')
  when('the human passes --mech PERMANENT_VIA_REFERENCE (or EPHEMERAL_VIA_GITHUB_APP) on set')
    then('keyrack does NOT prompt, and uses the named mechanism')
      sothat('an expert or a script is not blocked on an interactive question')
  when('the human passes an --mech the aws.params vault does not support')
    then('keyrack rejects it and names the supported mechanisms')
      sothat('a wrong mechanism fails at set, not silently later')

# usecase.5 = unlock then get a reference key — frictionless on a machine with an identity

given('a registered aws.params reference key and a present, authorized AWS identity (a grove\'s instance role, or a laptop SSO/profile)')
  when('the human or box runs `keyrack unlock --env prod`')
    then('unlock succeeds with NO human prompt')
      sothat('an unattended box unlocks by its own identity — the identity is the unlock')
  when('the box then runs `keyrack get --key ANTHROPIC_API_KEY --env prod --value`')
    then('the decrypted secret value is returned')
      sothat('the box obtains its credential with no secret ever placed on it')
    then('the output matches the shape every other keyrack grant returns')
      sothat('callers and shell `keyrack source` treat aws.params like any other vault')

# usecase.6 = unlock then get a github-app key — a short-lived token, not the master key

given('a registered aws.params github-app key and a present, authorized AWS identity')
  when('the box runs `keyrack unlock --env prod` then `keyrack get --key EHMPATHY_SEATURTLE_GITHUB_TOKEN --value`')
    then('a short-lived (~1h) installation token is returned, never the app master key')
      sothat('a compromised box yields only a ~1h token, revocable centrally')

# usecase.7 = get before unlock — locked, with the fix

given('a registered aws.params key not unlocked this session')
  when('the human runs `keyrack get --key ANTHROPIC_API_KEY --env prod`')
    then('keyrack reports the key is locked and names the unlock command to run')
      sothat('the human recovers in one step, never a bare failure')

# usecase.8 = --max-duration bounds how long a value stays unlocked

given('a key registered with --max-duration 1h')
  when('the box unlocks, then reads within the window')
    then('the value is served')
  when('the box reads after the window elapses')
    then('the key reads as locked again, and needs a fresh unlock')
      sothat('a fetched secret does not linger past its intended lifetime')

# usecase.9 = the value is rotated in the store between sessions

given('a registered aws.params reference key already unlocked earlier')
  when('the value is rotated in the store, and the box unlocks again after the max-duration window')
    then('the newly rotated value is served')
      sothat('rotation upstream is honored on the next unlock, not stale forever')

# usecase.10 = boundary — no AWS identity present

given('a registered aws.params key on a machine with NO ambient AWS identity')
  when('the human or box runs `keyrack unlock --env prod`')
    then('keyrack fails loud: it states no AWS identity was found and names the fix (SSO login, or attach a role)')
      sothat('the human is never left with a silent empty value or a raw stack trace')

# usecase.11 = boundary — identity present but not authorized

given('a present AWS identity whose grant does not cover the referenced param')
  when('the box unlocks a key whose param the identity may not read')
    then('keyrack surfaces the access denial, names the param and identity, and states the read grant to add')
      sothat('an operator fixes the grant without guesswork')
  when('the identity may read the param but may not decrypt it')
    then('keyrack surfaces a DISTINCT decrypt-denied error and names the decrypt grant to add')
      sothat('the operator fixes the exact gap, not a generic denial')

# usecase.12 = boundary — the referenced param is absent

given('a registered aws.params key whose param does not exist in the store')
  when('the box unlocks the key')
    then('keyrack reports the param is absent and names how to create/place it (or fix the reference)')
      sothat('an absent param reads as a clear, fixable state, not a crash')

# usecase.13 = boundary — the referenced param is not a decryptable secret

given('a registered aws.params key that points at a plaintext (non-secret) param')
  when('the box unlocks the key')
    then('keyrack refuses and states the param must be a decryptable secret')
      sothat('a plaintext value is never mistaken for and emitted as a secret')

# usecase.14 = boundary — the aws capability is not installed on the host

given('a host where the aws-vault capability is not installed')
  when('the human unlocks (or sets) an aws.params key')
    then('keyrack fails loud and names the one command that installs the capability')
      sothat('a user who never uses aws pays zero, and one who does gets a one-step fix')

# usecase.15 = boundary — region cannot be determined

given('a registered aws.params key on a machine with a present identity but no determinable region')
  when('the box unlocks the key')
    then('keyrack fails loud and states where a region must be supplied')
      sothat('the auth-present-but-region-absent gap is named, not a cryptic failure')

## notes on scope of these criteria

- `set` (register + autocompute, and persist for the github-app mech) is the crux — usecases
  1–4 cover it most heavily, per the wisher.
- happy paths: 1, 2, 3, 5, 6, 8, 9. locked/gate: 7. boundaries/errors: 10–15.
- every error criterion names a fix (usecases 7, 10–15) — the surface keeps a human in a pit
  of success on the unhappy path, not only the happy one.
- deliberately absent (mechanism, for the blueprint): how the value is read/written, where it
  is held between unlock and get, which package performs the AWS calls, and the exact grant
  shape internals.

up. the locator still pairs a plain rule with the bottom rule, so the transcript reads as the box:
`withheld` / `input-region-dirty`. this cure does not reach this cell — it widens the predicate to
the one measured label shape, and no further.

it still fails safe where it matters:

- no byte reaches the driver. the say is withheld
- the hint sends the foreman to `rhx clone get --what buffer` first, and that read shows the
  transcript rows (`● …`, `Ran 1 shell command`), not a human's words. so the foreman can see the
  box is mislocated before they reach for `--force`

the honest residual: `--force` here would write over the real box. the hint does not name the
mislocation as a cause. a structural locator (the `❯` row as the anchor, rather than the last rule
pair) would close it; that is a larger change, caught as a dream, not this nano fix.

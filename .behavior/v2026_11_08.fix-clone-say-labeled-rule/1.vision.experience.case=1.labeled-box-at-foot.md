# case=1 — a labeled box at the foot

cell = labeled × none × box · feel = happy · care = critipath

## narrative

the foreman runs a driver clone enrolled as `mechanic`. claude code titles the box:

```
────────────────────────────── mechanic ─
❯
─────────────────────────────────────────
```

the foreman sends `rhx clone say @:driver --what 'status?'`. before, every say came back
`withheld` / `focus-unrecognized`, with a hint to tear the clone down. now the say is `released`,
and the driver answers.

## timeline

```

  when('[t0] the foreman runs `rhx clone say @:driver --what "status?"`')
    then('the foreman sees `released`, exit 0')       // before: withheld / focus-unrecognized, exit 2
```

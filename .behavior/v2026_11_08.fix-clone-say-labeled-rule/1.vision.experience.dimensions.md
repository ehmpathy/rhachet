# experience dimensions — a labeled input-box rule

actor = the **foreman**, a caller of `rhx clone say` / `rhx clone get` against a live clone.

two spaces. the **screen space** is what the foreman meets. the **row space** is the edge set of
the one predicate the cure changes (`isRuleRow`); no actor meets a row alone, so its cells are
itemized and clamped as unit cases, never demoed.

## the screen space

| axis | closed values | why closed | why orthogonal to the rest |
|---|---|---|---|
| **box rule** — the shape of the box's top rule | `plain` · `labeled` (one label, no `─` in it) · `unparsed` (any other shape, e.g. a `─` inside the label) | the three outcomes of `isRuleRow` on that row, before and after the cure: always a rule, a rule only after the cure, never a rule | the rule's shape is set by the brain's title; it does not depend on what sits above the box, nor on the host |
| **rules above** — rows higher on the screen that `isRuleRow` reads as a rule, of any shape (plain, or labeled once the cure lands) | `none` · `one` · `a pair` | `getInputBand` opens the box on the nearest rule above its bottom rule, so a count of 0, 1, or ≥2 rules above is all it can distinguish | the transcript (tool blocks, dividers) sets it, independent of the box title |
| **surface** — what the brain draws at the foot: an input box, or a menu | `box` · `modal` | the two shapes a healthy screen takes; defined by what is DRAWN, never by the focus the classifier returns, so it does not correlate with the box rule | a menu is drawn with an option run and a footer, neither of which carries the box title |
| **host** — the pty | `healthy` · `broken` (0x0 geometry, or a detached host with no tty) | the two measured causes that leave every screen unreadable | set at spawn, before any row renders |
| **box bottom** — the rule that closes the box, and what sits beneath it | `bare` · `labeled` · `bare, a labeled row beneath` (a status line) | only a bare rule closes a box (`getInputBand`), so these three are every case the closer can meet | the bottom rule and the rows under it are drawn apart from the title and the transcript |
| **box content** — what the box holds | `placeholder` (dim) · `human text` (bright) · `queued hint` (dim, a busy brain) | the three contents the classifier parts: `clear`, `dirty`, `clear` + `queued` | set by who typed and whether the brain is mid-turn, never by the rule shapes |

### cells that are impossible or collapse

- `host = broken` × any → **one verdict**: no screen renders, so every other axis is moot. `unrecognized`
- `surface = modal` × `box rule` × `rules above` → **one verdict**: the modal detectors read the option
  run above the band and the footer below the LAST rule; the box title changes neither the last
  rule nor what lies below it. the cure can only move `band.top` down, which widens the option-run
  scan — the safe direction. so all nine (3 box rules × 3 rules above) collapse to `modal`

## the row space — `isRuleRow`, on the trimmed row

| row kind | example | verdict |
|---|---|---|
| a plain rule, ≥20 glyphs | `──────────────────────────` | rule |
| a labeled rule | `────────────────────────────── mechanic ─` | rule (the cure) |
| a short divider, labeled or not | `── note ──` | no rule |
| prose with a `─` | `● a reply ── here` | no rule |
| a rule with two label groups / a `─` in the label | `────────────────────── a ─ b ─` | no rule (fail closed) |
| a ruled transcript header | `──…── Results ──…──` | rule (the band never closes on it) |
| a label with no `─` tail | `────────────────────────────── mechanic` | no rule (fail closed — an unmeasured shape) |
| a blank row | `   ` | no rule |

a labeled row is a rule, but only a bare rule closes a box; the box bottom axis above holds the
consequences.
